1학습 목표

  • FastMCP 인스턴스에 도구·리소스·프롬프트를 등록할 수 있습니다.
  • 등록하지 않은 함수와 @mcp.tool 함수를 발견 결과로 비교할 수 있습니다.
  • 독립 실행 가능한 course_server.py를 stdio 서버로 제공할 수 있습니다.

2이 내용을 배우는 이유

프로토콜 구조를 알아도 서버가 기능을 공개하지 않으면 클라이언트는 아무것도 발견하지 못합니다. FastMCP는 Python 함수의 타입 힌트와 docstring에서 입력 스키마와 설명을 만들고, 장식자(decorator)로 구성 요소 종류를 등록합니다. 이 절에서 만든 서버 파일은 다음 세 절에서 그대로 실행하므로 학생이 복사할 기준 파일이 됩니다.

3앞에서 배운 내용

앞 절에서 list_tools, list_resources, list_prompts와 실제 호출 방법을 확인했습니다. Ch4에서 함수와 타입 힌트를, Ch19에서 @tool 장식자와 입력 스키마를 배웠습니다. FastMCP의 @mcp.tool은 LangChain의 @tool과 이름이 비슷하지만 서로 다른 등록소에 함수를 넣습니다.

4핵심 개념

쉬운 예

게시판에 종이를 붙이지 않으면 방문자는 종이가 있다는 사실을 알 수 없습니다. Python 함수도 FastMCP 인스턴스에 등록해야 MCP 발견 요청에 나타납니다. @mcp.tool은 실행 가능한 기능, @mcp.resource(URI)는 읽을 자료, @mcp.prompt는 재사용 메시지를 등록합니다. 함수 이름은 기본 구성 요소 이름이 되고 docstring은 설명이 됩니다. 인자의 타입 힌트는 JSON Schema 입력 정의를 만듭니다. 서버 파일 마지막의 if __name__ == '__main__' 블록은 파일을 직접 실행할 때 stdio 전송을 시작합니다. 이 블록이 있어야 다른 클라이언트가 파일을 하위 프로세스로 실행할 수 있습니다.

정의와 경계

FastMCP는 MCP 서버와 클라이언트를 Python으로 구현하는 프레임워크입니다. FastMCP 인스턴스는 등록된 구성 요소와 서버 설정을 보관합니다. @mcp.tool이 붙은 함수는 이름, 설명, 입력 스키마와 실행 함수를 가진 도구가 됩니다. @mcp.resource에는 클라이언트가 요청할 URI를 지정하고, @mcp.prompt 함수에는 프롬프트 인자를 타입으로 선언합니다. course_server.py는 외부 API나 사용자 파일을 읽지 않고 모듈 안의 공개 규정 딕셔너리만 반환합니다. 이 제한 덕분에 서버 제작과 프로토콜 호출을 외부 상태 변경 없이 반복할 수 있습니다.

7주의할 점과 실무 메모

  • 도구 docstring은 모델이 어떤 기능을 언제 호출할지 판단하는 자료가 됩니다. 내부 구현 설명보다 입력 범위와 반환 내용을 구체적으로 적습니다.
  • 도구는 읽기 전용으로 만들었습니다. 파일 삭제·메일 발송·결제처럼 되돌리기 어려운 동작에는 승인, 중복 방지, 감사 로그를 추가해야 합니다.
  • stdio 서버에서 일반 print를 표준 출력에 쓰면 프로토콜 메시지를 손상할 수 있습니다. 진단 로그는 표준 오류나 FastMCP 로깅 기능으로 보냅니다.
  • 학생 배포 파일은 course_server.py, 다섯 개 노트북, pyproject.toml, uv.lock입니다. .env와 실행 환경의 비밀 값은 배포 목록에 포함하지 않습니다.

8정리와 다음 절

  • MCP의 발견·전송·모델 호출은 서로 다른 층이므로 각 층의 값을 따로 측정합니다.
  • 서버 기능은 클라이언트가 발견할 수 있어도 인증과 인가를 통과한 범위에서만 실행합니다.
  • 실습 결과는 고정 버전과 로컬 읽기 전용 서버의 범위에서 해석합니다.

다음 학습과 이어지는 지점 — 다음 절에서는 완성한 course_server.py를 실제 하위 프로세스로 실행하고 stdio와 원격 HTTP의 신뢰 경계를 비교합니다.

9복습 문제

문제 1

일반 함수가 list_tools에 나타나지 않는 이유는 무엇인가요?

해설 — FastMCP 인스턴스에 도구로 등록되지 않았기 때문입니다.

문제 2

타입 힌트는 MCP 도구에서 어디에 쓰이나요?

해설 — 클라이언트가 받는 도구 입력 JSON Schema를 만드는 데 쓰입니다.

문제 3

stdio 서버가 표준 출력에 임의 문자열을 쓰면 왜 문제인가요?

해설 — 클라이언트가 JSON-RPC 메시지로 해석해야 할 스트림에 다른 문자열이 섞이기 때문입니다.

문제 4

course_server.py의 기능이 읽기 전용인 이유는 무엇인가요?

해설 — 학습 중 잘못된 호출이 외부 상태를 바꾸지 않도록 실행 위험을 제한하기 위해서입니다.
