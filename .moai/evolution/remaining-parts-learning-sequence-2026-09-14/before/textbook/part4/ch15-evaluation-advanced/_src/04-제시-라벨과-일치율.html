1학습 목표

  • 교육용 제시 라벨과 독립적인 사람 라벨을 구분할 수 있습니다.
  • 정확 일치율과 혼동 행렬을 계산할 수 있습니다.
  • 운영 평가 모델(LLM judge) 적용 전에 필요한 사람 검토 절차를 설명할 수 있습니다.

2이 내용을 배우는 이유

평가 모델이 일관되게 점수를 낸다는 사실만으로 사람의 품질 기준과 맞는다고 말할 수 없습니다. 사람이 먼저 기준표를 읽고 독립적으로 라벨을 붙인 자료가 있어야 일치율을 계산할 수 있습니다. 이 교재에는 기존 인간 라벨이 없으므로, 실습 정답은 작성자가 만든 교육용 제시 라벨로 분명히 표시합니다.

3앞에서 배운 내용

앞 절은 평가 모델 조건을 고정하고 순서 교환을 수행했습니다. 이 절은 같은 판정 결과를 이진 라벨로 바꾸어 비교합니다. 저장된 세 평가 모델 결과는 실제 모델 출력이지만 비교 기준은 교육용 작성자 기준입니다.

4핵심 개념

쉬운 예

답안지를 만든 사람의 예시 점수와 여러 채점자가 독립적으로 매긴 점수는 근거가 다릅니다. 두 자료를 같은 이름으로 부르면 일치율의 의미도 달라집니다. 이 절은 작성자 기준과 사람 수집 라벨을 구분합니다.

정의

정확 일치율은 전체 사례 중 두 라벨이 같은 비율입니다. 양성 일치와 음성 일치를 분리하려면 혼동 행렬을 함께 봅니다. 클래스가 한쪽으로 치우치면 높은 일치율이 나타날 수 있습니다. 실제 운영에서는 여러 검토자가 같은 기준표로 일부 사례를 독립 판정하고, 의견 차이를 조정한 뒤 기준을 고칩니다. LangSmith Annotation Queue는 이 과정을 지원하지만 이 실습에는 클라우드 키가 없어 로컬 JSON으로만 구조를 확인합니다.

도식 읽기

{{svg:04-평가-흐름}}

교재 제시 라벨과 평가 모델 값을 사례 ID로 짝지어 일치율을 계산합니다. 제시 라벨은 사람 수집 라벨과 구분하며, 마지막에는 불일치 사례의 원문을 확인합니다.

5실행 예제

노트북은 여섯 개의 교육용 제시 라벨과 평가 모델 예시 라벨을 비교합니다. 정확 일치율, TP·TN·FP·FN을 직접 계산합니다. 출력의 0.833은 여섯 사례 중 다섯 사례가 같다는 뜻입니다. 이 값은 작성자 기준과 예시 평가 모델의 일치율이며 인간 평가자와의 일치율로 표시하지 않습니다.

{{notebook:04-제시-라벨과-일치율}}

확인할 점 — 비교 사례 6개, 일치율 0.833과 TP 3·TN 2·FP 1·FN 0을 확인하고 인간 평가 결과와 구분합니다.

6실험 결과 해석

교육용 작성자 기준과 예시 평가 모델 라벨 6쌍 가운데 5쌍이 같아 정확 일치율은 0.833이었습니다. 혼동 행렬은 TP 3, TN 2, FP 1, FN 0이었습니다. 이 수치는 독립 검토자가 만든 인간 라벨과의 일치율이 아니므로 운영 평가 모델 적용 근거로 사용할 수 없습니다.

7주의할 점과 실무 메모

  • 작성자 기준 라벨을 사람 다수 검토 결과로 설명하지 않습니다.
  • 사례 여섯 개의 일치율은 운영 임계값을 정하기에 부족합니다.
  • 운영 적용 전에는 실제 도메인 담당자의 독립 라벨과 정기적인 재측정이 필요합니다.

8정리와 다음 절

  • 작성자 기준 라벨과 사람 수집 라벨은 서로 다른 자료입니다.
  • 일치율 0.833과 혼동 행렬을 같은 여섯 사례에서 계산했습니다.
  • 운영 적용에는 도메인 검토자의 독립 라벨이 추가로 필요합니다.

다음 학습과 이어지는 지점 — 다음 절에서는 품질 점수와 함께 원인을 찾을 수 있도록 로컬 실행 추적에 단계별 시간과 사용량을 남깁니다.

일치율과 함께 혼동 행렬을 보는 이유는 무엇인가요?

어떤 종류의 불일치가 많은지와 클래스 쏠림을 확인하기 위해서입니다. 오답 시 다시 볼 곳: 핵심 개념과 실행 예제
