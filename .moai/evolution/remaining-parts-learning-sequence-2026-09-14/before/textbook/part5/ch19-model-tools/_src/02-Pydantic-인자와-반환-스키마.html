1학습 목표

  • Pydantic으로 도구 인자의 범위와 의미를 검증할 수 있습니다.
  • Literal과 Field가 만든 JSON Schema를 읽을 수 있습니다.
  • 허용하지 않은 상태와 범위를 벗어난 개수가 함수 실행 전에 거부되는지 확인할 수 있습니다.

2이 내용을 배우는 이유

모델이 문자열을 만들 수 있다는 사실만으로 업무 입력이 안전해지지는 않습니다. 상태 이름의 허용 목록과 반환 개수 범위를 코드로 정하면 잘못된 요청을 데이터 조회 전에 멈출 수 있습니다.

Ch 20에서 ToolNode로 실행 흐름을 조립하기 전에 도구 한 개가 어떤 정보와 결과를 주고받는지 확인합니다.

4핵심 개념

비유로 먼저 이해하기

도구 설명서는 주문서와 비슷합니다. 모델은 함수 내부를 보지 않고 이름, 설명, 선택 항목을 보고 요청합니다.

정의

인자 스키마는 모델이 채워야 할 입력 칸과 각 칸의 조건을 정의합니다. Field의 설명과 최솟값·최댓값은 JSON Schema로 변환되어 모델과 실행기 사이의 공통 형식이 됩니다.

Literal은 선택 가능한 문자열을 JSON Schema의 enum으로 나타냅니다. 모델은 paid, pending, cancelled라는 후보를 설명서에서 볼 수 있고, 실행기는 후보 밖의 shipped를 거부합니다. limit의 ge와 le는 각각 최솟값과 최댓값입니다. 반환값은 OrderRecord와 TypeAdapter로 검사해 주문 ID·고객 ID·상태·금액의 자료형과 금액의 최솟값을 확인합니다. 입력과 반환 형식을 검사해도 데이터에 주문이 실제로 존재하는지까지 보장하지는 않습니다.

도구 호출(tool call)은 구조화된 실행 요청이며 도구 메시지(ToolMessage)는 실행 결과와 호출 ID를 돌려주는 메시지입니다.

6일부러 실패해 보기

shipped는 허용 상태 목록에 없고 limit=0은 최솟값보다 작으므로 조회 함수가 실행되기 전에 ValidationError가 발생합니다. 오류의 loc와 type을 읽으면 수정할 입력 필드를 구분할 수 있습니다.

출력 읽기

오류 출력의 loc는 문제가 생긴 필드를 가리킵니다. shipped 입력에서는 status가, limit=0에서는 limit가 표시됩니다. type은 각각 허용 목록 위반과 최솟값 위반을 구분합니다. 프로그램은 이 정보를 운영 로그에 남기거나 사용자에게 고칠 항목을 안내할 수 있습니다. 수정 셀에서 pending을 넣으면 O102가 반환됩니다. 이 행은 공개 CSV에 실제로 있으므로 스키마 통과와 데이터 조회 성공을 함께 확인합니다. 단, Literal 후보를 바꾸면 모델 설명서와 테스트, 데이터 문서도 함께 갱신해야 합니다.

7주의할 점과 실무 메모

설명 문장에 허용 값을 적는 것만으로는 검증되지 않습니다. 자료형 또는 검증 규칙에도 같은 제약이 있어야 실행기가 거부할 수 있습니다.

JSON Schema를 출력하면 enum, minimum, maximum에 해당하는 제약을 찾을 수 있습니다. 모델 제공자는 이 설명을 도구 호출 형식으로 변환하지만 최종 검증 책임은 애플리케이션에 있습니다. 오류를 잡아 무조건 빈 목록으로 바꾸면 잘못된 상태와 검색 결과 없음이 구분되지 않습니다. 입력 오류는 입력 오류로 남기고, 허용된 입력에서 행이 없을 때만 빈 결과로 해석합니다. 반환 목록의 필드 이름도 안정적으로 유지해야 후속 모델이 금액과 상태를 혼동하지 않습니다.

반환 타입 주석만으로 실행 시점의 반환값이 자동 검증되지는 않습니다. 이 절은 OrderRecord에 필드별 자료형과 금액의 최솟값을 정의하고, TypeAdapter(list[OrderRecord])로 실제 목록을 검사합니다. 검증을 마친 객체를 다시 사전으로 출력해 다음 모델 호출에 전달할 필드가 유지되는지도 확인합니다.

  • 도구 설명과 인자 스키마도 모델 컨텍스트를 사용합니다.
  • API 가격과 모델 동작은 달라질 수 있으므로 실행 시점의 공식 정보를 확인합니다.

8정리와 다음 절

  • 상태 목록과 개수 범위를 JSON Schema와 실제 검증에 함께 반영했습니다.
  • shipped와 limit=0은 함수 본문이 실행되기 전에 거부됩니다.
  • 유효한 pending 입력은 공개 자료의 O102를 반환합니다.
