1학습 목표

  • 질문 관련성과 이미 선택한 결과와의 차이를 한 점수로 결합하는 선택 방법의 입력과 출력을 설명할 수 있습니다.
  • Q001에서 λ에 따른 관련성과 다양성 변화를 비교할 수 있습니다.
  • 관찰한 수치가 설명하는 범위와 설명하지 못하는 범위를 구분할 수 있습니다.

2이 내용을 배우는 이유

상위 결과가 같은 문서의 비슷한 청크로 채워지면 서로 다른 근거를 확인하기 어렵습니다. MMR은 질문 관련성과 선택 결과 사이의 차이를 함께 계산합니다. λ만 바꾸어 고유 부모 수와 관련성 점수를 같이 보면 다양성을 얻기 위해 무엇을 잃었는지 확인할 수 있습니다.

Ch11에서 만든 질문과 정답 문서 ID를 유지한 채 한 조건씩 바꿉니다. Q001의 후보와 선택 수를 유지하고 λ만 바꾸어 결과를 비교합니다.

3앞에서 배운 내용

Ch10에서 PDF를 문서와 청크로 나누고 메타데이터에 출처를 보존했습니다. Ch11의 evaluation-queries.jsonl은 질문마다 gold_doc_ids를 제공합니다. 이 절에서는 그 정답 ID에 해당하는 공개 PDF 6건을 다시 추출한 advanced-documents.json과 같은 30문항을 사용합니다. 앞 절의 변수나 실행 상태는 필요하지 않습니다.

4핵심 개념

쉬운 예

도서관에서 책을 찾을 때 먼저 검색대가 관련 서가를 좁히고, 그 안에서 제목과 목차를 자세히 읽어 우선순위를 정한다고 생각해 봅니다. 첫 단계가 서가를 빠뜨리면 다음 단계는 그 책을 검토할 수 없습니다. 반대로 후보를 지나치게 많이 가져오면 자세히 읽는 시간이 늘어납니다.

정의

질문 관련성과 이미 선택한 결과와의 차이를 한 점수로 결합하는 선택 방법입니다. MMR은 질문 관련성에서 이미 선택한 결과와의 최대 유사도를 뺀 결합 점수를 계산합니다. λ를 적용한 점수가 가장 큰 후보를 하나씩 반복 선택합니다.

5실행 예제

노트북은 Python 3.12 새 커널에서 실행합니다. 먼저 부모 문서 수, 자식 청크 수, 질문 수를 출력해 입력 범위를 확인합니다. 다음 셀은 가장 작은 문항 하나에서 중간 결과를 보여 줍니다. 마지막 셀은 조건을 바꾸거나 평가 범위를 넓힙니다. 출력의 문서 ID, 점수, 실행 시간 또는 로그 수를 본문 설명과 대조합니다.

6실험 결과 해석

같은 질문에서 λ를 1.0·0.5·0.2로 바꾸고 선택된 부모 ID의 고유 개수를 비교했습니다. λ가 작을수록 중복 억제가 강해지지만 관련성 점수가 낮은 청크가 포함될 수 있습니다. 따라서 고유 개수와 관련성 점수를 함께 읽습니다.

한 번의 출력은 이 데이터와 실행 환경에서 관찰한 결과입니다. 다른 도메인, 더 긴 문서, 다른 언어 비율에서는 순서와 시간이 달라질 수 있습니다. 설정을 채택하기 전에는 실제 서비스 질문을 같은 형식으로 추가해 다시 계산해야 합니다.

7주의할 점과 실무 메모

  • 이번 절의 중간 결과를 확인한 뒤 다음 단계로 전달합니다. 검색 후보, 선택 결과, 부모 원문, 재작성 질문, 로그 행은 서로 다른 데이터입니다.
  • 실행 시간은 CPU, GPU, 배치 크기, 입력 길이, 모델 캐시에 따라 달라집니다. 장치와 패키지 버전을 로그에 함께 남깁니다.
  • MMR 계산은 로컬에서 실행되어 API 비용이 없지만 후보 수가 늘면 후보끼리 비교하는 연산이 증가합니다.
  • 공개 PDF 6건과 30문항은 학습용 기준선입니다. 실제 서비스의 문서 분포와 질문 유형을 대신하지 않습니다.

8정리와 다음 절

  • MMR은 질문 관련성과 선택 결과 사이의 차이를 결합합니다.
  • λ별 고유 부모 수와 관련성 점수를 함께 확인했습니다.
  • 이 결과는 Q001의 후보에 MMR을 적용해 관찰한 실행 사례입니다.

9복습 문제

1. 이해 — 이번 절에서 고정한 조건은 무엇인가요?

λ 비교에서 바꾸지 않은 입력을 두 가지 적어 보세요.

Q001과 고정 후보 유사도 행렬, 선택 수를 유지하고 λ만 바꿨습니다. 오답 시 다시 볼 곳: 3절 ‘앞에서 배운 내용’

2. 이해 — λ가 작아지면 무엇을 더 중요하게 보나요?

MMR 식에서 λ=0.2의 의미를 설명해 보세요.

질문 관련성보다 이미 고른 결과와의 차이에 더 큰 비중을 둡니다. 관련성 0인 청크도 선택될 수 있으므로 점수를 함께 확인합니다. 오답 시 다시 볼 곳: 6절 ‘실험 결과 해석’

3. 적용 — 중복 결과가 많을 때 무엇을 바꾸나요?

질문과 후보를 유지한 채 실행할 비교를 적어 보세요.

선택 수를 고정하고 λ만 여러 값으로 바꾸어 고유 부모 수와 관련성 점수를 함께 비교합니다. 오답 시 다시 볼 곳: 5절 ‘λ 값 비교’

4. 분석 — 고유 부모 수가 늘면 품질도 높아졌나요?

λ=0.2 출력의 관련성 점수를 근거로 판단해 보세요.

단정할 수 없습니다. 고유 부모는 4개였지만 관련성 0인 청크도 포함되었습니다. 다양성과 정확도는 별도 관찰입니다. 오답 시 다시 볼 곳: 6절 ‘실험 결과 해석’
