2이 내용을 배우는 이유

검색 문서가 맞아도 생성된 답이 문서에 없는 사실을 더할 수 있습니다. 초안을 만든 뒤 근거와 다시 대조하면 답의 어느 부분이 문서로 확인되는지 점검할 수 있습니다.

Ch9의 기본 RAG는 검색 한 번과 생성 한 번으로 구성되었습니다. Ch14에서는 질문을 바꾸거나 결과를 검사하는 단계를 추가합니다. 모든 선택은 if 문, 수치 임계값, 반복 상한에 적힌 규칙으로 실행합니다. 모델이 다음 행동을 자율적으로 결정하는 에이전트는 아직 사용하지 않습니다.

4핵심 개념

근거 검사

근거 검사
이 절은 Self-RAG를 재현하지 않습니다. Self-RAG 원 논문은 검색 필요성, 관련성, 답의 유용성을 나타내는 reflection token을 학습한 모델을 사용합니다. 여기서는 일반 모델에 0~1 근거 점수를 요청하고 0.9 미만일 때 한 번 수정하는 교육용 검사만 구현합니다.
흐름을 정하는 규칙
근거 점수를 0에서 1 사이로 제한하고 0.9 미만일 때만 한 번 수정합니다. 수정 뒤에는 다시 반복 평가하지 않습니다.

호출 표기와 실행 시점

이 절은 답변 초안을 만든 뒤 근거 문서와 얼마나 맞는지 점수를 요청하고, 기준 미만이면 한 번 수정합니다. 생성, 평가, 수정이 서로 다른 단계이며 평가 프롬프트와 기준값도 실행 기록의 일부입니다.

다른 상황에 적용

보고서 요약에서 숫자와 날짜가 원문에 있는지 평가하고 근거가 약하면 해당 문장을 삭제해 다시 생성할 수 있습니다. 이때 평가 모델이 ‘맞다’고 했다는 사실과 실제 원문 검증 결과를 구분해야 합니다.

비교와 경계

원래 Self-RAG는 검색·생성 과정에 반성 토큰을 통합한 연구 방법입니다. 이 절은 생성 후 근거 검사에서 영감을 받은 축소 흐름입니다. judge 점수는 사실의 증명이 아니므로 코드 규칙과 사람 평가로 교차 확인합니다.

도식의 상자를 위에서 아래로 읽습니다. 나란한 상자는 분기하거나 따로 실행한 뒤 다시 합치는 처리입니다. 생성한 질문, 가상 문서, 평가 점수는 검색을 돕는 중간 값이며 출처로 인용하지 않습니다.

6실험 결과 해석

전자책 질문의 첫 초안은 세 권, 7일, [LIB-004]를 정확히 포함했습니다. 수정 분기를 확인하려고 원문에 없는 ‘연체료 500원’을 검사 초안에 추가했습니다. 근거 점수는 0.5였고, 모델은 근거 없는 문장을 제거했습니다. 생성·검사·수정에 합계 409토큰, 약 2.87초가 들었습니다.

모델이 자기 답을 평가한 점수는 객관적인 정답률이 아닙니다. 별도의 사람이 만든 평가셋과 독립 평가기가 필요합니다. Ch15에서 생성 지표를 더 체계적으로 다룹니다.

코사인 유사도는 질문과 문서 벡터가 같은 방향을 가리키는 정도입니다. 이 값은 정답 확률이 아니며 데이터와 임베딩 모델이 바뀌면 임계값도 다시 정해야 합니다. 실제 출력이 좋아지지 않았다면 개선으로 바꾸어 서술하지 않습니다.

7주의할 점과 실무 메모

  • 운영 전에 확인합니다. 같은 모델이 생성과 평가를 모두 맡으면 오류 성향이 겹칠 수 있으므로 운영 평가는 사람 라벨이나 독립 평가기와 대조해야 합니다.
  • 기록할 항목을 정합니다. 평가 점수의 원문 응답과 숫자 파싱 결과를 함께 남기면 형식 오류를 확인할 수 있습니다.

8정리와 다음 절

  • 고정한 통제 오류는 근거 점수를 낮추고 한 번의 수정 분기를 관찰하게 했습니다.
  • 자기 점수는 객관적인 정답률이 아니므로 독립 평가 결과와 대조해야 합니다.

9복습 문제

문제 4개 · 해설 포함

1. Self-RAG에서 영감 받은 근거 검사의 입력과 출력은 무엇입니까?

검색 원문과 답변 초안을 입력하면 0~1 근거 점수와 기준 미달일 때 수정한 답을 출력합니다.

2. 이 절의 실제 출력은 패턴 선택에 어떤 근거를 줍니까?

원문에 없는 연체료 문장 때문에 점수가 0.5가 되었고 수정 답에서는 해당 문장이 제거되었습니다.

3. 코드에서 호출 수나 후보 수를 제한하는 규칙은 무엇입니까?

0.9 미만일 때만 수정하고 수정은 한 번으로 끝냅니다.

4. 생성한 중간 문장을 최종 답의 출처로 쓰면 안 되는 이유를 설명하세요.

모델이 만든 문장은 원문 자료에서 확인한 사실이 아닙니다. 실제 검색된 문서의 ID와 본문만 근거로 인용합니다.
