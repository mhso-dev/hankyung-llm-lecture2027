1학습 목표

  • 이 절을 마치면 질의 분해의 입력과 출력을 설명할 수 있습니다.
  • 이 절을 마치면 질의 분해, 하위 질문, 다중 사실, 근거 집합의 역할을 코드의 입력·처리·출력으로 구분할 수 있습니다.
  • 이 절을 마치면 하위 질문을 늘려도 서로 다른 근거가 추가되지 않은 결과를 해석할 수 있습니다.

2이 내용을 배우는 이유

‘휴학생은 전자자료와 일반 도서를 각각 이용할 수 있나요?’에는 두 판단이 들어 있습니다. 하나의 검색 결과가 두 사실을 모두 포함할 수도 있지만, 서로 다른 문서에 흩어져 있다면 일부 근거를 놓칩니다. 하위 질문마다 검색하면 필요한 사실을 점검하기가 수월해집니다.

Ch9의 기본 RAG는 검색 한 번과 생성 한 번으로 구성되었습니다. Ch14에서는 질문을 바꾸거나 결과를 검사하는 단계를 추가합니다. 모든 선택은 if 문, 수치 임계값, 반복 상한에 적힌 규칙으로 실행합니다. 모델이 다음 행동을 자율적으로 결정하는 에이전트는 아직 사용하지 않습니다.

3앞에서 배운 내용

Ch11에서 정답 문서 ID와 Recall을 분리해 기록했습니다. Ch12에서는 core-documents.json의 문서 12건과 core-queries.json의 질문 8건으로 검색 설정을 비교했습니다. 이 절은 두 파일의 내용을 챕터 폴더에 복제해 같은 문서와 정답을 사용합니다. 전체 제공 PDF와 30문항을 쓰지 않는 축소 표본입니다.

4핵심 개념

질의 분해

질의 분해
질의 분해는 복합 질문을 사실 하나씩 답할 수 있는 하위 질문으로 나누는 패턴입니다. 하위 질문의 답을 바로 최종 답으로 쓰지 않고, 각 질문으로 원문을 검색한 뒤 근거 집합을 합칩니다. 분해가 지나치면 호출 수가 늘고 원문의 관계가 사라질 수 있으므로 하위 질문 수를 제한합니다.
흐름을 정하는 규칙
복합 질문을 최대 두 개의 하위 질문으로 나눕니다. 각 하위 질문에서 한 문서만 검색하고, 문서 ID가 같은 결과는 하나의 근거로 셉니다.

호출 표기와 실행 시점

질의 분해는 복합 질문을 독립적으로 검색할 수 있는 하위 질문으로 나눕니다. 각 하위 질문은 서로 다른 근거를 찾고, 마지막 단계가 근거를 합쳐 원 질문에 답합니다. 두 하위 질문의 답을 단순히 이어 붙이지 말고 원 질문의 관계와 조건을 다시 확인해야 합니다.

다른 상황에 적용

‘법인카드 발급 조건과 분실 시 절차’를 발급 조건 질문과 분실 처리 질문으로 나누면 서로 다른 규정 절을 찾을 수 있습니다. 두 결과를 합칠 때 동일한 카드 종류와 적용 시점을 확인해야 합니다.

비교와 경계

Multi-Query는 같은 정보에 도달하는 표현을 여러 개 만들고, 질의 분해는 서로 다른 정보 요구를 나눕니다. 질문을 너무 잘게 나누면 조건 사이의 관계가 사라질 수 있으므로 각 하위 질문과 원 질문의 대응을 저장합니다.

6실험 결과 해석

모델은 복합 질문을 전자자료 이용과 일반 도서 이용의 두 질문으로 나누었습니다. 두 검색 모두 ACC-002를 1위로 반환했습니다. 서로 다른 근거 수는 1이었습니다. 분해했지만 이 축소 데이터에서는 새 문서를 추가로 찾지 못했습니다.

분해는 여러 문서가 필요할 때 도움이 될 수 있습니다. 이번 결과는 하나의 문서에 두 사실이 함께 있어 검색 범위가 넓어지지 않은 사례입니다. 개선이 관찰되지 않은 결과도 패턴 선택의 근거입니다.

코사인 유사도는 질문과 문서 벡터가 같은 방향을 가리키는 정도입니다. 이 값은 정답 확률이 아니며 데이터와 임베딩 모델이 바뀌면 임계값도 다시 정해야 합니다. 실제 출력이 좋아지지 않았다면 개선으로 바꾸어 서술하지 않습니다.

7주의할 점과 실무 메모

  • 운영 전에 확인합니다. 하위 질문을 합쳤을 때 원 질문의 비교·조건 관계가 사라지지 않았는지 별도로 확인해야 합니다.
  • 기록할 항목을 정합니다. 하위 질문별 문서 ID를 보존해야 최종 답의 각 문장을 어느 원문이 뒷받침하는지 확인할 수 있습니다.

8정리와 다음 절

  • 질문을 나누어도 여러 하위 질문이 같은 문서를 찾으면 근거 범위는 넓어지지 않습니다.
  • 한 문서에 여러 사실이 함께 있으면 분해 호출만 늘고 새 근거는 추가되지 않을 수 있습니다.

9복습 문제

문제 4개 · 해설 포함

1. 질의 분해의 입력과 출력은 무엇입니까?

여러 사실이 들어 있는 복합 질문을 입력하면, 사실별 하위 질문 목록과 각 질문의 원문 근거를 출력합니다.

2. 이 절의 실제 출력은 패턴 선택에 어떤 근거를 줍니까?

두 하위 질문이 모두 ACC-002를 찾아 서로 다른 근거 수가 한 건에 머물렀습니다.

3. 코드에서 호출 수나 후보 수를 제한하는 규칙은 무엇입니까?

하위 질문은 두 개, 질문별 검색 문서는 한 건으로 제한합니다.

4. 생성한 중간 문장을 최종 답의 출처로 쓰면 안 되는 이유를 설명하세요.

모델이 만든 문장은 원문 자료에서 확인한 사실이 아닙니다. 실제 검색된 문서의 ID와 본문만 근거로 인용합니다.
