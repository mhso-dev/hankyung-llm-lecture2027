1학습 목표

  • create_react_agent 호출을 create_agent 호출로 바꿀 수 있습니다.
  • prompt, state, structured output 관련 v1 변경점을 점검할 수 있습니다.
  • 설치한 1.4.0의 함수 서명으로 이식 범위를 확인할 수 있습니다.

2이 내용을 배우는 이유

이전 create_react_agent 코드를 v1 create_agent로 옮길 때 무엇을 바꾸어야 하는가?

이름만 바꾸면 마이그레이션이 끝난다고 생각하기 쉽지만 반환 상태와 사용자 상태 형식도 달라졌습니다. 먼저 입력·출력 경계를 고정해야 기존 호출자의 동작을 보존할 수 있습니다.

3앞에서 배운 내용

Ch20의 직접 조립 그래프를 사용합니다. 필요한 자료와 객체는 노트북에서 다시 선언하므로 앞 노트북의 메모리 상태는 필요하지 않습니다.

4핵심 개념

정의와 구체 예

v1의 create_agent는 langchain.agents에서 가져옵니다. 이전 langgraph.prebuilt.create_react_agent의 prompt는 정적 지시에서 system_prompt로 대응합니다. 구조화 결과는 별도 후처리보다 response_format과 structured_response를 사용합니다. 사용자 상태는 Pydantic 모델 대신 TypedDict 기반 AgentState를 사용합니다.

코드를 읽는 순서

마이그레이션은 이름을 일괄 치환하는 작업보다 호출 경계의 변화를 확인하는 작업입니다. inspect.signature(create_agent)는 현재 설치된 함수가 받는 매개변수 이름과 기본값을 문자열로 보여 줍니다. 셀의 for name in [...] 검사는 이 교재가 사용하는 여섯 인자가 실제 1.4.0 API에 존재하는지 확인하며, 예전 API가 어떻게 동작했는지를 실행하는 검사는 아닙니다.

대응표에서 import 위치, 인자 이름, 반환 상태를 따로 보는 이유가 있습니다. prompt를 system_prompt로 바꿔도 사용자 상태 형식이나 구조화 결과를 읽는 위치가 예전 코드에 남아 있으면 실행은 일부만 고쳐집니다. 최소 실행은 새 import→그래프 생성→invoke→마지막 메시지 읽기까지 한 경로를 통과시켜 호출부가 서로 맞는지 확인합니다.

5실행 예제

준비 셀에서 Python 3.12와 고정 패키지를 확인한 뒤, 데이터·함수·객체 생성·invoke·관찰을 짧은 셀로 나누어 실행합니다. 각 코드 셀의 첫 주석은 그 셀에서 확인할 행동을 설명합니다.

다른 상황과 적용 경계

실제 서비스에서는 먼저 기존 호출의 관찰 테스트를 고정한 뒤 한 경계씩 바꿉니다. 도구 호출 횟수, 메시지 종류, 구조화 결과 필드처럼 사용자에게 보이는 동작을 기록하면 단순히 import가 성공했다는 사실보다 회귀를 빨리 찾을 수 있습니다.

이 절의 표는 대표적인 이동 지점을 설명하며 모든 0.x API의 호환 목록은 아닙니다. 설치된 1.4.0의 서명에 인자가 있다는 사실도 특정 모델 제공자가 모든 조합을 지원한다는 보장은 아닙니다. 구조화 출력과 도구를 함께 쓸 때의 제공자 지원 범위는 02절의 조건을 다시 확인해야 합니다.

6실험 결과 해석

설치된 1.4.0 서명에서 model, tools, system_prompt, response_format, state_schema, context_schema를 모두 확인했습니다. create_react_agent→create_agent, prompt→system_prompt 등 네 행을 출력하고 v1 에이전트의 실제 답을 받았습니다.

동적 프롬프트와 상태 변경은 단순 인자 치환으로 옮길 수 없습니다. v1에서는 미들웨어가 권장되는 경우가 있으므로 Ch22에서 훅 단위로 다시 확인합니다.

7주의할 점과 실무 메모

  • 동적 프롬프트와 상태 변경은 단순 인자 치환으로 옮길 수 없습니다. v1에서는 미들웨어가 권장되는 경우가 있으므로 Ch22에서 훅 단위로 다시 확인합니다.
  • 실제 모델 호출 비용은 절당 1달러 미만으로 예상하며, API 키 값은 출력하지 않습니다.
  • 재실행하면 모델 문장과 지연이 달라질 수 있으므로 저장된 원문 출력과 조건을 함께 읽습니다.

9복습 문제

1. create_agent의 새 import 경로는 무엇인가요?

해설 — langchain.agents입니다.

2. 정적 prompt에 대응하는 v1 인자는 무엇인가요?

해설 — system_prompt입니다.

3. 마이그레이션 전에 고정할 것은 무엇인가요?

해설 — 입력·출력 상태와 도구 부작용 같은 경계입니다.
