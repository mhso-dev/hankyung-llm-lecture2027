## Ch14 RAG 패턴

| 절 | 첫 사용과 보정 위치 | 다른 상황·비교 경계 |
| --- | --- | --- |
| 01 질문 재작성 | 대화 기록+현재 질문 입력, 독립 검색 질문 반환, 실제 검색 실행 시점을 설명 | 상품 반품 후속 질문에 적용. 질문 재작성과 대화 요약의 목적 차이 설명 |
| 02 Multi-Query | 변형 질문 생성→각 검색→문서 ID별 최고 코사인 점수 보존→점수 내림차순 정렬 흐름을 설명. 이 절에는 RRF가 없고 09절에서 사용함을 명시 | 육아휴직의 지급·절차·기간 관점에 적용. 표현 확장과 질의 분해의 차이 설명 |
| 03 질의 분해 | 복합 질문을 하위 질문으로 나누고 근거를 다시 원 질문 관계로 합치는 흐름을 설명 | 법인카드 발급·분실 절차에 적용. Multi-Query와 분해의 정보 요구 차이 설명 |
| 04 Step-back | 구체 질문과 한 단계 일반화 질문의 입력·검색 결과 역할을 설명 | 연휴 고객센터 공지와 공통 규정 검색에 적용. 일반 규칙이 구체 예외를 대체하지 않는 범위 설명 |
| 05 HyDE | 가상 문서 생성→임베딩→실제 문서 검색을 설명하고 가상 문서는 반환 근거가 아님을 명시 | 계정 잠금 질문에 적용. 질문 재작성과 가상 답변형 중간 표현 비교 |
| 06 CRAG | 첫 검색 점수→임계값 분기→한 번 보정→재검색을 상태 기준으로 설명 | 상품 검색 보정에 적용. 원 논문 CRAG와 수업용 단일 보정의 범위 구분 |
| 07 Self-RAG | 초안 생성→근거 평가→기준 미만 한 번 수정의 실행 순서를 설명 | 보고서 숫자·날짜 검증에 적용. 원 Self-RAG와 생성 후 judge 검사의 범위 구분 |
| 08 RAPTOR | 상위 요약 노드와 하위 원문 ID, 상위 검색 뒤 원문으로 내려가는 흐름을 설명 | 부서별 위키 계층에 적용. 원 논문의 재귀 군집과 category 한 단계 축소 구현 구분 |
| 09 패턴 비교 | 동일 질문·문서·정답 조건에서 기준선·Multi-Query·HyDE를 비교하는 단위를 설명 | 새로운 도메인에서 동일 시험셋 비교에 적용. 한 사례 승리와 전체 우수성의 경계 설명 |
