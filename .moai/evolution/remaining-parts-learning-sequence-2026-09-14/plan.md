# 나머지 작성 파트 개념 학습 개선

범위는 작성된 Part 2~7, Ch6~34의 179절과 대응 노트북입니다. Part 8은 아직 작성되지 않아 이번 기존 교재 개선 범위에 없습니다. Part 1의 35절은 보존합니다.

각 절을 처음 배우는 독자의 순서로 읽고, 필요한 이유·용어 정의·문법·입력/처리/반환·실행 시점·출력 해석을 실제 첫 사용 전에 설명합니다. 실제 선수 절을 확인하고 선택 경로를 건너뛴 독자도 필요한 국소 설명으로 시작할 수 있게 합니다. 기본 사례에서 다른 상황, 조건 비교, 경계까지 개념을 깊게 설명합니다. 공식 문서는 정확성의 근거이며 본문 구성은 학습 질문을 따릅니다. 비용 관련 부연으로 분량을 채우지 않습니다.

본문 정본과 노트북 마크다운을 함께 개정합니다. 코드를 바꿀 때만 새 커널에서 실제 실행하고 출력·해석을 갱신합니다. 설명만 고치면 코드·출력 보존을 검증합니다. 생성기가 있으면 정본을 덮어쓰지 않고 동기화합니다. 장별 작성 뒤 독립 검토, HTML 재빌드, 코드/출력/화면/복사/다운로드/묶음 검증을 수행합니다. 기존 역사적 검증 기록은 보존하며 이번 근거는 이 폴더에 남깁니다.
