## 안정본 재검토 중 추가 보정

1. Ch30-09는 API 키 확인, 실제 HTTP 호출, 별도 Agent 궤적, SSE 조립 설명을 각각의 코드 바로 앞에 나눴습니다. HTTP 실행 설명이 `.env` 준비 코드 앞에 놓였던 문제를 해결했습니다.
2. Ch31-05의 첫 DB 준비 설명은 `psycopg` 연결, vector 확장, `ch31_shared` 스키마 재생성을 정확히 설명합니다. 실제 `pg_dump`·복원 셀 앞에서는 Docker 명령, 문자열 출력, 복원 뒤 행 수·HNSW 검사 범위를 따로 설명합니다.
3. Ch34-05의 준비 설명은 바로 다음 `import math`와 `math.ceil()`의 사용 시점만 설명합니다. 존재하지 않는 폴더 탐색·환경 변수·파일 기록을 설명하던 문장을 제거했습니다.
4. Ch33-04는 오류율만 `errors / requests`로 계산하고 `p95_ms`는 자료에 이미 집계된 값을 읽는다고 HTML과 노트북에 명시했습니다. 원시 지연에서 p95를 계산한다고 확대하지 않습니다.
5. Ch33-05의 `sha256(stable-v1)`과 `sha256(regressed-v2)`는 롤백 이력 형식을 확인하기 위한 모의 식별자입니다. 실제 Docker 이미지 ID나 레지스트리 digest가 아니며, 운영에서는 앞 절에서 확인한 실제 식별자를 전달해야 한다고 첫 사용에서 설명합니다.

## 한국어 산문 감사와 언어 게이트 문맥 판정

- Ch31의 목표·실행 해설은 절별 실제 행동과 출력으로 바뀌었고, Ch33의 동일 비유·선수 문단은 제거됐습니다. 낯선 말을 낯선 말로 다시 정의하거나 비용 설명으로 깊이를 대신하는 미해결 S1은 없습니다.
- 금지 표현을 HTML 본문과 노트북 마크다운에서 다시 검사했습니다. `함정`, 내부 용어인 `회수`, 함수 반환을 뜻하는 `돌려줍니다`, `당연히`·`간단히`·`쉽게`는 발견되지 않았습니다. `되돌립니다`는 롤백의 실제 의미이므로 실행 의미의 금지 표현과 다릅니다.
- Ch30 언어 게이트의 수치 WARN `1`은 Ch30-09의 근거 없는 “1달러 미만”을 삭제하면서 생겼습니다. 수치 손실이 아니라 P7-09의 사실 교정입니다.
- Ch33 언어 게이트의 `-256`·`256` WARN은 Ch33-03이 로컬 이미지 ID를 SHA-256 레지스트리 digest처럼 설명하던 문장을 제거하면서 생겼습니다. 현재 Ch33-05의 `SHA-256`은 고정 문자열로 모의 식별자를 만드는 실제 코드와 일치하며, 실제 이미지 ID가 아니라고 명시합니다.
- Ch33의 `15`·`29`·`32` 감소는 다섯 절에 복제돼 있던 Ch15·Ch29·Ch32 공통 선수 문단을 절별 실제 선수 내용으로 바꾼 결과입니다. 필요한 Ch15·Ch29 연결은 02절에, Ch32 연결은 01·03절에 남아 있습니다.
- Ch33의 `0` 감소는 모든 절에 반복됐던 종료 코드 공통 설명을 제거한 결과입니다. 종료 코드가 학습 대상인 01·02·04·05절에는 실제 0·1 판정이 그대로 남아 있습니다.
- 따라서 Ch30·33의 자동 수치 WARN은 보존하되, 원문 대조 결과는 모두 의도한 사실 교정과 반복 제거입니다. 직접 인용, 실행 수치, 저장 출력의 의미 손실은 없습니다.
- `ai-slop-reviewer`와 `korean-humanize`의 맥락 정독·최종 의미 보존 기준을 적용했습니다. 외부 맞춤법 검사는 상업적 대량 처리 제한에 따라 실행하지 않았고 로컬 전문 정독으로 대체했습니다.
