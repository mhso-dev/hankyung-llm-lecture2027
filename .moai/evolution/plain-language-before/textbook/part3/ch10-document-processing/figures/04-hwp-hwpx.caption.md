# HWP와 HWPX는 확장자뿐 아니라 내부 구조가 다르다

- 설명 대상: HWP는 바이너리 전용 파서가 필요하고, HWPX는 ZIP 안의 XML을 읽으므로 형식을 판별한 뒤 알맞은 경로를 선택합니다.
- 캡션: HWP는 바이너리 전용 파서가 필요하고, HWPX는 ZIP 안의 XML을 읽으므로 형식을 판별한 뒤 알맞은 경로를 선택합니다.
- 시선 순서: 왼쪽 입력 → 가운데 변환 또는 비교 → 오른쪽 결과
- alt: 한글 문서 입력이 HWP 바이너리 파서 경로와 HWPX ZIP XML 파서 경로로 나뉜 뒤 같은 Document 계약으로 합쳐지는 흐름
- 삽화 판단: 구성 요소와 관계를 정확히 표시해야 하므로 기술 도식이 더 적합합니다.
