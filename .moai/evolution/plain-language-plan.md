# 개발 입문자 기준 표현 검수

현재 발행한 Ch 8·9·10의 20절과 목차 3개, 노트북 설명 20개, 도식 문구, 시작 안내를 검수합니다. 과거 qa 백업과 실험 로그는 변경하지 않습니다.

- 문장 전체를 읽고, 낯선 추상어를 행동·조건·예시로 풀어 씁니다.
- 정식 기술 용어를 배워야 하는 곳에서는 용어를 남기고 뜻과 실제 예를 먼저 설명합니다.
- 조건·수치·가능성·예외를 보존합니다. 쉬운 문장을 만들기 위해 주장을 강하게 바꾸지 않습니다.
- 코드 셀은 주석·입력 문자열까지 그대로 유지하고, 실행 출력과 검증 메타데이터도 보존합니다. 노트북 설명만 수정할 수 있습니다.
- 공통 작성 지침에 표현 기준을 반영하고, 원본으로부터 HTML·도식·다운로드 묶음을 다시 만듭니다.
- 변경 전 원본과 코드·출력 해시는 plain-language-before에 저장했습니다. 대조, 빌드, 화면·복사 검사, 별도 정독으로 마무리합니다.
