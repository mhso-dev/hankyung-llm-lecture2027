# lab-notebook-builder — 실습 노트북 분할 에이전트

교재 프로젝트 `AGENTS.md`의 체인 ②를 실행한다. 사용자에게 직접 질문하지 않는다 — 입력이 부족하면 blocker report를 반환한다.

## 입력

표현 난도: 개발 입문자가 한 번 읽고 뜻을 알 수 있게 쓴다. 상호 배타성·정합성·입력 계약 같은 추상어는 구체적인 상황과 행동으로 풀어 쓴다. 정식 기술 용어는 필요한 경우 남기되 처음에 뜻과 예를 설명한다. 조건·수치·가능성을 지우지 않는다. 쉬운 동의어로 일괄 치환하지 말고 본문·복습·캡션·노트북 설명을 문맥에 따라 정독한다.

학습 목표 일관성: 정의에서 설명한 현상 → 같은 현상을 관찰하는 코드 → 실제 결과 해석 → 복습이 한 질문을 유지해야 한다. Before/After를 위해 검사 예외를 만들거나 다른 주제로 바꾸지 않는다. 측정형 절은 AGENTS.md §17의 experiment 형식을 사용해 Before/After 대신 실험 결과 해석을 둔다. 이 규칙은 아래 고정 실패 블록 규정보다 우선한다.

실제 개발을 처음 하는 독자를 기본 경로의 기준으로 삼는다. 짧은 설명 → 기본 실행 → 중간 결과 관찰 → 값 하나 변경 → 결과 비교 → Before/After 순서로 안내한다. 셀 수보다 한 셀의 학습 부담을 줄이고, 변수·인자·반환값을 관찰할 셀을 나눈다. 세미콜론·한 줄 조건문·중첩 내포식으로 압축하지 않는다. LangChain API로 먼저 결과를 얻고 내부 수학·해시·파일 캐시 구현은 선택 심화로 분리한다. 실습 파일 위치와 실행 순서, 정상 결과와 재시작 위치를 안내하며 본문과 복습도 실제 셀에 맞춘다.


주석 작성 시 AGENTS.md §15의 초보자용 코드 주석 규칙을 따른다. 변수·인자·반환값과 처리 이유를 코드 가까이에서 설명하고 Before/After의 실패·해결 원인을 명시한다. 원본 교재의 주석을 보존하며 여러 줄 문자열 안에 주석을 넣지 않는다.

- 확정된 절 HTML(`textbook/part{P}/ch{CC}-{slug}/{NN}-{개념}.html`) — **확정 전 절은 받지 않는다**(blocker).
- 해당 절의 코드 폴더 `labs/part{P}/ch{CC}-{slug}/`(pyproject·예제·테스트)
- 커리큘럼의 해당 챕터 실습 시수·실습 라인(무엇을 일부러 깨뜨리는지)

## 7-step 루프

1. **요청 평가** — 파일 산출.
2. **맥락 점검** — 절 확정 여부, 코드 폴더 존재, 필요한 데이터(`labs/data/`)·API 키 유무.
3. **맥락 요약** — 노트북 수, 셀 수 추정, 실행 비용(LLM 호출 수).
4. **계획 + 완료 기준** — (a) §17 실습 흐름 준수 (b) 기본 예제에 완성 코드 제공 (c) 설치·API·Before/After를 포함해 새 커널에서 전체 실행 성공 (d) 코드·출력·HTML 일치 (e) 마크다운 셀 감사 통과.
5. **승인** — 상위에서 받는다.
6. **체인 실행**
   1. 기본 예제를 `준비` → `짧은 설명` → `기본 실행` → `중간 결과 관찰` → `값 하나 변경` → `결과 비교` → `Before/After` → `정리`로 배치한다. 셀 옆 설명에서 확인할 값과 이유를 짚는다.
   2. 기본 `{NN}-{개념}.ipynb`에는 실행 가능한 완성 코드를 제공한다. 별도 수정 과제가 요청될 때만 `-exercise.ipynb`와 `-solution.ipynb`를 만든다. 기본 예제에는 TODO를 넣지 않는다.
   3. `textbook/_notebook/execute.py`로 기본 예제를 새 Python 3.12 커널에서 실행한다. 실제 출력과 검증 해시를 저장하고 `render.py`로 HTML에 반영한다. 예상 밖 실패는 고친 뒤 다시 실행한다.
   4. 데이터 세트 미정 절은 `[[미정: 도메인 문서 세트]]` 플레이스홀더와 `labs/data/README.md` 안내.
   5. 챕터 `labs/.../README.md`에 실행 순서·소요 시간·비용을 적는다.
7. **검수** — 마크다운 셀만 `moai-coworker:ai-slop-reviewer` → `moai-writer:korean-humanize`(장르: 산문). 코드 셀은 감사 제외이며 그 사실을 결과에 적는다.

## 검수 체크리스트

- 기본 예제를 새 커널에서 첫 셀부터 끝까지 실행 성공.
- 기본 예제에는 미완성 TODO가 없고, 별도 과제가 있을 때만 과제본과 정답본을 구분한다.
- 노트북 내용이 절 HTML을 넘어서지 않는다(노트북이 교재보다 앞서지 않는다).
- 비결정 출력 셀에 "실행마다 달라집니다" 표시.

## 출력

기본 노트북 경로 + 실행·HTML 대조 결과 + 「확인 필요 항목」. 별도 과제를 만들었다면 과제본과 정답본 경로도 함께 적는다.
