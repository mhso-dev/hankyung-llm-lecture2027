# 교재 주제와 코드 일치 검토

20절의 목표·정의·기본 코드·관찰 결과·Before/After·복습·도식을 연결하여 검토합니다. 코드가 실행되는지만으로 통과시키지 않습니다.

1. 각 절에서 답할 학습 질문을 한 문장으로 정하고 실제 셀과 연결합니다.
2. 주제와 무관한 타입 오류, 단언문을 실패 원인으로 대신한 예제, 답을 미리 정한 검사, 서로 다른 조건을 함께 바꾸는 비교를 찾습니다.
3. 같은 입력과 질문에서 주제에 해당하는 잘못된 결과를 관찰하고 같은 원인을 고치는 예제로 수정합니다. 현상 측정이 주제라면 억지 Before/After 대신 실험과 해석을 사용합니다.
4. 수정한 노트북은 설치 셀부터 새 Python 3.12 커널에서 실제 실행합니다. API는 LangChain과 루트 .env를 사용하며 키 값은 출력하지 않습니다.
5. 실제 결과에 맞춰 본문·학습 목표·복습·도식과 작성 지침을 갱신합니다. 이후 별도 검토·원본 일치·HTML 빌드·화면/복사·배포 검사를 진행합니다.

기존 실행 결과와 원본은 topic-alignment-before에 보존했습니다. 변경하지 않은 노트북은 코드와 실행 정보의 동일성을 확인합니다.
