# Ch 9 주제 정합성 검토

| 절 | 학생의 질문 | 기존 문제 | 수정 | 실제 실행 근거 |
|---|---|---|---|---|
| 01 | PDF 근거로 출처 있는 답을 어떻게 만드나요? | 없음 | 빈 문맥 Before와 검색 문맥 After를 유지했습니다. | 기존 새 커널 실행에서 빈 문맥은 가짜 출처, After는 `[E01 p.2]`를 출력했습니다. |
| 02 | 청크 겹침은 경계의 정보에 어떤 영향을 주나요? | 크기보다 큰 겹침의 생성자 오류만 보여 주었습니다. | 겹침 0에서 “월요일”이 갈라지고, 겹침만 5로 바꾸면 단어 전체가 남도록 고쳤습니다. | Python 3.12.13 새 커널 PASS. Before 두 조각, After `일은 월요일입니다.` 출력. |
| 03 | 두 근거가 필요한 질문에서 k는 무엇을 바꾸나요? | 문자열 k의 타입 오류라 검색 품질과 거리가 있었습니다. | 같은 복합 질문에서 k만 1→2로 바꾸고 ID와 본문을 비교했습니다. | 새 커널 PASS. Before D01만, After D01·D03과 두 본문 출력. |
| 04 | 검색 문서의 실제 쪽 번호를 답의 출처로 어떻게 보존하나요? | 임의의 `page=1`을 새로 넣어 출처 복구 근거가 약했습니다. | 실제 hit의 `doc_id`·`page`를 복사하고 같은 질문을 생성 모델로 다시 호출했습니다. | 새 커널 PASS. `[D01 p.1]` 태그와 같은 태그가 든 실제 답 출력. |
| 05 | 같은 거부 답의 원인이 검색 누락인지 문서 부재인지 어떻게 아나요? | 없음. 다만 After가 새 호출처럼 읽힐 수 있었습니다. | 앞서 실행한 k=2 검색·생성 결과를 다시 표시하며 추가 호출이 없다고 밝혔습니다. | 기존 새 커널 PASS. DISTRACTOR→DISTRACTOR+ANSWER와 실제 거부/복구 답 보존. |
| 06 | 설정이 바뀌면 기존 색인을 다시 써도 되나요? | 청크 크기와 겹침을 함께 바꾸고, 잘못 재사용한 실제 청크를 보이지 않았습니다. | 기본 분할을 실제 색인에 적용하고 `chunk_size`만 500→10으로 바꿔 재색인했습니다. | 새 커널 PASS. 잘못 재사용한 15자 청크와 새 7자 청크, 새 해시 저장 확인. |
