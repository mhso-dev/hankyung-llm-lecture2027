# Ch 6 깊이 보강 독립 검토

검토자: 작성자와 구분된 code-reviewer. 읽기 전용 역할의 검토 결과를 리더가 저장했습니다.

검토 범위: `_src/*.html` 6개, `03-구조화-출력과-검증.ipynb`, `_make_notebooks.py`의 03 생성 정의.

최종 판정: `corrected` / **APPROVE**. 잔여 CRITICAL·HIGH·MEDIUM 지적은 0건입니다.

## 사용자 의도와의 일치

비용 설명을 새로 확장하지 않고 개념 차이를 상황과 실행 결과로 비교하도록 보강했습니다. 01은 호출 방법을 독립 입력·중간 조각·비동기 대기와 연결합니다. 02는 같은 문장이 시스템 지시·이전 답변·사용자 입력에 놓일 때의 역할을 비교합니다. 03은 타입 변환·엄격 검증·추가 필드·JSON 문법 오류·수량 범위 오류를 실제 셀로 비교합니다. 04는 채팅·JSON·자막 등의 사례에서 중간 청크와 완료 결과를 구분합니다. 05는 일시 오류와 고정 입력 오류, 재시도와 폴백을 비교합니다. 06은 문자·토큰·첫 텍스트 지연·전체 지연·성공 상태를 서로 다른 관찰값으로 설명합니다.

옵션 목록은 사례를 이해하는 보조 수단으로 사용했습니다. 에이전트 실행을 앞당겨 도입하지 않았습니다.

## 지적과 수정

| 위치 | 지적 | 최종 수정 |
| --- | --- | --- |
| 01 호출 방법 | 비동기 대기의 주체가 모호하고 입력별 오류 수집이 기본 동작처럼 읽힘 | 대기 중 다른 작업을 수행한다는 뜻과 `return_exceptions=True`를 명시 |
| 02 메시지 | 추가한 저장·이름 공간 문단이 운영 설계에 치우침 | 해당 제목·표·문단을 삭제하고 역할 비교 유지 |
| 03 선수 학습 | Pydantic을 처음 다룬다는 문장이 Ch 2 10절과 모순 | Ch 2 B 경로와의 연결로 교정 |
| 03 스키마 표 | 스키마 종류와 `include_raw`가 같은 범주로 배치됨 | 원본 응답 옵션을 표에서 제거하고 별도 본문에서 설명 |
| 03 strict·주문 예시 | 엄격 검증의 과일반화, JSON 문법·값 제약·사실 확인 혼동 | Python 딕셔너리 입력으로 한정하고 세 검사의 경계를 설명 |
| 05 재시도 | 검증 오류의 과일반화, 의료·법률·야간 운영 예시의 범위 확대 | 로컬·고정 입력 오류로 한정하고 정적 안내문 폴백의 기능 차이로 교체 |
| 06 지연 예시 | 빈 메타데이터 청크와 첫 텍스트 혼동, 가정값이 실측처럼 읽힘 | 첫 비어 있지 않은 텍스트 청크 기준과 설명용 가정 명시 |
| 03 생성원 | 실행 노트북에만 새 셀이 있어 재생성 시 사라짐 | 생성 정의와 셀 주석 동기화 |

## 기술 검증

고정 환경의 LangChain 1.4.0, langchain-core 1.6.2, Pydantic 2.13.5를 확인했습니다. 모델 호출 메서드, 세 제공자의 구조화 출력, 재시도·폴백 인자를 실제 설치 소스와 대조했습니다. 배치 기본 구현과 `return_exceptions`도 확인했습니다.

03 노트북은 Python 3.12.13 새 커널에서 14개 코드 셀을 실행했고 오류 출력은 없습니다. 기본 변환, `int_type`, `extra_forbidden`, 정상 주문, `JSONDecodeError`, `greater_than_equal`을 실제 출력과 대조했습니다. 마크다운 교정 뒤에도 코드·출력 해시는 유지됐습니다. 생성원은 Python 구문 검사를 통과했고, 메모리에서 생성한 6개 노트북의 셀 소스가 현재 파일과 일치합니다.

HTML 6개의 고정 제목 10개와 노트북·SVG 삽입 표시를 확인했습니다. 금지 어휘와 Ch 6의 조기 에이전트 구현은 발견하지 못했습니다. LSP·ast-grep 도구는 없어 HTML 파서·정적 검색·Python 컴파일·노트북 실행 기록을 사용했습니다.

## 한국어 감사와 Phase 6

초보자용 기술 산문으로 검토했습니다. `ai-slop-reviewer`와 `korean-humanize` 기준으로 전문을 읽고 범주 혼합·과일반화·운영 설명 과다를 국소 교정했습니다. 코드·수치·고유명사·출처와 제목의 독립성, 부정·조건, 예시, 선수 학습 연결을 대조했습니다. 2초·0.3초는 설명용 가정으로 표시했습니다.

Phase 6 최종 정독 판정은 `corrected`입니다. 의미 보존 15항을 대조했으며 과윤문과 근거 없는 주장 추가는 발견하지 못했습니다. 이 챕터 검토는 정독 판정이며 별도의 정량 언어 게이트 실행을 완료했다고 주장하지 않습니다. 안내 문서의 정량 게이트 결과는 `guidance-language-review.md`에 별도로 있습니다.

외부 맞춤법 서비스에는 공개 교재 원문을 대량 전송하지 않았습니다. 해당 스킬의 대량·상업적 처리 제한에 따라 외부 검사를 생략하고 로컬 정독으로 대체했습니다. 외부 Codex 감사 도구는 사용하지 않았습니다.

독립 검토는 최종 HTML 재빌드·화면 검증 통과를 조건으로 승인했습니다. 리더가 교정 후 수행한 검증 결과는 `final-checks.json`과 `verification.md`에 기록했습니다.
