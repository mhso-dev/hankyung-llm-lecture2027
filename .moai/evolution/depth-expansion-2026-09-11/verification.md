## 변경 범위

Ch 6의 정본 HTML 조각 6개에 개념 비교와 상황 예시를 추가했습니다. 03절 노트북에 타입 변환·엄격한 검증·추가 필드·주문 데이터의 JSON 문법과 값 제약을 확인하는 코드 셀 5개를 추가했습니다. 비용 설명을 늘리는 개정은 하지 않았습니다. 노트북 생성 원본에도 같은 예시를 반영했습니다.

집필 기준은 `textbook/AUTHORING.md`와 `textbook/_template/README.md`에 반영하고 `.moai/context.md`·`.moai/evolution/signals.md`에 사용자 요구와 반영 범위를 남겼습니다. 전체 34개 챕터·214절은 구조를 집계했습니다. Ch 6 이외의 33개 챕터는 예시 보강 후보를 정리한 단계이며 본문 개정 완료 대상이 아닙니다.

## 실행과 비교

| 검증 | 결과와 범위 |
| --- | --- |
| 변경 노트북 새 커널 실행 | Python 3.12.13, 코드 14셀, 오류 출력 0개. 기존 실제 모델 호출 3개를 포함한 전체 실행 |
| 기존 코드 보존 | 원래 코드 9셀의 내용과 순서를 그대로 유지하고 비교 예시 5셀 추가 |
| 로컬 비교 결과 | 문자열 `"2"`는 기본 검증에서 정수로 변환, 엄격 검증에서는 `int_type`, 추가 키는 `extra_forbidden` |
| 주문 예시 | 정상 주문 통과, JSON 문법 오류는 `JSONDecodeError`, 수량 0은 `greater_than_equal` |
| 모델의 범위 충돌 응답 | 허용 범위의 응답과 `parsing_error=None` 확인. 검증 실패를 관찰했다고 서술하지 않음 |
| 생성원 동기화 | 격리 메모리 생성 결과와 실제 노트북 6개의 셀 소스가 모두 일치. 생성원 구문 검사 통과 |

03절의 이후 문장 교정은 마크다운에 한정했습니다. 코드와 실행 출력의 해시를 보존하고 HTML을 다시 빌드했습니다. 다른 5개 노트북은 코드가 바뀌지 않아 API를 다시 호출하지 않았으며 기존 실행 검증과 최종 HTML 일치를 확인합니다.

## 화면과 배포

공통 검증기의 Ch 6 검사에서 6절·53개 코드 셀, 최대 22줄을 확인했습니다. 1280px와 390px 화면에서 목차 1개와 본문 6개, 총 14건의 글자 크기·대비·잘림·가로 넘침·그림 경계·셀 복사·전체 복사·다운로드 대조 14건이 모두 통과했습니다. 최종 결과는 `final-checks.json`에 기록했습니다.

Part 2 묶음과 전체 실습 묶음은 수정 노트북을 포함하도록 재생성했습니다. 파일 목록의 해시와 압축 내부 파일 해시를 대조하고, 최종 파일 상태를 `final-artifacts.json`에 저장했습니다. 생성된 HTML을 직접 고치지 않고 정본과 빌더로 생성합니다.

## 독립 검토와 확인 필요 항목

안내 문서의 한국어 검토는 `guidance-language-review.md`, Ch 6의 기술·한국어 검토는 `chapter-review.md`에 기록합니다. 스키마 방식과 원본 응답 옵션의 구분, JSON 문법과 값 제약·사실 확인의 구분, Ch 2 선수 학습 연결, 첫 비어 있지 않은 텍스트 청크 기준, 설명용 가정과 실제 측정의 구분을 검토했습니다.

외부 맞춤법 서비스에는 문서를 전송하지 않았습니다. `korean-spell-check` 스킬의 대량·상업적 처리 제한을 고려해 외부 검사 단계를 생략하고 로컬 맞춤법·문체·원문 의미 대조를 수행했습니다. 외부 서비스에 의한 맞춤법 검사가 완료되었다고 표시하지 않습니다.

추가한 상황 비교 중 실행 코드가 없는 것은 설명용 사례입니다. 제공자별 모든 옵션을 새로 실행한 것은 아니며, 실제 설치 소스·시그니처 확인과 노트북의 실제 실행 범위를 구분합니다. 전체 214절의 기술 재검증과 본문 개정은 이번 완료 범위에 포함하지 않습니다.
