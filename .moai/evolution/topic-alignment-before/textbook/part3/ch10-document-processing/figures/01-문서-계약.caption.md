# 파일이 달라도 본문과 출처를 같은 두 칸에 담는다

- 설명 대상: 파일별 읽기 도구는 본문을 page_content에, 출처를 metadata에 담아 반환합니다.
- 캡션: 파일별 읽기 도구는 본문을 page_content에, 출처를 metadata에 담아 반환합니다.
- 시선 순서: 왼쪽 입력 → 가운데 변환 또는 비교 → 오른쪽 결과
- alt: PDF 원본이 로더를 거쳐 본문과 출처 메타데이터를 가진 Document 객체로 변환되는 흐름
- 삽화 판단: 구성 요소와 관계를 정확히 표시해야 하므로 기술 도식이 더 적합합니다.
