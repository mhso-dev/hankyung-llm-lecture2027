# 구조 청킹과 의미 청킹 — 경계를 정하는 신호가 다르다

- 설명 대상: 구조 청킹은 문서 작성자가 남긴 제목을 사용하고, 의미 청킹은 인접 문장의 임베딩 거리가 임계값을 넘는 지점을 사용합니다.
- 캡션: 구조 청킹은 문서 작성자가 남긴 제목을 사용하고, 의미 청킹은 인접 문장의 임베딩 거리가 임계값을 넘는 지점을 사용합니다.
- 시선 순서: 왼쪽 입력 → 가운데 변환 또는 비교 → 오른쪽 결과
- alt: 제목 계층을 따라 나누는 구조 청킹과 문장 임베딩 거리의 임계값을 따라 나누는 의미 청킹의 비교
- 삽화 판단: 구성 요소와 관계를 정확히 표시해야 하므로 기술 도식이 더 적합합니다.
