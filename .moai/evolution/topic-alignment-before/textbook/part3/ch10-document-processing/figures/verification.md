# Ch 10 도식 검증 기록

- 생성기: `_gen_figures.py`
- 산출물: 8개 도식의 SVG, Excalidraw JSON, 접근성 캡션
- 구조 검증: 도식당 상자 7개 이하, 표시 글자 14px 이상, 요소가 viewBox 안에 배치됨
- 접근성 검증: SVG마다 `title`과 `desc`를 포함함. 파랑 `#1e40af`, 초록 `#166534`, 노랑 `#92400e`, 빨강 `#991b1b`, 보조 글자 `#595959`를 사용했으며, 흰색과 도식 영역의 합성 배경을 기준으로 측정한 최소 명암비는 4.63:1임
- 일치성 검증: SVG와 Excalidraw JSON은 같은 요소 목록에서 생성되며, 생성기를 연속 실행해도 파일 해시가 같음
- 모바일 표시: SVG의 원래 너비를 유지하고 바깥 래퍼에서 가로 스크롤하도록 빌드 CSS에서 처리함
- Excalidraw MCP: 현재 세션의 도구 목록에 `read_me`와 `create_view`가 없어 MCP 초안 미리보기를 실행하지 못함
- 삽화 판단: 8개 주제 모두 형식 분기, 데이터 흐름, 실험 조합처럼 정확한 라벨과 관계가 핵심이므로 삽화보다 기술 도식이 적합함. Higgsfield 삽화는 생성하지 않음
