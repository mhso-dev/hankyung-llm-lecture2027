1학습 목표

  • 값을 변수에 저장하고 이름을 사용해 다시 읽을 수 있습니다.
  • 정수·실수·문자열·불리언 자료형을 출력 결과에서 구분할 수 있습니다.
  • 계산 전에 문자열을 정수로 변환해야 하는 이유를 설명할 수 있습니다.

2이 내용을 배우는 이유

프로그램은 이름, 수량, 가격, 회원 여부처럼 성격이 다른 값을 처리합니다. 주문 수량을 매번 숫자 2로 직접 적으면 그 값이 무엇을 뜻하는지 알기 어렵고, 수량을 바꿀 때 여러 줄을 찾아야 합니다. 값에 quantity라는 이름을 붙이면 읽는 사람은 뜻을 파악할 수 있고 프로그램은 같은 값을 여러 계산에 사용할 수 있습니다. 이 절에서는 값을 저장하고 계산하며, 입력의 자료형이 예상과 다를 때 결과가 어떻게 달라지는지 확인합니다.

3앞에서 배운 내용

Ch 1에서 Python 3.12가 선택된 터미널과 노트북 셀을 준비하고 print()로 출력을 확인했습니다. 이 절의 노트북은 이전 커널의 변수에 의존하지 않습니다. 첫 셀부터 실행하면 상품 이름과 주문 정보가 새로 만들어집니다. 코드 셀 왼쪽의 실행 번호가 1부터 6까지 이어지는지 확인합니다.

4핵심 개념

값에 이름표를 붙입니다

창고 선반의 상자에 “무선 키보드”라고 표시하면 상자를 열지 않아도 내용을 짐작할 수 있습니다. Python의 변수(variable)는 값을 가리키는 이름입니다. product_name = "무선 키보드"에서 product_name은 변수이고 오른쪽 문자열이 값입니다. 등호로 오른쪽 값을 왼쪽 이름에 연결하는 일을 대입(assignment)이라고 합니다. 이 문장은 오른쪽부터 읽어 “문자열을 product_name에 저장합니다”라고 해석합니다. 수학의 등식과 달리 “두 항이 같다”는 판정이 아닙니다.

자료형(type)은 값의 종류와 사용할 수 있는 연산을 정합니다. 정수(int)는 2처럼 소수점이 없는 수, 실수(float)는 39000.0처럼 소수점이 있는 수입니다. 문자열(str)은 "무선 키보드"처럼 글자를 따옴표로 감싼 값입니다. 불리언(bool)은 참과 거짓을 나타내는 True와 False입니다. 문자열 "2"와 정수 2는 화면에 비슷하게 보이지만 가능한 연산이 다릅니다.

함수 호출은 print(...)처럼 함수 이름 뒤에 소괄호를 붙여 기능을 실행하는 표기입니다. 소괄호 안의 값이 함수의 입력이고, 함수가 만든 값이 반환값입니다. type(quantity)는 변수의 값을 입력받아 자료형을 반환합니다. f"상품: {product_name}"의 앞글자 f는 중괄호 안의 변수 값을 문자열에 넣겠다는 뜻입니다. :.0f와 :.0%는 출력 모양만 정하며 저장된 숫자를 바꾸지 않습니다.

5실행 예제

준비 셀의 입력은 상품 이름, 수량 2개, 단가 39000.0원, 회원 여부 True입니다. 각 대입문의 오른쪽 값이 처리되어 왼쪽 변수에 저장됩니다. 기본 실행에서 *는 수량과 단가를 곱하고, 결과 78000.0을 order_total에 저장합니다. type(quantity).__name__은 자료형 객체에서 이름을 읽어 int를 반환하고 단가는 float를 반환합니다.

다음 셀의 입력은 주문 금액과 할인율 0.1입니다. 곱셈으로 할인액 7800.0을 처리하고, 뺄셈으로 결제 금액 70200.0을 만듭니다. :.0%는 0.1을 화면에서 10%로 표시합니다. 값 하나 변경 셀에서는 상품 이름과 단가를 고정하고 수량만 2에서 3으로 바꿉니다. 원래 변수를 덮어쓰지 않아 78000원과 117000원을 나란히 비교할 수 있습니다.

6일부러 실패해 보기

화면 입력이나 CSV 파일에서 읽은 "2"는 숫자 모양이지만 문자열일 수 있습니다. Before 셀에서 문자열 "2"에 3을 곱하면 오류가 발생하지 않고 222가 출력됩니다. 문자열 곱셈은 같은 글자를 지정한 횟수만큼 반복하기 때문입니다. 주문 수량 6을 기대했다면 실행은 끝났어도 계산 결과는 잘못되었습니다.

After 셀은 int(input_quantity)로 값을 정수로 변환한 뒤 같은 3을 곱합니다. 변환 전 자료형은 str, 변환 후 자료형은 int, 계산 결과는 6입니다. 마지막 assert는 결과가 실제로 6인지 확인합니다. 변환할 문자열이 "두 개"처럼 숫자 형식이 아니면 int()가 실패합니다. 사용자 입력을 처리할 때는 Ch 2의 파일과 예외 절에서 그 실패도 다룹니다.

7주의할 점과 실무 메모

  • 변수 이름은 q보다 quantity처럼 뜻을 드러내게 작성합니다. 가격의 단위도 이름이나 설명에 적어야 39000이 원인지 다른 통화인지 판단할 수 있습니다.
  • float는 일부 소수를 이진수로 근사해 저장합니다. 금액을 정확히 정산하는 프로그램은 정수 원 단위나 decimal.Decimal 사용을 검토합니다.
  • bool 값은 True와 False로 첫 글자를 대문자로 씁니다. 따옴표를 붙인 "False"는 불리언이 아니라 글자입니다.
  • type() 출력은 학습과 진단에 유용합니다. 실제 업무 코드에서는 입력 형식과 변환 규칙을 문서로 정하고 경계에서 확인합니다.

8정리와 다음 절

  • 변수는 값을 가리키는 이름이며 대입문으로 연결합니다.
  • 정수·실수·문자열·불리언은 사용할 수 있는 연산이 다릅니다.
  • 문자열 입력을 숫자 계산에 사용하려면 계산 전에 알맞은 수 자료형으로 변환합니다.

9복습 문제

문제와 해설

1. quantity = 2에서 변수와 값은 각각 무엇입니까?

정답: 변수는 quantity, 값은 정수 2입니다. 등호는 오른쪽 값을 왼쪽 이름에 대입합니다.

2. 노트북에서 quantity와 unit_price의 자료형 이름은 무엇으로 출력됩니까?

정답: 각각 int와 float입니다. 값 2에는 소수점이 없고 39000.0에는 소수점이 있습니다.

3. 단가를 유지하고 수량을 2에서 3으로 바꾸면 주문 금액은 얼마에서 얼마로 변합니까?

정답: 78000원에서 117000원으로 변합니다. 39000원짜리 상품 한 개가 추가된 차이입니다.

4. 문자열 "2" * 3이 6이 되지 않는 이유와 수정 방법을 쓰십시오.

정답: 문자열 곱셈은 글자를 반복하므로 "222"가 됩니다. int("2") * 3처럼 정수로 변환하면 6을 얻습니다.
