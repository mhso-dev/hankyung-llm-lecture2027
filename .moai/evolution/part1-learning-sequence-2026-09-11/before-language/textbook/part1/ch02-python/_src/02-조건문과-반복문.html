1학습 목표

  • if·elif·else로 금액 구간에 맞는 한 경로를 실행할 수 있습니다.
  • for와 while 반복의 종료 조건을 설명할 수 있습니다.
  • break와 continue가 반복 순서에 미치는 영향을 출력에서 확인할 수 있습니다.

2이 내용을 배우는 이유

주문 금액이 50000원 이상이면 배송비를 받지 않고, 그보다 작으면 배송비를 더해야 합니다. 주문이 세 건이면 같은 판정을 세 번 적용해야 합니다. 모든 경우를 줄마다 복사하면 기준이 바뀔 때 여러 곳을 수정해야 하고 일부 주문을 빠뜨릴 수 있습니다. 조건문은 어떤 문장을 실행할지 고르고, 반복문은 같은 처리 규칙을 여러 값에 적용합니다. 프로그램이 값을 저장하는 단계를 넘어 실제 규칙에 따라 행동하려면 두 흐름을 함께 이해해야 합니다.

3앞에서 배운 내용

앞 절에서 변수에 주문 수량과 금액을 저장하고 숫자 자료형으로 계산했습니다. 이 절에서는 세 주문 금액 [18000, 42000, 65000]과 무료 배송 기준 50000을 새 커널에서 준비합니다. 대괄호로 묶인 여러 값은 다음 절에서 자세히 배울 목록입니다. 지금은 앞에서부터 금액을 하나씩 꺼낼 수 있는 묶음으로 사용합니다.

4핵심 개념

갈림길과 반복 구간

배송 규칙표에서 주문 금액에 맞는 행 하나를 고르는 과정이 조건문과 비슷합니다. 조건문(conditional statement)은 참이나 거짓으로 판단되는 조건에 따라 실행 경로를 고릅니다. >=는 “크거나 같다”, <는 “작다”, ==는 “두 값이 같다”라고 읽는 비교 연산자입니다. 비교 결과는 불리언 True 또는 False입니다. if 조건:의 콜론은 다음 들여쓰기 블록이 해당 조건에 속함을 나타냅니다. elif는 앞 조건이 거짓일 때 확인할 추가 조건이고, else는 앞의 모든 조건이 거짓일 때 실행합니다. 위에서부터 검사하며 처음 참이 된 한 경로만 실행합니다.

반복(iteration)은 정해진 규칙을 여러 번 적용하는 일입니다. for amount in test_amounts:는 묶음에서 값을 하나씩 꺼내 amount에 저장하고 들여쓴 블록을 실행합니다. while 조건:은 조건이 참인 동안 계속 실행하므로 반복 중에 조건을 거짓으로 만드는 변화가 필요합니다. index += 1은 현재 값에 1을 더해 다시 저장하는 복합 대입입니다. break는 반복 전체를 즉시 끝내고, continue는 현재 차례의 남은 문장을 건너뛰고 다음 차례로 이어집니다.

len(목록)은 항목 수를 반환합니다. 위치 번호는 0부터 시작하므로 길이가 5인 목록의 위치는 0부터 4까지입니다. range(4)는 끝값 4를 포함하지 않고 0, 1, 2, 3을 제공합니다. enumerate(목록)는 존재하는 각 항목에 위치 번호를 붙여 두 값을 함께 제공합니다. 이 함수들은 입력 묶음을 직접 바꾸지 않습니다.

5실행 예제

기본 실행의 입력은 다섯 주문 금액과 두 배송 기준입니다. for가 금액 하나를 amount에 저장하고, 조건문이 첫 번째로 참인 경로의 배송비를 shipping_fee에 저장합니다. 49999원은 50000원 이상이 아니므로 2000원 경로로 들어가고, 50000원은 >=에 경계값이 포함되어 0원 경로로 들어갑니다. 처리 결과는 금액마다 한 줄씩 출력됩니다.

while 예제의 입력에는 정상 금액, 건너뛸 값 -1, 종료 표시 0이 함께 있습니다. len()이 반환한 항목 수보다 index가 작은 동안 위치의 값을 읽습니다. 위치 번호를 먼저 1 늘리므로 continue를 만나도 다음 항목으로 이동합니다. 0에서는 break가 실행되어 뒤의 65000원은 읽지 않으며, 처리 목록에는 18000과 42000만 남습니다.

값 하나 변경 셀은 원래 주문 세 건을 유지하고 무료 배송 기준만 50000원에서 40000원으로 바꿉니다. 두 개수 변수를 0에서 시작해 조건이 참일 때마다 1을 더합니다. 원래 기준의 누적 결과는 1건, 변경 기준의 누적 결과는 2건입니다.

{{notebook:02-조건문과-반복문|example}}

확인할 점 — while 셀에서 index += 1이 조건 검사보다 앞서 실행되므로 continue를 만나도 위치 번호가 증가합니다. 이 증가가 없다면 -1에서 같은 값을 계속 확인하게 됩니다.

6일부러 실패해 보기

목록 길이가 3이면 사용할 수 있는 위치 번호는 0, 1, 2입니다. Before 셀은 range(len(order_amounts) + 1)을 사용해 0, 1, 2, 3을 만듭니다. 앞의 세 값은 출력되지만 위치 3의 항목은 없으므로 실제 IndexError와 list index out of range 메시지가 나타납니다. range()의 끝값이 포함되지 않는다는 사실을 알고 있어도 길이에 1을 더하면 범위를 넘습니다.

After 셀은 enumerate(order_amounts)로 올바른 위치 번호와 주문 금액을 함께 받습니다. 출력은 0 18000, 1 42000, 2 65000이며 처리 건수는 3건입니다. 목록을 순서대로 처리하는 목적이라면 값만 직접 순회할 수 있습니다. 위치 번호까지 출력하거나 기록해야 할 때 enumerate()를 사용하면 범위를 따로 계산하지 않아도 됩니다.

7주의할 점과 실무 메모

  • 조건의 순서는 결과를 바꿉니다. amount >= 30000을 amount >= 50000보다 먼저 두면 65000원도 먼저 참이 된 30000원 경로로 들어갑니다.
  • while 조건에 쓰는 값을 반복 안에서 바꾸지 않으면 종료되지 않을 수 있습니다. 시작값, 변화, 종료 조건을 함께 확인합니다.
  • continue 앞에서 상태 변경이 빠지지 않았는지 확인합니다. 이 노트북은 index += 1을 먼저 실행해 다음 항목으로 이동합니다.
  • break 뒤의 항목은 처리되지 않습니다. 0 뒤의 65000원이 출력에서 빠진 이유가 업무 규칙과 일치하는지 확인해야 합니다.

8정리와 다음 절

  • if·elif·else는 위에서부터 조건을 검사해 한 경로를 실행합니다.
  • for는 항목을 순회하고 while은 조건이 참인 동안 실행합니다.
  • break는 반복을 끝내며 continue는 현재 차례만 건너뜁니다.

다음 학습과 이어지는 지점 — 다음 절에서는 반복문이 읽은 여러 값을 목록, 튜플, 딕셔너리, 집합에 목적별로 저장합니다.

9복습 문제

문제와 해설

1. 첫 주문 18000원의 배송비가 3000원인 이유를 조건 순서에 따라 설명하십시오.

정답: 50000원 이상과 30000원 이상 조건이 모두 거짓이므로 마지막 else 경로가 실행됩니다.

2. while 셀에서 실제로 처리된 주문 금액은 무엇입니까?

정답: 18000원과 42000원입니다. -1은 continue로 건너뛰고, 0에서 break가 실행되어 뒤의 65000원은 처리하지 않습니다.

3. 무료 배송 기준을 50000원에서 40000원으로 바꾸면 무료 배송 주문 수는 어떻게 달라집니까?

정답: 1건에서 2건으로 늘어납니다. 42000원이 변경한 기준을 새로 충족합니다.

4. Before 셀의 IndexError를 enumerate()가 방지하는 이유는 무엇입니까?

정답: enumerate()는 목록에 실제로 존재하는 항목과 위치 번호만 제공합니다. 길이에 1을 더한 잘못된 위치 3을 만들지 않습니다.
