1학습 목표

  • 입력값과 반환값에 타입힌트를 표시한 함수를 정의하고 호출할 수 있습니다.
  • 지역 변수와 함수 밖 변수의 범위를 출력으로 구분할 수 있습니다.
  • 변경 가능한 기본 인자가 호출 사이에서 공유되는 문제를 None으로 수정할 수 있습니다.

2이 내용을 배우는 이유

주문 금액에서 할인액을 빼는 계산을 여러 화면에서 사용한다고 가정합니다. 계산식을 매번 복사하면 한 화면만 다른 반올림 규칙을 사용할 수 있고, 수정할 곳도 늘어납니다. 계산에 이름을 붙여 한 번 정의하면 입력만 바꾸어 같은 규칙을 다시 사용할 수 있습니다. 함수는 프로그램을 역할 단위로 나누고 입력과 결과의 경계를 보여 줍니다. 이 절에서는 결제 금액 계산을 함수로 만들고, 함수 안의 변수와 기본 인자가 어디까지 유지되는지 확인합니다.

3앞에서 배운 내용

01절에서 정수와 실수로 금액을 계산했고, 03절에서 목록이 변경 가능하다는 사실과 복사 방법을 확인했습니다. 이 절의 calculate_payment()는 주문 금액 78000과 할인율 0.1을 입력으로 받습니다. 마지막 비교에서는 문자열 태그를 목록에 추가하므로 앞 절의 목록 변경과 별칭 관찰이 필요합니다.

4핵심 개념

계산 절차에 이름을 붙입니다

함수(function)는 입력을 받아 정해진 처리를 하고 결과를 제공하는 코드 묶음입니다. def 뒤에 함수 이름과 입력 자리를 적어 정의합니다. 함수 정의에 적은 amount와 discount_rate 같은 이름을 매개변수(parameter)라고 합니다. 실제 호출에서 전달하는 78000과 0.1은 인자(argument)입니다. 반환(return)은 함수가 처리한 결과를 호출한 곳으로 보내는 동작입니다.

범위(scope)는 변수 이름을 사용할 수 있는 코드 영역입니다. 함수 안에서 만든 지역 변수는 그 함수 안에서 사용하며, 함수 밖의 같은 이름을 가진 변수와 구분됩니다. 기본 인자(default argument)는 호출할 때 값을 생략하면 사용할 값입니다. 기본 목록처럼 변경 가능한 객체는 함수가 정의될 때 한 번 만들어져 호출 사이에서 공유될 수 있습니다. 타입힌트(type hint)는 입력과 반환값으로 예상하는 자료형을 코드에 적는 표시입니다. 예를 들어 amount: int는 정수를 기대하고 -> int는 정수를 반환한다는 뜻입니다. Python 실행기가 이 표시만으로 입력을 자동 변환하거나 거부하지는 않습니다.

5실행 예제

calculate_payment(amount: int, discount_rate: float) -> int는 주문 금액과 할인율을 받아 할인 후 금액을 정수로 반환합니다. 준비 셀에서 78000과 0.1을 전달하면 70200이 출력됩니다. 기본 실행은 반환값을 payment에 저장하고 1000으로 나눈 몫을 적립 예정 점수로 계산합니다. 실제 출력은 결제 금액 70200원과 적립 예정 70점입니다.

지역 변수 관찰 셀은 함수 밖 label에 "주문"을 저장합니다. make_label() 안에서도 같은 이름을 사용하지만 "주문번호 A102"를 반환한 뒤 바깥 변수를 출력하면 여전히 "주문"입니다. 두 이름은 범위가 다르므로 함수 안 대입이 바깥 값을 바꾸지 않습니다.

값 하나 변경 셀은 주문 금액 78000원을 유지하고 할인율만 0.1에서 0.2로 바꿉니다. 같은 함수가 10% 할인에는 70200원, 20% 할인에는 62400원을 반환합니다. 함수를 다시 작성하지 않고 입력만 바꾸어 같은 계산 규칙을 적용했습니다.

6일부러 실패해 보기

Before 함수는 tags: list[str] = []처럼 빈 목록을 기본값으로 둡니다. 이 목록은 호출할 때마다 새로 만들어지지 않습니다. 첫 호출 직후 복사한 상태는 ['신규']입니다. 두 번째 호출에서 "배송"을 추가한 뒤 첫 번째 반환값을 다시 확인하면 ['신규', '배송']으로 바뀌어 있습니다. 두 번째 반환값도 같은 두 태그를 담고, first_tags is second_tags가 True입니다. 호출마다 독립된 태그 목록을 기대했다면 잘못된 결과입니다.

After 함수는 기본값을 None으로 둡니다. 함수 안에서 tags is None일 때 새 빈 목록을 만든 뒤 태그를 추가합니다. 첫 호출 결과는 ['신규'], 두 번째 호출 결과는 ['배송']이고 같은 객체인지 확인한 값은 False입니다. list[str] | None은 문자열 목록 또는 값이 없음을 나타내는 None을 받을 수 있다는 표시입니다. 마지막 두 assert가 두 결과가 분리되었는지 확인합니다.

7주의할 점과 실무 메모

  • 함수 이름은 calc()보다 calculate_payment()처럼 역할이 드러나게 작성합니다. 함수 하나에는 설명할 수 있는 한 역할을 둡니다.
  • 함수 안에서 print()만 실행하고 반환하지 않으면 결과를 뒤 계산에 사용하기 어렵습니다. 호출한 곳에서 필요한 값은 return으로 제공합니다.
  • 타입힌트는 실행 중 검증을 대신하지 않습니다. 외부 입력의 실제 자료형과 허용 범위는 프로그램 경계에서 확인해야 합니다.
  • 목록·딕셔너리·집합처럼 변경 가능한 값을 기본 인자로 직접 만들지 않습니다. None을 기본값으로 두고 함수 안에서 새 객체를 만듭니다.

8정리와 다음 절

  • 함수는 매개변수로 입력을 받고 return으로 결과를 반환합니다.
  • 지역 변수는 함수 안의 범위에 속하며 바깥의 같은 이름과 구분됩니다.
  • 변경 가능한 기본 인자는 호출 사이에 공유되므로 None을 사용해 새 값을 만듭니다.

다음 학습과 이어지는 지점 — 다음 절에서는 파일에서 읽은 문자열을 함수에 전달하고, 파일이 없거나 숫자 변환이 실패할 때 발생하는 예외를 처리합니다.

9복습 문제

문제와 해설

1. calculate_payment(78000, 0.1)에서 매개변수와 인자를 구분하십시오.

정답: 함수 정의의 amount와 discount_rate가 매개변수이고, 호출에서 전달한 78000과 0.1이 인자입니다.

2. 78000원에 10%와 20% 할인을 적용한 반환값은 각각 얼마입니까?

정답: 10% 할인은 70200원, 20% 할인은 62400원입니다. 주문 금액은 같고 할인율만 바뀌었습니다.

3. make_label()을 호출한 뒤 바깥 label이 여전히 "주문"인 이유는 무엇입니까?

정답: 함수 안의 label은 지역 변수이며 함수 밖 변수와 범위가 다르기 때문입니다.

4. 빈 목록을 기본 인자로 직접 두었을 때 관찰한 문제와 수정 방법을 쓰십시오.

정답: 같은 목록이 두 호출에 공유되어 두 태그가 함께 남고 객체 동일성도 True였습니다. 기본값을 None으로 두고 함수 안에서 새 목록을 만들면 호출 결과가 분리됩니다.
