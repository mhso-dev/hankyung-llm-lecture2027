## 01 변수와 자료형

- 발견한 누락: 대입문을 오른쪽부터 읽는 방법, 함수 호출의 소괄호, `type(...).__name__`, f-string의 중괄호, `:.0f`와 `:.0%`, `assert`와 `==`가 설명 전에 등장했습니다.
- 수정 위치: HTML 4·5블록과 노트북의 실행 환경, 기본 실행, 중간 관찰, Before/After 설명 셀을 보강했습니다.
- 실제 선수 개념: Ch 1의 노트북 셀 실행과 `print()`만 사용합니다. 변수·대입·자료형·형식 문자열은 이 절에서 처음 정의합니다.
- 코드 연결: `quantity * unit_price`는 입력 2와 39000.0을 처리해 78000.0을 만들고, 화면에는 `:.0f`로 78000원을 표시합니다. 문자열 `"2" * 3`과 `int("2") * 3`의 차이를 출력 222와 6으로 연결했습니다.

## 02 조건문과 반복문

- 발견한 누락: `>=`, `<`, `==`, 콜론과 들여쓰기, `for ... in ...`, `len()`, 위치 번호, `+=`, `append()`, `range()`, `enumerate()`가 한꺼번에 등장했습니다. 목록 자체는 03절의 주제입니다.
- 수정 위치: HTML 3~6블록과 노트북의 준비, 기본 실행, 중간 관찰, 값 변경, Before/After 설명 셀을 보강했습니다.
- 실제 선수 개념: 01절의 변수·숫자·불리언·비교 결과를 사용합니다. 목록은 “여러 값을 앞에서부터 읽는 묶음”으로만 먼저 안내하고 구조 선택은 03절로 넘겼습니다. 예외 처리는 05절 선수 개념이므로 Before 셀에서 사용 목적만 짧게 예고했습니다.
- 코드 연결: 다섯 금액을 세 배송비 경로에 연결하고 49999와 50000으로 경계를 해석했습니다. `while`에서는 위치 증가 → 음수 건너뛰기 → 0에서 종료 → 정상 금액 추가 순서를 출력 `[18000, 42000]`과 연결했습니다.

## 03 자료구조

- 발견한 누락: 네 자료구조의 괄호 모양과 읽기 방식, 딕셔너리의 콜론, `set()`·`sorted()`·`len()`·`append()`의 입력과 반환, `is`의 의미가 압축되어 있었습니다.
- 수정 위치: HTML 4블록과 노트북의 준비, 기본 실행, 중간 관찰, 값 변경, Before/After 설명 셀을 보강했습니다.
- 실제 선수 개념: 01절의 변수와 자료형, 02절의 반복과 위치 번호를 사용합니다. 목록·튜플·딕셔너리·집합의 선택 기준과 변경 가능성은 이 절에서 처음 정의합니다.
- 코드 연결: 같은 주문 정보를 목록·튜플·딕셔너리·집합으로 표현하고 위치·키·포함 검사로 읽습니다. 대입과 복사의 차이는 `cart is backup`의 True/False 및 두 목록의 실제 출력으로 연결했습니다.

## 04 함수

- 발견한 누락: 함수의 기본 정의와 호출보다 타입 힌트와 지역 범위가 먼저 등장했습니다. 타입 힌트는 07절의 학습 주제이므로 선수 순서를 위반했습니다. `//`, 기본값, `None`, 매개변수와 인자의 대응도 추가 설명이 필요했습니다.
- 수정 위치: HTML 학습 목표와 4~7·10블록, 노트북 전체 설명 셀을 고쳤습니다. 모든 함수 정의에서 타입 힌트를 제거했습니다.
- 실제 선수 개념: 01절의 변수·계산, 03절의 목록·변경 가능성·복사를 사용합니다. `def`·호출·매개변수·인자·처리·`return`·지역 범위·기본값은 이 절에서 처음 정의합니다. 타입 힌트는 07절로 넘겼습니다.
- 코드 연결: `calculate_payment(78000, 0.1)`의 두 입력이 할인액 계산과 반올림을 거쳐 70200을 반환하고, 반환값이 적립 점수 계산의 다음 입력이 되는 흐름을 명시했습니다. 가변 기본값 문제는 같은 객체 True에서 호출별 객체 False로 바뀌는 출력과 연결했습니다.

## 05 파일과 예외

- 발견한 누락: `from ... import ...`, `Path`의 `/`, `write_text()`·`read_text()`·`splitlines()`·`split()`의 입력과 반환, 다중 대입, 목록 컴프리헨션, 함수 타입 힌트가 설명 전에 등장했습니다. 모듈과 타입 힌트는 07절의 주제입니다.
- 수정 위치: HTML 4·5·9블록과 노트북 전체 설명 셀을 보강했습니다. 함수 타입 힌트를 제거하고 두 목록 컴프리헨션을 02절의 `for`와 03절의 `append()`로 바꿨습니다.
- 실제 선수 개념: 02절의 반복, 03절의 목록·튜플·`append()`, 04절의 함수 입력·처리·반환을 사용합니다. 모듈 가져오기는 필요한 이름을 준비하는 표기로만 예고하고 상세는 07절로 넘겼습니다.
- 코드 연결: 경로 입력 → UTF-8 전체 문자열 → 줄 목록 → 쉼표 분리 → 정수 변환 → 튜플 반환 순서를 실제 출력과 연결했습니다. 누락 파일만 빈 목록으로 바꾸고 다른 예외는 유지하는 경계를 Before/After에 명시했습니다.

## 06 클래스

- 발견한 누락: `class`, 클래스 호출, `__init__`, `self`, 점 표기, 속성과 메서드, 인스턴스 속성과 클래스 속성의 차이보다 타입 주석이 먼저 등장했습니다.
- 수정 위치: HTML 3~5블록과 노트북 전체 설명 셀을 보강했습니다. 클래스 속성, 인스턴스 속성, 메서드 정의에서 타입 힌트를 제거했습니다.
- 실제 선수 개념: 03절의 변경 가능한 목록과 객체 동일성, 04절의 함수 정의·호출·매개변수, 05절까지의 주문 데이터 예제를 사용합니다. 클래스·인스턴스·속성·메서드·초기화·`self`는 이 절에서 처음 정의합니다. 타입 힌트는 07절로 넘겼습니다.
- 코드 연결: `Order("민지")` 입력이 `customer`로 전달되고 새 인스턴스가 `first`에 저장되는 흐름, `first.add("노트")`에서 `first`가 `self`로 전달되는 흐름을 설명했습니다. 클래스 목록 공유 문제는 두 번째 주문 `['노트']`와 수정 후 빈 목록 출력으로 연결했습니다.
