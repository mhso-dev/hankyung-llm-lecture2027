# 독립 검토 후 통합 수정

## Ch 1

검토자가 지목한 코드의 뜻, 객체의 속성과 메서드 표기, `is not None`·단언문의 안내 문자열·`and`, 연산자, Docker 준비 판정의 `strip`·`bool`을 HTML과 노트북 설명에 반영했습니다. 복습 해설의 미정의 용어 ‘피연산자’는 ‘더하는 두 값’으로 풀었습니다. 코드·실행 번호·출력은 보존했습니다. 독립 검토자는 반영 위치를 다시 읽고 `accept`로 판정했습니다. PC·모바일 화면과 복사·다운로드 검사 12건도 통과했습니다.

## Ch 2 01~06

03절에 객체와 변수 이름의 관계를 설명했습니다. 04절의 `//`는 음수에도 맞는 내림 정의로 고치고 현재 양수 예제의 70.2→70을 연결했습니다. 06절의 ‘생성자’는 이미 정의한 ‘초기화 메서드’로 통일하고 `is not`을 설명했습니다. 위 세 절은 코드·출력을 바꾸지 않았습니다.

05절은 복습에서 묻던 `연필,많이`의 변환 오류를 실제로 관찰하도록 After 셀에 추가했습니다. 파일 누락을 처리하는 함수와 수량을 변환하는 함수의 역할을 구분하고, 바깥의 예외 처리문은 관찰을 위한 것임을 설명했습니다. 공통 실행기로 Python 3.12 새 커널에서 6개 코드 셀을 순차 실행하여 통과했으며, 변경된 셀은 18줄입니다.

## 관찰과 검증의 구분

12절의 동시 작업 순서에 강제 단언문을 추가하자는 제안은 채택하지 않았습니다. 스케줄링 조건에 따라 관찰 순서는 달라질 수 있습니다. ‘이번 실행에서 관찰한 순서’와 ‘세 사건이 모두 완료되었는지 검사한 조건’을 본문과 노트북에서 구분하도록 수정했습니다. 두 가지 존대 질문 종결을 일괄 통일하자는 제안도 학습을 막는 오류가 아니므로 채택하지 않았습니다.

## Ch 5 실행 기록 복구

첫 통합 빌드에서 8개 중 7개 노트북의 최상위 실행 검증 메타데이터가 누락된 사실을 발견했습니다. 작성자의 생성기 비교 과정에서 셀 출력은 보존했지만 검증 메타데이터를 덮어쓴 것이 원인이었습니다. 실행 기록을 수동으로 붙이지 않고 공통 실행기로 7개를 새 커널에서 다시 실행했습니다. 이후의 교육 검토 수정도 최종 실행 기록과 코드·출력 해시를 기준으로 검증합니다.


## Ch 2 기본 학습 경로와 Ch 3 충돌 예제

타입힌트는 07절부터 도입하고, 기본 A 경로의 pytest 예제는 선택 B 경로의 일반 데코레이터를 선수 지식으로 요구하지 않도록 필요한 표기를 직접 설명했습니다. `finally`·`with`를 앞에서 배웠다는 잘못된 안내를 수정했습니다. async 예제는 코루틴 생성·태스크 예약·대기·출력·반환을 구분하며, 관찰 순서를 실행 환경 전체의 보장으로 확대하지 않습니다.

Git 충돌 예제는 Bob이 공통 초기 커밋에서 복제한 뒤 Alice와 서로 다른 변경을 하도록 수정했습니다. 뒤 절의 `reset --hard`를 먼저 사용하지 않습니다. 커밋 관례와 경로·출력 탐색 표기도 첫 사용 전에 설명합니다. 생성기와 실행 노트북의 셀 원문을 대조했습니다.

## Ch 4 관찰 가능한 비교

02절에서 정상 합계 77,000원, 중복 조인 합계 136,000원, 수정 합계 77,000원을 실제 계산합니다. 03절은 SQL 별칭과 `USING`을 설명하고 연결을 `try/finally`로 명시적으로 닫습니다. 04절의 기본 페이지네이션 함수는 주소와 대기 시간만 받으며, 요청·누적·다음 페이지·종료를 보여 줍니다. 공용 모듈의 확장 기능은 기본 노트북과 구분했습니다. 05절에는 같은 HTML에 서로 다른 선택자를 적용하는 비교를 추가했습니다. HTML과 노트북에 `astype`, `assign`, `parse` 등 첫 메서드 설명을 맞췄습니다. 공용 모듈 테스트 10개를 실행해 통과했습니다.

## Ch 5 기본 개념과 실험 범위

벡터 정의와 2차원 예제를 실제 임베딩 앞에 두고, 배열의 모양·축·점곱 표기를 설명했습니다. 어텐션 예제의 수작업 가중치는 실제 모델 내부 측정값과 구분합니다. 컨텍스트 실험은 실제 모델 한도와 입력·출력 길이를 확인하고, 다음 절의 temperature·seed·top_p를 먼저 쓰지 않도록 결정적 생성으로 정리했습니다. 두 환각 응답만으로 내부 학습 원인을 추론하던 표현을 수정했습니다. 첫 반환과 화면 출력을 구별하고 두 노트북 생성기에 같은 문장을 반영했습니다. 마지막 코드 수정 뒤 8개 노트북을 모두 새 커널에서 실행했습니다.
