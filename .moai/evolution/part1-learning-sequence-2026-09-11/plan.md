# Part 1 설명 순서 개정

대상은 Ch 1~5의 35절과 대응 노트북입니다. 사용자 지적의 핵심은 처음 등장하는 개념·메서드를 설명하지 않은 채 예시와 옵션으로 넘어가는 문제입니다. 분량이나 옵션 수를 늘리는 것을 완료 기준으로 삼지 않습니다.

1. 각 절을 순서대로 읽고 첫 등장 용어·문법·함수와 실제 선수 학습 위치를 확인합니다.
2. 해결할 문제, 개념의 뜻, 코드 표기 읽는 법, 입력·처리·반환, 기본 실행·출력 해석을 사용보다 앞에 둡니다.
3. 기본 동작을 이해한 뒤 다른 상황·조건 변경·반례를 설명합니다. 새 예시는 학습 질문에 직접 필요할 때만 실행 코드로 추가합니다.
4. 본문과 노트북 설명을 함께 고칩니다. 생성기가 있으면 정본과 동기화합니다. 코드 변경 시 새 커널에서 실행하고, 설명만 고치면 코드·출력 해시 보존을 확인합니다.
5. 작성자와 구분된 검토자가 처음 배우는 독자의 관점에서 다시 읽습니다. 실행·화면 통과와 교육적 설명 검토를 구분합니다.
6. 35절의 HTML·노트북 일치, PC·모바일 화면·복사·다운로드, 배포 묶음을 검증합니다.

장별 책임을 나누되 절의 학습 순서는 유지합니다. 비용·운영 관련 설명을 추가해 분량을 채우지 않습니다. 기술적 사실은 고정 환경과 공식 자료로 확인합니다. 원본은 `before/`에 보존합니다.

완료 기록에는 절마다 발견한 설명 누락, 추가한 설명의 위치, 먼저 소개한 개념, 실제 코드·출력과의 연결, 검증 결과를 남깁니다. 표에 ‘통과’만 쓰거나 문장 수만 세는 검토로 대체하지 않습니다.
