# 다양한 문서와 구형 모델 탐색 결과

2026-09-09. GPT-3.5 Turbo와 GPT-4.1 nano에 같은 세 길이의 입력을 각각 세 번 호출했습니다. 모임 B-742 → 공간 R-518 → 규정 P-361을 연결하여 최대 대출 기간 17일과 세 근거 코드를 답하는 과제입니다. 모든 이름과 문서는 합성 자료입니다. 이전 휴관일 한 문장 과제와 다른 탐색 과제이므로 이전 실험과 직접 비교하여 noise 다양성만의 효과라고 해석하지 않습니다.

정답 근거 세 문장은 보존했고, 주변 문서를 5·57·161개로 늘렸습니다. 주변 문서는 행사·공간·대출 규정·운영 메모로 구성했으며 고유 식별자로 정답 근거와 모순되지 않게 만들었습니다. 근거는 자료를 네 구간으로 나눈 경계에 같은 순서로 배치했습니다. 입력·질문·평가 기준·모델 목록·반복 수를 호출 전에 저장했습니다.

| 모델 | 주변 문서 | 실제 입력 토큰 | 기간 정답 | 근거 코드 모두 제시 |
|---|---:|---:|---:|---:|
| GPT-3.5 Turbo | 5 | 668 | 3/3 | 2/3 |
| GPT-3.5 Turbo | 57 | 4,447 | 3/3 | 2/3 |
| GPT-3.5 Turbo | 161 | 12,009 | 3/3 | 3/3 |
| GPT-4.1 nano | 5 | 469 | 3/3 | 3/3 |
| GPT-4.1 nano | 57 | 3,087 | 3/3 | 2/3 |
| GPT-4.1 nano | 161 | 8,329 | 3/3 | 2/3 |

두 모델 모두 실제 호출이 성공했습니다. 모든 응답은 출력 상한에 잘리지 않고 정상 종료했습니다. 답 18개를 정독하여 대출 기간이 모두 17일임을 확인했습니다. 누락된 근거 코드는 주로 중간 연결의 공간 코드였습니다. GPT-3.5에서 누락은 긴 조건에 집중되지 않았고, nano의 누락도 반복 세 번만으로 길이 의존 저하를 확정할 수 없습니다.

따라서 이번 탐색에서는 기간 정답 성능 저하를 관찰하지 못했습니다. 입력 한도 초과나 노골적인 잘못된 근거를 넣어 실패를 만들지 않았습니다. temperature=0에서의 반복 세 번은 큰 표본의 통계적 검증을 뜻하지 않으며, 이 결과를 일반적인 모델 순위로 사용하지 않습니다. 학생용 교재는 이 탐색 결과만으로 교체하지 않았습니다.

입력 정본: diverse-noise-inputs.json. 모든 응답 정본: diverse-noise-results.jsonl. 실행 코드: diverse_noise_probe.py.

공식 정보: https://developers.openai.com/api/docs/models/gpt-3.5-turbo · 확인 2026-09-09. 문서상 GPT-3.5 Turbo는 API에서 사용할 수 있으며 context window는 16,385토큰입니다. 이번 실제 응답 토큰 수는 그 범위 안입니다.
