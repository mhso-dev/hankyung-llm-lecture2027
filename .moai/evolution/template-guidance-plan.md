# 템플릿과 지침 업데이트 계획

1. 기존 학생 HTML·노트북과 지침 원문을 보존합니다.
2. 현재 Jupyter 화면과 공통 렌더러를 재사용하는 paired·experiment 템플릿과 생성 도구를 만듭니다. 미완성·미실행 초안은 완성 HTML로 빌드하지 않습니다.
3. 새 세션 진입 안내, 집필·검토 기준, Claude/Codex 에이전트의 오래된 지시를 함께 정리합니다.
4. 검증기의 20절 고정 조건을 실제 원본 목록 기준으로 바꾸고 새 챕터만 검증하는 경로를 제공합니다.
5. 격리된 예제로 두 형식의 생성·실제 커널 실행·빌드·복사를 검증합니다. 기존 20절 불변과 별도 검토를 확인한 뒤 완료합니다.

사용자의 명시적 템플릿 생성·지침 업데이트 요청에 따라 프로젝트 안의 템플릿·도구·진입 문서까지 수정합니다. 플러그인·스킬 원본은 수정하지 않습니다.
