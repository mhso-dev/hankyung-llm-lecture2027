## 적용 범위와 남겨 둔 절차

이번 실행 검증은 템플릿을 위한 로컬 Python 예제로 수행했습니다. 기존 교재의 API 호출을 반복하지 않았습니다. 앞으로 API를 사용하는 새 절은 실제 API 호출까지 검증해야 합니다.

자동 검사는 실행 기록과 HTML 일치를 확인합니다. 코드가 학습 주제를 설명하는지는 집필 점검표와 별도 정독으로 판단합니다. 새 챕터의 패키지 고정과 학생 시작 화면·배포 묶음 등록도 작성자가 수행하며, 사용 안내에 절차를 명시했습니다.

내부 운영 문서의 한국어 표현은 문맥과 의미 보존을 대조했습니다. 외부 맞춤법 서비스에는 전송하지 않았으며 외부 맞춤법 검사를 통과했다고 주장하지 않습니다.
