# Ch 17 Agent 개요 실습

노트북 여섯 개(`notebooks/01~06-*.ipynb`)는 Python 3.12 새 커널에서 절마다 따로 실행할 수 있습니다. 앞 절 노트북의 변수는 쓰지 않습니다. 01·02·05절은 모델을 부르지 않고, 03·04·06절은 실제 모델 `gpt-5.4-mini`를 부릅니다.

## 준비

실습 폴더(`labs/part5/ch17-agent-overview`)에서 `uv sync --locked`를 실행하고, 이 폴더의 `.venv` 커널을 고릅니다. 그다음 `notebooks/` 폴더의 노트북을 열어 첫 셀부터 차례로 실행합니다. VS Code와 Jupyter는 노트북이 있는 폴더에서 커널을 시작합니다.

03·04·06절은 API 키가 필요합니다. 프로젝트 맨 위 `.env` 파일에 `OPENAI_API_KEY`를 적어 두면 노트북이 읽습니다. 키 값은 출력하거나 파일에 저장하지 않습니다. 이 세 노트북의 첫 코드 셀은 `langchain` 1.4.0, `langchain-openai` 1.6.1, `python-dotenv` 1.2.3을 설치하고 판 번호를 출력합니다. 실습 폴더 잠금과 같은 판입니다.

## 도구 파일 `notebooks/agent_tools.py`

앞에서 배운 함수는 `notebooks/agent_tools.py`에 모아 두었습니다. 파일을 열면 코드를 볼 수 있습니다. 노트북과 같은 폴더(`notebooks/`)에 있는 파일이고, 02~06절 노트북이 `from agent_tools import …` 한 줄로 가져옵니다. 커널이 `notebooks/` 폴더에서 시작해야 이 파일을 가져올 수 있습니다.

함수 열여섯마다 어느 절에서 배웠는지 주석으로 적었습니다(01절 셋, 02절 하나, 03절 여섯, 04절 다섯, Ch 6 06절 `estimate_cost` 하나). 함수를 처음 가르치는 절은 노트북 안에 함수를 적고 설명하며, 다음 절부터 이 파일에서 가져옵니다. 이 파일은 `json`·`time`만 씁니다.

## 절마다 하는 일

- 01절은 손으로 만든 실행 기록 사례를 칸 「고른 쪽」으로 가릅니다. 모델이 고른 단계가 없으면 워크플로우, 있으면 에이전트 후보입니다.
- 02절은 진단 질문 다섯에 답해 일이 워크플로우로 충분한지 점수를 내고 추천을 냅니다.
- 03절은 모델이 다음 행동을 JSON 글로 고르고 코드가 도구 흉내를 부르는 루프를 만듭니다. 루프는 모델의 끝 선택·사람 확인·같은 도구 다시 고름·바퀴 한도로 멈춥니다.
- 04절은 같은 문의를 코드가 차례를 정한 흐름과 03절 루프로 실행해 모델 요청 수와 토큰 수, 걸린 초를 잽니다.
- 05절은 공개 자료 속 단계 차례와 제품 문서 단서를 읽고, 이 챕터의 환불 문의 흐름을 자율성 진단표로 진단합니다.
- 06절은 챕터 끝 실습 절입니다(아래).

도구는 모두 이 챕터에서 만든 도구 흉내(정해 둔 결과 글을 내놓는 파이썬 함수)라 실제 주문을 조회하거나 환불을 등록하지 않습니다. 노트북은 파일을 쓰지 않습니다.

## 자료 파일 `data/`

자료 파일 넷은 05절 노트북만 읽고 고치지 않습니다.

- `public-trace-extracts.json`은 공개 저장소의 파일 둘에서 단계 차례를 추린 자료입니다. SWE-agent 쪽은 시범 기록(demonstration)이고, mini-SWE-agent 쪽은 테스트에 쓰려고 저장한 파일입니다. 원본 커밋, 원문 주소, SHA-256 지문, MIT 라이선스를 함께 적었습니다. 두 자료의 한 일을 모델이 그 자리에서 골랐는지는 확인하지 못했습니다.
- `product-trace-evidence.json`은 Codex·Claude Code·Deep Research의 공식 문서가 공개한 단서를 정리한 자료입니다. 세 제품은 이 과정에서 실행하지 않았습니다.
- `autonomy-diagnostic-sheet.csv`는 답 칸이 빈 자율성 진단표이고, `autonomy-diagnostic-example.json`은 자료를 만든 사람이 적은 작성 예시입니다. 자료 속 영어 칸 이름과 옛 말은 원본을 옮긴 것이라 그대로 두었고, 노트북 결과 읽기에서 풀어 읽습니다.
