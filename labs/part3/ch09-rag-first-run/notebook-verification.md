## 독립 실행 조건

모든 노트북은 첫 셀에서 해당 절에 필요한 패키지 버전을 설치합니다. OpenAI API를 호출하는 다섯 노트북은 `find_dotenv(usecwd=True)`로 프로젝트 루트의 `.env`를 찾고 `OPENAI_API_KEY`의 존재를 확인합니다. API를 쓰지 않는 02절은 `.env`를 읽지 않고 설치된 패키지 버전만 확인합니다. `rag.py`, `harness.py`, `__file__`, `sys.path` 또는 다른 절에서 만든 상태를 사용하지 않습니다.

## 의도한 실패

각 노트북의 실패 셀은 예외나 실패 조건을 셀 안에서 포착합니다. 잘못된 출처 가정, 청크 크기보다 큰 겹침, 문자열 `k`, 누락된 `page` 메타데이터, `k=1`의 정답 문서 누락, 청크 설정 변경에 따른 해시 불일치를 차례로 재현했습니다. 의도한 실패 뒤의 검증 셀까지 모두 실행되었습니다.

## 제한 사항

API 응답과 검색 점수는 실행 시점에 따라 달라집니다. 05절은 이번 실행에서 확인한 검색 순위와 거부 응답을 단언문으로 검사하므로, 재실행에서 모델 결과가 달라지면 해당 검사가 실패할 수 있습니다. 이때 실패를 숨기지 않고 실제 응답과 검색 문서 ID를 다시 확인합니다. 이 검증은 수업용 소규모 문서로 실행 가능성과 단계 연결을 확인한 결과이며, 기존 176개 청크 전체 말뭉치 실험을 다시 측정한 결과는 아닙니다. 이전 전체 말뭉치 결과는 `textbook/part3/ch09-rag-first-run/qa/notebook-before/`에 보관했습니다.

2026-09-08에 01·04·05절의 생성 모델을 `init_chat_model("openai:gpt-5.4-mini")`로 초기화하고, `invoke()` 응답에서 `.text`를 읽도록 통일했습니다. 이 세 노트북은 변경 후 Python 3.12 새 커널에서 실제 API로 다시 실행했습니다. 02·03·06절은 기존 LangChain 코드와 실행 결과를 유지했습니다.
