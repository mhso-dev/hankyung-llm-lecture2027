# Ch 25 Streaming 실습

노트북 네 개(`notebooks/01~04-*.ipynb`)는 Python 3.12 새 커널에서 절마다 따로 실행할 수 있습니다. 앞 절 노트북의 변수는 쓰지 않습니다. 다만 02~04절은 앞에서 배운 함수를 같은 폴더의 도구 파일 `notebooks/stream_tools.py`에서 가져오므로, 노트북은 `notebooks/` 폴더에서 엽니다.

## 준비

실습 폴더(`labs/part6/ch25-streaming`)에서 `uv sync --locked`를 실행하고, 이 폴더의 `.venv` 커널을 고릅니다. 그다음 `notebooks/` 폴더의 노트북을 열어 첫 셀부터 차례로 실행합니다. VS Code와 Jupyter는 노트북이 있는 폴더에서 커널을 시작합니다. 노트북 파일만 다른 폴더로 옮기거나 다른 폴더에서 커널을 시작하면, 02~04절의 가져오기 셀이 `ModuleNotFoundError`로 멈춥니다.

노트북의 첫 코드 셀은 그 절에서 쓰는 패키지를 설치하고 판 번호를 출력합니다. 01절은 `langgraph` 1.2.11과 `langgraph-checkpoint` 4.2.0을 설치합니다. 02~04절은 `langchain` 1.4.0·`langchain-openai` 1.6.0·`langgraph` 1.2.11·`python-dotenv` 1.2.3을 설치합니다. 모두 실습 폴더 잠금(`uv.lock`)과 같은 판입니다.

## 모델 요청과 API 키

01절은 모델을 부르지 않습니다. 모델 요청은 0번이고, API 키가 없어도 실행됩니다.

02~04절은 실제 OpenAI 모델 `gpt-5.4-mini`를 temperature 0으로 부릅니다. 노트북을 처음부터 끝까지 한 번 실행하면, 모델 요청은 02절 2번, 03절 2번, 04절 3번입니다. 요금표(2026-09-17)로 어림한 예상 비용은 02·03절이 각각 0.001달러 아래, 04절이 0.002달러 아래입니다. 예상 비용은 요금표로 셈한 값이고, 청구 금액이 아닙니다.

API 키는 `.env` 파일의 `OPENAI_API_KEY`에서만 읽습니다. 노트북은 커널이 시작한 폴더에서 위로 올라가며 처음 찾은 `.env` 파일을 읽습니다. 그래서 키는 프로젝트 맨 위(학생 묶음이면 `part6-practice/`)의 `.env`에 적어 둡니다. 노트북은 키가 있는지만 확인하고, 키 값은 출력하거나 파일에 저장하지 않습니다.

모델의 답 글과 스트림 청크 수는 실행마다 달라질 수 있습니다. 03·04절에서 잰 초도 기기와 네트워크, 실행한 때에 따라 달라집니다. 네 노트북 모두 파일을 읽거나 쓰지 않습니다. 교재 출력은 Linux의 Python 3.12.13으로 만들었고, 다른 판과 Windows·macOS에서는 실행하지 않았습니다.

## 도구 파일 `notebooks/stream_tools.py`

앞에서 배운 함수는 `stream_tools.py`에 모아 두었습니다. 파일을 열면 코드를 볼 수 있습니다. 노트북과 같은 폴더(`notebooks/`)에 있는 파일이고, 노트북이 `from stream_tools import …` 한 줄로 가져옵니다. 커널이 `notebooks/` 폴더에서 시작해야 이 파일을 가져올 수 있습니다.

함수 일곱마다 어느 절에서 배웠는지 바로 위 주석에 적었습니다. 함수를 처음 가르치는 절은 노트북 안에 함수를 적고 설명하며, 다음 절부터 이 파일에서 가져옵니다. 함수는 노트북에서 만든 이름을 바로 읽지 않고, 필요한 값을 모두 인자로 받습니다. 파일이 가져오는 모듈은 시각을 읽는 `time` 하나입니다.

- `collect_events` — 이 챕터 01절 노트북 4절에서 배웠습니다. 그래프를 한 번 실행하며 받은 사건을 목록에 모아 내놓습니다. 02절이 가져옵니다.
- `positions_of` — 이 챕터 01절 노트북 4절에서 배웠습니다. 한 모드의 사건이 몇 번째에 나왔는지 목록으로 내놓습니다. 02·03·04절이 가져옵니다.
- `mode_order` — 이 챕터 02절 노트북 4절에서 배웠습니다. 같은 모드가 이어지면 한 번만 적어, 모드가 바뀐 차례를 내놓습니다. 03·04절이 가져옵니다.
- `estimate_cost` — Ch 6 06절에서 배웠고, Ch 21 도구 파일의 같은 이름 함수 본문을 그대로 옮겼습니다. 사용량과 요금으로 요청 한 번의 예상 비용을 셉니다. 03절이 가져옵니다.
- `collect_timed_events` — 이 챕터 03절 노트북 3절에서 배웠습니다. 그래프를 한 번 실행하며, 사건을 꺼낼 때마다 그때의 시각을 적습니다. 04절이 가져옵니다.
- `first_text_place` — 이 챕터 03절 노트북 5절에서 배웠습니다. 글자가 든 첫 스트림 청크가 몇 번째 사건인지 내놓습니다. 04절이 가져옵니다.
- `three_times` — 이 챕터 03절 노트북 7절에서 배웠습니다. 첫 사건 시간·첫 토큰 도착 시간·전체 걸린 시간을 계산합니다. 04절이 가져옵니다.

앞 챕터 도구 파일과는 따로 둔, 이 챕터만의 파일입니다. 앞 챕터 도구 파일은 이 실습 폴더에 없는 패키지를 가져와서, 파일째 가져오지 않고 이 챕터 노트북이 쓰는 함수만 옮겼습니다.

## 절마다 하는 일

- 01절은 모델 없이 노드 둘짜리 그래프를 스트림 모드 일곱으로 한 번 실행하고, 모드마다 사건 수·나온 자리·모양을 셉니다. 체크포인터를 뺀 실행과, Ch 24 01절의 멈춤 표시를 스트림 사건으로 받는 장면도 봅니다.
- 02절은 노드 안에서 모델을 부르고, 진행 값과 스트림 청크와 갱신을 한 실행에서 함께 받습니다. 스트림 청크의 글을 이어 붙여 답 글과 견주고, 모드 `messages`를 뺀 실행도 봅니다.
- 03절은 사건마다 받은 시각을 적어, 첫 사건 시간·첫 토큰 도착 시간·전체 걸린 시간을 한 요청 안에서 잽니다. 요청 한 번의 예상 비용을 셈하고, 모드 목록의 차례만 바꾼 실행도 봅니다.

## 04절 실습 — 요청 전 진행 값을 켜고 끄며 자료실 문의 답 흘려 보이기

노트북 `notebooks/04-Streaming-실습.ipynb`는 챕터 끝 실습 절입니다. 30분 안팎의 분량이고, 따로 내는 과제와 새 API는 없습니다. 01절 모드 목록, 02절 진행 값과 스트림 청크 이어 붙이기, 03절 사건마다 시각 적기를 자료실 문의 하나에 모읍니다. 모은 기능으로 문의 창 화면을 흉내 냅니다. 모델 요청은 세 번입니다.

같은 설정으로 두 번 실행한 뒤, 칸 `show_notice` 하나만 `"no"`로 바꿔 모델 요청 전 진행 값을 끄고 한 번 더 실행합니다. 도구 파일에서 함수 다섯(`collect_timed_events`·`first_text_place`·`mode_order`·`positions_of`·`three_times`)을 가져옵니다. 사건 수와 걸린 초, 답 글은 실행마다 달라질 수 있습니다.
