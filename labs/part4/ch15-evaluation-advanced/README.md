# Ch 15 평가 심화 실습

노트북 아홉 개(`notebooks/01~09-*.ipynb`)는 Python 3.12 새 커널에서 절마다 따로 실행할 수 있습니다. 앞 절의 변수는 쓰지 않고, 필요한 자료는 준비 셀에서 파일로 읽습니다. 실제 API 키 값은 노트북과 출력에 저장하지 않습니다.

`notebooks/rag_tools.py`는 앞에서 배운 함수를 모아 둔 도구 파일입니다. 파일을 열면 코드를 볼 수 있습니다. 노트북과 같은 폴더(`notebooks/`)에 있는 파일이고, 02절을 뺀 여덟 노트북이 `from rag_tools import …` 한 줄로 가져옵니다. 함수 열다섯마다 어느 챕터의 어느 절에서 배웠는지 주석으로 적었습니다(Ch 11 넷, Ch 6 06절 하나, 이 챕터 02~08절 열). 이 파일은 `json`과 `math`만 씁니다.

`data/evaluation-cases.json`에는 평가 사례 세 건(Q002·Q006·Q090)이 있습니다. 사례마다 질문·근거 문서·`gpt-5.4-mini`가 쓴 답·기준 답과, 교재를 만들 때 한 번 받은 근거 충실도 판정 글이 들어 있습니다. 기준 답은 교재 작성자 한 사람이 적은 글이고, 사람 여럿이 따로 매긴 라벨이 아닙니다. 이 파일은 읽기만 합니다.

01절은 Ch 12 실습 폴더의 기록 두 개(`labs/part3/ch12-retrieval-tuning/runs/advanced-continuity-experiment-log.jsonl`·`advanced-continuity-test-result.json`)도 읽습니다. 노트북은 연 자리에서 위 폴더로 올라가며 프로젝트 맨 위를 찾아 이 파일을 엽니다.

평가 모델은 `gpt-5.4-mini`(`temperature=0`·`reasoning_effort="none"`)입니다. 노트북 아홉 개를 한 번씩 모두 실행하면 평가 모델 요청은 46번이고 임베딩 요청은 없습니다. 절별로는 01절 0번, 02절 14번, 03·04절 8번씩, 05·06절 3번씩, 07절 6번, 08절 0번, 09절 4번입니다. 준비물에 적은 절별 예상 비용 상한을 더하면 미화 0.2달러 아래입니다. 예상 비용은 요금표로 계산한 값이고 실제 청구 금액과는 다를 수 있습니다. 01·08절은 API 키 없이 실행됩니다.

`runs/batch-eval-input.jsonl`은 08절이 쓰는 입력 파일입니다. 판정 요청 여섯 줄이 OpenAI 일괄 처리(Batch API) 입력 형식으로 들어 있고, 08절은 이 파일을 쓰고 제출 전에 검사까지만 합니다. 파일 올리기·일괄 작업 만들기·결과 받기·할인 청구는 하지 않았습니다.

`notebooks/09-평가-심화-실습.ipynb`는 챕터 끝 실습입니다. 08절이 쓴 `runs/batch-eval-input.jsonl`에서 요청 식별자로 두 줄씩 골라 판정 요청 글을 `gpt-5.4-mini`에 하나씩 보내고(요청 네 번), 07절 짝지어 보는 검사와 06절 방식의 예상 비용을 봅니다. 입력 파일은 읽기만 하고 일괄 처리 제출과 파일 쓰기는 하지 않습니다. 프로젝트 맨 위 `.env`의 `OPENAI_API_KEY`가 필요합니다.
