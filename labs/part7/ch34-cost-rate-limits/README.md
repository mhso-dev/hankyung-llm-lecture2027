# Ch34 비용 · Rate Limit 엔지니어링 실습

이 폴더에는 Ch 34 교재의 노트북 여섯과, 노트북이 함께 쓰는 파일이 들어 있습니다.
노트북은 `notebooks/` 폴더에 있고, 커널도 이 폴더에서 시작합니다.

## 준비

Python 3.12와 uv를 씁니다.
실습 폴더에서 아래 명령을 실행하면, 잠금 파일과 같은 버전으로 가상환경 `.venv`가 만들어집니다.

```bash
uv sync --locked
```

그다음 `notebooks/` 폴더의 노트북을 열고, 실습 폴더의 `.venv` 커널을 고릅니다.
노트북마다 첫 셀부터 순서대로 실행합니다.
01·03·04·06의 첫 셀은 그 절이 쓰는 패키지를 잠금과 같은 버전으로 설치합니다.
교재 출력은 Linux의 Python 3.12.13으로 만들었습니다.
다른 버전과 Windows·macOS에서는 실행하지 않았습니다.

## 노트북과 모델 요청 수

| 노트북 | 한 번 실행할 때의 모델 요청 | API 키 | 설명 |
|---|---|---|---|
| `01-프롬프트-캐시-계측.ipynb` | 4번(`gpt-5.4-mini`) | 씀 | 요금표로 어림한 비용은 0.01달러보다 적음 |
| `02-Batch-API.ipynb` | 0번 | 쓰지 않음 | `data/`의 자료 파일을 읽기만 함 |
| `03-모델-라우팅.ipynb` | 6번(`gpt-5.4-nano` 2번, `gpt-5.4-mini` 4번) | 씀 | 요금표로 어림한 비용은 0.001달러보다 적음 |
| `04-백오프-큐-동시성.ipynb` | 0번 | 쓰지 않음 | 요청은 이 컴퓨터 안의 연습용 서버로만 보냄 |
| `05-예산-가드와-p95.ipynb` | 0번 | 쓰지 않음 | 셀에 적은 토큰 수로 예상 비용을 셈 |
| `06-비용과-Rate-Limit-실습.ipynb` | 5번(`gpt-5.4-nano` 2번, `gpt-5.4-mini` 3번) | 씀 | 챕터 끝 실습 절, 요금표로 어림한 비용은 약 0.006달러 |

여섯 노트북을 한 번씩 실행하면 모델 요청은 모두 15번입니다.
금액은 교재를 만들 때 본 사용량과 모델 안내의 요금표로 어림한 예상 비용이고, 청구 금액이 아닙니다.
요금표는 01·03·05가 2026-09-29, 06이 2026-09-30에 확인한 값입니다.
여러분의 키로 보내는 요청에는 실제 요금이 붙습니다.

## API 키

01·03·06은 프로젝트 폴더의 `.env` 파일에 적은 `OPENAI_API_KEY`를 씁니다.
키를 읽는 셀은 커널이 시작한 폴더부터 위쪽 폴더로 올라가며 `.env` 파일을 찾습니다.
키 값은 출력하지 않고, 키가 없으면 그 셀에서 멈춰 모델 요청이 나가지 않습니다.
02·04·05는 키를 읽지 않습니다.

## 도구 파일 `notebooks/cost_tools.py`

앞 챕터와 이 챕터 앞 절에서 배운 함수를 모아 둔 파일입니다.
노트북은 `from cost_tools import …` 한 줄로 함수를 가져옵니다.
커널이 `notebooks/` 폴더에서 시작해야 이 파일을 가져올 수 있습니다.
파일을 열면 함수마다 어느 절에서 배웠는지 적은 주석이 있습니다.

## 02의 자료 파일 `data/`

02 노트북은 일괄 작업을 만들지 않고, `data/`의 파일 셋을 읽기만 합니다.
파일 `batch-output.jsonl`은 결과 파일, `batch-errors.jsonl`은 오류 파일, `batch-job.json`은 작업 기록입니다.
세 파일은 2026-09-29 교재를 만들 때, 노트북 밖에서 한 번 맡긴 일괄 작업에서 받았습니다.
요청 다섯 줄(`gpt-5.4-mini`, 요청 주소 `/v1/chat/completions`) 가운데 넷이 끝나고 하나가 거절되었습니다.
받은 파일에서 작업·파일·요청마다 붙는 ID와 시각은 빼고 두었습니다.

## 04의 연습용 서버 `notebooks/always_429_server.py`

어떤 요청에도 상태 코드 429만 보내는 작은 서버입니다.
제공자의 요청 제한을 흉내 낸 것이고, 모델의 답은 보내지 않습니다.
04 노트북이 이 파일을 자식 프로세스로 띄워 `127.0.0.1`의 포트 58034에서 받게 하고, 마지막 셀에서 끕니다.
그 포트를 다른 프로그램이 쓰고 있으면 셀이 멈추므로, 셀의 포트 번호를 바꿔 그 셀부터 다시 실행합니다.
마지막 셀의 출력 `포트가 아직 열려 있는가: False`로 서버가 꺼졌는지 확인합니다.

02가 만드는 입력 파일만 운영체제 임시 폴더에 씁니다.
