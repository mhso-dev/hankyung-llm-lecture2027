# Ch 6 LangChain 시작 실습

Python 3.12와 `uv`를 사용합니다. 프로젝트 루트의 `.env`에서 API 키를 읽으며 키 값은 출력하지 않습니다. 일곱 노트북은 각각 새 커널에서 독립 실행할 수 있습니다. 02 노트북은 Anthropic·Google 두 제공자에 요청을 보내지 않습니다. 키가 없으면 기록표에 `키 없음`, 키가 있으면 `키 있음, 부르지 않음`으로 적습니다.

챕터 폴더를 VS Code에서 열고 다음 명령으로 잠금 환경을 준비합니다.

```bash
uv sync --locked
```

그런 다음 이 폴더의 `.venv`를 노트북 커널로 선택합니다. 첫 실제 API 호출은 `01-계층-지도와-첫-호출.ipynb`의 `invoke()` 셀에서 일어납니다. `06-토큰-비용-지연-비교.ipynb`은 실행할 때마다 `runs/provider-comparison-continuity.json`을 새 기록으로 덮어씁니다(실행 시각별 사본은 만들지 않습니다). Ch 7의 08절 노트북이 이 파일을 읽습니다. 파일의 `pricing.openai`는 mini 요금이고, 기록표 줄(`records`)의 키는 한국어(`모델`·`응답한 모델`·`출력 토큰 수` 등)입니다.

`07-LangChain-실습.ipynb`은 챕터 끝 실습 절입니다. 학습 카드 요청에 폴백과 비용 기록을 붙여 기본 경로의 기다리는 시간만 바꾼 두 실행을 비교하며, 파일을 만들거나 고치지 않습니다(`runs` 폴더도 그대로 둡니다).
