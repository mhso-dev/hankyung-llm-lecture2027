# Ch 2 파이썬 실습

Ch 1에서 준비한 Python 3.12와 VS Code의 Jupyter 화면을 사용합니다. 이 챕터는 API 키가 필요하지 않습니다. 패키지 설치에는 인터넷 연결이 필요합니다.

압축을 푼 뒤 `labs/part1/ch02-python` 폴더를 VS Code에서 엽니다. 터미널도 이 폴더에서 열고 다음 명령을 실행합니다.

```text
uv sync --locked
uv run python --version
uv run python -m pytest --version
```

Python 3.12와 pytest 9.1.1을 확인합니다. 노트북 오른쪽 위의 커널 선택에서 이 폴더의 `.venv`를 고릅니다. 첫 코드 셀부터 `Shift+Enter`로 실행합니다. 각 노트북은 새 커널에서도 독립적으로 실행됩니다. 설치 셀이 있으면 설치가 완료된 뒤 다음 셀을 실행합니다.

처음 프로그래밍을 배운다면 01~08절을 순서대로 학습합니다. 각 예제의 결과를 예측하고 실행한 뒤 값 하나를 바꾸어 비교합니다. 실패와 수정 비교에서는 같은 입력을 유지하면서 코드의 어느 부분이 달라졌는지 확인합니다. 08절에서 도입한 pytest를 사용해 앞에서 수정한 버그도 다시 검사합니다.

09~11절은 기초 문법을 알고 있는 B트랙의 확장 내용입니다. A트랙은 이 시간에 01~08절의 예제 수정과 테스트를 보충합니다. 12절의 `async/await`는 두 트랙 모두 학습합니다. A트랙은 08절 다음에 12절로 이어갈 수 있습니다. B트랙도 01~08절의 복습 문제로 기초를 점검합니다. 13절은 1~7절의 부품으로 주문 파일의 합계를 내는 실습이고, 두 트랙이 함께 실행합니다.

12절은 Jupyter가 이미 실행하는 이벤트 루프를 사용하므로 노트북의 `await` 셀을 그대로 실행합니다. 같은 코드를 일반 `.py` 파일로 옮기면 실행 진입점을 따로 작성해야 합니다. 자세한 이유는 12절 본문에서 설명합니다. 출력에 나타나는 대기 시간과 테스트 소요 시간은 컴퓨터 상태에 따라 달라집니다.

제공된 기본 노트북에는 완성 코드와 실제 실행 출력이 들어 있습니다. 출력부터 읽고 답을 확인하지 말고, 먼저 결과를 예측한 뒤 실행 출력과 비교합니다. 화면이 HTML이면 코드를 실행할 수 없으므로 노트북 다운로드 버튼으로 `.ipynb` 파일을 받아 엽니다.
