1
학습 목표
에이전트의 모델·도구·루프가 각각 맡는 역할을 설명할 수 있습니다.
완료·최대 단계·예산·사람 확인을 서로 다른 정지 이유로 기록할 수 있습니다.
상태 전이 시뮬레이션과 실제 도구 에이전트 구현을 구분할 수 있습니다.
2
이 내용을 배우는 이유
모델과 도구를 연결한 뒤 종료 규칙을 두지 않으면 같은 검색을 반복하거나 비용 상한을 넘길 수 있습니다. ‘모델이 알아서 끝낸다’는 설명만으로 운영 조건을 만들 수 없습니다. 모델이 완료를 제안하는 경로와 프로그램이 강제로 멈추는 경로, 사람이 판단을 이어받는 경로를 따로 설계해야 합니다.
3
앞에서 배운 내용
Ch 13에서는 노드와 엣지로 상태가 이동하는 모습을 확인했고, Ch 16에서는 최대 호출 수와 비용 상한을 모델 호출 전에 검사했습니다. 이 절은 그 상태와 상한 개념을 에이전트 후보의 반복 구조에 적용합니다. 실제 ToolNode와 조건부 엣지는 Ch 20에서 처음 직접 조립합니다.
4
핵심 개념
쉬운 예와 정의
탐사팀에서 분석가는 다음 조사 장소를 고르고, 측정 장비는 현장의 값을 가져오며, 기록 담당자는 결과를 다음 판단 자료에 넣습니다. 탐사 완료 선언과 연료 한도, 위험 지역 앞의 책임자 확인도 필요합니다.
모델(model)
은 현재 상태를 읽고 다음 행동 또는 완료를 제안합니다.
도구(tool)
는 검색·파일 읽기·계산처럼 환경과 상호작용하고 결과를 반환합니다.
루프(loop)
는 모델의 선택, 도구 결과, 갱신된 상태를 다시 모델 입력으로 이어 주는 반복입니다.
정지 조건(stopping condition)
은 반복을 종료하는 판정입니다.
하드 리밋(hard limit)
은 최대 단계와 예산처럼 모델 의사와 관계없이 프로그램이 적용하는 상한입니다.
사람 확인(human check)
은 정보 부족이나 고위험 행동 앞에서 판단을 넘기는 종료 상태입니다.
판단 절차
루프 설계표에는 현재 상태, 모델이 선택할 수 있는 행동, 각 도구의 반환값, 상태 갱신 규칙을 적습니다. 그 다음 정상 완료, 최대 단계, 예산 상한, 사람 확인을 종료 상태로 나눕니다. 정지 이유가 여러 개면 모두 기록하되 프로그램이 어떤 우선순위로 반환할지 정합니다. 부작용이 있는 행동은 일반 반복 안에 그대로 넣지 않고 별도 승인 경계를 둡니다.
도식 읽기
{{svg:03-흐름}}
도식은 모델의 다음 행동, 도구 결과, 상태 갱신, 정지 조건이라는 구성 요소를 한 줄로 소개합니다. 반복 경로 자체를 표현한 도식은 아닙니다. 정지 조건은 정상 완료·강제 상한·사람 확인으로 구분해 기록합니다.
5
실행 예제
노트북은 Python 3.12의 새 커널에서 독립 실행됩니다. 외부 API를 호출하지 않고, 교육용 사건 목록에 정지 규칙을 적용합니다. 실제 모델이 행동을 고르거나 도구를 실행하지는 않습니다.
{{notebook:03-모델-도구-루프와-정지-조건}}
확인할 점
— 완료 사건을 제거한 경로가 실행 중 상태로 남는지, 최대 단계·예산·사람 확인이 서로 다른 정지 이유로 기록되는지 확인합니다.
6
실험 결과 해석
완료 사건이 있는 다섯 단계 합성 추적은 ‘완료’로 판정됐습니다. 마지막 완료 사건을 제거한 네 단계 추적은 정지 이유가 없어서 실행 중 상태로 남았습니다. 별도 사례에서는 여섯 사건에 도달한 경로가 ‘최대 단계’, 누적 비용이 상한에 도달한 경로가 ‘예산’, 확인 사건을 포함한 경로가 ‘사람 확인’으로 기록됐습니다. 이 코드는 사건 목록에 규칙을 적용했을 뿐 모델이 행동을 선택하거나 검색 도구를 실행하지 않았습니다. 따라서 자율 에이전트를 구현한 결과로 해석하지 않습니다.
7
주의할 점과 실무 메모
완료 조건은 ‘좋아 보이는 답’보다 검증할 수 있는 산출물과 연결합니다. 예를 들면 테스트 통과와 필요한 파일 존재 여부입니다.
여러 정지 조건이 동시에 맞을 수 있으므로 판정 우선순위와 발생한 모든 사건을 로그에 보존합니다.
모델의 완료 선언만 신뢰하지 말고 프로그램 상한과 필요한 사람 확인을 함께 둡니다.
8
정리와 다음 절
모델은 행동을 제안하고 도구는 환경 결과를 반환하며 루프가 상태를 잇습니다.
완료·최대 단계·예산·사람 확인은 서로 다른 정지 이유입니다.
이 절의 코드는 사건 판정기이며 실제 도구 에이전트가 아닙니다.
