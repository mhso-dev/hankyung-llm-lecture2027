# Part 5의 앞뒤 학습 연결

Ch 17은 중간 프로젝트의 처리 흐름을 놓고 어떤 판단을 모델에 맡길지 검토합니다. 공개 제품 실행 기록은 공개된 범위만 읽으며, 교육용 재구성 자료와 직접 실행한 출력은 구분합니다. 자율성을 진단한 결과, 에이전트를 도입할 필요가 없다고 결론 내릴 수도 있습니다.

Ch 18은 Ch 2의 함수·비동기 실행을 사용합니다. 다섯 가지 패턴으로 같은 과제의 결과를 비교하고, 동적 작업 분해와 생성·평가 반복의 정지 조건을 확인합니다. Ch 39에서는 이 정지 조건을 더 큰 반복 작업에 적용합니다.

Ch 19는 Ch 4의 데이터 조회 함수와 입력·반환 형식을 도구 설계에 연결합니다. 노트북은 `labs/part5/ch19-model-tools/data/orders.csv`를 읽습니다. 이 파일은 Ch 4의 `orders.csv`와 바이트 단위로 같고, 첫 번째 노트북에는 Ch 4의 `fetch_orders()` 본문과 원본 SHA-256이 함께 적혀 있습니다. `labs/part1/ch04-data-tools`는 원본을 비교할 때 사용합니다. 모델의 도구 호출 요청과 실제 함수 실행을 구분하고, 실행 결과를 해당 호출 ID에 연결합니다.

Ch 20은 Ch 13의 그래프 상태와 조건부 엣지에 모델과 도구를 연결합니다. Ch 19에서 익힌 도구 설명과 호출 형식을 사용하며, 노트북의 실행 환경과 예제 데이터는 각 절에서 다시 준비합니다. Ch 21에서는 직접 만든 루프를 `create_agent`와 비교합니다. Ch 22에서는 Ch 16의 검증·사용량 제한을 Middleware로 구성합니다.

앞 챕터의 측정값을 새 실험 결과로 옮겨 적지 않습니다. 같은 과제를 비교할 때는 질문·데이터·모델·평가 기준·반복 횟수를 기록합니다. 다른 데이터로 구성한 원리 예제 사이의 숫자는 개선율로 계산하지 않습니다.
