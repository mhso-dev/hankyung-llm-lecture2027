# Ch 17 Agent 개요 실습

다섯 개의 노트북은 Python 3.12의 새 커널에서 각각 독립 실행됩니다. 외부 API를 호출하거나 자율 도구 에이전트를 구현하지 않습니다. 교육용 고정 사례로 워크플로우와 에이전트의 경계, 워크플로우 적합 조건, 정지 조건, 비용·지연·경로 지표를 분석합니다.

마지막 노트북은 공식 저장소에 공개된 SWE-agent와 mini-SWE-agent의 실제 실행 궤적 두 건을 추린 자료 `data/public-trace-extracts.json`을 읽습니다. 추출본에는 원본 커밋, 원문 URL, SHA-256, MIT 라이선스, 사건 순서를 기록했습니다. 이 컴퓨터에서 두 제품을 다시 실행한 로그는 아닙니다. `data/product-trace-evidence.json`의 Codex·Claude Code·Deep Research 항목은 공식 문서가 공개한 사건 유형과 제한 인터페이스만 정리한 보조 자료입니다.

`data/autonomy-diagnostic-example.json`은 중간 프로젝트 규정 RAG의 작성 예시입니다. `data/autonomy-diagnostic-sheet.csv`는 프로젝트마다 복사해 사용할 빈 진단표입니다. 예시 결론은 ‘워크플로우 유지’이며, Ch 20에서 고정 분기와 모델 분기를 실제로 비교한 뒤 갱신합니다.

# 워크플로우와 에이전트 경계

누가 다음 단계를 정하는지 사건별로 표시해 두 구조의 경계를 확인합니다.
## 실행 환경 준비

외부 API를 호출하지 않습니다. 교육용 고정 사례를 읽고 분류하므로 실행할 때마다 같은 결과가 나옵니다.
## 사례 준비

`decision_owner`는 다음 행동을 정한 주체입니다. `code`면 미리 작성한 경로, `model`이면 입력과 관찰 결과를 본 모델의 선택입니다.
## 경계 분류

도구 사용 여부보다 다음 단계의 결정 주체를 먼저 봅니다.
## 값 하나를 바꿔 비교

같은 환불 절차에서 도구를 세 개로 늘려도 분기를 코드가 정하면 분류는 바뀌지 않습니다.
## 전체 사례 집계

분류 결과는 교육용 사례의 필드에서 계산한 값입니다. 실제 제품의 내부 구조를 측정한 결과가 아닙니다.

점수와 비용은 설계를 비교하기 위한 교육용 고정값입니다. 모델 호출, 실제 청구, 품질 측정을 수행하지 않습니다.

값은 가상 수업 사례에 대해 미리 정한 진단 응답입니다.

규정 질의응답에 모델 결정 단계를 두 개 추가했다고 가정합니다. 호출 수와 시간은 실제 측정값이 아닙니다.
## 민감도 확인

임계값 변화에 따라 추천이 달라지는지 확인합니다.

# 모델·도구·루프와 정지 조건

완성된 에이전트를 만들지 않고 사건 목록으로 루프와 정지 이유를 읽습니다.
## 실행 환경 준비

아래 코드는 모델이나 도구를 호출하지 않는 상태 전이 시뮬레이터입니다. Ch 20의 ToolNode 그래프 루프를 미리 구현하지 않습니다.

완료, 최대 단계, 예산, 사람 확인 요청을 서로 다른 종료 이유로 보존합니다.

# 자율성의 대가

같은 최종 답에 도달한 두 합성 궤적을 비용·지연·경로 편차·디버깅 단서로 비교합니다.
## 실행 환경 준비

사건별 시간과 비용 단위는 교육용 합성값입니다. 제공자 가격이나 Ch 20의 실제 호출 측정을 대신하지 않습니다.
## 합성 궤적 준비

워크플로우는 경로가 고정되어 있고, 에이전트 후보는 관찰에 따라 검색을 반복했다고 가정합니다.
## 단계·비용·지연 계산

최종 답의 정확도는 주어지지 않았으므로 처리량 지표만 계산합니다.
## 원인 위치 찾기

지연이 큰 사건과 반복 사건을 표시하면 디버깅의 출발점을 만들 수 있습니다.
## 경로 편차 비교

같은 최종 결과라도 중간 경로가 다르면 최종 답만으로 효율과 잘못된 행동을 평가할 수 없습니다.

# 제품 트레이스와 자율성 진단

공식 저장소에 공개된 실제 실행 궤적 두 건과 제품 추적 단서를 읽고 중간 프로젝트 진단표를 완성합니다.
## 실행 환경 준비

`public-trace-extracts.json`은 공개된 SWE-agent·mini-SWE-agent 원시 궤적에서 사건 순서를 추출한 자료입니다. 원본 커밋·URL·SHA-256·MIT 라이선스를 함께 기록했습니다. 이 컴퓨터에서 두 제품을 다시 실행한 로그는 아닙니다.
## 실제 공개 궤적 읽기

첫 궤적은 14개의 action-observation 턴, 두 번째 궤적은 10개의 명령과 반환 결과를 포함합니다.
## 오류 뒤 경로 변경 확인

원시 궤적에서 반환 실패나 편집 거부 다음에 실제 행동이 바뀐 위치를 읽습니다.
## 공식 제품 추적 단서와 증거 수준

Codex·Claude Code·Deep Research 문서는 추적 인터페이스와 행동 유형을 확인하는 보조 자료입니다. 실제 단일 실행 원문과 구분합니다.
