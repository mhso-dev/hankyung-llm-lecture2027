## 실제 실행

20개 노트북 모두 Python 3.12.13의 새 Jupyter 커널에서 준비 셀부터 마지막 셀까지 실행했습니다. 의도한 실패는 예상 조건을 확인한 뒤 다음 셀로 진행합니다. 실행일·셀 번호·코드 및 출력 해시는 각 `.ipynb`에 기록했습니다.

API 예제는 프로젝트 `.env`에 있는 키를 읽어 LangChain을 통해 실제로 호출했습니다. 생성은 `init_chat_model`·`invoke`, 임베딩은 `OpenAIEmbeddings`를 사용합니다. 호출 코드를 바꾼 12개 노트북을 다시 실행했으며, 이후 Before/After 보완 과정에서 전체 20개 노트북을 다시 실행했습니다. Ch 8은 `gpt-5.4-mini`로 컨텍스트 구성과 실패 조건을 비교했습니다. Ch 9는 생성과 임베딩을 실제 호출했습니다. 05절의 두 프롬프트를 각각 5회 실행했으며, 이번 실행에서는 두 조건 모두 근거 없는 기간을 만들지 않았습니다. 검색 결과 수를 1에서 2로 늘려 정답 문서가 추가되는 것도 확인했습니다. 06절은 설정 해시로 색인을 재사용하고 JSONL 기록을 저장한 뒤 다시 읽었습니다. Ch 10은 시맨틱 청킹, 첫 호출과 캐시 재사용, 청킹 3종×임베딩 2종의 6개 조합을 확인했습니다. 임베딩 메서드가 사용량을 반환하지 않으므로 토큰 수는 `local_token_estimate`로 구분합니다. 모의 응답을 실제 API 출력으로 표시하지 않았습니다.

API 실행 결과는 고정 답안이 아닙니다. 재실행하면 답변·검색 점수·토큰 사용량이 달라질 수 있습니다. 작은 수업용 표본에서 확인한 결과이므로 과거 전체 문서 세트의 품질 평가와 구분합니다.
