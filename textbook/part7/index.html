Part 7 실습 파일 받기 · 앞에서 배운 Agent 개발

실습을 준비합니다

압축을 풀고 해당 챕터의 README에서 준비할 프로그램을 확인합니다. Python 예제는 챕터 폴더에서 uv sync --locked로 환경을 만든 뒤 같은 폴더의 .venv를 노트북 커널로 선택합니다. 노트북은 절마다 커널을 새로 시작하고 준비 셀부터 실행합니다.

Docker와 PostgreSQL을 사용하는 절은 Python 커널 외에 별도 프로세스가 필요합니다. README에 적힌 실습용 이름·포트·종료 절차를 확인합니다. API를 호출하는 절은 본인의 키를 .env에 넣고, 공개 저장소나 이미지에 키를 포함하지 않습니다.

결과를 읽는 기준

실습 결과에서는 무엇을 실행했는지 먼저 확인합니다. 로컬 서버가 응답한 사실, 컨테이너가 실행된 사실, 외부 클라우드에 배포된 사실은 각각 별도의 증거가 필요합니다. 이 교재의 작은 표본과 한 번의 실행 시간을 자신의 서비스 성능 목표에 그대로 대입하지 않습니다.

이미지 크기와 대화 비용을 절반 이하로 줄이는 활동은 비교 과제입니다. 개선 전후에 같은 기능과 평가 질문을 유지하고, 측정값과 함께 줄어든 기능·달라진 지연·품질을 기록합니다. 개선하지 못한 경우에도 관찰한 값과 다음에 확인할 원인을 적습니다.
