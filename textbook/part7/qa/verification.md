## 통합·배포 검사

- 29절·챕터 목차 5개·Part 7 목차·전체 목차의 1280px/390px 화면 72건이 통과했습니다. 글자 크기·대비·잘림·화면 밖 요소·SVG 경계·가로 넘침·깨진 이미지·셀 복사·전체 복사·다운로드 코드 비교를 검사했습니다. 대표 PC·모바일 화면도 직접 확인했습니다. 근거: `visual-results.json`.
- 도식 29쌍은 SVG와 편집 가능한 Excalidraw의 상자·텍스트·화살표를 대조했습니다. 모든 챕터에 같은 요소 명세에서 두 형식을 생성하는 `_gen_figures.py`가 있습니다. 근거: `figure-consistency.json`.
- Part 7 묶음은 공개 파일 107개와 선수 파일 1개를 포함합니다. 전체 묶음은 452개 파일입니다. 압축 무결성·manifest SHA-256·현재 원본 바이트 일치·비밀 환경 파일 제외를 확인했습니다. 교재 내부 파일 링크 오류는 0개입니다. 근거: `delivery-results.json`.
- 최종 ZIP을 임시 폴더에 풀어 5개 챕터의 `uv sync --locked`와 `ipykernel`·`pip` 가져오기를 확인했습니다. 추출된 Ch30 01절·Ch31 03절·Ch33 02절은 각각 `notebooks/` 폴더에서 새 커널로 실행했습니다. 원래 작업 폴더를 참조하지 않습니다. 근거: `bundle-execution.json`.
- 현재 사용 가능한 비밀값과 공개 원고·실습 171개 파일 및 두 ZIP의 바이트를 대조해 노출 0건을 확인했습니다. 비밀값 자체는 보고서에 저장하지 않았습니다. 근거: `secret-scan.json`.
- 기존 Part 1–6 본문·노트북 376개의 SHA-256이 작업 전과 같습니다. 공통 변경은 새 챕터 등록, 공개 파일 목록과 묶음 포함 규칙으로 한정했습니다.
- 공통 도구 회귀 검사는 44개 테스트와 26개 하위 검사가 통과했습니다. Ch30 테스트 6개, Ch33 테스트 5개와 통합 스크립트 Ruff도 통과했습니다. Starlette TestClient의 기존 deprecation warning 1건은 기능 실패가 아닙니다.

## 독립 검토와 보완

작성자와 다른 에이전트가 기술 검토를 수행했습니다. SSE 줄바꿈 처리, 실제 모델 연결, DB 기준 버전과 출력, 실제 평가 함수 회귀, 실제 HTTP 롤백, LangChain 사용량과 빈 응답 문제를 보완한 뒤 재검증했습니다. 통합 과정에서는 경로 탐색, 예약 문자가 든 DB 비밀번호, 도식 원본의 누락과 방향·색 설명을 추가 수정했습니다. Ch32의 예약 문자 `@:/%` 인증은 실제 PostgreSQL에서 SELECT 1로 확인했습니다.

한국어 감사는 작성 모델과 다른 모델이 일반 슬롭 점검→로컬 맞춤법 정독→정밀 윤문·Phase 6 원문 대조 순서로 수행했습니다. Ch30·Ch31·공통 안내는 accept, Ch32·Ch33·Ch34는 corrected이며 보류 항목은 없습니다. 숫자와 출력의 기술 동기화는 재실행 근거를 별도로 기록했습니다. 변경률이 낮다는 자동 WARN은 숨기지 않고 전문 정독 판정과 함께 보존했습니다.

감사 기록은 `qa/language/ch31-final.md`, `qa/language/ch33-final.md` 및 프로젝트 루트 `qa/language/{guides,ch30,ch32,ch34}-final.md`입니다. Ch30 최종 경로 보정은 감사 완료 본문·노트북 마크다운을 바꾸지 않고 코드와 실제 출력만 다시 검증했습니다.

## 확인 필요 항목

- 원격 GitHub PR·Actions, 레지스트리 push/pull·서명, 클라우드 배포, Kubernetes 클러스터 적용과 외부 모니터링 알림은 실행하지 않았습니다. 로컬 빌드·HTTP 복구와 구분해 본문에 표시했습니다.
- Batch는 입력 JSONL 세 건을 생성·검사했으며 외부 제출·결과 수집·청구 확인을 하지 않았습니다.
- OpenAPI Generator 7.25.0이 FastAPI SSE `itemSchema`를 인정하지 않아 `--skip-validate-spec`로 SDK를 생성했습니다. JSON SDK 컴파일과 직접 작성한 SSE fetch 클라이언트 실행은 통과했지만 운영 프록시·다중 인스턴스 재생은 별도 검증이 필요합니다.
- Ch31의 작은 표본은 Seq Scan을 선택했습니다. 운영 규모 HNSW 성능과 복원 후 그래프 스레드 재개는 검증 범위에 포함하지 않았습니다. Docker 크기는 현재 arm64 환경의 로컬 이미지 크기입니다.
- 외부 맞춤법 서비스는 스킬의 상업적 대량 처리 제한으로 전송하지 않았습니다. 로컬 전문 정독으로 대체했습니다. Excalidraw MCP 호출은 도구가 없어 같은 명세의 로컬 SVG/JSON 생성으로 대체했습니다. 개념 전달에 별도 삽화가 필요하지 않아 이미지 생성 크레딧 사용은 0입니다.
- 모델 단가·요청 한도는 각 절의 공식 자료 확인일 기준입니다. 실제 계정 청구액 전체와 운영 비용 절반 감소를 달성했다고 주장하지 않습니다.

최종 파일 해시는 `final-artifact-hashes.json`에 기록합니다. 학생용 본문 정본은 `_src/`, 실행 정본은 `.ipynb`이며 초기 원고 생성기로 감사 완료 문장을 덮어쓰지 않습니다.
