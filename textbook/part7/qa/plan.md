# Part 7 집필·검증 계획

기준: 커리큘럼 v6 Ch30–34, 총 88시간(강의 28·실습 60). 독자는 개발 입문자이며 기존 Jupyter 테마와 개념 단위 구조를 유지한다.

|---|---|---|---|
| Ch30 | 10/22 | 비동기 API, 입력·출력, 의존성·인증, Agent 연결, SSE, 연결 종료·오류, CORS·시간 제한, OpenAPI·SDK | 실제 HTTP·스트림 오류 |
| Ch31 | 5/11 | 비동기 DB, 트랜잭션, 마이그레이션, 연결 풀, 벡터·상태·백업 | 실제 롤백·풀 고갈 |
| Ch32 | 5/11 | 이미지·레이어, 다단계 빌드, 캐시·크기, Compose, 운영 설정 | 이미지 크기와 구동 상태 |

공식 자료 확인 → 노트북 새 커널 실행 → 본문·도식·복습 → 빌드 → 독립 주제 검토·한국어 감사 → 화면·복사·배포 묶음 검사 순으로 진행한다. 에이전트별 챕터 소유권을 분리하며 공통 도구와 최종 연결은 주 담당자가 관리한다.

학생 발행본에 미실행 출력을 넣지 않는다. 외부 PR·클라우드 배포·Batch 작업을 실행하지 않았으면 해당 상태를 구분한다. 실측 감소율은 동일 조건에서 확인한 값만 제시하며 과제 목표를 달성 결과로 바꾸지 않는다.

완료 기준은 각 절 실행 검증, 코드와 출력의 HTML 일치, 주제·공식 자료 일치, 개념 설명의 충분한 분량, 복습 해설, 도식과 본문의 일치, 1280/390px 화면 및 복사·다운로드 검사, 공개 파일 경계와 압축 해시 검사다.

Excalidraw MCP는 현재 callable 도구 목록에 없다. 도식은 공통 요소 생성기에서 SVG와 Excalidraw JSON으로 함께 생성하고 이 대체 경로를 검토 기록에 남긴다. 내용이 데이터·서비스 흐름이므로 장식용 삽화는 추가하지 않는다.
