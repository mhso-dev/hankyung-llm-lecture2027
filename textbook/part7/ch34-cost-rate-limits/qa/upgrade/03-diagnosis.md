## 4. 설계 (handoff §02 → §03 · 앞 작업자 결정 그대로)

- **모델**: 과정 표준(`temperature=0`·`reasoning_effort="none"`)에 **모델 이름만 바꿈**(`gpt-5.4-nano` 셀·`gpt-5.4-mini` 셀, 노트북에 보이게) · `max_tokens`·`seed`·`max_retries` 없음(SDK 기본 재시도 2 켜 둠) · 키 셀 과정 표준(`nbkit.KEY`). 02에서 mini가 low + 온도 0을 400으로 거절한 사실 → 생각하는 단계는 바꾸지 않음(노트북 1절 끝·b3).
- **실험**: 모델 라우터 `choose_model(inquiry, length_limit)` = 글자 수 > 기준 길이면 mini, 아니면 nano(이름만 내놓음). 문의 글 셋 = 01 문의 글 둘 + 02 둘째 문의 글의 앞부분(20·25·36글자), 요청 글 = 문의 글 + 공백 + 답 형식 글(01·02 요청 글과 글자까지 같음 — 생성기 `check_requests()`가 실행마다 대조, 흔들림 확인 스크립트의 글·함수 AST도 대조). 실행 1 기준 길이 30(nano·nano·mini) → 실행 2 값 하나만 0(mini 셋 — 라우팅 없이 과정 표준 모델 하나로 보낸 때와 같음).
