# 03절 그림 설계표 (Alembic 적용과 롤백 · paired)

- 색(규격 §5-3·handoff 「색」 — 01·02가 이은 챕터 약속): 셀에 적은 값(환경 변수에 넣은 접속 글) **초록(tool)** · 우리가 적은 코드(사본 만들기·노트북이 쓴 판 파일·함수 `try_upgrade`·`command.downgrade` 줄) **파랑(flow)** · 노트북 출력으로 확인한 값(판 번호·칸·줄·After와 판 내리기 결과·받아 출력한 오류) **노랑(measure)** · 실습 폴더에 있던 파일(첫 판 파일·`env.py`)·Alembic이 만든 SQL 글·서버가 문장을 막아 판 번호를 적지 않은 일(설치판 소스)·두 판 공통 조건 **회색(클래스 없음)** · **보라 0장**(모델 없음) · **빨강은 Before 결함 결과만**(Before 판 올리기가 막힌 뒤 `판 번호: 20260911_01`·`칸: ['id', 'question']` 그대로 — 03-3·03-4 두 상자). Before에서 받아 출력한 오류 `IntegrityError`·`NotNullViolation`·`23502`는 노랑(규격 §5-3).
- 같은 요소는 절 안 모든 그림에서 같은 색: 노트북이 쓴 판 파일·`try_upgrade`(파랑) · 판 번호·칸·줄 출력(노랑) · 첫 판 파일·`env.py`(회색).
- 라벨 규칙: 모델을 부르지 않아 라벨 값은 모두 노트북이 출력한 값입니다. 새 커널 두 번(A 프로젝트 맨 위 커널 `executed_at` 17:09:43Z · B `notebooks/` 커널) 셀별 출력 31개 모두 같음(B는 끝 셀 출력 조각 나눔만 달라 `outputs_sha256`이 다름 — 글자는 같음), 묶음을 푼 `notebooks/`에서 키 없이 한 번 더 — 31개 같음·`outputs_sha256`도 A와 같음. 흔들리는 값 없음. 개수는 한글(두 칸·세 줄·셋), 숫자는 출력에 있는 것만(`20260911_01`·`20260929_02`·`23502`·`50`·`12~15`). 대괄호·따옴표는 라벨에서 뺌(`['id', 'question']` → 「칸 id · question」, `'미정'` → 「미정」).
- 차례: 노트북 밖 확인(`/tmp/ch31-03/exp/e1_scene.py` 5번 같음) → 사본 시험 둘(`/tmp/ch31-03/try/copy1·copy2`, PASS 31셀 — copy1에서 칸 목록이 `{id,question}` 글로 와 `::text`를 더함) → 새 커널 A(`run_section.sh`, 그림 첨부 단계에서 멈춤 — 03-1 PNG가 아직 없어서, 실행·저장은 끝난 뒤) → 사본 B(`/tmp/ch31-03/runB`, `--cwd labs/part7/ch31-database/notebooks`) → 묶음 모양(`/tmp/ch31-03/bundle`) → **이 설계표** → `.mmd` 다섯·캡션 → `run_section.sh … --no-exec`(렌더·첨부·빌드) → PNG 확인 → 삽화(PNG를 본 뒤 alt·그림 읽기) → `--no-exec`.
