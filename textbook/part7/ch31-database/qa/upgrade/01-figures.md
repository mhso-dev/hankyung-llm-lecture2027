# 01절 그림 설계표 (SQLAlchemy 비동기 PostgreSQL · experiment)

- 색(규격 §5-3·과정 요약 §8 — 이 챕터 색 약속을 01이 엶): 셀에 적은 자료·값(접속 글·표 `requests`의 문의 세 줄) **초록(tool)** · 우리가 적은 코드(엔진 만들기·`async with` 블록·SQL 글·함수 `read_question`·await 줄·`gather()` — 실험에서 바꾼 기다리는 방법 포함) **파랑(flow)** · 노트북 출력으로 확인한 값(연결 수·줄 수·기록 앞 세 개·참·거짓) **노랑(measure)** · 라이브러리의 연결 풀·블록 끝 확정·PostgreSQL 서버·두 실행 공통 조건 **회색(클래스 없음)** · **보라 0장**(모델 없음) · **빨강 0장**(experiment 절 — 받은 결함 결과 없음).
- 같은 요소는 절 안 모든 그림에서 같은 색: 함수 `read_question`·await 줄·`gather()`(파랑) · 연결 수·기록 출력(노랑) · 연결 풀·서버(회색).
- 라벨 규칙: 모델을 부르지 않아 라벨 값은 모두 노트북이 출력한 값입니다. 새 커널 두 번(A 프로젝트 맨 위 커널 15:54:38Z · B `notebooks/` 커널 15:54:53Z) 셀별 출력 21개 가운데 19개 같음 — 다른 둘은 걸린 초가 찍힌 셀 [13]·[19]뿐. **걸린 초(0.47·0.48·0.19)는 흔들리는 값이라 라벨·캡션·alt에 넣지 않음**(규격 §2-7 9번 끝·챕터 리드 결정 4) — 참·거짓 비교(`True`)와 매번 같은 값(연결 수·기록 앞 세 개·받은 값)만. 개수는 한글(하나·셋·세 줄), 숫자는 출력에 있는 것만(`0.15`·`55431`·`127.0.0.1`·문의 번호 1·2·3). 대괄호·따옴표·중괄호는 라벨에서 뺌(`[('시작', 1), …]` → 「시작 1 · 끝 1 · 시작 2」).
- 차례: 노트북 밖 확인(`.cache/ch31-01/exp/e1_shape.py` 6번) → 사본 시험(`/tmp/ch31-01/try`, 같은 커널 세 번 이어 실행 포함) → 새 커널 A(`run_section.sh`, 그림 첨부 단계에서 멈춤 — 01-1 PNG가 아직 없어서) → 사본 B → **이 설계표** → `.mmd` 넷·캡션 → `run_section.sh … --no-exec`(렌더·첨부·빌드) → 삽화(PNG를 본 뒤 alt·그림 읽기) → `--no-exec`.
