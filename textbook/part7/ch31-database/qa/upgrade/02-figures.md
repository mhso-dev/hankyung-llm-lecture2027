- 색(규격 §5-3·handoff 「색」 — 01이 연 챕터 약속을 이어 씀): 셀에 적은 자료·값(표에 넣은 계좌 두 줄) **초록(tool)** · 우리가 적은 코드(begin 블록·이체 함수 둘·블록 안 SQL 글) **파랑(flow)** · 노트북 출력으로 확인한 값(잔액·합계·After·예시에서 받아 출력한 오류) **노랑(measure)** · 라이브러리가 블록 끝에 보내는 확정·취소, 두 판 공통 조건 **회색(클래스 없음)** · **보라 0장**(모델 없음) · **빨강은 Before 결함 결과만**(블록 둘로 따로 확정한 뒤 남은 잔액 `[(1, 500), (2, 1100)]`·합계 `1600` — 02-3·02-4 두 상자). Before에서 받아 출력한 오류 `IntegrityError`·`23514`는 노랑(규격 §5-3 「코드가 잡아서 출력한 오류 노랑, Before 결함 결과 빨강」).
- 같은 요소는 절 안 모든 그림에서 같은 색: 이체 함수·begin 블록(파랑) · 잔액·합계 출력(노랑) · 확정·취소(회색).
- 라벨 규칙: 모델을 부르지 않아 라벨 값은 모두 노트북이 출력한 값입니다. 새 커널 두 번(A 프로젝트 맨 위 커널 `executed_at` 16:31:16Z · B `notebooks/` 커널) 셀별 출력 23개 모두 같음(설치 셀은 출력 조각 나눔만 달라 `outputs_sha256`이 다름 — 글자는 같음). 흔들리는 값 없음. 개수는 한글(두 줄·둘·셋), 숫자는 출력에 있는 것만(`500`·`400`·`600`·`1100`·`1600`·`1000`·`23514`·`-100`·`100`). 대괄호·따옴표·중괄호는 라벨에서 뺌(`[(1, 500), (2, 1100)]` → 「1번 500 · 2번 1100」). 「한 묶음 작업」·「확정」·「취소」는 02가 정한 말(라벨에 괄호 원어는 넣지 않음).
- 차례: 노트북 밖 확인(`/tmp/ch31-02/exp/p1_scene.py` 5번 같음) → 사본 시험(`/tmp/ch31-02/try`, PASS 23셀) → 새 커널 A(`run_section.sh`, 그림 첨부 단계에서 멈춤 — 02-1 PNG가 아직 없어서, 실행·저장은 끝난 뒤) → 사본 B(`/tmp/ch31-02/runB`, `--cwd labs/part7/ch31-database/notebooks`) → **이 설계표** → `.mmd` 넷·캡션 → `run_section.sh … --no-exec`(렌더·첨부·빌드) → PNG 확인 → 삽화(PNG를 본 뒤 alt·그림 읽기) → `--no-exec`.
