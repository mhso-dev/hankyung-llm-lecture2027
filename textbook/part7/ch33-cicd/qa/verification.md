- OCI 이미지: Docker로 v1·v2 이미지를 실제 빌드했고 서로 다른 이미지 ID를 확인했습니다.
- 경보: 3·4분 연속으로 오류율 5%와 p95 800ms를 초과해 종료 코드 1을 확인했습니다. 서로 떨어진 두 위반 구간은 경보를 발생시키지 않는 반례 테스트도 통과했습니다.
- 롤백: 기존 배포 기록을 삭제하지 않고 롤백 사건을 추가했습니다. HTTP 서비스를 v1→v2→v1 순서로 실행해 `/health` 응답 200→503→200을 확인했습니다.
- 교재: `_build.py`와 `verify.py`가 5절을 빌드하고 20개 코드 셀을 검증했습니다.
