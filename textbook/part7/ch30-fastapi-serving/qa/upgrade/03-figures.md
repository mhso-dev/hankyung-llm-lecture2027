# 03절 그림 설계표 (ainvoke 요청 응답 · paired)

- 색(규격 §5-3·과정 요약 §8·handoff 「색」 — 02 색 약속을 이어 씀): 보낸 요청·**실습 폴더 파일의 함수·그래프·줄**(처리 함수 `chat` 몸통·에이전트 그래프 `agent`·노드 함수 `answer_node`·`graph.add_node` 줄)과 두 판이 함께 쓰는 입력(코드로 적은 자료) **초록(tool)** · 노트북에서 우리가 쓴 부르기 줄(`agent.ainvoke`·`await pending`·`agent.invoke`·`agent.stream`)과 값 바꿔 보기에서 **바꾼 값 파랑(flow)** · 노트북 출력으로 확인한 값(종류 `coroutine`·`dict`·칸·상태 코드·`True`·`False`) **노랑(measure)** · 라이브러리가 하는 일·설치판 소스로만 본 동작·출력을 함께 읽은 사실 **회색(클래스 없음)** · **보라 0장**(모델 없음 — 실습 그래프는 모델을 쓰지 않는 그래프) · **빨강은 03-4 Before 칸의 결과 상자 하나뿐**(동기 `invoke`·`stream`이 받은 `TypeError` — Before 결함 결과, 받아 출력했어도 빨강).
- 같은 요소는 절 안 모든 그림에서 같은 색: 처리 함수 `chat` 몸통·그래프 `agent`·노드 함수 `answer_node`(초록) · `agent.ainvoke`·`await`(파랑).
- 라벨 규칙: 모델을 부르지 않아 라벨 값은 모두 노트북이 출력한 값입니다. 새 커널 두 번(A 프로젝트 맨 위 커널 07:42:43Z · B `notebooks/` 커널 07:42:53Z) 셀별 출력 22/22 같음(설치 셀 출력이 스트림 둘로 나뉘는 자리만 달라 `outputs_sha256`만 다름 — 글자는 같음). 흔들림 확인(`03-probe.md`)은 모델 판단이 없어 두지 않고, 노트북 밖 같은 장면 5/5(`/tmp/ch30-03/exp/p3_scene.py`)만 진단에 적습니다. 라벨 숫자는 200 하나(셀 [7]·[22] `상태 코드: 200`)와 요청 주소의 `/v1/chat`(셀 [5] 소스 글·[7] 첫 줄 주석)뿐. 대괄호·따옴표·중괄호는 라벨에서 뺌(`['messages', 'answer']` → 「칸 messages와 answer」, 오류 글 `No synchronous function provided to "answer".` → 「동기로 부를 함수 없음」). 응답 글 `Agent 응답 시간이 초과되었습니다`는 라벨에 넣지 않음.
- 차례: 시험 tryA·tryB(`/tmp` 사본) → 새 커널 A(`run_section.sh`, 그림 첨부 단계에서 멈춤 — 03-1 PNG가 아직 없어서) → 사본 B → **이 설계표** → `.mmd` 다섯·캡션 → `run_section.sh … --no-exec`(렌더·첨부·빌드) → 삽화(PNG를 본 뒤 alt·그림 읽기) → `--no-exec`.
