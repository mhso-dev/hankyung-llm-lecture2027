# 04절 그림 설계표 (astream과 응답 스트림 · experiment)

- 색(규격 §5-3·과정 요약 §8·handoff 「색」 — 02·03 색 약속을 이어 씀): 우리가 넣은 입력(코드로 적은 자료)과 **실습 폴더 파일의 그래프·노드·줄**(노드 `answer`·함수 `_compose_answer`·`answer.split()`·`writer({"token": …})`) **초록(tool)** · 노트북에서 우리가 쓴 줄(`agent.astream` 부르기만·`async for`·받을 때마다 이어 붙이기)과 실험에서 **바꾼 값 `stream_mode` 파랑(flow)** · 노트북 출력으로 확인한 값(종류 `async_generator`·`dict`·사건 수·자리·`True`) **노랑(measure)** · 라이브러리 메서드 `astream` **회색(클래스 없음)** · **보라 0장**(모델 없음 — 실습 그래프는 모델을 쓰지 않는 그래프) · **빨강 0장**(experiment 절 — 받은 결함 결과 없음).
- 같은 요소는 절 안 모든 그림에서 같은 색: 노드 `answer`(초록) · `async for`·이어 붙이기(파랑) · 사건 수·자리 출력(노랑).
- 라벨 규칙: 모델을 부르지 않아 라벨 값은 모두 노트북이 출력한 값입니다. 새 커널 두 번(A 프로젝트 맨 위 커널 08:16:51Z · B `notebooks/` 커널 08:17:02Z) 셀별 출력 23/23 같음·`outputs_sha256`까지 같음(`e7a37a53…`). 노트북 밖 같은 장면 5/5(`/tmp/ch30-04/exp/p3_scene.py`, md5 `1a5a0d72…`). 개수는 한글(여섯·일곱·없음), 숫자는 자리 1·6·7만(셀 [19] `custom 나온 자리: [1, 2, 3, 4, 5, 6]`·`updates 나온 자리: [7]`). 대괄호·따옴표·중괄호는 라벨에서 뺌(`['custom', 'updates']` → 「custom과 updates」, `{'token': …}` → 「칸 token 하나」). 걸린 초는 재지 않아 라벨에 없음.
- 차례: 시험 tryA·tryB(`/tmp` 사본) → 새 커널 A(`run_section.sh`, 그림 첨부 단계에서 멈춤 — 04-1 PNG가 아직 없어서) → 사본 B → **이 설계표** → `.mmd` 넷·캡션 → `run_section.sh … --no-exec`(렌더·첨부·빌드) → 삽화(PNG를 본 뒤 alt·그림 읽기) → `--no-exec`.
