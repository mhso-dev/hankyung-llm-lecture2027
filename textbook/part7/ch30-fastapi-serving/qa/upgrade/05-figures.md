- 색(규격 §5-3·과정 요약 §8·handoff 「색」 — 02~04 색 약속을 이어 씀): 우리가 보낸 요청 본문(코드로 적은 자료)과 **실습 앱 파일의 처리 함수·줄**(`chat_stream`·`yield ServerSentEvent(…)`·그래프 `astream` 부르기) **초록(tool)** · 노트북에서 우리가 쓴 함수·줄(`split_sse`·`parse_sse`·`json.loads`·바로 부르기·시험용 클라이언트로 POST·작은 판 `stream_answer`)과 실험에서 **바꾼 값 `response_class` 파랑(flow)** · 노트북 출력으로 확인한 값(종류·개수·본문 종류·`True`) **노랑(measure)** · 라이브러리가 하는 일(내놓은 값을 SSE 사건의 글로 적음) **회색(클래스 없음)** · **보라 0장**(모델 없음 — 실습 그래프는 모델을 쓰지 않는 그래프) · **빨강 0장**(experiment 절 — 받은 결함 결과 없음).
- 같은 요소는 절 안 모든 그림에서 같은 색: 처리 함수 `chat_stream`(초록) · `split_sse`·`parse_sse`·작은 판 `stream_answer`(파랑) · 사건 수·본문 종류 출력(노랑).
- 라벨 규칙: 모델을 부르지 않아 라벨 값은 모두 노트북이 출력한 값입니다. 새 커널 두 번(A 프로젝트 맨 위 커널 08:53:39Z · B `notebooks/` 커널 08:53:58Z) 셀별 출력 25/25 같음(`outputs_sha256`은 설치 셀 스트림이 둘로 나뉜 자리만 달라 다름 — 02·03 선례). 노트북 밖 같은 장면 5/5(`/tmp/ch30-05/exp/p3_scene.py`, md5 `8e59350e…`, 표준 오류 0). 개수는 한글(여섯·일곱·셋·없음), 숫자는 출력에 있는 사건 번호 `sse-1:0`·`sse-1:5`와 본문 종류 글뿐. 대괄호·따옴표·중괄호는 라벨에서 뺌(`{'token': '질문을 '}` → 「칸 token 하나인 dict」, `['event', 'data', 'id']` → 「event data id」). 걸린 초는 재지 않아 라벨에 없음. 긴 코드(`response_class=EventSourceResponse`·`text/event-stream`)는 처음부터 `<br>`로 나눔(03·04 첫 렌더 교훈).
- 차례: 시험 tryA·tryB(`/tmp` 사본) → 새 커널 A(`run_section.sh`, 그림 첨부 단계에서 멈춤 — 05-1 PNG가 아직 없어서) → 사본 B → **이 설계표** → `.mmd` 넷·캡션 → `run_section.sh … --no-exec`(렌더·첨부·빌드) → 삽화(PNG를 본 뒤 alt·그림 읽기) → `--no-exec`.
