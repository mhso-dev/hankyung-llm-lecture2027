# 여러 줄 문자열 형식 검증

2026-09-09: 문서 본문과 프롬프트를 삼중 큰따옴표 안에 실제 줄바꿈과 빈 줄을 넣는 형식으로 통일했습니다. 줄바꿈 구분자와 출력 간격 용도의 이스케이프는 유지했습니다.

- PC·모바일 화면 및 복사 검사 46건과 산출물 44개의 비밀값 미포함 검사를 통과했습니다.
