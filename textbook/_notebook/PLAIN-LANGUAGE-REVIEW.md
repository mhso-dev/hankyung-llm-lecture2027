## 문장 수정

낯선 말을 다른 낯선 말로 설명하는 문장을 구체적인 상황과 행동으로 바꾸었습니다. 필요한 기술 용어는 남기고 뜻과 예를 덧붙였습니다.

| 이전 표현 | 수정 방식 |
| --- | --- |
| 국제 표준이나 상호 배타적인 오류 코드가 아닙니다 | 공통으로 정한 공식 이름은 아니며, 한 사례가 두 유형에 함께 해당할 수 있음을 실제 예로 설명 |
| 유입 경로와 정보 관계로 진단합니다 | 무엇을 넣었고 어떤 답이 나왔는지 함께 확인합니다 |
| 직교합니다 | 서로 90도를 이룹니다 |
| 문서 계약 | 본문·출처·쪽 번호 등 실제로 맞춰야 할 항목을 설명 |
| 왜 지금 이것인가 / 선수 지식 되짚기 | 이 내용을 배우는 이유 / 앞에서 배운 내용 |

본문의 설명, 복습 해설, 노트북의 설명 셀을 문맥에 따라 읽었습니다. 짧게 만들기 위해 조건을 지우거나 결과를 단정하지 않았는지도 별도로 검토했습니다. RAG가 제공된 자료만 사용한다고 읽히는 문장과 글자 수를 토큰 수로 고정 환산하는 문장을 바로잡았습니다. Context rot의 실제 결과와 관찰 범위는 유지했습니다.
