## 적용한 학습 흐름

짧은 설명 → 기본 실행 → 중간 결과 관찰 → 값 하나 변경 → 결과 비교 → Before/After 순서로 구성했습니다. 모든 기본 예제에 완성 코드를 제공하며, 상세 주석·여러 줄 문자열·학생용 10개 블록을 유지했습니다. 한 셀에서 이해할 동작을 작게 나누었습니다. 내부 수학·해시·캐시 구현과 대규모 조합 실험은 기본 성공 경험 뒤에 읽는 심화 또는 후속 확장으로 구분했습니다.

- Ch 8: 업무별 독립 메시지 구성, 근거 위치를 고정한 길이 비교, 동일 질문을 사용하는 세 컨텍스트 설계의 실제 응답·토큰 관찰.
- Ch 9: 제공 E01.pdf를 읽고 쪽·본문·출처를 확인한 뒤 분할·임베딩·검색·답변 생성까지 실행. 검색 결과 수 변경과 근거 유무 비교, 실제 분할 설정을 반영한 색인 캐시.
- Ch 10: 문서 형식별 관찰, LangChain 청킹 API, 문장 하나·목록·차원 변경 비교, 문서 임베딩 캐시, 청크 크기와 모델을 각각 바꾸는 세 검색 실행.

## 실제 실행 결과

Python 3.12.13의 새 Jupyter 커널에서 설치 셀부터 마지막 셀까지 실행했습니다. API 실습은 `.env`의 키로 LangChain을 통해 실제 생성·임베딩을 호출했습니다. 모의 응답은 사용하지 않았습니다. 코드와 출력 해시, 실행 번호, 실행 시각은 각 노트북의 검증 메타데이터에 남겼습니다. 수정된 코드는 다시 실행했습니다.

실행 작업 폴더는 프로젝트 밖의 별도 실습 폴더였습니다. 배포 대상 PDF와 예제 파일만 넣고 실행하여 제외된 답안 파일·생성 중간물·개인 경로에 의존하지 않음을 확인했습니다. 마지막에 배포 자료 26개의 바이트와 실행에 사용한 자료를 대조했습니다.

Ch 10의 작은 검색 비교에서는 30자 청크로 만든 첫 결과에서 필요한 단서가 빠지는 결과도 나타났습니다. 이 결과를 True/False와 본문으로 그대로 표시합니다. After는 판정 기준 부재를 수정하며, 모든 검색이 정답이라고 가정하지 않습니다. 검색 품질의 전체 평가와 키워드 포함 검사를 구분했습니다.

## 독립 검토와 지침

독립 검토에서 발견한 실험 조건의 동시 변경, 본문과 실제 호출의 불일치, 캐시 설정과 색인의 불일치, 출력 없는 비교 기록, 캐시 단계 설명 부족을 수정했습니다. 실제 결과가 예상과 다를 때는 출력에 맞게 설명과 검증 범위를 정했습니다.

AGENTS.md와 교재·노트북 작성 에이전트 네 파일에 개발 입문자를 기본 독자로 삼는 기준을 반영했습니다. 기본 예제와 선택 과제를 구분하고, 예제 코드에 TODO를 넣도록 되어 있던 이전 에이전트 지침도 수정했습니다. .moai/context.md에는 현재 학생용 산출물과 과거 모듈 구현 기록을 구분해 다음 집필의 기준을 남겼습니다. 본문뿐 아니라 챕터 목차의 목표·준비·후속 연결도 현재 노트북과 대조했습니다. 변경 전 교재와 노트북은 `.moai/evolution/guided-practice-before/`에 보관했습니다.

## 검증 범위와 남은 조건

- 실제 업무 HWP 변환과 OCR 엔진 실행은 포함하지 않습니다. 해당 절은 제공 파일의 형식 식별·텍스트 유무·XML 범위를 관찰하는 실습입니다.
- SemanticChunker는 유지보수가 종료된 langchain-experimental 0.4.2의 버전 고정 학습 예제입니다. 유지보수 상태를 본문과 노트북에 명시했습니다.
- 문서 100건의 전체 품질 평가와 최종 모델 선정은 이번 작은 기본 실습의 완료 범위에 포함하지 않습니다.
- 모델 응답·검색 결과·사용량은 재실행 시 달라질 수 있습니다. 이번 기록을 일반적인 성능 우열이나 실제 청구액으로 해석하지 않습니다.
- 외부 맞춤법 서비스는 기존에 확인한 상업적 대량 처리 제한으로 사용하지 않았습니다. 새 설명은 일반 슬롭 검토와 별도 한국어 정독으로 검토했습니다. 코드·출력은 윤문 대상에서 제외했습니다.
