# LangChain 호출 방식 통일

2026-09-08 사용자 요청에 따라 기존 개념·실험·노트북 테마를 유지하고 호출 계층을 통일합니다.

1. 현재 노트북·본문을 보관하고 기존 회귀 테스트를 확인합니다.
2. Ch 8·9의 생성 호출은 `init_chat_model`과 `invoke`, Ch 10의 임베딩은 `OpenAIEmbeddings`로 작성합니다. 직접 SDK 객체를 기본 실습에 사용하지 않습니다.
3. 바뀐 노트북은 Python 3.12 새 커널에서 실제 API로 실행하고 출력·토큰 설명을 갱신합니다. 임베딩 API가 제공하지 않는 사용량은 실제 사용량으로 표시하지 않습니다.
4. 공통 검증에 기본 실습의 직접 SDK import 금지 검사를 추가합니다. 전체 HTML·노트북 대조, 화면·복사, 비밀값 검사를 수행합니다.
5. 작성 지침·진행 기록을 갱신하고 변경 코드와 설명을 독립 검토합니다.

기존 파일형 모듈과 과거 실행 기록은 강사용 확장 자료로 보존합니다. 이 전환은 기본 실습 20개를 대상으로 하며, 직접 SDK 원리를 다루도록 명시된 Ch 18의 교육 경계는 유지합니다.
