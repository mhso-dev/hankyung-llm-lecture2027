# 노트북 형식 통일 계획

기존 Ch 8·9·10의 설명, 도식, 복습 문제를 보존하고 실행 예제를 독립 실행 노트북으로 바꿉니다. 원본과 기존 모듈은 보존합니다.

1. 기존 빌드 추출 테스트와 챕터별 테스트로 기준선을 확인합니다.
2. 절마다 준비 → 개념 설명 → 짧은 코드 → 실제 출력 → 해석 → 실패 확인 순서의 노트북을 만듭니다.
3. 동일한 실행 완료 노트북에서 HTML 코드와 결과를 생성하고 공통 Jupyter 테마를 적용합니다.
4. 빈 커널 실행, 출력·코드 해시, 복사 정확성, PC·모바일 화면을 검증합니다.
5. 작성 지침과 진행 맥락을 갱신하고 변경 문장을 독립 검토합니다.

기준선: 기존 Ch 9 빌드 회귀 테스트 3개 통과. 챕터별 테스트는 각 챕터 notebook-verification.md에 기록합니다.
