# 노트북 전환 독립 검토 기록

이 문서는 초기 테마 전환 시점의 검토 기록입니다. 후속 LangChain 호출 통일의 최종 결과는 [호출 통일 검증](LANGCHAIN-VERIFICATION.md)을 확인합니다.

**최종 판정: APPROVE. 남은 이슈 없음.**

검토일: 2026-09-08. 집필 담당과 별도의 검토 에이전트가 공통 실행 도구, 학생용 셀, 설명과 실제 출력의 일치 여부를 검토했습니다.

## 진단 요약

공통 실행·표시 도구와 작성 지침은 독립 검토를 통과했습니다. 본문 검토에서는 짧은 코드로 바꾸는 과정에서 일부 학습 목표와 해설이 이전 모듈 실험을 설명하는 문제가 발견되었습니다. 해당 지적을 반영한 뒤 원본 노트북과 HTML을 다시 대조했습니다.

## 수정 텍스트

수정 문장은 각 챕터 `_src/`와 노트북 마크다운에 반영했습니다. 코드와 실제 모델 출력은 윤문하지 않았습니다. Ch 9의 실제 모델 출력에 포함된 맞춤법 오류도 실행 증거로 보존했습니다.

## 주요 변경사항

- Ch 8: 기준 입력과 네 실패 조건을 실제 API로 비교하고 단정적인 결과 설명을 수정했습니다.
- Ch 9: 두 프롬프트를 각각 5회 실행한 결과, 검색 결과 수 변경, 같은 거부 답의 두 원인, 설정 덮어쓰기·해시·캐시·JSONL 저장과 읽기를 본문에 맞췄습니다. 이번 실행에서 환각이 나타나지 않았다는 사실을 명시했습니다.
- Ch 10: 실제 문자·재귀·토큰 분할, 시맨틱 경계, 캐시 재사용, 원문 하나의 청킹 3종×임베딩 2종을 실행했습니다. 예상 비용 계산과 전체 문서 실험은 확장 범위로 표시했습니다.
- 공통: 실행 전후 코드·출력 해시, Python 3.12 새 커널, 정확한 복사·내려받기, 비밀값 노출 여부를 확인했습니다. 최종 20개 노트북·116개 코드 셀·48개 화면 및 복사 검사를 통과했습니다. 검토에서 추가로 발견한 타입 표기 4곳은 공식 클래스 경로와 Pillow 열거형으로 수정했고, 공통 테스트 10개와 Ruff·Pyright를 다시 통과했습니다.

## 한국어 검토 범위

산문·최소 심각도 S1 기준으로 일반 슬롭 검수와 독립 한국어 정독을 진행했습니다. 외부 맞춤법 서비스는 해당 스킬의 상업적 대량 처리 제한 때문에 사용하지 않았습니다. 기존 설명 전체를 새로 윤문한 작업은 아니며, 변경 문장의 의미와 실행 사실 보존을 확인했습니다.
