# Ch 8 05 학습 목표 일관성 개편

2026-09-09. 사용자는 context rot의 정의와 코드가 서로 다른 이야기를 한다고 지적했습니다. 질문 검증 예외와 입력 배치 오류를 다루던 Before/After를 제거했습니다. 초기 두 조건 실습과 위치 3×3 도식도 교체했습니다.

## 현재 학습 흐름

정의(입력 길이에 따른 필요한 정보 활용 성능 저하) → 같은 질문·근거·모델·지시문·출력 상한·자료 중앙 배치 고정 → 주변 문장 수만 세 단계로 변경 → 각 길이 세 번 실제 호출 → 입력 토큰·답·정답 확인 → 관찰 결과 해석 → 같은 질문의 복습으로 구성했습니다.

| 조건 | 입력 토큰 | 자동 핵심어·출처 확인 | 독립 검토자의 답 원문 확인 |
|---|---:|---:|---|
| short | 64 | 3/3 | 세 답 모두 월요일·E01 p.2가 맞음 |
| medium | 2,224 | 3/3 | 세 답 모두 월요일·E01 p.2가 맞음 |
| long | 21,664 | 3/3 | 세 답 모두 월요일·E01 p.2가 맞음 |

Python 3.12 새 커널에서 9개 코드 셀을 실행하고 LangChain으로 gpt-5.4-mini를 아홉 번 호출했습니다. 모두 정답이므로 이번 조건에서는 성능 저하 미관찰로 해석합니다. 이 결과를 context rot 발생 사례로 쓰지 않습니다. 반복 문장과 단일 질문의 한계, 적은 반복 수, 문자열 검사의 한계를 본문에 명시했습니다.

## 형식과 검증

- 이 절은 `lesson_format="experiment"`를 명시하며 단일 노트북을 실행 예제에 표시합니다. 6번 블록은 실험 결과 해석입니다.
- 기존 19절의 Before/After 계약은 유지합니다. 실험형에서 Before/After를 섞거나 분할 삽입하는 경우를 검증 도구가 거부합니다.
- 노트북과 생성기의 전체 코드가 일치합니다. 도식 SVG와 Excalidraw는 같은 생성기에서 생성했습니다.
- 전체 20개 노트북·206셀의 HTML·코드·출력·다운로드 대조를 통과했습니다.
- 공통 회귀 테스트 22개, 수정 코드 Ruff와 공통 검증 코드 Pyright 검사를 통과했습니다.
- Ch 8의 7페이지 및 시작 페이지를 PC·모바일에서 검사한 16건이 통과했습니다.
- 배포 ZIP을 갱신하고 원본 해시와 필요한 자료, 실제 키 미포함을 확인했습니다.

별도 검토자가 정의·코드·실제 답 9개·결론·도식을 대조하고 한국어를 정독했습니다. 새로운 핵심 결함은 없었습니다. 일반 슬롭·한국어 의미 보존 검토를 마쳤으며 외부 맞춤법 서비스는 기존 상업적 대량 처리 제한으로 생략했습니다.
