# 실패 코드와 수정 코드 비교 검증

검증일: 2026-09-08.

기존 「일부러 실패해 보기」에 설명만 보이던 문제를 수정했습니다. 각 절의 같은 위치에서 **Before 실패 코드·실제 출력**과 **After 수정 코드·실제 출력**을 직접 비교합니다. PC에서는 두 열, 모바일에서는 위아래로 표시합니다.

노트북은 준비와 실행 예제 → Before → After 순서로 실행합니다. HTML의 두 블록은 같은 노트북의 셀을 나누어 표시하며, 중복 코드가 없습니다. 「전체 코드 복사」와 내려받는 노트북은 두 블록을 모두 포함합니다. 특정 셀의 복사 버튼은 해당 입력 코드만 복사합니다.

수정 코드는 같은 실패 원인을 해결하고 실제 결과를 출력합니다. 미지원 파일 형식은 형식 검사와 적절한 분기로 처리하며, HWP 변환이나 OCR 성공을 꾸미지 않습니다. 생성 모델과 임베딩은 LangChain 사용 원칙을 유지합니다.

## 검증 방법

변경 전 공통 테스트를 확인하고 분할 표시·한 쌍 누락·셀 순서·빈 결과 검사를 추가했습니다. 원본은 챕터별 `qa/before-after-before/`에 보관했습니다. 모든 노트북을 Python 3.12 새 커널에서 준비 셀부터 실행하고, 코드와 출력의 해시를 확인한 뒤 HTML을 생성합니다.

공통 대조는 ① 코드·출력·다운로드 파일 일치 ② Before/After가 실제 6번 블록에 표시되는지 ③ 각 단계에 코드와 실제 출력이 있는지 ④ 셀별·전체 복사 결과가 일치하는지 ⑤ PC·모바일에서 비교 배치와 가독성을 유지하는지 확인합니다.

## 최종 검증

전체 20개 노트북에 Before/After 20쌍을 배치했습니다. 코드 셀은 총 136개이며 최대 16줄입니다. 새 커널 실제 실행, 코드·출력·내려받기 파일 대조, 6번 블록의 비교 코드 배치를 모두 통과했습니다. 공통 회귀 테스트 18개와 챕터별 회귀 테스트 64개가 통과했고 Ruff·Pyright도 오류 없이 통과했습니다. PC·모바일 화면·복사·비교 배치 검사 48건과 전달 파일 44개의 비밀값 검사도 통과했습니다.

## 독립 검토

최종 판정은 **APPROVE**이며 남은 이슈는 없습니다. 20개 절의 실패 원인과 실제 수정, 코드·출력·다운로드·6번 블록 배치 일치를 독립 검토했습니다. 규정 충돌의 시행일 선택과 HWP 미지원 처리 설명도 실제 코드에 맞춰 확인했습니다.
