# 처음 개발하는 수강생을 위한 실습 개편

2026-09-09 사용자 확인: 개발 경험이 없는 수강생부터 웹 개발·기초 머신러닝 경험자가 함께 따라 할 수 있는 교재가 필요합니다.

20절의 실행 예제를 설명·실행·관찰·값 하나 변경·비교로 분할합니다. Ch 9는 제공 PDF를 읽고 검색·답변까지 연결하는 첫 성공 경험을, Ch 10은 고수준 청킹과 임베딩 API를 먼저 사용한 뒤 조건을 비교하는 흐름을 보강합니다. 기본 코드에서 세미콜론과 복합 처리를 풀어 쓰고, 기존 Before/After·상세 주석·삼중따옴표·학생용 구성을 유지합니다. HTML의 설명·목표·복습·선수 지식도 실제 코드에 맞춥니다.

리더는 공통 지침·실습 준비 안내·배포 자료·실행 검증·빌드를 담당하고 챕터별 작성은 독립 범위로 나눕니다. 원본은 `.moai/evolution/guided-practice-before/`에 보관합니다. 노트북 전체를 새 Python 3.12 커널에서 실행하고, 실제 API 출력·코드 해시·HTML·다운로드·PC/모바일 복사·데이터 경로를 확인합니다. 별도 검토자가 설명과 동작 및 학습 단계의 일치를 확인합니다.

실행 전 예상 비용은 기존 입력 규모와 저장된 참고 단가를 기준으로 전체 약 1달러 이내의 개발 검증 예산으로 잡습니다. 실제 청구액이 아닌 추정이며 입력 문서는 필요한 부분만 사용합니다.
