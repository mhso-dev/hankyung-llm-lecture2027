# 학생용 교재 구성 변경

2026-09-09 요청: 학생이 보는 교재에서 강사 노트를 제외합니다.

원본과 빌더를 보관한 뒤 강사 노트 본문·목차·전용 스타일을 제거하고 참고 자료를 10번 블록으로 조정합니다. 작성 지침과 집필 에이전트도 학생용 10개 블록을 기준으로 갱신합니다. 완료 여부는 20절의 본문·목차, 기존 코드·출력·Before/After 대조, 화면 검사로 확인합니다.
