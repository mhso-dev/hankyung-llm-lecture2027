## 3. 결론과 노트북 설계에 반영한 것

- **이번 모델(`gpt-5.4-mini`, temperature 0, 추론 none)은 이 실험에서 문서 속 지시를 따르지 않았습니다.** 방어 없이 넣은 요청에서도 따르지 않았으므로, 이 실험으로는 「문서를 구역으로 감싸기」가 효과가 있는지 **가를 수 없습니다**(Ch 11·12 「이 조건에서는 가를 수 없다」 태도).
- 그래서 노트북의 실험 1·2(방어 없음·구역 감싸기, 자료 파일 `E99`)는 그대로 두고 결과를 「이번 실행에서는」으로만 적습니다(결과 읽기 둘째 단락·b6·b7). 모델 답 문장·표지 결과는 그림 라벨·캡션·정리·복습에 넣지 않습니다.
- **결론은 결정적인 방어 동작에 세웁니다**: 말 목록 검사로 `E99`를 의심 문서로 찾음 · 한 흐름이 **모델을 부르기 전에** 격리해 멈춤(예약한 호출 0, 모델 요청 0, 기록 `blocked_document`) · 격리한 문서를 뺀 목록으로 다시 부름 · 손으로 적은 답의 없는 출처를 출력 검사가 막고 기록 · 기록 파일 줄 수와 원문 없음 · 바꿔 쓴 공격 문장은 말 목록 검사가 놓침(모델에 보내지 않음).
- 값 바꿔 보기에 쓰는 「바꿔 쓴 공격 문장」은 이 절에서 만든 글이지만 **모델에 보내지 않고** 말 목록 검사에만 넣습니다(후보 K1·K2와 다른 용도, 확인 요청 0번).
