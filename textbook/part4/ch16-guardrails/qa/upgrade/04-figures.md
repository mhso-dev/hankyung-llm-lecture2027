## PNG를 직접 열어 본 결과 (설명은 PNG를 본 뒤에 씀)

- `04-1`: 위에서 아래로 초록(질문 셋) → 파랑(예약) → 화살표 둘로 나뉘어 **왼쪽 보라 모델 → 노란 받은 응답 둘**, **오른쪽 노란 셋째 질문 멈춤**. 두 갈래 모두 노트북 7절에서 실제로 실행한 흐름이라 실선이고 「화살표가 둘로 나뉩니다」로 썼습니다. 긴 갈래(상자 둘)가 왼쪽에 놓였습니다(03절이 적은 dagre 배치와 같음).
- `04-2`: 첫 판에서 검사 둘·셋 상자 글이 저절로 꺾여(「…한도 / 안인가」) `<br>`로 미리 세 줄로 나눠 다시 렌더했습니다(474 → 458). 파란 검사 셋이 위에서 아래로 계단처럼 왼쪽으로 내려가고, 각 검사에서 **점선**이 오른쪽 노란 ValueError 상자로 모입니다. 점선은 검사에 걸릴 때만 가는 갈래입니다(세 갈래는 8·7·9절에서 각각 한 번씩 실제로 걸림). 맨 아래 노란 상자는 5절 한 번 예약 뒤의 두 칸입니다.
- `04-3`: 왼쪽 칸 Before(초록 → 빨강), 오른쪽 칸 After(초록 → 파랑 → 노랑 둘), 아래 가운데 회색 상자. After 칸은 모델 상자를 넣지 않았습니다(02-3처럼 폭을 줄이려고, 모델 요청 두 번은 도식 읽기 문장으로). 회색 상자 「두 칸 모두 같은 질문 셋 · 호출 한도 둘 · 비용 상한 0.01」은 6절 Before와 7절 After가 모두 같은 `questions`·`max_calls`·`max_cost_usd`를 쓴 코드로 확인한 사실입니다.
- `04-4`: 왼쪽 칸 7절(비용 상한 0.01), 오른쪽 칸 9절(0.003), 칸마다 초록 → 노랑, 아래 회색 상자. 노란 상자 글은 `<br>`로 미리 세 줄로 나눴습니다.

## 라벨에 넣지 않은 값

- **흔들린 값**: 모델 답 문장(새 커널 C·D에서 둘째 답 끝말 「쉽니다」/「휴관합니다」가 갈림). 토큰 수(입력 122·출력 53)는 C·D 두 번 같았지만 모델 출력에 달린 값이라 그림에 넣지 않았습니다.
- **라벨에 넣은 값**: 정한 값(호출 한도 둘·비용 상한 0.01·0.003·예상 비용 0.002)과 코드가 정하는 결과(보낸 요청 둘·하나, 멈춘 질문 자리, 예약 한 번 뒤 두 칸). 모두 C·D 두 번 같았습니다.
- **개수는 한글로**: 「질문 셋」·「요청 셋·둘·하나」·「호출 한도 둘」·「검사 하나·둘·셋」·「칸 둘」. 숫자를 그대로 쓴 라벨은 정한 값 `0.01`·`0.003`·`0.002`, 모델 이름 `5.4`, 칸 제목의 절 번호(7절·9절), 출력 그대로의 `calls 1`·`0 이상`뿐입니다.
