## 5. 설계 — paired

- 공통 재료(노트북 1~5절, example): 자리 찾기 → 자료 파일 읽기·`E01` 고르기 → 이 절에서 정한 값(01절과 같은 `max_chars = 500`·`system_text`, `document_line`) → **가짜 값 넷**(`fake_values`) → `find_raw_values` 정의 → 질문(휴관일 질문 + 연락처·회원 번호 문장) → `validate_query` 통과(`질문에 든 원문 값 수: 4`) → 4절 정규식 넷 `re.findall` → 5절 `re.sub` 한 번 → `PII_PATTERNS`·`PII_NAMES` → `mask_pii` 정의 → 가리기(`종류별 개수: {'email': 1, 'phone': 1, 'rrn': 1, 'card': 1}`·`가린 질문에 남은 원문 값 수: 0`).
- **Before**(`lesson_part="before"`, 6절): 가리기 함수를 만들어 두고도 부르지 않은 흐름. 입력 검사를 지난 질문 그대로 보낼 사용자 메시지(`…에 남은 원문 값 수: 4`)·기록 한 줄(`json.dumps`, `…: 4`). **모델에는 보내지 않음**(보내기 직전에서 멈춤) — Ch 22 02 본문 「한 줄을 빠뜨리면 원문이 나갑니다」와 같은 장면.
- **After**(`lesson_part="after"`, 7~9절): 가린 질문으로 메시지(`…: 0`) → **모델 요청 1번**(`답에 든 원문 값 수: 0`) → 기록 한 줄(가린 질문 + 개수, `…: 0`) → 두 흐름 표(`가리지 않은 흐름 | 4 | 4`·`가린 흐름 | 0 | 0`) → 8절 손 확인(`출처 표시가 든 글: 메일 <EMAIL_MASKED>, 출처 [E01 p.1]` + `assert` 둘, `조사를 붙여 쓴 글: 메일 <EMAIL_MASKED> 주세요`) → 9절 값 바꿔 보기(질문 속 전화번호만 빈칸 모양으로 `replace` → `'phone': 0`·`남은 원문 값 수: 1`).
