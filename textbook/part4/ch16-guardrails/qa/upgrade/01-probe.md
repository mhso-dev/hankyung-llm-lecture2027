# Ch 16 01절 흔들림 확인 기록 — 모델 답의 출처 표시

- 작업 2026-09-23 · 규격 `QUALITY-UPGRADE.md` §2-7 10번 끝(「입력을 고치기 전에 먼저 흔들림을 확인합니다」)에 따른 **노트북 밖 확인 실행**.
- 까닭: 01절의 핵심 관찰(「모델 답이 적은 출처 표시가 이번 검색 결과의 허용 목록 안에 있어 출력 검사를 통과한다」)은 모델이 쓴 답 한 줄에 기댑니다. 모델이 `[E01 p.1]`을 안 적으면 결과 읽기·그림·정리가 모두 흔들립니다. 그래서 **노트북을 실행하기 전에** 같은 요청을 따로 다섯 번 보냈습니다.
- **결론**: 다섯 번 모두 답 끝에 `[E01 p.1]`이 있었습니다(**5/5**). 입력은 그대로 두고 노트북을 썼습니다. 다만 **답의 글자 수는 72·73으로 갈렸습니다**(문장 끝 마침표가 있는 답과 없는 답). 그래서 답 글자 수는 결과 읽기 첫 단락·그림 라벨·캡션·정리에 넣지 않았습니다(규격 §2-7 9번 끝).

## 1. 방법

- 스크립트 기기 `$HOME/ch16work/probe01.py`(세션 홈, 마운트 폴더 밖). 가상환경 `.cache/vm/venv-ch16-guardrails`(노트북 실행과 같음).
- 키는 `.env`에서 `load_dotenv`로만 읽고 출력하지 않았습니다.
- 모델 `init_chat_model("openai:gpt-5.4-mini", temperature=0, reasoning_effort="none")` — `nbkit.model_source()`와 같은 인자.
- 요청 글은 노트북 5절이 만드는 메시지 두 개와 같은 글입니다. 문서는 `labs/part4/ch16-guardrails/data/retrieved-documents.json`의 `E01`(읽기만).

```text
system: 검색 문서에 있는 사실만 써서 한국어 한 문장으로 답하세요. 답 끝에 쓴 문서의 출처를 [문서ID p.쪽] 꼴로 적으세요.
user:   질문: 도서관 휴관일은 언제인가요?
        검색 문서 E01 1쪽: 미르시립도서관은 매주 월요일과 법정 공휴일에 휴관합니다. 공휴일이 월요일과 겹치면 다음 날인 화요일에도 휴관합니다.
```

## 2. 결과 — 다섯 번

| 회차 | 답 글자 수 | 답 끝에 `[E01 p.1]`이 있는가 |
|---|---|---|
| 1 | 73 | 있음 |
| 2 | 73 | 있음 |
| 3 | 73 | 있음 |
| 4 | 72 | 있음 |
| 5 | 72 | 있음 |

- 다섯 번 모두 답 본문은 「미르시립도서관은 매주 월요일과 법정 공휴일에 휴관하며, 공휴일이 월요일과 겹치면 다음 날인 화요일에도 휴관합니다」였고, 1~3회는 문장 끝에 마침표가 있었고 4~5회는 없었습니다.
- **확인 요청 합계 5번**(모두 `gpt-5.4-mini`, 임베딩 0). 예상 비용은 미화 0.01달러 아래입니다(예상 비용 ≠ 청구 금액).

## 3. 본문에 반영한 것

- **안 흔들린 값만 결론에**: 답 끝의 출처 표시 `[E01 p.1]`, 허용 목록 `['[E01 p.1]']`, 검사를 통과한 답 수 `1`, 막은 답 수 `2`.
- **흔들린 값은 뺌**: 모델 답의 글자 수(72 또는 73). 노트북 어느 셀도 모델 답의 글자 수를 출력하지 않습니다.
- **모델이 쓴 글에는 `assert`를 걸지 않았습니다**(규격 §3). `assert`는 손으로 정한 글자에 대한 세 검사 함수의 동작에만 걸었습니다.

## 4. 노트북 실행과 대조 (2026-09-23)

- 노트북 새 커널 실행 네 번(앞 코드 `33feddc6…`의 A 08:46:10·B 08:46:30, 교재 코드 `3538ba12…`의 C 09:06:27·D 09:06:44 UTC) 모두 답 끝에 `[E01 p.1]`이 있었습니다. 확인 다섯 번과 합치면 **아홉 번 모두** 같은 표시입니다.
- 답 본문은 아홉 번 모두 같은 문장이었고, 문장 끝 마침표만 갈렸습니다(A·D 없음, B·C 있음). 교재 출력은 C입니다(`run_section.sh`가 실행한 판, 마침표 있음).
- C·D는 코드 두 곳(`repeat_count = 100`, 손 확인 셀의 `max_chars`)만 고친 판입니다. 모델에 보내는 요청 글은 A·B와 같습니다.
- 이 기록의 요청 수: 확인 5 + 노트북 4 = **9번**(모두 `gpt-5.4-mini`, 임베딩 0). 예상 비용 합계는 미화 0.01달러 아래입니다(추정, 청구 금액 아님).
