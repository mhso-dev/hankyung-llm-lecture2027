# 05-5-번진-도장과-예비-도장 (Higgsfield 삽화)

설명 대상 문장(본문 b4 비유 단락): 01절 탁자에 이번에는 손도장 둘이 놓였다고 해 봅니다. 파란 도장으로 쪽지에 찍었는데 무늬가 번졌습니다. 같은 도장으로 한 번 더 찍어도 번지자, 곁에 둔 초록 예비 도장으로 찍었습니다. 몇 번 찍었고 어느 도장이 찍혔는지는 대장에 한 줄 적고, 개인정보가 있던 자리는 02절처럼 천으로 덮습니다.

구성 요소와 배치: 흰 바탕 나무 탁자 가운데에 **쪽지 한 장** — 왼쪽에 **번진 파란 동그라미 무늬 둘**(= 기본 흐름 두 번의 시간 초과, 5절 둘째 실행), 오른쪽에 **또렷한 초록 동그라미 무늬 하나**(= 예비 모델의 예비 답). 쪽지 곁에 **나무 손도장 둘**(파란 바닥 = 기본 모델, 초록 바닥 = 예비 모델). 탁자 뒤에 **01절의 펼친 대장**(= 감사 기록)과 한 줄 앞머리를 덮은 **02절의 덮개 천**(= 가린 개인정보). 숫자·글자 없이 무늬의 수·또렷함·색으로만 읽히게 했습니다.

시선 순서: 쪽지의 번진 파란 무늬 둘 → 또렷한 초록 무늬 → 곁의 두 도장(색 짝 맞추기) → 뒤쪽 대장과 천.

검수 기준: 그림만 보고 「파란 도장은 번지고 초록 도장이 또렷하게 찍혔다」가 읽히는가. 번진 파란 무늬가 둘, 초록 무늬가 하나, 도장이 둘인가. 글자·숫자·사람이 없는가.

비유 계열: 이 챕터의 **도장과 도장 대장**(01절)·덮개 천(02절)을 같은 탁자 위에서 다시 썼습니다(handoff §04 → §05 9번 제안 「대장 + 덮개 천」에 인계 지시서의 「번진 도장 → 두 번째 도장」을 합침). 쓰지 않은 것: Ch 22 04절 삽화(전화 세 대), Ch 9~15의 카드·봉투·서랍·쟁반·바구니·사과·저울·스티커, 03절 두루마리·04절 개찰구.
