## 경계 확인

Ch12의 36행을 생성 실패로 표시하지 않았습니다. 실제 답변과 Groundedness judge는 세 사례에 대해서만 실행했습니다. 운영 judge 모델은 `[[미정: judge 모델]]`로 유지했습니다. 독립적인 사람 라벨이 없어 인간 평가자와의 일치율은 확인 필요 항목입니다. LangSmith API 키가 없어 클라우드 trace는 실행하지 않았습니다. Batch는 JSONL 생성과 검증까지만 수행했고 실제 제출·완료·할인 청구는 확인하지 않았습니다.

Ch16보다 먼저 Middleware를 사용하지 않았고 LangGraph 에이전트를 도입하지 않았습니다. 기본 노트북은 프로젝트 전용 모듈을 import하지 않으며 각자 Python 3.12 새 커널에서 실행됩니다.
