# Ch 15 공식 문서 조사

확인일은 2026-09-10입니다. 과정 기준은 Python 3.12, LangChain 1.4, LangSmith 0.7.14입니다.

LangSmith의 RAG 평가에서 Correctness는 응답과 정답 답변을 비교하므로 reference answer가 필요합니다. Relevance는 응답과 질문, Groundedness는 응답과 검색 문서, Retrieval relevance는 검색 문서와 질문을 비교합니다. Ch11의 `gold_doc_ids`는 검색 정답 문서 식별자이며 정답 답변 문장과 구분했습니다.

LangSmith trace는 전체 요청과 child run의 입력·출력·시간·사용량을 연결합니다. 스트리밍 호출에서 첫 토큰 이벤트가 있어야 TTFT를 계산할 수 있습니다. 이 교재는 질문 재작성, 검색, 리랭킹, 생성을 child run으로 나누는 로컬 JSON 구조를 실행했습니다. LangSmith API 키가 없어 cloud 업로드는 선택 확장으로 남겼습니다.

OpenAI Batch API 입력은 JSONL이며 각 요청에 `custom_id`, `method`, `url`, `body`를 둡니다. 공식 API 문서는 현재 24시간 completion window와 50% 할인 정책을 안내합니다. 이 교재는 파일 생성과 정적 검증까지만 실행했으며 업로드·완료·실제 청구 할인은 확인하지 않았습니다.
