## 라벨에 넣지 않은 값

- **까닭 글**: 새 커널 두 번(실행 A·B)에서 판정 두 셀(6절 `rag-judge-v1.0.0`·8절 `rag-judge-v1.1.0`)의 까닭 문장이 달랐습니다. 어느 그림에도 까닭 문장을 넣지 않았습니다.
- **점수·네 칸 수·일치율**: 두 실행에서 모두 같아(점수 여덟, 일치율 셋, 값 바꿔 보기 셋) `04-2`·`04-3`·`04-4` 라벨에 넣었습니다.
- **03절과 다른 값**: 새 판 `rag-judge-v1.1.0`의 Q090 점수는 03절 두 실행에서 1, 이 절 두 실행에서 0이었습니다. `04-3`에는 이 절 두 실행의 값(두 판 모두 `1 · 1 · 0 · 0`)만 넣었고, 03절과 다르다는 사실은 본문 b6·b7에 적었습니다. **(바로잡음, 2026-09-21 마감 — 검토 A A-10)** 이 줄의 「이 절 두 실행의 값만」은 새 판 값이 조건 없이 라벨에 들어간 상태였고(`04-diagnosis.md` §8의 「그림에 넣지 않았다」와도 어긋남), `04-4`도 「두 판 일치율 1.0」이었습니다. 마감에서 `04-3` 가운데 상자를 「점수 / 02절 판 1 · 1 · 0 · 0 / 새 판은 이번 두 실행에서 / 같은 점수」, 회색 상자 끝줄을 「이번 두 실행에서 같은 점수」로, `04-4` 노란 상자를 「02절 판 일치율 0.75 / 규칙 함수 0.75」·「02절 판 일치율 1.0 / 규칙 함수 0.5」로 줄이고 회색 상자에 「새 판은 이번 두 실행에서 / 02절 판과 같은 값」을 더했습니다(다시 렌더 폭 635·557).
