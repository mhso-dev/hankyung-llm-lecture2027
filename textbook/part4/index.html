실험에서 확인한 범위

어느 노드로 이동할지는 조건문·임계값·호출 횟수로 정합니다. 모델은 질문을 재작성하거나 답변과 평가 결과를 생성합니다. 이 파트에서 배운 조건과 처리 순서는 중간 프로젝트에 적용합니다.

같은 질문에서 검색 품질이 나아져도 호출 수나 지연이 늘 수 있습니다. 문서 수·질문 수· 정답 기준·모델을 함께 기록하고, 실행한 표본 밖에서도 같은 결과가 나오는지는 추가로 확인합니다. 모델 평가 점수만으로 답변이 정확하다고 판단하지 않습니다. 실제 근거와 사람이 검토한 평가 기준도 확인합니다.

제공 문서와 개인정보 예시는 학습용 합성 자료입니다. API 생성 문장과 처리 시간은 실행마다 달라질 수 있습니다. API 재실행에는 사용량에 따른 비용이 발생합니다. 계정이 필요한 외부 평가 서비스와 비동기 작업은 각 절에서 실제 실행 여부를 확인합니다.

중간 프로젝트에 적용하기

검색부터 출처 있는 답변까지 이어지는 그래프와 RAG 패턴 한 가지 이상, 가드레일 한 가지 이상을 연결합니다. 평가 질문 50문항을 준비하고 개선 전후의 검색 재현율(Recall@50)과 답변의 근거 충실도(Groundedness)를 구분해 제시합니다. Recall@50은 정답 문서 중 상위 50개 검색 결과에 포함된 문서의 비율이며, Groundedness는 답변의 주장을 검색 문서가 뒷받침하는지 살펴봅니다. 대화당 비용의 95백분위수(p95)와 전체 처리 흐름 도식도 함께 작성합니다. p95는 측정한 대화 비용을 작은 순서로 나열했을 때 약 95% 지점의 값입니다. 교재의 작은 실험 결과를 프로젝트의 50문항 평가 결과로 옮겨 적지 않고, 자신의 전체 흐름을 다시 실행해 측정합니다.
