# Ch13 LangGraph 기초 실습

각 노트북은 Python 3.12 새 커널에서 첫 셀부터 독립 실행합니다. 노트북의 설치 셀과 `pyproject.toml`은 LangGraph 1.2.11, LangChain 1.4.0을 고정합니다. LangChain 1.4.0이 LangGraph 1.2.11 이상을 요구하므로 함께 설치되는 최신 1.2 계열을 사용합니다.

07절은 `labs/part3/ch12-retrieval-tuning/data/advanced-documents.json`과 `runs/advanced-continuity-integrated-result.json`을 읽습니다. 저장된 답변은 재사용하지 않습니다. 제공 PDF를 다시 읽고 OpenAI 임베딩과 Kiwi BM25 검색, RRF 병합, `BAAI/bge-reranker-v2-m3` 재정렬, `gpt-5.4-mini` 생성을 실제로 실행합니다. 예상 API 비용은 미화 1달러 미만이며, 실행 전 프로젝트 루트 `.env`에 `OPENAI_API_KEY`가 있어야 합니다. 키 값은 출력하지 않습니다.
