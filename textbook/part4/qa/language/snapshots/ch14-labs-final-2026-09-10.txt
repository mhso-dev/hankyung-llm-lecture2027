# Ch 14 RAG 패턴 확장 실습

Python 3.12와 uv를 사용합니다. 각 노트북은 빈 커널에서 독립 실행됩니다. 프로젝트 루트 `.env`의 `OPENAI_API_KEY`가 필요하며 키 값은 출력하지 않습니다.


실습은 Ch12의 교육용 문서 12건과 질문 8건을 그대로 복제해 사용합니다. 원본은 `labs/part3/ch12-retrieval-tuning/data/core-*.json`입니다. Ch11에서 사용한 정답 문서 ID 방식으로 `Recall@3`을 계산합니다. 이 축소 표본은 패턴의 중간 결과를 읽기 위한 자료이며 실제 서비스 품질을 대표하지 않습니다.

모든 생성 호출은 `gpt-4.1-mini`, 임베딩은 `text-embedding-3-small` 256차원을 사용합니다. 아홉 노트북을 한 번씩 실행할 때 예상 비용은 0.10달러 미만입니다. 각 절은 변형 질문 수와 재시도 수를 코드에서 제한합니다. 실행 시간은 네트워크와 API 상태에 따라 달라집니다.

06절은 CRAG 논문의 학습된 검색 평가기와 웹 검색을 재현하지 않고, 검색 점수 임계값에 따른 한 번의 보정 검색만 구현합니다. 07절은 reflection token을 학습한 Self-RAG 모델을 재현하지 않고, 생성 뒤 근거 점수를 확인하는 교육용 흐름입니다. 08절은 범주가 주어진 작은 자료에서 한 단계 요약 노드를 직접 만듭니다. RAPTOR 논문의 반복 군집화와 전체 트리 구축을 재현한 구현이 아닙니다.
