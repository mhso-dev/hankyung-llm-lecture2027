# Ch 15 평가 심화 실습

8개 노트북을 Python 3.12 새 커널에서 순서와 관계없이 독립 실행할 수 있습니다. Ch12의 공개 학습용 검색 로그를 읽는 절은 프로젝트 루트부터 상위 폴더를 찾아 상대 경로로 접근합니다. 실제 API 키 값은 노트북과 출력에 저장하지 않습니다.

`data/evaluation-cases.json`에는 공개 가상 문서를 사용해 `gpt-5.4-mini`로 생성한 답변 3건과 Groundedness judge 출력 3건이 있습니다. `reference_kind`는 `교육용 작성자 기준`이며 독립적인 인간 평가 라벨이 아닙니다. 운영 judge 모델은 `[[미정: judge 모델]]`로 유지합니다.

`runs/batch-eval-input.jsonl`은 OpenAI Batch API 제출 형식의 로컬 검증 결과입니다. 실제 업로드, Batch 완료, 실제 할인 청구를 확인한 기록은 아닙니다.
