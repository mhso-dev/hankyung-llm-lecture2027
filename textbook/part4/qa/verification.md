## 해석 범위와 확인 필요 항목

Ch 15 05절의 로컬 추적 시간과 캐시 토큰은 기록 구조와 시간 차이 계산을 배우기 위한 고정 예시이며 실제 API 계측값이 아닙니다.

- LangChain 1.4.0이 요구하는 범위에 따라 LangGraph는 1.2 계열의 1.2.11로 고정했습니다. Ch 13의 패키지 잠금과 참고 버전이 일치합니다.
- Ch 14는 원리 학습용 문서 12건과 질문 8건을 사용합니다. 비교는 세 질문에 대한 결과이며 원 논문의 전체 CRAG·Self-RAG·RAPTOR를 재현하지 않습니다. 09절 추정 비용은 생성 모델 입력·출력·캐시 단가를 적용한 값이며 임베딩 비용과 실제 청구액 정산을 포함하지 않습니다. 각 절의 모델·사용량·단가 기준을 확인해야 합니다.
- Ch 15의 제시 라벨은 독립적인 도메인 검토자의 사람 평가가 아닙니다. 운영 judge는 `[[미정: judge 모델]]`이며, 비용 백분위수 실습 데이터는 합성입니다. LangSmith 클라우드 업로드와 실제 Batch 제출·완료·할인 청구는 확인하지 않았습니다. 로컬 추적, JSONL 생성·검증, 모의 결과의 ID 연결 범위를 본문에 명시했습니다.
- Ch 16의 문서 지시문 공격은 완화 전후 모두 영향이 관찰되지 않았습니다. 완화 효과를 입증한 결과로 설명하지 않습니다. 준비한 정규식이 우회 공격 전반을 막는다는 뜻도 아닙니다. 호출 전 계획 비용 상한은 제공자의 실제 청구액을 강제로 제한하는 기능이 아닙니다.
- Excalidraw MCP 미리보기 도구가 제공되지 않아 로컬 SVG·편집용 JSON 생성과 브라우저 검증으로 대체했습니다. 생성형 삽화는 사용하지 않았으며 Higgsfield 크레딧 사용량은 0입니다.
- 외부 맞춤법 전송은 [korean-spell-check SKILL.md](/Users/mhso/.codex/plugins/cache/moai-cowork/moai-writer/1.4.1/skills/korean-spell-check/SKILL.md)의 “사용 금지 … 상업적 대량 처리” 규칙에 따라 생략했습니다. 일반 슬롭 검토와 로컬 맞춤법·윤문, 작성자와 분리된 최종 의미 대조의 판정·원본 해시는 `language/`에 기록합니다. 코드·출력은 언어 교정 대상에서 제외했습니다.
