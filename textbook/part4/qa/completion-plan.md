# Part 4 집필·검증 계획

2026-09-10 · 커리큘럼 v6 · Ch 13~16 · 강의 27시간, 실습 37시간

Ch 13은 상태·노드·조건 분기·리듀서·Send·Command·통합 RAG를 작성합니다. Ch 14는 대화형 검색과 다중 질의, 질문 분해, Step-back, HyDE, CRAG, Self-RAG, 계층 요약과 비교 실험을 작성합니다. Ch 15는 실제 실패 로그에서 평가 항목을 도출하고 네 가지 RAG 평가·judge 편향·기준 라벨 비교·트레이싱·비용 분포·회귀·Batch 요청 준비를 다룹니다. Ch 16은 입출력·개인정보·히스토리·예산·재시도·인젝션 대응을 파이썬으로 구현합니다.

집필은 챕터별 담당자가 병렬로 수행합니다. 각 담당자는 새 템플릿으로 개념 절을 만들고 노트북을 먼저 실행합니다. 별도 연구 담당자는 공식 문서·버전·선수 자료와의 연결을 확인합니다. 한국어 검토자는 집필 담당자와 구분된 세션에서 원문과 수정문을 읽습니다. 전체 배포 목록과 공통 목차는 통합 담당자가 수정합니다.

완료 조건은 각 절의 고정 10블록과 복습 3~5문항, 새 Python 3.12 커널의 준비 셀 포함 실행, 실제 API 결과, 코드·출력·다운로드 일치, 1280px·390px 화면 검사, 도식 정본 일치, 기술 정독 및 한국어 감사, 파트 목차·실습 ZIP·진행표 갱신입니다. 실제 로그와 출력으로 뒷받침하지 못한 주장은 삭제하거나 범위를 좁힙니다.

기존 공통 실행·렌더링 검사는 수정 전 38개와 하위 검사 16개가 통과했습니다. 변경하는 공통 파일은 `build_index.py`와 `build_bundle.py`이며 기존 원본은 `before-integration/`에 보관합니다. 발행 목록에 파트 4만 추가하며 이전 교재의 코드·출력은 수정하지 않습니다.

Part 3의 36건 TF-IDF+MMR 설정 로그에는 생성 답변이 없다는 점을 평가 실습에서 구분합니다. 교육용 기준 라벨을 사람이 수집한 라벨로 표시하지 않습니다. 모델·프롬프트·질문·문서·정답 조건과 실험 반복 수를 기록합니다. 유료 API는 절당 예상 사용량을 정하고 1달러 미만으로 설계합니다. 미실행 외부 서비스는 실행 결과로 표시하지 않습니다.
