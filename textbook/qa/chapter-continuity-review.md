검토일: 2026-09-10. 현재 작성된 마지막 챕터는 Ch12이며, 대상은 12개 챕터의 87개 절·학생용 노트북입니다. Ch13 이후는 커리큘럼의 예정 학습과 현재 산출물의 대응만 확인합니다. 이전 Part3 PASS는 이번 검토의 판정 근거로 사용하지 않습니다.

학생용 수정 전에 `continuity-evidence/full-course-before.tar.gz`에 본문 원본·실행 노트북·데이터·로그·배포물·작성 기준 966개 파일을 보존했습니다. 개별 SHA-256은 `before-manifest.json`, 노트북 87개의 코드·출력·실행 횟수·메타데이터는 `notebook-before-invariants.json`, 챕터별 수량은 `chapter-inventory.json`에 기록했습니다. 이 파일들은 모두 같은 `continuity-evidence/` 폴더에 있습니다.

- G05·중간: Ch10 06절은 앞 HWPX 파서가 문단·표 유형을 보존한 것처럼 설명하지만 04절은 본문 문자열만 추출합니다. HTML 제목·Markdown 입력과 HWPX의 현재 한계를 구분합니다.
- G06·높음: Ch9·Ch10 README는 배포되지 않는 `examples/`, `harness.py`, 내부 검사 모듈을 실행 경로로 안내합니다. Ch9는 06절의 PDF 기본 실행도 선택 확장으로 잘못 설명합니다. 현재 학생용 01~마지막 노트북, 실제 입력 경로·API 준비·저장 로그·다음 평가로 안내를 맞춥니다. 내부 스크립트는 원본 보존 자료에 남으며 학생의 학습 연결을 대신하지 않습니다.
- G07·중간: Ch8의 `E01-p3`은 작은 근거 레코드 ID, Ch9 이후의 `E01`과 `page=3`은 문서·쪽 분리입니다. 같은 원천 위치로 대응하되 ID 문자열을 직접 비교하지 않도록 Ch8 본문과 Part3 안내에 설명합니다.
- G08·높음: Ch8 학생 노트북이 `E01-p5`의 주차 정보를 90분으로 적었지만 실제 PDF 및 기존 자료는 최초 2시간 무료입니다. 같은 출처 ID의 사실 충돌이므로 실제 원문에 맞춰 코드·응답·설명·생성 원본을 고치고 필요한 API 실행을 반복합니다. `ch06-08-review.md`와 독립 초기 보고서에서 근거를 확인합니다.

Ch1~8의 구간별 추가 문제·최소 계획은 각 담당자의 `ch01-03-review.md`, `ch04-05-review.md`, `ch06-08-review.md`에 기록합니다. 검토자는 실제 수정 완료와 실행 증거를 별도로 확인하며, 단순 설명 수정은 실행 결과를 재생성하지 않습니다.

- G09·높음: Ch6~10·12의 학생 준비 셀은 `%pip`를 사용하지만 잠금 환경에는 pip가 없어 실제 `No module named pip`를 재현했습니다(`pip-before.json`). 기존 검사기의 `--with pip`가 이 누락을 가렸습니다. `%pip`를 쓰는 챕터에만 Ch2에서 이미 고정한 `pip==26.2`를 추가하고, 검증용 패키지가 섞이지 않은 학생 `.venv`에서 `%pip --version`까지 실행합니다.

- G10·높음: 전체 87개 노트북의 설치 핀을 잠금 파일과 대조해 네 불일치를 확인했습니다(`install-pin-before.json`). Ch9 01·02의 pypdf 6.7.5는 잠금 6.17.0으로, Ch10 08의 pypdf 6.17.0과 tiktoken 0.12.0은 잠금 6.18.0과 0.14.0으로 맞춥니다. 기존 셀이 같은 커널 환경을 다른 버전으로 바꾸는 문제이므로 해당 세 노트북은 준비 셀부터 실제 재실행하고, 새 Ch10 검색 로그를 Ch11에 전달해 다시 평가합니다.
- G11·높음: Ch8 03절은 E01 p.2에 없는 ‘임시 휴관은 별도 공지’를 정상 근거로 전달하고, E01 p.3의 연령 제한 없는 회원 조건을 ‘성인 회원’으로 좁혀 출처를 유지합니다. 원문이 지원하는 예외와 조건으로 수정하고 새 API 응답을 확인합니다. 고의 실패 사례는 정상 근거와 구분해 유지합니다. 독립 초기 보고서 F09에서 원 PDF·셀 근거를 확인합니다.
