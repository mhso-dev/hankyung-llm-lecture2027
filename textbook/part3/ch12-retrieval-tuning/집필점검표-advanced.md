## 코드와 본문 대조

- [x] 07~12의 모든 코드 셀은 25줄 이하이며 셀마다 한 가지 학습 행동을 수행합니다.
- [x] 07~12는 프로젝트 전용 Python 모듈이나 이전 노트북 변수에 의존하지 않습니다.
- [x] 두 CrossEncoder는 같은 저장된 후보를 점수화하며 모델별 점수 계산을 후보 수마다 반복하지 않습니다.
