# Ch 9 한국어 검토 기록

확인일: 2026-09-08. 장르: 산문, 최소심각도: S1. 대상은 6절과 목차의 코드·출력 블록을 제외한 텍스트입니다.

## 진단 요약

담당 검토자가 전문을 정독하고 구어적 실행 표현, 비유 단락 밖 은유, 압축문을 약 30곳 국소 교정했습니다. 리더가 공식 문서와 실험 로그에 따른 사실 범위 보정, 도식 색 설명, 수량 단위와 의문형 제목을 반영했습니다. 다른 모델의 최종 Phase 6 정독 판정은 `accept`입니다.

자동 게이트는 `WARN`(exit 1), 문자 변경률은 3.00%입니다. 따옴표 검사 실패의 다섯 문장과 일곱 강조 문구는 외부 인용이 아닌 교재의 예상 질문·시연 대사·내부 설명입니다. 정독에서 외부 인용 손실이 없음을 확인했습니다. 실제 출력 12블록은 별도 원본 대조와 SHA-256 검사로 보존을 확인했습니다.

수치 경고 다섯 건은 top-1 일반화, gpt-5.4 계열의 매개변수 단정, 미확인 비용 오차, 41장 색 범례 설명, 입력 한도 8,191→8,192 보정에 대응합니다. 저윤문과 단문 최장 5연속 경고도 목록·강사 노트가 포함된 기술 산문 맥락에서 정독했고 전달 차단 사유로 판정하지 않았습니다.

- 실행·측정·반환 표현을 표준 문어체로 정리했습니다.
- 벡터 차원·모델 성향·temperature·토큰 증가·비용 설명을 실제 조건에 맞췄습니다.
- 학생이 고정한 흐름을 파랑으로 표시하는 도식과 본문 설명을 맞췄습니다.
- 수량 단위와 의문형 제목을 다듬고 코드·과거 출력은 보존했습니다.
