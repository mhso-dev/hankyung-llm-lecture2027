색 규칙(01~05절 선례 그대로): 코드가 만든 자료·사람이 정한 값(설정 파일·실행 설정·문서 청크·기록 파일·평가셋 라벨) 초록, 정의한 함수와 코드 단계(`make_index_key`) 파랑, 실행한 `gpt-5.4-mini` 보라, 출력으로 확인한 값(검색 결과·답·이름표 대조) 노랑, 이번에 실행하지 않은 단계와 두 조건 공통 값 회색입니다. 같은 요소는 절 안 모든 그림에서 같은 색입니다(설정 06-1·06-2·06-4 초록, 검색 결과 06-1·06-2·06-3 노랑, 모델 06-1 보라).
빨강은 paired Before 결함 결과(바꾼 설정의 이름표가 `chunk_id`에 없음) 하나뿐입니다(규격 §5-3). 06-3 값 바꿔 보기의 k=4 결과는 결함이 아니라 노랑입니다.
06-2·06-3·06-4는 두 칸에 모두 같았던 값(Ch 11이 지표에 쓰는 세 칸 / 같은 색인 이름표 / 검색 개수 2와 1위 `E01 p.1`)을 결과 상자에 넣지 않고 맨 아래 회색 상자로 뺐습니다(규격 §5-3, Ch 7 02-1).
점수는 실행마다 소수 넷째 자리가 달라지므로(03절 확인) 그림 라벨과 캡션에 넣지 않았습니다. 라벨의 숫자는 모두 노트북 출력에 있는 값입니다.
