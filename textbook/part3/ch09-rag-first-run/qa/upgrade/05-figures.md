색 규칙(01~04절 선례): 코드가 만든 자료·사람이 정한 값(검색 결과·검색 출처·E01 원문·정답 출처)은 초록, 정의한 함수(`find_missing_words`)는 파랑, 실행한 `gpt-5.4-mini`는 보라, 출력으로 확인한 값은 노랑, 실행하지 않은 요청과 두 조건 공통 값은 회색입니다. 같은 요소는 절 안 모든 그림에서 같은 색입니다(검색 출처 05-1·05-3·05-4 초록, 정답 출처 05-1·05-2 초록, 모델 05-3·05-4 보라, Before 결함 결과 05-1·05-4 빨강).
빨강은 paired Before 결함 결과(휴관일 질문 k=1 검색 누락)뿐이고, 같은 요소라서 05-1과 05-4 두 그림에 같은 빨강으로 나옵니다(규격 §5-3 「같은 요소는 같은 색」). 4절 와이파이 질문의 보류 답은 결함 결과가 아니라 노랑입니다.
05-3·05-4는 두 칸에 모두 같았던 값(정답 출처 빈 목록 / 보류 문장 False·법정 공휴일 빠짐·user 글에 없던 말 없음)을 결과 상자에 넣지 않고 맨 아래 회색 상자로 뺐습니다(규격 §5-3, Ch 7 02-1). 05-4 결과 상자의 「끝에 E01 p.1」「끝에 E01 p.2」는 두 답에서 다른 값이라 양쪽 칸에 적었습니다(Ch 8 07-3 선례).
