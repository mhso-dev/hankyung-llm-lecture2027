색 규칙(01~03절 선례 이어받음): 코드가 만든 자료·넣은 글(검색 결과, 기록, developer 과업 명세)은 초록, 정의한 함수(`make_note`·`build_notes_messages`·`check_answer`·`find_missing_words`)는 파랑, 실행한 `gpt-5.4-mini`는 01-1·01-4처럼 보라, 출력으로 확인한 답·검사 결과는 노랑입니다. 같은 요소는 절 안 모든 그림에서 같은 색입니다(기록 04-1·04-4 초록, 모델 04-1·04-3·04-4 보라, 검사 결과 04-1·04-2·04-3·04-4 노랑).
빨강은 04-4 Before 결과 한 상자뿐입니다(paired Before 결함 결과, 규격 §5-3). 7절 값 바꿔 보기의 「출처 표시 없음」은 결함 결과가 아니라 값을 바꿔 확인한 출력이라 노랑입니다. 04-2의 check_answer 상자는 함수라 파랑, 그 결과 상자는 노랑입니다(04-1은 결과 상자에 함수 이름을 라벨로 붙여 노랑).
04-3·04-4는 두 조건에서 같았던 값(같은 user 글, 「월요일」·「7권」, 빠진 지킬 말 `[]`)을 결과 상자에 넣지 않고 맨 아래 회색 상자로 뺐습니다(규격 §5-3, Ch 7 02-1).
