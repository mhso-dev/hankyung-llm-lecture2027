색 규칙(Ch 8 선례 이어받음): 코드가 만든 자료(PDF·Document·문서 청크·벡터스토어)와 넣은 글(질문·user 글)은 초록, 코드 단계(`PdfReader`·`RecursiveCharacterTextSplitter`·`similarity_search`)는 파랑, 실행한 서비스 모델은 보라(임베딩 모델 `text-embedding-3-small`과 답을 쓰는 `gpt-5.4-mini` 둘 다 — Part 1·2 「실행한 모델 보라」), 출력으로 확인한 값은 노랑입니다. 같은 요소는 절 안 모든 그림에서 같은 색입니다(질문 01-1·01-3 초록, `gpt-5.4-mini` 01-1·01-4 보라, 문서 청크·벡터스토어 01-1·01-2 초록).
빨강은 01-4 Before 결과 한 상자뿐입니다(paired Before 결함 결과, 규격 §5-3). 6절 k=1 결과(휴관 문장 빠짐)는 값 바꿔 보기에서 코드가 확인한 값이라 노랑입니다.
01-4는 두 답에 모두 있던 「월요일」 `True`를 After 결과 상자에 넣지 않고 맨 아래 회색 상자로 뺐습니다(규격 §5-3, Ch 7 02-1). 두 답의 휴관 요일 문장도 둘 다에 있어 결과 상자에 쓰지 않았습니다.
