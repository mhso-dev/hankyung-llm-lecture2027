- 설명 대상 문장: 까닭을 보여 준 줄은 `검색 결과에 없는 정답 출처: ['E01 p.2']`입니다.
- 캡션: k=1에서는 정답 출처 2쪽이 검색 결과에서 빠졌고 답은 입력에 없는 휴관 내용을 적었습니다. k=2에서는 2쪽이 들어와 답이 2쪽 기록의 내용을 담았습니다.
- 읽는 법: 위 칸 Before, 아래 칸 After, 칸마다 왼쪽에서 오른쪽으로. 초록 = 검색 출처(`['E01 p.1']` / `['E01 p.1', 'E01 p.2']`, 다른 조건은 k 하나), 보라 = 같은 모델, 빨강 = Before 결함 결과(`검색 결과에 없는 정답 출처: ['E01 p.2']`, 답 `휴관일은 다음 날로 변경됩니다.`, 끝 `[E01 p.1]`), 노랑 = After 확인 값(`검색 결과에 없는 정답 출처: []`, 답 `그 다음 날인 화요일에도 휴관합니다.`, 끝 `[E01 p.2]`). 회색 = 두 답 공통(`보류 문장 있음: False`, 빠진 지킬 말 「법정 공휴일」, `user 글에 없는데 답에 나온 말: []`) — 한쪽 효과로 넣지 않음(규격 §5-3).
- alt: 위 칸 Before 휴관일 질문 k=1에는 초록 상자 검색 출처 E01 p.1 표지, 보라 상자 gpt-5.4-mini, 빨간 상자 빠진 정답 출처 E01 p.2 답은 입력에 없는 휴관 내용 끝에 E01 p.1이 차례로 있고, 아래 칸 After 휴관일 질문 k=2에는 초록 상자 검색 출처 E01 p.1 E01 p.2, 보라 상자 gpt-5.4-mini, 노란 상자 빠진 정답 출처 없음 답은 2쪽 기록에 있는 내용 끝에 E01 p.2가 차례로 있으며, 맨 아래 회색 상자에 두 답 모두 보류 문장 False 법정 공휴일 빠짐 user 글에 없던 말 없음이 있는 비교 그림
