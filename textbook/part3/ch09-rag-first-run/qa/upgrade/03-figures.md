색 규칙(01·02절 선례 이어받음): 코드가 만든 자료·넣은 글(문서 청크, 저장 항목, 질문, 질문 벡터·저장 벡터)은 초록, 코드 단계와 정의한 함수는 파랑, 실행한 임베딩 모델 `text-embedding-3-small`은 01절처럼 보라, 출력으로 확인한 값은 노랑입니다. 같은 요소는 절 안 모든 그림에서 같은 색입니다(문서 청크·저장 항목 03-1 초록, 검색 03-1·03-4 파랑).
빨강은 03-4 Before 결과 한 상자뿐입니다(paired Before 결함 결과, 규격 §5-3). 6절 k=8은 값 바꿔 보기라 03-3 주황 막대로만 그렸습니다.
03-4는 두 조건에서 같았던 질문과 1위 `[E01 p.2] | 498 | 0.6251`을 결과 상자에 넣지 않고 맨 아래 회색 상자로 뺐습니다(규격 §5-3, Ch 7 02-1). After 결과 상자에는 k=3에서 더 들어온 2·3위만 적었습니다.
03-3은 xychart라 막대 `#f59e0b`를 「주황 막대」로 부릅니다(규격 §5-3, Ch 5 C-2). 점수 숫자는 두 번째 새 커널 출력(첫 새 커널은 1위 0.5832·4위 0.3544·7위 0.322·8위 0.1541)으로 적었습니다.
