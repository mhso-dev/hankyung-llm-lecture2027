# Ch 9 보완 계획

기존 학습 범위·절 순서·실행 결과를 보존하며 Ch 10의 가독성과 원본 연결 방식을 적용합니다.

1. 원본과 빌드 파일을 qa/before에 보존하고 기존 테스트를 먼저 실행합니다.
2. 기존 CSS와 도식 표시를 Ch 10과 맞춥니다. 목차 원고를 _src/index.html로 옮깁니다.
3. 교재 코드 블록을 실습 원본에 연결합니다. 기존 출력은 이관한 기록임을 명시하고 새 실행으로 위장하지 않습니다.
4. 문장 검토는 코드·출력을 제외한 산문만 수정하고 원문과 의미·수치를 대조합니다.
5. 빌드·본문 구성·원본 코드 및 출력·PC/모바일 화면·회귀 테스트·린트로 확인합니다.

완료 기준: 6절과 목차의 내용 범위 유지, 원본 연결 검증, 화면 14건 통과, 기존 테스트 통과, 새 검토 및 미실행 항목 기록. API 재호출은 이번 보완의 필수 조건이 아닙니다.
