# Ch 9 노트북형 교재 전환 계획

## 보존할 동작

- 여섯 절의 학습 목표, 개념 설명, 도식, 주의 사항, 복습 문제, 강사 노트를 유지합니다.
- 기존 `rag.py`, `harness.py`, `examples/`와 역사적 실험 결과는 삭제하거나 수정하지 않습니다.
- 각 절의 고정 제목 `b1`부터 `b11`까지를 유지합니다.

## 바꿀 범위

1. 현재 `_src`를 `qa/notebook-before/`에 보관합니다.
2. 각 절의 `b5` 실행 예제를 같은 이름의 노트북 토큰으로 바꿉니다.
3. `b6`은 노트북에서 실제로 예외를 포착하거나 실패 조건을 확인하는 셀을 가리키도록 고칩니다.
4. 여섯 노트북을 빈 커널에서 위에서 아래로 실행합니다.
5. 실제 OpenAI 임베딩과 생성 호출 여부, 셀 길이, 독립 실행 조건을 검증 기록에 남깁니다.

## 완료 기준

- 여섯 노트북이 nbformat 4 JSON으로 유효합니다.
- 코드 셀은 원칙적으로 15줄 이하이고, 25줄을 넘는 셀이 없습니다.
- 각 노트북은 로컬 헬퍼 import, `__file__`, `sys.path` 없이 독립 실행됩니다.
- 모든 노트북이 `find_dotenv(usecwd=True)`로 프로젝트 루트 `.env`를 찾습니다.
- OpenAI API를 사용하는 노트북은 모의 객체 없이 실제 호출에 성공합니다.
- `_src`의 도식 수, 복습 문제 수, 고정 제목이 전환 전보다 줄지 않습니다.
