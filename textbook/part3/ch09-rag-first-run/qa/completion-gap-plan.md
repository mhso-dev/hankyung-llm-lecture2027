# Ch 9 커리큘럼 격차 보완 계획

1. 06절 기본 노트북에서 YAML 설정 파일을 실제로 만들고 다시 읽는다.
2. 환경 변수로 검색 조건을 바꾼 뒤 검색과 생성을 모두 실행한다.
