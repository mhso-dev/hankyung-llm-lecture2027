# Ch9 Before/After 전환 계획

1. 기존 실행 예제와 출력은 기본 셀로 유지합니다.
2. 각 노트북 끝에 같은 실패를 재현하는 `before` 셀과 원인을 수정한 `after` 셀을 이어 배치합니다.
3. 잘못된 코드의 예외은 셀 안에서 포착하고, 수정 코드는 성공 출력과 `assert`로 확인합니다.
4. `_src` 5번과 6번 블록은 각각 `|example`과 `|failure` 토큰을 사용하여 셀을 중복하지 않습니다.
5. 빈 Python 3.12 커널에서 여섯 노트북을 순차 실행하고, 출력·코드 해시와 소스 규약을 다시 검사합니다.
