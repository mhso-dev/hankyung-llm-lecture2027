- 설명 대상 문장: 오른쪽 상자의 빈칸은 검색이 고른 문서 청크 두 개이고, 책상 위 카드 두 장은 user 글에 넣은 근거입니다. 왼쪽 책상은 검색 없이 질문만 보낸 Before, 오른쪽 책상은 검색한 근거를 넣은 After입니다.
- 캡션: 두 책상은 같은 질문을 받았습니다. 오른쪽 책상에만 상자에서 골라 온 카드 두 장이 올라와 있습니다.
- 읽는 법: 두 책상 위 비교(오른쪽에만 카드 두 장) → 바닥 상자 비교(왼쪽 꽉 참, 오른쪽 빈칸). 값 없음(비유). 상자 속 카드 수는 문서 청크 8개의 비율이 아님.
- alt: 나란히 놓인 똑같은 나무 책상 두 개에 파란 명찰·주황 클립보드·노란 메모지·빈 답안지와 연필이 있고, 오른쪽 책상에만 흰 카드 두 장이 노란 메모지 옆에 놓여 있으며, 책상마다 앞 바닥에 흰 카드가 한 줄로 꽂힌 긴 상자가 있는데 왼쪽 상자는 꽉 차 있고 오른쪽 상자 가운데에는 빈칸이 있는 삽화
