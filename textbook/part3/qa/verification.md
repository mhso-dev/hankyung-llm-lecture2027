## 실제 실행과 설명의 범위

Python 3.12 새 커널에서 준비 셀부터 순차 실행했습니다. 검증 메타데이터에는 코드·출력 SHA-256과 실행 시점이 있습니다. 코드·출력·HTML 다운로드를 대조한 결과는 공통 `textbook/_notebook/checks/notebook-contracts-part3-*.json`에 있습니다.

Ch 9은 실제 임베딩·검색·출처 있는 생성과 YAML 설정 변경·JSONL 저장을 확인합니다. Ch 10은 문서 형식·청크·임베딩 예제와 3개 청킹 방법×2개 크기 비교를 확인합니다. Ch 11은 30개 질문을 문서 ID 기준으로 평가하고 중복 문서·빈 정답 정책을 분명히 합니다. 별도 임시 폴더에 ZIP을 풀어 `evaluate.py`를 실행했을 때도 R@5=1, R@50=1, P@5=0.2, nDCG@5=0.9051549589가 재현됐습니다.

Ch 12의 실제 pgvector 0.8.2에서 vector 2001차원 HNSW 오류, halfvec 생성 성공, 필터 반복 탐색 off의 반환 0개와 strict_order의 5개를 확인했습니다. 전반의 교육용 문서 12개·질문 8개에서는 dense 7/8, Kiwi BM25 8/8, RRF 7/8이 관찰됐습니다. RRF가 개선됐다고 해석하지 않습니다.

후반은 제공 PDF 6건과 질문 30개를 사용합니다. 두 CrossEncoder가 같은 후보를 점수화했고, TF-IDF+MMR의 개발 설정 36건을 비교한 뒤 고정 설정을 시험 질문 15개에 한 번 평가했습니다. 이 36건을 모든 검색 단계를 함께 튜닝한 기록으로 표시하지 않습니다. 별도의 고정 통합 실행은 PDF 6건·35쪽 → dense·Kiwi BM25 → 직접 RRF → CrossEncoder → 부모 원문·출처 선택 → 실제 모델 답변을 확인했습니다. `[E02 p.3]`과 ‘연간 60만 원’이 선택한 원문과 일치합니다. 출처 있는 한 번의 답변은 전체 질문의 답변 정확도를 보장하지 않습니다.

## 배포·회귀 검사

`integration-results.json`은 32절 코드·출력·다운로드 일치와 ZIP 해시를 기록합니다. `delivery-results.json`은 HTML 38개, 로컬 링크 572개, ZIP CRC·개별 파일 해시, 실제 키 비노출, 비공개 전체 질문 원본·정답 노트북·`.env` 제외를 확인합니다. `bundle-smoke.json`은 압축 해제본만으로 자동 평가가 실행되는 근거입니다.

`visual-summary.json`은 1280px·390px의 74개 화면 검사를 모읍니다. 본문·보조 글자 크기, 대비, 잘림, 가로 넘침, 도식 라벨 경계, 이미지, 셀별·전체 코드 복사, 노트북 다운로드를 검사했습니다. Ch 12의 13개 도식은 같은 정본의 SVG·Excalidraw 라벨·화살표 일치와 별도 26개 화면도 검사했습니다.

공통 실행·렌더링 검사 38개와 하위 검사 16개가 통과했습니다. 실제 모델 진행 출력의 CR 문자가 HTML 파일 읽기에서 LF로 바뀌는 실패를 회귀 검사로 먼저 재현하고, HTML 문자 참조로 CR을 보존해 수정했습니다. 출력·코드를 바꾸지 않았습니다. 변경 스크립트 Ruff도 통과했으며 정적 검사 기록은 `integration-static.json`입니다. 공통 목차는 실제 Part 목차와 ZIP이 모두 존재할 때만 묶음 링크를 표시합니다.
