# Ch 8 → Ch 9 → Ch 10 수정 전 연결성 검토

검토 범위는 학생용 정본인 각 챕터의 `_src/`, 실행 노트북, 실제 출력, 로그 파일입니다. 기존 완료 보고와 QA PASS는 판정 근거로 사용하지 않았습니다. 수정 전 원본은 `before.tar.gz`와 `before-manifest.json`에 별도 보존되어 있습니다.

노트북 근거의 셀 번호는 마크다운과 코드 셀을 모두 포함한 **1부터 시작하는 전체 셀 번호**입니다. 코드 셀은 수정 전 실행 번호 `In[n]`과 핵심 변수 이름을 함께 적습니다.

## 수정 원칙

- 두 경로의 기존 `runs.jsonl`과 상세 로그는 덮어쓰지 않습니다.
- 실행 ID별 로그는 새 파일로 보존하고, 고정 이름 파일은 다음 챕터가 읽는 최신 포인터로만 사용합니다.
- Ch 10의 짧은 6조합 예제는 청킹 경계를 비교하는 기본 학습으로 유지합니다. Ch 11에 넘길 로그는 영역이 다른 별도 실행임을 본문에 명시합니다.
- 신규 공통 모듈은 추가하지 않고, 각 노트북의 짧은 준비·검색·기록 셀로 완결합니다.
