## 진단 요약

수정 전 검토 보고서는 C01~C08의 원인, 영향, 최소 수정 계획을 현재 학생용 파일 기준으로 설명합니다. 수정 후 검증 보고서는 실제 전달 파일, 평가 단위, 개발·시험 분리, 36개 설정 비교와 별도 통합 RAG의 관계, 실행·화면·배포 증거, 미검증 범위를 구분합니다. `.moai/context.md`의 최신 학생용 연결 설명도 같은 파일 이름과 평가 범위를 사용합니다.

1차 정독에서 문장 두 곳과 중간 산출물 해시 불일치를 찾았습니다.

- 수정 전 보고서의 “후반 자료, PDF 30문항 평가”는 “후반 PDF 6건·30문항 평가”로 풀어야 문서와 질문의 관계가 분명합니다.
- 수정 후 보고서의 “실제 18 PDF”는 “실제 PDF 18건”으로 고쳐야 표준 문어체와 맞습니다.
- 검토 시점의 실제 ZIP SHA-256은 Part 3 `5095d357…`, 전체 `b1552149…`였지만 `delivery-results.txt`와 `continuity-static-results.json`은 이전 빌드 해시를 담고 있었습니다. 보고서 상단이 진행 중임을 명시한 상태에서 확인한 중간 불일치이며, 최종 ZIP 재생성 뒤 증거 파일과 보고서의 “최신 해시” 주장을 다시 대조해야 합니다.
- `continuity-evidence/independent-final-review.md`는 보고서에서 최종 검토 근거로 연결하지만 1차 정독 시점에는 아직 생성되지 않았습니다. 파일 생성과 최종 판정이 끝나기 전에는 완료 근거로 사용할 수 없습니다.

## 로컬 맞춤법·표현 검토

기술상 필요한 대조문은 유지했습니다. `TF-IDF가 아니라`, `증거가 아니라`처럼 앞 항목을 배제해야 뜻이 성립하는 문장은 수사적 대조로 세지 않았습니다. 데이터 수, 질문 분할, 지표 이름, 경로, 해시는 윤문하지 않았습니다. 금지된 구어 표현과 `함정`, 내부 집필 용어인 `회수`는 최신 보고서의 학생 대상 설명에 새로 나타나지 않았습니다.

`metrics.py --genre essay`의 보조 판정은 수정 전 보고서와 수정 후 보고서가 각각 `medium`(위험 점수 4), `.moai/context.md` 최신 연결 섹션이 `low`(위험 점수 2)였습니다. 보고서의 표·경로·수치 나열이 쉼표와 어휘 지표에 영향을 주므로 자동 등급만으로 문장을 바꾸지 않았습니다. 전문 정독에서 수사적 반복이나 보고서 의미를 가리는 문장 구조는 확인되지 않았습니다. 결과 JSON은 `language/metrics/chapter-continuity-review.json`, `chapter-continuity-verification.json`, `context-current-sections.json`에 보존했습니다.
