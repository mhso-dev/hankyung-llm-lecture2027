## 수정 텍스트 판정

다음 변경은 의미·수치·실행 범위를 보존하며 학생의 연결 경로를 더 분명하게 만듭니다.

- Ch 8 06절은 Ch 11이 선택 결과의 검색 지표를 평가하고 생성 답변은 Ch 15에서 평가한다고 구분했습니다.
- Ch 9는 실제 PDF 18개와 Q001을 검색해 순위가 있는 JSONL을 만들며, 생성 답은 같은 행에 보존하지만 Ch 11 검색 지표에는 사용하지 않는다고 설명합니다.
- Ch 10은 짧은 원문 6조합 관찰과 실제 PDF 18개·Q001의 6조합 연결 로그를 분리했습니다. 서로 다른 문서와 질문의 수치를 직접 비교하지 않는다는 한계도 명시했습니다.
- Ch 11의 Recall·Precision·nDCG·조건별 오류 분석은 dev 15문항을 사용합니다. test 15문항은 설정 선택에 노출하지 않는다는 설명이 유지되었습니다.
- Ch 12 07절은 전반 12문서·8문항에서 후반 PDF 6건·30문항으로 바뀌는 이유, ID 대응, 지표 비교 한계를 설명합니다.
- Ch 12 08절은 개발 15문항의 고정 후보를 두 리랭커가 한 번씩 점수화한다는 실행 범위를 수치와 함께 맞췄습니다.
- Ch 12 09~11절의 대표 문항을 시험용 Q009에서 개발용 Q001로 바꾸어 시험 문항 사전 노출을 막았습니다.
- Ch 12 12절은 TF-IDF+MMR 개발 설정 36건, 선택 설정의 시험 평가 1회, dense·BM25·RRF·CrossEncoder·답변 생성 스모크 실행 1건을 서로 다른 실행으로 구분했습니다.
- Ch 11·12 README는 새 커널 실행 전 `uv sync --locked` 계열 명령과 커널 선택을 안내합니다. Ch 12 README의 새 `advanced-continuity-*` 파일 이름은 현재 노트북의 저장 경로와 일치합니다.

## 주요 변경사항 및 Phase 6 대조

### 의미 보존

- 수정 전 수치와 수정 후 수치를 기계적으로 유지하지 않고, 재실행 결과가 바뀐 곳은 현재 노트북 출력과 대조했습니다. Ch 12 08절의 nDCG@5 1.000·실행 시간 15.89초/19.86초와 Ch 12 12절의 개발 0.9754·시험 0.9508은 현재 출력과 일치합니다.
- Q009를 Q001로 바꾼 절은 모두 대표 질문을 dev 분할로 옮기려는 기술적 의도를 유지합니다. 질문 ID만 바꾸고 문서 ID·기관명까지 바꾸지 않은 사례가 없는지 함께 읽었습니다.
- Ch 12 통합 스모크 실행은 Q002, PDF 6건 35쪽, 쪽 본문 전달이라는 현재 코드와 일치합니다. 이 실행에서 검색 지표나 생성 답변 품질을 평가하지 않았다는 한계를 유지했습니다.
- 수정문에서 새 주장, 새 수치, 새 평가 완료 주장을 추가하지 않았습니다. 위 표의 네 항목은 반영 전이므로 최종 승인 대상에서 제외합니다.

### 과윤문 역방향 확인

- 기술 범위를 구체화한 문장을 짧게 만들기 위해 데이터 수, 질문 분할, 평가 단위, 로그 필드를 삭제하지 않았습니다.
- `doc_id`, `page`, `chunk_id`, `gold_doc_ids`, dev/test, Recall@k, Precision@5, nDCG@5와 같은 학습 용어는 치환하지 않았습니다.
- 변경하지 않은 본문의 반복 비유·표현은 이번 연결성 수정 범위 밖이므로 전면 윤문하지 않았습니다.
- 격식 상향, 광고식 강조, 수사적 `A가 아니라 B` 반복, 상투적 결론은 새로 넣지 않았습니다.

## 판정

1차 지적 S2 2건과 S1 2건은 모두 반영되었습니다. Ch 11 06절을 고치는 과정에서 통합 RAG를 30문항 실행으로 잘못 표현한 문장도 발견해, 개발용 15문항 설정 비교·시험용 15문항 확인·개발용 Q002 한 문항 통합 실행으로 다시 바로잡았습니다. 현재 내용에는 남은 S1 이상 한국어·의미 결함이 없습니다.

다만 다중 정답 Recall과 빈 정답 평균 제외 회귀 수정으로 코드·출력·관련 설명이 다시 고정되는 중입니다. 최종 `changed-prose.json`과 학생 ZIP 해시가 나온 뒤 원문↔최종 수정문을 한 번 더 대조해야 Phase 6를 확정할 수 있습니다. 따라서 현재 상태 판정은 **내용 승인·최종 해시 대기**입니다.

## 구조 지표 보조 판정

최신 `changed-prose.json`에서 추가된 산문 131행을 따로 추출해 `metrics.py --genre essay`로 확인했습니다. 결과는 `metrics/changed-prose-added.json`에 저장했습니다. 도구 판정은 `high`였지만, 서로 다른 35개 파일의 HTML·노트북·README 문장을 한 문서처럼 이어 붙여 계산하면서 문장 종결 쉼표 비율과 어휘 다양성이 기준에서 벗어난 결과입니다. 개별 문서의 논리 전개나 수정문 의미 보존을 판정하는 자료로 사용할 수 없으므로 **INCONCLUSIVE**로 처리합니다. 최종 판정은 변경 문장별 전문 정독과 현재 코드·출력 대조를 기준으로 합니다.
