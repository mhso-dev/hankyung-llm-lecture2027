## 수정 전 실행 상태

- `evaluate.py` 기본 실행은 Ch 11의 공개 PDF 90쪽을 다시 읽고 30개 질문을 `word+bigrams` 기준선으로 평가합니다. Ch 9·10 실행 결과 파일을 받는 인자와 로더가 없습니다.
- Ch 9 06의 현재 학생용 로그는 임시 폴더에 질문 하나와 D01·D02 ID 목록을 남기며, `qid`·`page`·`chunk_id`·순위가 없습니다.
- Ch 10 08의 현재 학생용 결과는 인라인 쇼핑몰 예제 하나를 6개 조합으로 검색한 메모리 객체입니다. 파일로 저장하지 않고 Ch 11의 Q001·E01과 대응하지 않습니다.
- `labs/part3/ch09-rag-first-run/runs` 및 Ch 10의 과거 Q001·Q037·Q088 상세 로그는 현재 학생용 노트북이 만드는 기본 산출물이 아니므로 연결 근거로 사용하지 않습니다.
- Ch 11 30개 기준선의 질문별 dev/test 분할은 고정되어 있습니다. Ch 9·10 continuity 결과는 질문의 부분집합이므로, 같은 파일에서 분할을 결합하되 30개 전체 점수와 직접 비교하지 않아야 합니다.

## 수정 완료 조건

1. Ch 9·10의 실제 검색 결과를 새 JSONL 로그로 보존하고 Ch 11이 읽습니다.
2. Ch 11은 `qid`·질문·정답 문서 ID·검색 항목 필드를 검사한 뒤, 문서 ID 중복 제거 정책으로 Recall@5·50, Precision@5, nDCG@5를 계산합니다.
3. 검색 평가와 생성 답변 평가를 분리하고, 서로 다른 질문 수·검색기·평가 단위의 수치를 직접 비교하지 않습니다.
4. 학생 노트북 06은 새 Python 3.12 커널에서 처음부터 실행하고, 원로그를 덮어쓰지 않으며 Ch 11의 새 결과 파일을 만듭니다.
