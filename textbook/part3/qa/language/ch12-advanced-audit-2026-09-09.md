## 수정 전 정독 소견

### 즉시 고칠 곳

- 08절 `비교을`, 12절 `로그을`은 목적격 조사가 잘못되었습니다.
- 08절의 `회수 가능 범위`는 학생용 문장에서는 `검색할 수 있는 범위`로 풀어야 합니다.
- 09절의 `약 2천 자 이상의`는 근삿값과 하한이 겹칩니다. 실제 출력에 맞춰 `2천 자가 넘는` 또는 `약 2천 자인`으로 구분해야 합니다.
- 10절 노트북의 `최대 한계 관련성`은 MMR의 뜻을 전달하지 못합니다. `최대 주변 관련성(Maximal Marginal Relevance, MMR)` 또는 영문 원어와 약어를 사용해야 합니다.
- 08절 노트북의 `첫 순위의 nDCG@5`는 상위 다섯 순위를 평가하는 지표 범위를 잘못 읽히게 합니다.

### 반복 템플릿 때문에 주제와 어긋난 곳

- 11절의 질문 재작성 정의와 12절의 실험 로그 정의 뒤에 `후보·점수·반환` 설명이 동일하게 붙어 있습니다. 각 절의 실제 입력·처리·출력으로 바꿔야 합니다.
- 09절과 10절도 같은 설명을 자식 검색·부모 반환, MMR 결합 점수·반복 선택에 맞게 구체화해야 합니다.
- 07~12의 주의 메모에 `OpenAI 호출은 11절의 짧은 재작성 1회`가 반복됩니다. 07~10에는 다른 절의 비용 메모가 들어가 있고, 12에는 통합 생성 호출 범위가 빠질 수 있으므로 실제 실행과 맞춰야 합니다.
- 10~12의 복습 문제와 주의 메모에는 다른 절의 후보 수·리랭커 질문이 남아 있습니다. 10은 λ와 다양성, 11은 원문 질문 보존과 재작성 적용 조건, 12는 개발/시험 분리와 로그 재현성을 물어야 합니다.
- 12절의 두 번째 도식 뒤 설명은 `첫 도식`과 `이 도식`의 지시 대상이 섞여 있습니다.
- 07~12 참고 자료가 모두 같은 세 링크입니다. 각 절의 실제 구현 근거와 맞는 공식 자료로 정리해야 합니다.

## Phase 6 최종 대조

### 1차 반영본 대조

- 조사 오류, 내부 용어 `회수 가능 범위`, MMR 제목, nDCG@5 범위 설명, 질문 재작성·실험 로그 정의, 절별 비용 메모와 복습 문제는 의도한 뜻을 유지한 채 고쳐졌습니다.
- 09절의 `2천 자가 넘는 원문`은 실제 출력 2,729자와 맞습니다.
- 12절의 36개 개발 설정, 개발 nDCG@5 0.9754, 시험 nDCG@5 0.9508, PDF 6건 35쪽, 통합 실행 14.72초는 최종 노트북 출력과 맞습니다.
- 추가 대조에서 08절 본문의 모델별 시간 32.92초·35.29초가 최종 출력 31.56초·35.89초와 다른 것을 확인했습니다.
- 07·09·10·11절은 30문항을 읽지만 본 실험은 각각 Q009 중심 또는 두 질문 비교입니다. 공통 학습 목표·배우는 이유·정리 문장이 30문항 전체 평가로 읽히므로 실제 실행 범위로 한정하도록 재반영을 요청했습니다.

### 최종 판정

08절의 모델별 시간은 최종 노트북 출력과 같은 31.56초·35.89초로 수정됐습니다. 07·09·10절은 Q009 실행 사례로, 11절은 대화형 후속 질문 1개와 Q009 실행 사례로 범위가 한정됐습니다. 11절에서 12절로 이어지는 문장도 질문 재작성이 36개 설정 탐색에 포함된다는 오해가 없도록 개발·시험 질문 구분, 설정 비교 기록, 별도 통합 검색·생성 실행으로 구체화됐습니다.

수정 전후를 다시 읽어 다음을 확인했습니다.

- 교차 인코더, 후보 수, 부모 문서 반환, MMR, 질문 재작성, 실험 로그의 핵심 정의와 처리 순서가 보존됐습니다.
- 6개의 PDF, 30문항, Q009, 후보 수 5·10·20, `child_k` 3·8·20, λ 1.0·0.5·0.2, 개발 설정 36개, 개발·시험 각 15문항과 지표 수치가 실제 출력 범위와 맞습니다.
- 08절 시간 31.56초·35.89초, 09절 부모 원문 2,729자를 근거로 한 `2천 자가 넘는`, 12절 통합 실행 14.72초가 실제 노트북 출력과 맞습니다.
- 없던 성능 주장이나 일반화가 추가되지 않았고, 공개 PDF 6건과 학습용 질문이라는 한계가 유지됐습니다.
- 문단 순서, `~합니다`체, 초보자에게 설명하는 어조를 유지했으며 과도한 격식 상향·상투구·문학적 비유를 추가하지 않았습니다.
- 초기 지적 표현과 핵심 금지 표현을 다시 검색한 결과 0건이었습니다. 여섯 `_src` 파일은 각각 고정 10블록을 유지했고 여섯 노트북에는 마크다운 셀이 모두 존재합니다.
- 07·09·10·11절 복습 1번의 해설도 각 실험에서 실제로 고정한 Q009, 후보 본문, 자식·부모 문서, 유사도 행렬·선택 수, 대화 맥락·후속 질문으로 한정했습니다.
- 11절의 LLM 질문 재작성과 무관한 PostgreSQL `ts_rewrite` 참고 자료를 삭제했습니다.

결정적 게이트는 `WARN`(exit 1)이었습니다. P0의 변경률 4.13%는 국소 교정 범위와 맞습니다. P3에서 사라진 수치는 07·09·10·11의 반복된 `30`을 실제 1~2문항 실행 범위로 고친 것, 08절의 이전 시간 32.92초·35.29초를 최종 출력으로 바꾼 것, 반복 범위 문장에서 불필요해진 `6`을 줄인 것, 무관한 참고 자료의 확인 날짜를 함께 삭제한 것입니다. P5의 단문 경고는 고정 10블록과 기존 짧은 문장 비율에서 발생했습니다. 전문 정독에서 의미 손실이나 새 단문화는 확인되지 않았으므로 Phase 6에서 수동 판정 `accept`로 확정합니다.

외부 맞춤법 검사는 상업적 대량 전송 제한 때문에 생략했습니다. 최종 판정은 `accept`입니다.
