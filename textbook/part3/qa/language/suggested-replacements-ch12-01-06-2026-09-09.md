# Ch 12 전반 한국어 교정 제안

검토 범위: `ch12-retrieval-tuning` 01~06절과 현재 렌더링된 챕터 색인  
장르: 산문  
최소심각도: S1  
검토 입력: 코드·실행 출력·경로를 제외한 학생 본문 16,243자

아래 제안은 수치, 실행 조건, 한정어를 그대로 두고 문법·문어체·기술 용어의 대응만 바로잡습니다.

## 01절

1. `코사인 거리와 유클리드 거리(L2 distance)가 무엇을 비교하는지` → `코사인 유사도(cosine similarity)와 유클리드 거리(L2 distance)가 무엇을 비교하는지`
   - 이 절의 정의와 실행 예제는 코사인 거리가 아니라 코사인 유사도를 계산합니다.
2. `-1부터 1 사이 값으로 나타냅니다.` → `-1에서 1 사이의 값으로 나타냅니다.`
3. `문서 수가 N개이고 벡터 차원이 D개일 때` → `문서 수가 N이고 벡터 차원이 D일 때`
4. `모델·차원·전처리가 다른 벡터를 같은 표에서 비교하지 않습니다.` → `모델·차원·전처리가 다른 벡터를 같은 검색 공간에서 비교하지 않습니다.`
   - 데이터베이스 표보다 벡터 공간의 비교 가능성을 말하는 문장입니다.

## 02절

5. ``pgvector의 `vector`와 `halfvec` 차이를`` → ``pgvector의 `vector`와 `halfvec`의 차이를``
6. `코사인 거리 연산자와 같은 연산자 클래스로` → `코사인 거리 연산자에 맞는 연산자 클래스로`
7. `현재 0.8.2 컨테이너의 관찰이 일치한 사례입니다.` → `실습 컨테이너의 0.8.2에서 관찰한 결과가 일치한 사례입니다.`
8. `ef_search에 따른 recall 차이` → `ef_search에 따른 Recall 차이`
9. ``실습 컨테이너는 검증한 `0.8.2-pg17`입니다.`` → ``실습 컨테이너는 실행을 검증한 `0.8.2-pg17`입니다.``

## 03절

10. `데이터베이스에 조건에 맞는 행이 있는데도` → `데이터베이스에 조건을 만족하는 행이 있는데도`
11. `질문 벡터에 가까운 common 3,000개와 조금 더 먼 rare 12개를` → `질문 벡터에 가까운 common 범주의 벡터 3,000개와 조금 더 먼 rare 범주의 벡터 12개를`
12. 소제목 `일부러 실패해 보기` → `실패 확인`
    - 복습 문제의 `「일부러 실패해 보기」`도 `「실패 확인」`으로 함께 바꿉니다.
13. `반복 탐색은 이 원인을 직접 바꾸지만 지연 시간이 늘 수 있습니다.` → `반복 탐색은 초기 후보 이후까지 탐색을 이어 이 문제를 해결하지만 지연 시간이 늘 수 있습니다.`
    - 반복 탐색은 필터 적용 순서라는 원인을 바꾸지 않고 탐색 범위를 늘립니다.

## 04절

14. `sparse 검색은 질문과 문서에서 같은 낱말이 얼마나 구별되어 나타나는지 사용합니다.` → `sparse 검색은 질문과 문서에 같은 낱말이 나타나는지와 말뭉치에서 그 낱말이 얼마나 드문지를 사용합니다.`
15. `같은 낱말도 만나지 못하므로` → `같은 낱말도 일치하지 않으므로`
16. `품사 정책을 질의셋으로 비교합니다.` → `질의셋에서 품사 정책별 결과를 비교합니다.`
17. `한국어 sparse 검색은 공백보다 형태소 단위가 유용할 수 있습니다.` → `한국어 sparse 검색은 공백 분리보다 형태소 단위가 유용할 수 있습니다.`

## 05절

18. `어느 한쪽이 항상 우수하다고 정하기보다` → `어느 한쪽이 항상 우수하다고 단정하기보다`
19. `글자가 정확히 일치하는지 자체가` → `글자가 정확히 일치하는지 여부 자체가`
20. `dense에는 질문 벡터를, sparse에는 형태소 목록을 넣는 차이는 각 검색기의 원리에서 생깁니다.` → `dense에는 질문 벡터를 넣고 sparse에는 형태소 목록을 넣습니다. 이러한 입력 차이는 각 검색기의 원리에서 생깁니다.`
21. `sparse가 한 질문을 더 맞혔지만` → `sparse가 dense보다 한 질문에서 정답 문서를 더 top-3에 포함했지만`
22. `P@5·nDCG@5·반환 개수도 함께 봅니다.` → `P@5·nDCG@5·반환 개수도 함께 확인합니다.`
23. `sparse가 한 질문을 더 top-3에 포함했다고만 말할 수 있습니다.` → `sparse가 dense보다 한 질문에서 정답 문서를 더 top-3에 포함했다고만 말할 수 있습니다.`

## 06절

24. `RRF는 점수 대신 각 검색기에서 몇 위인지 사용합니다.` → `RRF는 점수 대신 문서가 각 검색기에서 몇 위인지 나타내는 순위를 사용합니다.`
25. `앞 순위의 기여를 크게 계산합니다.` → `상위 순위의 기여를 크게 계산합니다.`
26. ``두 검색기 모두 1위라 0.03279점을 받아`` → ``두 검색기에서 모두 1위이므로 0.03279점을 받아``
27. `동일 가중치 RRF가 dense보다 개선되지 않았고 sparse보다 한 질문 적게 맞혔음을 보여 줍니다.` → `동일 가중치 RRF의 Recall@3는 dense와 같았고, 정답 문서를 포함한 질문 수는 sparse보다 1개 적었음을 보여 줍니다.`

28. `후보 밖 문서는 복구하지 못한다는 경계를 설명할 수 있습니다.` → `후보 밖 문서는 복구하지 못한다는 한계를 설명할 수 있습니다.`
