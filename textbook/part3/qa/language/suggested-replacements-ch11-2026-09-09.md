# Ch 11 한국어 교정 제안

검토 범위: `ch11-evaluation` 01~06절과 렌더링된 챕터 색인  
장르: 산문  
최소심각도: S1  
검토 입력: 코드·실행 출력·경로를 제외한 학생 본문 15,719자

아래 제안은 지표 정의, 수치, 평가 범위, 가능성 표현을 유지하면서 문법과 기술 문어체를 바로잡습니다.

## 01절

1. `질문은 쉬움·보통·어려움에서 각각 10개를 고르고, 각 수준을 개발용 5개와 시험용 5개로 나눕니다.` → `질문은 쉬움·보통·어려움 난이도에서 각각 10개를 고르고, 각 난이도의 질문을 개발용 5개와 시험용 5개로 나눕니다.`
2. `정답 문장이 답 생성 실험에 섞이는 문제도 줄일 수 있습니다.` → `정답 문장이 답변 생성 실험에 섞이는 문제도 줄일 수 있습니다.`
3. `층화한 30개에는 쉬움·보통·어려움 문서가 포함됩니다.` → `층화한 30개에는 쉬움·보통·어려움 난이도의 질문이 포함됩니다.`
   - 층화한 대상은 문서가 아니라 질문입니다.
4. `정답 문서 ID는 원문을 읽고 붙입니다.` → `정답 문서 ID는 원문을 읽고 부여합니다.`
5. `기존 검색기의 편향이 라벨에 들어갑니다.` → `기존 검색기의 편향이 라벨에 반영됩니다.`
6. `학습용 라벨은 공개해도 되지만 답변 문장·개인정보·비공개 평가 자료는 별도 권한으로 관리합니다.` → `이 실습의 학습용 라벨은 공개 PDF의 문서 ID만 담습니다. 답변 문장·개인정보·비공개 평가 자료는 별도 권한으로 관리합니다.`
   - 라벨 일반의 공개 가능성을 단정하지 않고 현재 실습 범위를 밝힙니다.

## 02절

7. `정답 문서가 1차 검색 후보 50개에 없다면 재정렬기를 바꿔도 되살릴 수 없습니다. Ch 12에서 상위 순위를 조정하기 전에 후보 생성 단계의 책임을 Recall@50으로 확인합니다.` → `정답 문서가 1차 검색 후보 50개에 없다면 재정렬기를 바꿔도 복구할 수 없습니다. Ch 12에서 상위 순위를 조정하기 전에 후보 생성 단계가 정답 문서를 포함했는지 Recall@50으로 확인합니다.`
8. `질문별 점수를 계산한 뒤 질문에 같은 가중치를 주어` → `질문별 점수를 계산한 뒤 각 질문에 같은 가중치를 주어`
9. ``문서 ID 중복 제거는 `k`를 자르기 전에 수행합니다.`` → ``문서 ID 중복 제거는 상위 `k`개를 선택하기 전에 수행합니다.``
10. `먼저 50개를 자른 뒤 중복을 제거하면` → `먼저 상위 50개를 선택한 뒤 중복을 제거하면`
11. `17개 문서 기준선은 Ch 12 설정 우열을 가르는 Recall 실험으로 충분하지 않습니다.` → `17개 문서 기준선은 Ch 12의 설정 우열을 판단할 Recall 실험으로는 충분하지 않습니다.`
12. `Recall@50은 후보 안에 포함한 정답 문서의 비율입니다.` → `Recall@50은 후보에 포함된 정답 문서의 비율입니다.`

## 04절

15. `같은 안내문도 첫 화면에 있으면 곧바로 발견하고 다섯 번째 화면에 있으면 찾는 시간이 늘어납니다.` → `같은 안내문도 첫 번째 자리에 있으면 곧바로 발견하고 다섯 번째 자리에 있으면 찾는 시간이 늘어납니다.`
   - nDCG@5가 비교하는 것은 서로 다른 화면이 아니라 상위 다섯 자리입니다.
16. `0~1로 정규화합니다.` → `0에서 1 사이로 정규화합니다.`
17. `수계산` → `손계산` 두 곳
18. `정답들을 가장 좋은 순서에 놓은 DCG입니다.` → `정답 문서를 가장 좋은 순서에 놓은 DCG입니다.`
19. `놓친 정답이 분모에서도 사라져 점수가 부풀 수 있습니다.` → `놓친 정답이 분모에서도 사라져 점수가 부풀려질 수 있습니다.`

## 05절

20. `작은 집단의 차이를 원인으로 단정하지 않을 수 있습니다.` → `작은 집단의 차이를 특정 원인의 결과라고 단정하지 않고 해석할 수 있습니다.`
21. `표 질문, 시점 조건, 여러 문서를 함께 읽는 질문은 검색 과정에서 다른 어려움을 만납니다.` → `표 질문, 시점 조건, 여러 문서를 함께 읽는 질문에서는 검색 과정에서 서로 다른 문제가 생길 수 있습니다.`
22. `검색 단계의 이름으로 기록해야 합니다.` → `문제가 발생한 검색 단계에 맞는 이름으로 기록해야 합니다.`
23. `검색 평균도 조건별 값과 개별 결과를 함께 봐야` → `검색 평균도 조건별 값과 개별 결과를 함께 확인해야`
24. `Ch 12의 가설로 옮깁니다.` → `Ch 12에서 검증할 가설로 정리합니다.`
25. `슬라이스를 결과를 본 뒤 계속 추가하면` → `결과를 본 뒤 슬라이스를 계속 추가하면`
26. `전체 평균과 조건별 평균을 함께 봅니다.` → `전체 평균과 조건별 평균을 함께 확인합니다.`

## 06절

27. `명령 한 번으로 30개 질문을` → `명령 하나로 30개 질문을`
28. `한 명령으로 실행합니다.` → `명령 하나로 실행합니다.`
29. `nDCG와 Recall@5를 보조로 보고` → `nDCG와 Recall@5를 보조 지표로 사용하고`
30. `로그가 같은 스키마로 쌓이면` → `로그가 같은 스키마로 축적되면`
31. `기준 로그를 덮어쓰기보다 새 실행 파일을 추가합니다.` → `기준 로그를 덮어쓰지 말고 새 실행 파일을 추가합니다.`
32. `자동 실행은 같은 계산을 반복 가능하게 만들고 해석은 사람이 검토합니다.` → `자동 실행을 사용하면 같은 계산을 반복할 수 있으며, 결과는 사람이 해석합니다.`
33. `실험 로그를 30건 이상 쌓습니다.` → `실험 로그를 30건 이상 축적합니다.`
