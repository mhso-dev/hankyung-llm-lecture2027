검토 범위: Ch 9·10 학생 README 2개와 노트북 14개의 마크다운 셀  
장르: 산문

코드 셀·출력·노트북 메타데이터·README의 코드 블록은 검토 입력에서 제외했습니다.

## Ch 9

1. README: ```.cache/`(색인)와 `runs/`(실험 로그)는 실행하면 생깁니다.``` → ```.cache/`(색인)와 `runs/`(실험 로그)는 실행하면 생성됩니다.```
2. 03절: `Document와 가까움 점수를 한 쌍으로 반환합니다.` → `Document와 유사도 점수를 한 쌍으로 반환합니다.`
3. 03절: `어떤 문서가 먼저 선택되었는지 봅니다.` → `어떤 문서가 먼저 선택되었는지 확인합니다.`
4. 05절: ``둘째 문서 `ANSWER`에는`` → ``두 번째 문서 `ANSWER`에는``
5. 05절: `모델이 똑같이 “찾을 수 없습니다”라고 답해도` → `모델이 같이 “찾을 수 없습니다”라고 답해도`
6. 05·06절의 `생성 답` → `생성된 답변` 세 곳
7. 06절: `환경 변수의 조건으로 이 노트북 전체가` → `환경 변수에 지정한 조건으로 이 노트북 전체가`

## Ch 10

8. 01절: `파일을 읽는 도구가 글자로 준 쪽 번호는` → `파일을 읽는 도구가 문자열로 제공한 쪽 번호는`
9. 01·02·03·04·05·07절 소제목 `일부러 실패해 보기` → `실패 확인` 여섯 곳
10. 02절: `두 글자 수가 다르면` → `두 결과의 글자 수가 다르면`
11. 03절: `` `style`처럼 화면 설정용인 태그를`` → `` `style`처럼 화면 표시를 설정하는 태그를``
12. 05절: `큰 경계를 보존할 수 없을 때 다음 경계를 사용합니다.` → `빈 줄처럼 큰 단위의 경계에서 나눌 수 없을 때 다음 경계를 사용합니다.`
13. 06절: `백분위 값 하나만 바꿉니다.` → `백분위수 하나만 바꿉니다.`
14. 06절: `백분위 값을 95에서 50으로 낮춥니다. 95는` → `백분위수를 95번째에서 50번째로 낮춥니다. 95번째 백분위수는`
15. 06절: `50은 중앙값보다 큰 거리도` → `50번째 백분위수는 중앙값보다 큰 거리도`
16. 06절: ``백분위 값을 `0`으로 낮추면`` → ``백분위수를 `0`번째로 낮추면``
17. 06절: `50 백분위 결과와 비교합니다.` → `50번째 백분위수 결과와 비교합니다.`
18. 07절: ``128차원 모델에 256차원 캐시와 같은 `namespace`를 사용하면`` → ``128차원 모델에 256차원 캐시에 사용한 것과 같은 `namespace`를 지정하면``
19. 08절: `두 모델을 각각 세 청크 집합에 적용합니다.` → `두 모델을 각각 세 개의 청크 집합에 적용합니다.`
