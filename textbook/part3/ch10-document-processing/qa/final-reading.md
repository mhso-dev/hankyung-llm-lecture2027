# Ch 10 Phase 6 독립 최종 정독

확인일: 2026-09-08  
검토 범위: `_src/` 8절과 `index.html`, `research.md`, `qa/language/before/` 원문, 언어 감사 게이트·불변식 기록. 코드 템플릿과 실행 출력은 읽기 대상에서 제외했습니다.

## 판정: accept

초기 정독에서 지목한 `05-문자-재귀-토큰-청킹.html` 13행의 “2026년의 긴 컨텍스트 모델”은 “긴 컨텍스트 모델”로 보정되었습니다. `research.md`의 버전·근거 한계는 “2026년에 청크가 커진다”는 일반 경향을 공식·재현 가능한 근거로 확인하지 못했다고 명시하므로, 시점 표현을 삭제한 현재 문안이 근거 범위와 일치합니다.

## 자연스러움 정독

- 장르·독자·목적: 초보 수강생을 위한 기술 산문이며, 파일 형식별 추출·청킹·임베딩 실험의 범위와 검증 경계를 이해시키는 글입니다.
- 1독: 01의 공통 문서 계약에서 08의 3×2 기록 실험까지 진행 순서가 자연스럽습니다. “실행했지만 일반화하지 않는다”는 태도가 PDF, HWPX, 임베딩, 실험 절에서 일관됩니다.
- 2독: 100건 목표, 18건 색인 기준선, 3건 스캔 변형본의 역할을 구분하며 혼동을 피합니다. 실제 OpenAI 임베딩과 교육용 특징 벡터도 분리해, 실행 출력이 품질 벤치마크로 오독되지 않습니다.
- 3독: 단문·복문이 섞여 있고 같은 종결의 과도한 연속이나 영어식 수사 헤딩은 보이지 않습니다. 동결된 국소 수정도 “표 구분 표식”, “N개의 청크/토큰”처럼 표준 문어체를 보완하며 호흡이나 주장 강도를 바꾸지 않습니다.

## 의미 보존 대조

- `qa/language/before/`와 현재 `_src/`의 차이는 03~07절과 목차의 13개 국소 문어체 보정입니다. 표 구분 표식, 수량 단위, 띄어쓰기, 강사 노트의 현재 구현 범위만 바뀌었습니다.
- 근거가 부족한 동향 문장의 `2026년` 삭제를 제외한 수치, 날짜, 고유명사, URL, 코드 자리표시자, 직접 인용은 보존되었습니다. 최종 게이트의 `numbers` 경고는 이 연도 삭제를 탐지한 것이며, 보호 불변식 기록에서 승인된 예외로 표시했습니다. 현재 목차·본문에 3×2의 6개 조합과 여섯 실행이 모두 남아 있습니다.
- 02절의 E02·S01 출력 수치와 OCR 미실행, 04절의 최소 HWPX 표식 한계, 07~08절의 `educational-feature-hash` 비벤치마크 상태, OpenAI API 미실행, 18건 기준선·100건 미충족은 서로 모순 없이 반복됩니다.
- OpenAI 가격·차원, E5/BGE-M3 모델 카드 SHA, HWPX·PDF·OCR·상용 파서의 근거는 `research.md`와 각 절 참고 자료에 연결됩니다. `SemanticChunker` 근거는 안정 API 문서가 아닌 LangChain 계획 이슈임을 06절과 조사 문서가 함께 제한합니다.

## 재판정

국소 보정 후 문단의 교육적 주장, 수치, 조건, 실행 상태는 바뀌지 않았습니다. 이 검토 범위에서는 전달을 막는 근거·의미 보존·문체 문제가 없습니다.
