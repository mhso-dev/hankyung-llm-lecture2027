# HWP와 HWPX는 확장자뿐 아니라 내부 구조가 다르다

- 설명 대상: HWP는 바이너리 전용 파서가 필요하고, HWPX는 ZIP 안의 XML을 읽으므로 내부가 ZIP인지 확인한 뒤 알맞은 읽기 방법을 선택합니다.
- 캡션: HWP는 바이너리 전용 파서가 필요하고, HWPX는 ZIP 안의 XML을 읽으므로 내부가 ZIP인지 확인한 뒤 알맞은 읽기 방법을 선택합니다.
- 시선 순서: 왼쪽 입력 → 가운데 변환 또는 비교 → 오른쪽 결과
- alt: HWP는 전용 파서가 필요하다고 분류하고 HWPX는 ZIP 안의 본문 XML을 읽습니다. Document 변환은 후속 단계입니다.
- 삽화 판단: 구성 요소와 관계를 정확히 표시해야 하므로 기술 도식이 더 적합합니다.
