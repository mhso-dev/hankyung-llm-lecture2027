# 캐시 이름에 어떤 설정을 구분해 넣어야 할까요?

- 설명 대상: 본문과 모델 설정을 구분해 저장하는 설계입니다. 모델·차원·전처리 조건이 바뀌면 캐시 이름에도 반영해야 합니다.
- 캡션: 본문과 모델 설정을 구분해 저장하는 설계입니다. 모델·차원·전처리 조건이 바뀌면 캐시 이름에도 반영해야 합니다.
- 시선 순서: 왼쪽 입력 → 가운데 변환 또는 비교 → 오른쪽 결과
- alt: 본문 해시, 임베딩 모델, 벡터 차원, 전처리 버전으로 캐시 키를 만들고 일치하면 히트, 하나라도 다르면 미스로 분기하는 흐름
- 삽화 판단: 구성 요소와 관계를 정확히 표시해야 하므로 기술 도식이 더 적합합니다.
