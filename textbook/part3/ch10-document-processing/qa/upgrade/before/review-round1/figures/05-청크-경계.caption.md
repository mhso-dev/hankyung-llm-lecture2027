# 같은 원문을 문자·재귀·토큰 기준으로 나누기

- 설명 대상: 문자 수와 토큰 수는 같은 숫자라도 경계가 다르며, 재귀 분할은 문단과 문장 구분자를 우선 사용합니다.
- 캡션: 문자 수와 토큰 수는 같은 숫자라도 경계가 다르며, 재귀 분할은 문단과 문장 구분자를 우선 사용합니다.
- 시선 순서: 왼쪽 입력 → 가운데 변환 또는 비교 → 오른쪽 결과
- alt: 같은 문서를 문자 수, 토큰 수, 재귀 구분자 기준으로 자르는 방법과 겹침 구간을 비교한 도식
- 삽화 판단: 구성 요소와 관계를 정확히 표시해야 하므로 기술 도식이 더 적합합니다.
