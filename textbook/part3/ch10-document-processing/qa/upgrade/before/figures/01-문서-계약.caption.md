# 파일에서 읽은 내용과 출처를 후속 두 칸에 옮길 준비

- 설명 대상: 01절은 출처를 준비하고 02~04절은 본문과 구조를 읽습니다. 후속 단계에서 두 결과를 Document의 두 칸에 옮깁니다.
- 캡션: 01절은 출처를 준비하고 02~04절은 본문과 구조를 읽습니다. 후속 단계에서 두 결과를 Document의 두 칸에 옮깁니다.
- 시선 순서: 왼쪽 입력 → 가운데 변환 또는 비교 → 오른쪽 결과
- alt: 파일별로 본문과 출처를 확인한 뒤 후속 단계의 page_content와 metadata에 옮기는 흐름
- 삽화 판단: 구성 요소와 관계를 정확히 표시해야 하므로 기술 도식이 더 적합합니다.
