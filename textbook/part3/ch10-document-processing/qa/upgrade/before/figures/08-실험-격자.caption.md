# 세 번 실행해 한 조건씩 비교하기

- 설명 대상: 같은 원문과 질문을 유지하고, 먼저 청크 크기만 바꾼 뒤 같은 30자 청크에서 모델만 바꾸어 비교합니다.
- 캡션: 같은 원문과 질문을 유지하고, 먼저 청크 크기만 바꾼 뒤 같은 30자 청크에서 모델만 바꾸어 비교합니다.
- 시선 순서: 왼쪽 입력 → 가운데 변환 또는 비교 → 오른쪽 결과
- alt: 같은 원문과 질문에서 45자 small 모델, 30자 small 모델, 30자 large 모델을 차례로 실행하는 비교 순서
- 삽화 판단: 구성 요소와 관계를 정확히 표시해야 하므로 기술 도식이 더 적합합니다.
