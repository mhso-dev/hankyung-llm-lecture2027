# 표를 텍스트로 바꿀 때 — 머리글과 행의 대응을 보존한다

- 설명 대상: 표의 각 값을 어느 열의 값인지 알 수 있게 변환해야 검색 결과만 읽어도 행의 의미가 유지됩니다.
- 캡션: 표의 각 값을 어느 열의 값인지 알 수 있게 변환해야 검색 결과만 읽어도 행의 의미가 유지됩니다.
- 시선 순서: 왼쪽 입력 → 가운데 변환 또는 비교 → 오른쪽 결과
- alt: 같은 표가 구조 손실 경로에서는 값만 나열되고 구조 보존 경로에서는 각 행에 머리글이 반복되는 비교
- 삽화 판단: 구성 요소와 관계를 정확히 표시해야 하므로 기술 도식이 더 적합합니다.
