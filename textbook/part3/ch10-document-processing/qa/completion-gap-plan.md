# Ch 10 커리큘럼 격차 보완 계획

1. 08절 기본 노트북을 재귀·토큰·구조 기반 청킹과 두 임베딩 모델의 6개 조합으로 확장한다.
2. 각 조합에서 실제 임베딩 색인과 검색을 실행하고 같은 필드로 결과를 기록한다.
3. 저장소의 18개 디지털 PDF·3개 스캔 PDF·149개 교육용 질문과 수강생 업무 문서 100건을 구분한다.
4. 상용 파서와 업무 문서 100건은 자격증명·문서 준비가 필요한 선택 실습으로 명시한다.
5. 새 커널 실행, HTML 빌드, 내용·화면·복사 검증을 다시 수행한다.

## 완료 결과

- 08절은 재귀·토큰·구조 기반 청킹과 두 OpenAI 임베딩 모델의 여섯 조합을 실제로 실행합니다.
- 배포용 <code>manifest.json</code>과 PDF 파일을 대조해 디지털 PDF 18건·스캔 변형 3건을 확인하며, 실제 업무 문서 100건 준비 상태는 거짓으로 출력합니다. 정답 정보를 포함한 집필용 전체 질의셋은 학생 배포에서 제외합니다.
- Ch 10 노트북 8개를 Python 3.12.13 새 커널에서 모두 실행했습니다.
- 공통 검증기는 8절·코드 셀 64개를 통과했고, 1280px·390px 화면에서 글자 크기·대비·잘림·가로 넘침·그림·복사 검사가 모두 통과했습니다.
