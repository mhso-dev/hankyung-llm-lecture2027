# Ch 10 한국어 감사 보고서

검수일: 2026-09-08  
검수 범위: `_src/` 8개 절과 `index.html`  
장르: 산문 · 최소 심각도: S1  
최종 판정: **accept**

## 감사 결과

1. `ai-slop-reviewer`: 전체 본문을 정독하고 표준 문어체, 수량 단위, 표 구분 용어, 강사 노트의 구현 범위를 국소 보정했습니다. 영어식 수사 제목과 상투적 결론 주입은 발견되지 않았습니다.
2. `korean-spell-check`: 외부 맞춤법 검사기 전송을 **생략**했습니다. 스킬은 “사용자 주도 최종 검수, 저빈도 요청, 문서·이메일·README 교정 용도로만 쓸니다”, “사용 금지: … 상업적 대량 처리”라고 명시합니다. 공식 [이전 검사기](https://nara-speller.co.kr/old_speller/)도 비상업용과 개인·학생 무료 이용 범위를 안내합니다. 5만 7천 자 이상의 기관 교육용 챕 전체를 자동 전송하는 작업은 해당 범위를 넘어서므로, 외부 전송 없이 로컬 정독으로 맞춤법과 띄어쓰기를 확인했습니다.
3. `korean-humanize`: 원문과 윤문본을 대조했습니다. 다른 모델의 Phase 6 독립 최종 정독은 `accept`로 판정했습니다. 확정본은 [Phase 6 보고서](../final-reading.md)에 기록했습니다.

## 주요 보정

- `표 표식`을 `표 구분 표식`으로 바꾸고 `결론 내리지`를 올바르게 띄어 썼습니다.
- `N개 청크`, `N토큰`을 `N개의 청크`, `N개의 토큰`으로 바꿔 수량 단위를 일관되게 표현했습니다.
- 오버랩 설정값이 실제 중복 길이의 최댓값임을 명확히 적었습니다.
- 구현하지 않은 제목 메타데이터 검사를 청크 본문·출처 메타데이터 검사로 바꿔 실습 코드와 맞춰습니다.
- 공식·재현 근거가 없는 `2026년의 긴 컨텍스트 모델` 일반화에서 연도만 삭제했습니다. 현재 문안은 `긴 컨텍스트 모델`이며, 주장의 범위가 조사 근거와 일치합니다.

## 불변식과 게이트

- 코드·출력 자리표시자, 인라인 코드, URL, 직접 인용을 9개 파일 모두에서 보존했습니다.
- 수치 불변식은 `2026` 삭제 1건만 달라졌습니다. 위에 기록한 근거 정합성 보정으로 승인된 예외입니다. 나머지 수치와 날짜는 보존했습니다.
- 결정적 게이트는 `WARN`(종료 코드 1)입니다. P1·P2는 `PASS`, P0은 문자 변경률 0.2%의 보수적 저윤문 경고, P3은 승인된 `2026` 삭제 경고입니다. 이 두 경고는 전문 정독과 원문 대조로 확인했으며 전달을 막는 문제는 아닙니다.
- 기계적 지표의 위험 대역은 `high`입니다. 산문 기준선이 `essay`로 대체된 규칙 매칭 결과이며, 완성도 등급이나 전달 판정으로 사용하지 않았습니다.

## 최종 상태

의미·수치·출처·실행 상태를 보존했고 과윤문 징후를 발견하지 않았습니다. 외부 맞춤법 서비스와 선택적 MCP Codex 감사는 실행하지 않았으며, 로컬 3단 감사와 다른 모델의 Phase 6 독립 정독으로 마감했습니다. 구성된 Opus 5 세션은 실행하지 않았으며, 실행하지 않은 검수를 수행한 것으로 간주하지 않았습니다.
