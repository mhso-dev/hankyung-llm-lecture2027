# Ch10 Before/After 실행 셀 보강 계획

## 목표

각 절의 기본 예제 뒤에 잘못된 코드와 수정 코드를 연속으로 배치합니다. 두 코드는 같은 원인을 다루며, Before 셀은 구체적인 오류나 잘못된 결과를 출력하고 After 셀은 수정 결과를 단언문으로 검증합니다.

## 변경 범위

- 8개 노트북의 실패 마크다운과 코드에 `lesson_part=before`를 지정합니다.
- 각 Before 셀 바로 뒤에 `lesson_part=after` 마크다운과 코드를 추가합니다.
- 본문 실행 예제에는 `|example`, 실패 절에는 `|failure` 삽입 모드를 사용합니다.
- 레거시 HWP는 지원하지 않는 형식으로 분류하고, HWPX만 ZIP/XML로 읽는 분기를 실제 코드로 실행합니다.

## 검증

Python 3.12 빈 커널에서 8개 노트북을 순서대로 실행합니다. 각 단계에 코드와 실제 출력이 있는지, 셀 순서가 example → before → after인지, 코드 셀이 25줄 이하인지 확인합니다. 기존 38개 회귀 테스트와 잠금 파일 검사도 다시 실행합니다.
