챕터 간 실행 연결

Ch9 06절과 Ch10 08절의 실제 검색 로그를 Ch11 06절에서 읽어 검색 지표를 계산합니다. 각 노트북은 새 커널에서 실행하며, 앞 장의 변수 대신 저장한 파일을 사용합니다. 배포 묶음의 labs/part3/continuity-guide.md에 실행 순서와 식별자 대응을 정리했습니다.

Ch12의 36건은 RRF 가중치와 MMR 관련성 비중의 설정 비교입니다. 검색부터 답변 생성까지 이어지는 통합 RAG는 별도로 실행하고 기록합니다. Ch11은 검색을 평가하며 생성 답변 평가는 Ch15에서 이어집니다.

실험 결과를 읽을 때

검색 후보에 정답이 포함되었는지와 정답이 상위에 있는지를 따로 확인합니다. Recall@50은 후보 누락을, Precision@5와 nDCG@5는 상위 결과의 관련성과 순서를 살펴보는 데 사용합니다. 지표를 비교할 때 질문·정답 문서 ID·문서 집합과 설정을 함께 기록합니다.

제공 PDF 21건은 학습용 합성 자료입니다. 자신의 업무 분야 문서 100건을 사용하는 확장 실습에서는 문서 사용 권한과 개인정보를 확인하고, 실제 문서에서 평가 질문과 정답 근거를 다시 작성합니다.

리랭커에 입력한 후보에 정답 문서가 없다면 재정렬만으로 해당 문서를 추가할 수 없습니다. 한 설정의 평균 점수가 높아져도 어떤 질문의 결과가 나빠졌는지 함께 읽습니다. 실제 문서의 출처와 내용을 확인하는 과정은 지표 계산과 별도로 필요합니다.

Part 3을 마치면 Ch 13에서 이 검색 흐름을 그래프로 옮깁니다. Part 3에서 만든 질문·정답 문서 ID·실험 기록은 다음 평가 실습에도 사용합니다.
