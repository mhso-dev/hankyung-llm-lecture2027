1학습 목표

  • DCG@5와 IDCG@5를 수식으로 계산할 수 있습니다.
  • nDCG@5가 정답 순위를 반영하는 방식을 설명할 수 있습니다.
  • 작은 순위 예제를 손으로 계산한 값과 함수 결과를 대조할 수 있습니다.

2이 내용을 배우는 이유

Precision@5는 정답이 1위여도 5위여도 같은 점수를 줍니다. 실제 검색에서는 위쪽 문서를 먼저 읽고 생성 모델에도 위쪽 문서가 먼저 전달됩니다. nDCG@5는 관련 문서가 아래로 내려갈수록 기여도를 줄여 순서의 품질을 표현합니다.

3앞에서 배운 내용

03절에서 상위 다섯 자리 안의 정답 수를 계산했습니다. 이번 절은 같은 고유 문서 순위에 위치 할인을 적용합니다. 정답 문서 ID가 같으면 관련도 1, 다르면 0을 사용합니다.

4핵심 개념

비유 — 앞자리의 가치를 더 크게 셉니다

같은 안내문도 첫 번째 자리에 있으면 곧바로 발견하고 다섯 번째 자리에 있으면 찾는 시간이 늘어납니다. 순위 할인은 아래쪽 결과의 기여도를 점차 줄입니다.

누적 할인 이득 (DCG)
각 순위의 관련도에 위치별 할인값을 적용해 더한 값입니다.
이상적 DCG (IDCG)
같은 정답 문서를 가장 좋은 순서에 놓았을 때의 DCG입니다.
정규화 (normalization)
DCG를 IDCG로 나누어 0에서 1 사이로 맞추는 과정입니다.
이진 관련도 (binary relevance)
정답은 1, 나머지는 0으로 표시하는 방식입니다.
등급 관련도 (graded relevance)
관련 정도를 0, 1, 2처럼 여러 단계로 표시하는 방식입니다.

DCG@5 = Σ (2^rel_i - 1) / log2(i + 1)이고 nDCG@5 = DCG@5 / IDCG@5입니다. 순위 i는 1부터 시작합니다. 이진 관련도에서는 분자의 2^rel_i - 1이 관련도와 같지만, 전체 식을 유지하면 등급 라벨로 확장할 수 있습니다.

IDCG는 검색 결과에서 발견된 정답 수가 아니라 전체 정답 문서 수로 계산합니다. 정답을 놓친 검색기가 작은 IDCG를 사용해 높은 점수를 받지 않도록 하기 위해서입니다. 정답 문서가 없으면 nDCG를 계산하지 않고 해당 질문을 검색 평균에서 제외합니다.

수식의 세 단계를 코드와 연결하기

코드는 먼저 검색 순위를 [0, 1, ...] 같은 관련도 배열로 바꿉니다. 다음으로 각 위치의 이득에 log2(i+1) 할인을 적용해 DCG를 만들고, 전체 정답을 가장 앞에 놓은 IDCG로 나눠 nDCG를 반환합니다. assert는 손계산과 함수가 같음을 확인할 뿐 검색 품질을 높이지 않습니다.

이진 라벨에서는 정답 여부만 반영하고, 등급 라벨에서는 매우 관련·부분 관련 같은 차이도 이득에 들어갑니다. 두 정책은 같은 nDCG 이름을 써도 값의 의미가 다릅니다. 정답이 하나인 이 실습에서는 1위와 5위의 차이를 읽는 데 집중합니다.

6실험 결과 해석

dev 15개 기준 실행의 nDCG@5는 약 0.893입니다. 현재 결과는 설정 선택용이며, test 15개 결과를 보고 설정을 다시 바꾸지 않습니다. 질문 유형별 문항 수가 적고 문서 형식도 다르므로, 평균 차이만으로 난이도가 원인이라고 단정하지 않습니다.

nDCG가 높아도 Recall@50이 낮으면 후보 누락이 남습니다. 반대로 Recall이 1이고 nDCG가 낮으면 후보에는 들어왔으나 상위로 정렬하지 못한 사례가 많습니다. 두 지표를 함께 읽어 수정할 단계를 정합니다.

7주의할 점과 실무 메모

  • 로그 밑은 2를 사용하고 순위는 1부터 시작합니다.
  • IDCG는 전체 정답 라벨로 계산합니다.
  • 다른 등급 체계를 사용한 nDCG는 정책 버전 없이 직접 비교하지 않습니다.
  • 일반 Python 계산만 사용하므로 API 비용은 0달러입니다.

8정리와 다음 절

  • nDCG@5는 정답 문서의 위치를 반영합니다.
  • DCG를 이상적 순위의 IDCG로 나누어 비교 가능한 범위로 만듭니다.
  • Recall과 함께 읽어 후보 누락과 순위 문제를 구분합니다.

1. [이해] Precision@5가 같은 두 결과를 nDCG가 구분하는 기준은 무엇입니까?

정답 문서의 순위입니다. 2절을 확인합니다.

2. [이해] IDCG는 무엇입니까?

정답 문서를 가장 좋은 순서에 놓은 DCG입니다. 4절 정의를 다시 확인합니다.

3. [적용] 정답이 1위에서 3위로 내려가면 nDCG는 어느 방향으로 변합니까?

감소합니다. 로그 할인값이 작아지기 때문입니다.

4. [분석] 검색 결과에서 발견한 정답만으로 IDCG를 만들면 어떤 문제가 생깁니까?

놓친 정답이 분모에서도 사라져 점수가 부풀려질 수 있습니다. 4절 마지막 단락을 확인합니다.
