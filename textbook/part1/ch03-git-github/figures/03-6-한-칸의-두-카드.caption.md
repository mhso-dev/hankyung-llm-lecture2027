- 읽는 법: 아래 줄 왼쪽에서 두 사람이 해 그림 파란 카드와 달 그림 주황 카드를 들고 어느 쪽을 꽂을지 몰라 마주 보고 멈춤(같은 줄을 다르게 고친 두 커밋, 멈춘 병합). 선반 칸은 오른쪽 끝에 하나뿐 → 가운데 탁자에서 해·상자 줄과 달·상자 줄이 그려진, 받침에 세워 둔 기준판(`policy.txt`, 화면이 아님)을 보며 해와 달이 함께 있는 흰 카드를 만듦(해결한 줄) → 오른쪽 화살표를 따라 흰 카드가 칸에 꽂힘(병합 커밋). 쓰지 않은 두 카드는 바닥 상자에 남음.
