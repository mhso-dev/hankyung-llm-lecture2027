- 설명 대상 문장: 책상이 작업 폴더, 열린 상자가 색인, 봉한 상자가 커밋입니다. 휴지처럼 기록하지 않을 파일은 무시 규칙에 적어 둡니다.
- 캡션: 보낼 물건만 열린 상자에 담고 봉합니다. 작업 폴더에서 고른 파일만 색인에 올리고 커밋으로 기록하는 모습과 같습니다.
- 읽는 법: 왼쪽 책상(작업 폴더) → 화살표 → 손이 책을 넣는 열린 상자(색인) → 화살표 → 선반의 봉한 상자(커밋). 책상에 같은 책이 남아 있는 것은 git add 뒤에도 파일이 작업 폴더에 남는다는 뜻으로 읽습니다. 책상의 휴지는 무시 규칙에 적은 파일, 컵은 이번 커밋에 고르지 않은 파일입니다.
- alt: 책상 위에 책, 컵, 휴지가 있고 같은 책 한 권이 열린 상자에 담기며, 오른쪽에는 테이프로 봉한 상자가 선반에 놓인 삽화
