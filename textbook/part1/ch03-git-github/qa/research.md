# Ch 3 공식 자료 조사

확인일: 2026-09-09. 실행 환경의 Git은 2.50.1, Python은 3.12.13입니다.

- Git 공식 문서에서 add·commit·gitignore의 현재 동작과 이미 추적된 파일에는 무시 규칙이 적용되지 않는 범위를 확인했습니다.
- GitHub 공식 문서에서 GitHub Flow의 브랜치·PR·리뷰·병합 흐름과 PR 리뷰의 승인·변경 요청 개념을 확인했습니다.
- Git 공식 문서에서 merge 충돌, revert가 반대 변경을 새 커밋으로 기록하는 동작, reflog가 로컬 참조 이동을 기록하는 범위, worktree의 별도 작업 폴더 연결을 확인했습니다.
- GitHub 공식 민감 정보 제거 문서에서 실제 시크릿은 먼저 폐기·교체하고 이력 재작성과 협업자 조치를 함께 수행해야 함을 확인했습니다.
- git-filter-repo 공식 설치 문서와 고정 버전 2.47.0을 확인했습니다. 실습은 Python 3.12와 Git 2.50.1 조건에서 실행했습니다.

본문은 공식 예제를 복제하지 않고 주문 서비스와 더미 저장소 예제로 다시 작성했습니다. URL과 확인 날짜는 각 절의 참고 자료에 기록했습니다.
