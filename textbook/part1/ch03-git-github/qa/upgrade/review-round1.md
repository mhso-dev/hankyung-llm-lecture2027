### Q1. §04 복구에 `HEAD@{1}`을 그대로 쓴 선택과 잘못된 커밋 초록 — 권고: 둘 다 유지

  - (1) `git reflog -5`와 `git branch recovered-idea HEAD@{1}`은 HEAD를 옮기지 않습니다. 기록을 읽은 바로 다음 셀에서 썼으므로 번호가 밀리지 않습니다 [확인: 출력 순서].

  - (3) 사람이 메시지로 줄을 고르고 git 이름으로 가리키는 방식은 실무에서 쓰는 방식 그대로입니다.
  - (4) 주의 메모에 「번호는 HEAD를 옮기면 달라짐, 쓰기 직전에 다시 확인」이 있습니다.
