색 규칙: 01~04절과 같이 커밋·파일은 초록, 우리가 실행한 명령은 파랑, 확인한 출력은 노랑, 실행하지 않은 단계는 회색입니다.
빨강은 Before 결함 결과(코드 11 검색에 커밋 두 줄)와 값 바꿔 보기에서 무시 규칙이 막지 못한 결과(코드 7 `종료 코드: 1`)에만 씁니다(규격 §5-3).
더미 키가 든 커밋 `feat: 할인율 설정 추가` 자체는 04절의 잘못된 커밋처럼 이력 속 커밋이라 초록입니다. 강제 올리기는 거절 없이 성공한 명령이라 파랑입니다.
코드 번호는 노트북 코드 셀 순번(준비 셀 = 1)입니다. 옛 Excalidraw 도식 `05-secret-response`는 05-4로 바꾸고 본문에서 뺐습니다(원본 `before/figures/`, `figures/05-secret-response.*`는 삭제하지 않음).
