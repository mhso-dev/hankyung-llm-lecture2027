셀 번호는 코드 셀 순번입니다(준비 1, run_git 2, 작성자 저장소 3, 리뷰어 규칙 4, add_on_branch 5, commit_without_key 6, update_branch 7, open_pull_request 8, merge_pull_request 9, count_key_commits 10, print_report 11, run_pull_request 12, 실행 1 13, 실행 2 14, 비교 15, 남은 환경 파일 16).

색 규칙: 이 절에서 조립한 함수는 파랑, 바꾸는 값은 초록, 기록장과 확인한 출력은 노랑입니다(Ch 2 13절 실습과 같은 나눔). 규격 §5-3에 따라 코드가 받아서 처리하고 기록한 일은 노랑, 프로그램을 멈춘 실패는 빨강입니다.
실행 2의 병합 충돌은 git 병합 명령이 종료 코드 1로 멈춘 것이지만, 조립 함수가 반환받은 `.returncode`로 알아채 두 규칙을 남긴 글로 해결하고 기록장에 `main 받기 종료 코드 | 1`로 적었습니다. 셀은 멈추지 않았습니다. 그래서 03절(사람이 멈춘 병합을 마주한 Before, 빨강)과 달리 Ch 2 13절의 「받아서 기록한 ValueError」처럼 노랑으로 둡니다. 색인 비교에서 찾은 더미 키도 코드가 찾아 막은 결과라 노랑입니다. 이 절 그림에 빨강은 없습니다.
