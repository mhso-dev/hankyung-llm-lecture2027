# Ch 3 집필 개요

기준: 커리큘럼 v6, 2026-09-09. 총 16h는 강의 5h와 실습 11h로 구성합니다. 절마다 강의 1h를 배정하고 01·02·04·05절은 실습 2h, 팀 충돌을 완주하는 03절은 실습 3h를 배정합니다.

| 절 | 학습 질문 | 실습 형식 | 도식 |
| --- | --- | --- | --- |
| 01 커밋과 gitignore | 커밋할 변경과 추적하지 않을 파일을 어떻게 구분합니까? | 기존 추적 파일에 무시 규칙이 소급되지 않는 실패와 수정 | 작업 폴더→스테이징→커밋·무시 경로 |
| 02 GitHub Flow와 PR 리뷰 | 기능 브랜치를 검토해 공유 main에 반영하려면 무엇을 확인합니까? | 빈 문자열 결함 리뷰와 정수 입력 검사 반영 | main→기능→리뷰→수정→병합 |
| 03 병합 충돌 해결 | 팀 원격에서 같은 줄의 변경을 어떻게 근거에 맞게 합칩니까? | 두 clone의 push 거부·pull 충돌·정책 근거 해결 | 공통 원격→두 변경→충돌→해결 |
| 04 revert·reflog·worktree | 공유 취소·로컬 복구·작업 폴더 분리를 어떻게 구분합니까? | hard reset 뒤 reflog 후보를 사용한 실제 복구 | revert·reflog·worktree 사용 조건 |
| 05 시크릿 이력 정리와 예방 | 파일 삭제만으로 부족할 때 어떤 순서로 대응합니까? | 더미 값 커밋·삭제·이력 재작성·원격 재검사 | 폐기·교체→조율→정리→예방 |

완료 기준: 5절·독립 노트북 5개·도식 5쌍·복습 20문항, Python 3.12 새 커널 실행, Git 2.50.1 실제 임시 저장소 결과, 본문 한국어 12,500자 이상, PC 1280px·모바일 390px 화면 4축과 복사·다운로드 검증입니다. 생성형 삽화는 동작 순서 설명에 필요하지 않아 사용하지 않습니다. Excalidraw 도구가 현재 호출 목록에 없어 같은 요소 목록의 편집 가능한 JSON과 SVG를 생성하는 대안을 사용합니다.
