# Ch 3 주제 대조 기록

커리큘럼의 커밋 단위, GitHub Flow, PR·코드 리뷰, 실제 팀 충돌, revert·reflog·worktree, gitignore·시크릿 사고 예방 항목을 다섯 절에 각각 연결했습니다.

- 01은 저장소 준비와 기능 커밋을 분리하고 기존 추적 파일의 무시 실패를 실제 Git 색인으로 확인합니다.
- 02는 PR 템플릿을 main에 먼저 두고 기능 diff에는 코드 한 파일만 남깁니다. 로컬 bare 원격이므로 실제 GitHub 승인 기능이 아님을 본문에 반복해 표시합니다.
- 03은 공용 bare 원격과 두 clone을 사용해 비 fast-forward push 거부, pull 병합 충돌, 정책 파일 근거 해결, 원격 main 갱신을 모두 실행합니다.
- 04는 공개 커밋에 revert를 적용하고, hard reset으로 보이지 않게 된 커밋을 저장해 둔 해시가 아니라 reflog에서 파싱한 후보로 복구합니다.
- 05는 더미 값만 사용하고 현재 파일 삭제 뒤 과거 커밋 접근을 확인합니다. 이력 재작성 후 로컬 mirror와 원격 재복제 mirror에서 경로와 값 검색이 모두 비었는지 확인합니다.

해석 제한은 본문 7번 블록과 집필 점검표에 기록했습니다. 특히 로컬 PR 모의 실습, reflog의 비영구성, 이력 재작성으로 외부 포크·캐시를 제거할 수 없다는 범위를 유지했습니다.
