# Ch 4 주제 독립 검토 반영

2026-09-09 독립 검토에서 제기된 구현 경계와 신뢰성 문제를 다음과 같이 수정하고 다시 실행했습니다.

- 중복 고객 표를 깨끗한 원본으로 교체하지 않고, 같은 오염 표에 “먼저 들어온 원본 유지” 규칙을 적용해 정리한 뒤 조인했습니다. 정리 전 `MergeError`도 실제로 확인합니다.
- 노트북의 `fetch_orders`, `find_customer_orders`, `fetch_articles` 인자와 핵심 연산을 `data_tools.py`의 공개 함수와 맞췄습니다. 노트북은 프로젝트 모듈을 import하지 않고 셀에서 함수를 완성합니다.
- 부모 고객이 없는 O104를 왼쪽 조인으로 발견합니다. SQLite에는 외래 키를 선언하고 `PRAGMA foreign_keys = ON`을 적용해 부모 없는 주문의 `IntegrityError`를 확인합니다.
- REST 함수는 방문 페이지를 기록하고 같은 `next_page`가 반복되면 `ValueError`로 종료합니다. 시간 제한, HTTP 상태 오류, 반복 페이지 검사를 pytest에 추가했습니다.
- 코드 셀 30개 모두에 한국어 주석을 넣고 로컬 서버 메서드와 조회 함수에 타입힌트를 추가했습니다.
- robots.txt 결과는 크롤러 경로 규칙에만 한정하고, 제공 HTML·robots fixture 파싱 범위를 본문과 노트북에 명시했습니다.

수정 후 새 커널 노트북 5개(셀 최대 24줄), pytest 8건, Ruff, Pyright, HTML 계약 검사를 모두 통과했습니다. 중복 키와 외래 키 예외는 발생하지 않았을 때 단언 실패하도록 반대 경로도 검사합니다.
