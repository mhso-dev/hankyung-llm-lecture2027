# Ch 4 공식 자료 조사

확인일: 2026-09-09. 실행 버전은 pandas 3.0.5, httpx 0.28.1, beautifulsoup4 4.15.0, lxml 6.1.3, Python 3.12.13입니다.

- pandas API: https://pandas.pydata.org/docs/reference/
- Python sqlite3: https://docs.python.org/3/library/sqlite3.html
- HTTPX QuickStart: https://www.python-httpx.org/quickstart/
- Python http.server: https://docs.python.org/3/library/http.server.html
- Beautiful Soup: https://www.crummy.com/software/BeautifulSoup/bs4/doc/
- Python robotparser: https://docs.python.org/3/library/urllib.robotparser.html
- Google robots.txt 소개: https://developers.google.com/search/docs/crawling-indexing/robots/intro

REST 예제는 외부 제공자 API가 아니라 localhost의 실제 HTTP 학습 서비스입니다. robots.txt는 크롤러 트래픽 규칙이며 사용 허가나 비공개 보장을 뜻하지 않습니다. 주소별 이용 약관, 저작권·데이터베이스 권리, 개인정보, 호출 제한은 별도로 확인해야 합니다.
