# Ch 4 집필 개요

총 16시간을 강의 5시간과 실습 11시간으로 구성합니다. 다섯 절은 각각 Pandas 표 선택, 관계형 키와 조인, SQL 조회, REST 페이지네이션, 문서 파싱과 스크래핑을 다룹니다. 실습 시간은 2·2·2·3·2시간입니다.

| 절 | 학습 질문 | 실제 실패 | 도식 |
| --- | --- | --- | --- |
| 01 | 상태와 금액을 어떻게 안전하게 조회하는가? | 문자열 금액 합계 | 조건 선택과 자료형 확인 |
| 02 | 조인 행 수를 어떻게 지키는가? | 중복 키로 행 증가 | 기본 키와 외래 키 |
| 03 | SQL 입력을 어떻게 분리하는가? | SQL 문자열 결합 | SQL 조회 함수 경계 |
| 04 | 모든 페이지를 어떻게 수집하는가? | 첫 페이지만 반환 | REST 종료 조건 |
| 05 | 없는 HTML 필드를 어떻게 처리하는가? | None 메서드 호출 | 문서 구조와 필드 추출 |

완료 기준은 독립 노트북 5개 새 커널 실행, 재사용 조회 함수 3개와 실제 pytest, 도식 SVG·Excalidraw 5쌍, 본문 합계 12,500자 이상, 공통 HTML 검증과 1280/390px 화면 검사입니다.
