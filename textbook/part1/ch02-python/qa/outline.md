# Ch 2 집필 개요

기준: 커리큘럼 v6, 2026-09-09. 총 40h = 강의 12h + 실습 28h. 절마다 강의 1h 분량의 자습 설명을 작성합니다. 01~08 각 실습 2h, 09~12 각 실습 3h를 배정합니다. 이는 전체 콘텐츠의 시간 배분이며 트랙별 추가 수업 시간을 합산한 값이 아닙니다. A는 09~11 배정 시간에 01~08 예제 수정·오류 찾기·테스트를 보충하고 B는 확장 내용을 진행합니다. 12는 공통입니다.

| 절 | 학습 질문 | 도식 |
|---|---|---|
|01 변수와 자료형|값의 종류에 따라 같은 연산의 결과는 어떻게 달라지는가?|이름·값·연산|
|02 조건문과 반복문|조건 경계와 반복 범위를 어떻게 확인하는가?|분기·반복 순서|
|03 자료구조|여러 값을 저장하고 바꿀 때 무엇이 함께 바뀌는가?|목록·복사 관계|
|04 함수|입력과 반환값을 분리해 같은 계산을 어떻게 재사용하는가?|입력·처리·반환|
|05 파일과 예외|파일을 저장하고 읽다 실패하면 어떤 정보를 확인하는가?|저장·읽기·예외|
|06 클래스|객체별 상태를 어떻게 분리하는가?|인스턴스별 상태|
|07 모듈과 타입힌트|파일을 나누고 함수의 입력과 결과를 어떻게 표현하는가?|import·호출|
|08 pytest|버그를 발견하는 테스트를 만들고 수정 결과를 어떻게 확인하는가?|실패·수정·재검사|
|09 데코레이터와 컨텍스트 매니저|공통 동작과 자원 정리를 어떻게 분리하는가?|함수 감싸기·정리|
|10 Pydantic|외부 입력의 변환과 검증을 어떻게 구분하는가?|입력·검증·오류|
|11 패키징과 테스트 격리|패키지를 설치하고 외부 상태와 분리해 어떻게 테스트하는가?|빌드·설치·테스트|
|12 async와 await|동기 대기 중 다른 작업이 멈추는 이유는 무엇인가?|이벤트 루프 실행 순서|
