## 01 변수와 자료형

- 학습 질문: 같은 모양의 `"2"`와 `2`가 계산에서 왜 다른 결과를 만드는가?
- 입력과 비교 조건: 상품과 단가 39000.0원은 유지하고 수량만 2에서 3으로 변경했습니다. 실패 비교는 문자열 `"2"`에 같은 3을 곱하고, 수정에서는 `int("2")`에 3을 곱했습니다.
- 실제 연산: 셀 1~4에서 대입·곱셈·`type()`·`int()`를 실행했습니다. 셀 5와 6이 Before/After입니다.
- 관찰 결과: 주문 금액 78000원, 수량 3일 때 117000원, 문자열 곱셈 결과 `222`, 정수 변환 뒤 결과 `6`입니다.
- 비교와 수정 이유: 문자열 반복은 정상 문법이어서 오류 없이 잘못된 수량을 만들 수 있습니다. 숫자 계산 전에 정수로 변환했습니다.
- 해석 범위와 한계: 숫자 모양의 문자열 변환만 확인했습니다. 숫자가 아닌 입력의 예외 처리는 05절 범위입니다.
- 본문·그림 대조: 도식의 2, 39000.0, 78000원은 셀 출력과 일치합니다. 복습 4문항은 실행 결과로 답할 수 있습니다.

## 02 조건문과 반복문

- 학습 질문: 조건의 순서와 반복 종료 문장이 실제 처리 결과를 어떻게 바꾸는가?
- 입력과 비교 조건: 주문 `[18000, 42000, 65000]`은 유지하고 무료 배송 기준만 50000원에서 40000원으로 바꿨습니다. 경계는 49999원과 50000원을 같은 규칙으로 실행했습니다.
- 실제 연산: `if/elif/else`, `for`, `while`, `continue`, `break`, `range`, `enumerate`를 셀 2~6에서 실행했습니다.
- 관찰 결과: 49999원의 배송비는 2000원, 50000원은 0원입니다. `while` 처리 결과는 `[18000, 42000]`, 기준 변경 전후 무료 배송 수는 1건과 2건입니다. 잘못된 범위는 `IndexError`를 냈습니다.
- 비교와 수정 이유: 존재하지 않는 위치 3까지 만든 범위를 `enumerate()`로 바꾸어 실제 항목 세 개만 처리했습니다.
- 해석 범위와 한계: 음수와 0의 의미는 이 실습에서 정한 입력 규칙입니다. 모든 주문 시스템의 규칙으로 일반화하지 않습니다.
- 본문·그림 대조: 도식의 18000원, 0 종료, `[18000, 42000]`은 실제 출력과 일치합니다. 복습 4문항은 출력과 조건에서 답을 찾을 수 있습니다.

## 03 자료구조

- 학습 질문: 같은 주문 정보를 목록·튜플·딕셔너리·집합 중 어디에 담아야 하는가?
- 입력과 비교 조건: 상품 목록 `[키보드, 마우스, 키보드]`, 좌표, 주문 금액을 고정했습니다. 값 하나 변경에서는 복사본에 헤드셋만 추가했습니다.
- 실제 연산: 위치와 키로 읽기, 포함 검사, `len`, `set`, `append`, `copy`, `is`를 실행했습니다.
- 관찰 결과: 목록 길이 3, 집합 길이 2입니다. 단순 대입 뒤 두 목록은 모두 헤드셋을 담고 `is`가 `True`; 복사 뒤 백업은 두 항목을 유지하고 `False`입니다.
- 비교와 수정 이유: `backup = cart`는 사본을 만들지 않으므로 `cart.copy()`로 바깥 목록을 분리했습니다.
- 해석 범위와 한계: 문자열만 든 1단계 목록을 비교했습니다. 중첩된 변경 가능 객체에는 얕은 복사의 한계가 있습니다.
- 본문·그림 대조: 도식의 길이 3/2와 객체 동일성 True/False가 셀 출력과 일치합니다. 복습 4문항은 네 구조의 실제 사용을 묻습니다.

## 04 함수

- 학습 질문: 함수의 입력과 결과를 어떻게 표시하며, 기본 목록이 왜 호출 사이에 공유되는가?
- 입력과 비교 조건: 주문 금액 78000원은 유지하고 할인율만 0.1에서 0.2로 바꿨습니다. Before/After는 같은 태그 `신규`, `배송`을 사용했습니다.
- 실제 연산: 타입힌트가 있는 함수 정의와 호출, `return`, 지역 변수, 변경 가능한 기본 목록, `None` 기본값을 실행했습니다.
- 관찰 결과: 10% 할인은 70200원, 20% 할인은 62400원입니다. Before 첫 호출 시점은 `[신규]`지만 두 번째 호출 뒤 첫 변수도 `[신규, 배송]`이 되고 동일성은 `True`입니다. After 결과는 `[신규]`와 `[배송]`, 동일성은 `False`입니다.
- 비교와 수정 이유: 정의 시 만들어진 기본 목록이 재사용되므로 기본값을 `None`으로 바꾸고 함수 안에서 호출마다 새 목록을 만들었습니다.
- 해석 범위와 한계: 타입힌트 표기와 실행 결과를 확인했지만 정적 타입 검사 도구는 실행하지 않았습니다. 타입힌트 자체는 런타임 검증이 아닙니다.
- 본문·그림 대조: 도식의 입력 78000/0.1, 반환 70200, 공유 True와 분리 결과가 실행 출력에 근거합니다. 복습 4문항은 매개변수·범위·기본 인자를 확인합니다.
