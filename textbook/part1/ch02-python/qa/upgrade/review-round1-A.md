- **[중] 05-1 키워드 인자와 기본값이 있는 매개변수를 같은 것처럼 설명**
  - 위치: 노트북 [5] 셋째 단락 「4절 `calculate_line_total(unit_price, quantity=1)`의 `quantity`처럼, `open()`의 `encoding`도 기본값이 있는 매개변수입니다」, 본문 b4 「파일 쓰기와 읽기」 셋째 단락, 복습 3 「4절의 어떤 매개변수와 같은 모양인가요?」와 해설, handoff `§05 → §06` 「키워드 인자(4절 quantity=1과 같은 기본값 매개변수에 이름으로 넣기)」
