셀 번호는 코드 셀 순번입니다(준비 1, 쓰기 2, 읽기 3, read_items 정의 4·호출 5, parse_order 정의 6·반복 7, 값 바꿔 보기 다시 쓰기 8·다시 읽기 9, 없는 파일 10, ValueError 11, Before 파일 만들기 12·정의 13·호출 14, After 정의 15·호출 16·잘못된 파일 17).
색 규칙: 글·파일·줄 목록처럼 값과 데이터는 초록입니다(1~4절 「값은 초록」과 같음). 우리가 적은 with 블록, 함수 안 차례, try·except 블록은 파랑입니다. 출력은 노랑입니다. 빨강은 실제로 틀린 Before 결과(05-4) 한 곳뿐입니다. 05-3의 FileNotFoundError는 except 블록이 받아 메시지로 남긴 오류라 노랑입니다(검토 1차 반영, 챕터 색 규칙 「잡아서 기록한 오류는 노랑, 프로그램을 멈춘 실패는 빨강」). 05-4의 초록 상자에 적은 오류 이름은 그 파일을 읽을 때 난 오류이고, 실패 결과가 아니라 입력 조건이라 초록으로 둡니다. 회색은 실행하지 않고 건너뛴 줄(05-3) 하나입니다.
노트북 8~9번 값 바꿔 보기(수량 3 → 5, 줄 수 2)와 11번 ValueError는 그림을 따로 만들지 않고 본문 문장으로 설명합니다.
