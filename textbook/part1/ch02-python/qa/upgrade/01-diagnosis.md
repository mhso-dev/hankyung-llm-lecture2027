## 바꾼 것

- 노트북(paired 유지): 제목(준비물 「API 키 불필요」, 호출 0번·비용 없음·1분 이내) → 오늘 볼 그림 → 준비(버전) → 변수 네 개 → `type()` 네 줄 → 주문 금액(정수×실수=실수) → 할인·결제 금액 → 변수만 넣은 f-string → 수량에 3 재대입(주문 금액 78000.0 그대로) → 다시 계산 117000.0 → Before `"2" * 3`=`222`·False → After `int()` 변환(str→int) → 곱셈 6·True·`assert` → 정리
- 학습 질문·데이터(무선 키보드, 수량 2, 단가 39000.0, 할인율 0.1, 문자열 "2"와 3)는 유지. 곱할 3의 뜻을 「상자 3개」로, 기대 수량 6을 변수 `expected_items`로 명시
- 사다리: L1(대입·print)과 이 절에서 가르치는 자료형·`type()`·`int()`·변수만 넣은 f-string만 사용. `.__name__`, `:.0f`·`:.0%` 형식 지정 제거. 조건문은 2절에서 배우므로 회원 할인 조건은 쓰지 않고 그렇게 적음. `upgrade_allow` 예외는 필요 없었음
- 새로 관찰한 동작: 재대입해도 앞서 계산한 변수는 다시 계산되지 않음(7번 소제목, 출력으로 확인)
- 본문 10블록 전체를 다시 씀. 용어 10개 표, 「이 절의 질문」, 「확인한 범위」(숫자 모양이 아닌 문자열 `int()`는 실행하지 않음), 복습 5문항
