셀 번호는 코드 셀 순번입니다(준비 1, 튜플 번호 읽기 2, OrderLine 정의 3, 인스턴스 두 개 4, pencil.add_count 5, 값 바꿔 보기 note.add_count 6, Before 정의 7·호출 8·심화 9, After 정의 10·호출 11).
색 규칙: 우리가 적은 클래스 정의·메서드 호출·찾는 코드는 파랑입니다. 인스턴스·목록처럼 저장된 값은 초록입니다(1~5절 「값은 초록」과 같음). 출력은 노랑입니다. 빨강은 실제로 틀린 Before 결과뿐입니다. 06-2의 「둘 다 ['노트', '연필']」과 06-4의 「준호 주문 ['노트', '연필']」은 같은 Before 출력이라 두 그림 모두 빨강입니다.
노트북 2번 셀(튜플 번호 읽기)은 그림을 따로 만들지 않고 본문 문장으로 설명합니다.
