셀 번호는 코드 셀 순번입니다(준비 1·2, check_stock 정의 3, 부르기만 4, await 5, 차례로 6, gather 7, 값 바꿔 보기 8, stock_main.py 저장 9·실행 10, Before lookup_stock 정의 11·ask_warehouse 정의 12·실행 13, After ask_warehouse 정의 14·실행 15, 심화 16).
위 표의 「N번 셀」은 노트북 소제목 번호(2~10)가 아니라 이 코드 셀 순번입니다. 그림 12-3의 줄 이름과 본문·캡션은 노트북 소제목 번호(5번 차례로, 6번 gather, 7번 값 바꿔 보기)로 부릅니다.
색 규칙: 우리가 적은 코드 줄은 파랑, 이름에 담긴 값과 동기 함수는 초록, 출력은 노랑입니다(1~11절과 같음). 빨강은 실제로 문제가 드러난 Before 결과(0.3초, 끝 연필 → 시작 노트)뿐입니다.
코드 셀 9·10(.py 파일과 asyncio.run(), 종료 코드 0)과 코드 셀 16 심화(스레드 이름 MainThread·asyncio_1)은 그림 없이 본문 문단으로 설명합니다.
