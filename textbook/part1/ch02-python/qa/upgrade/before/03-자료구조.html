1학습 목표

  • 목록·튜플·딕셔너리·집합을 저장 목적에 맞게 선택할 수 있습니다.
  • 위치, 키, 포함 여부를 사용해 각 자료구조의 값을 읽을 수 있습니다.
  • 변경 가능한 목록의 별칭 문제를 재현하고 복사로 분리할 수 있습니다.

2이 내용을 배우는 이유

주문 한 건에도 상품 순서, 배송 좌표, 주문번호와 금액, 중복을 제거한 상품 종류가 함께 들어갑니다. 이 값을 모두 낱개의 변수로 만들면 상품이 늘 때 변수도 계속 늘고, 어떤 값이 한 주문에 속하는지 파악하기 어렵습니다. Python은 여러 값을 묶는 자료구조를 제공합니다. 자료구조마다 순서, 변경 가능 여부, 값을 찾는 방법이 다르므로 목적에 맞게 선택해야 합니다. 이 절에서는 같은 주문 정보를 네 구조로 표현하며 선택 기준을 확인합니다.

3앞에서 배운 내용

01절에서 변수와 자료형을, 02절에서 여러 주문을 순회하는 반복문을 배웠습니다. 이 절은 문자열과 숫자를 한 묶음에 담고 for가 읽을 수 있는 형태로 준비합니다. 노트북은 주문 상품 ["키보드", "마우스", "키보드"]부터 새로 만드므로 앞 노트북의 값이 없어도 실행할 수 있습니다.

4핵심 개념

객체(object)는 실행 중 만들어진 값의 실체입니다. 변수 이름은 객체를 가리킵니다. 목록 하나에 변수 이름 두 개를 연결할 수도 있고, 같은 항목을 가진 목록을 별개의 객체로 만들 수도 있습니다. 이 차이를 아래의 별칭과 복사 예제에서 확인합니다.

찾는 방법에 맞춰 그릇을 고릅니다

목록(list)은 순서가 있는 변경 가능한 값의 묶음입니다. 대괄호로 만들며 items[0]처럼 0부터 시작하는 위치 번호로 읽습니다. 튜플(tuple)은 순서가 있지만 만든 뒤 항목을 바꿀 수 없는 묶음입니다. 소괄호로 만들며 좌표처럼 두 값의 자리와 수를 유지할 때 사용할 수 있습니다. 딕셔너리(dict)는 중괄호 안에 키: 값을 짝으로 저장합니다. 콜론의 왼쪽이 찾을 때 사용할 키이고 오른쪽이 저장할 값입니다. order["amount"]는 키로 78000을 읽습니다. 집합(set)은 중복이 없는 값의 묶음입니다. set(items)는 목록을 입력받아 중복을 제거한 새 집합을 반환합니다.

변경 가능(mutable)하다는 말은 만든 뒤 내부 항목을 추가하거나 삭제할 수 있다는 뜻입니다. 목록과 딕셔너리, 집합은 변경할 수 있고 튜플은 변경할 수 없습니다. append()는 목록 끝에 입력값을 추가하고, len()은 자료구조의 항목 수를 반환합니다. sorted()는 입력을 정렬한 새 목록을 반환하므로 원래 집합에 순서가 생기지는 않습니다.

별칭(alias)은 서로 다른 변수 이름이 같은 객체를 가리키는 상태입니다. backup = cart를 오른쪽부터 읽으면 cart가 가리키는 목록을 backup도 가리키게 한다는 뜻입니다. 새 목록은 만들어지지 않습니다. 복사(copy)는 cart.copy()가 별도의 새 목록을 반환하게 하는 방법입니다. is는 두 변수의 내용이 같은지가 아니라 같은 객체를 가리키는지 검사합니다.

도식 읽기

위쪽에는 서로 다른 자료구조 예제가 있습니다. 상품 목록에는 키보드가 두 번 있어 길이가 3이며, 이 목록으로 만든 집합에는 서로 다른 상품 두 개만 남습니다. 좌표 튜플과 주문 딕셔너리는 별도의 예이며 목록이 이 값들로 변환되는 것은 아닙니다. 아래쪽은 두 상품이 든 cart를 먼저 복사하고 원본에만 헤드셋을 추가하는 순서입니다. 최종 원본은 세 상품, 백업은 두 상품이며 서로 다른 목록을 가리킵니다.

5실행 예제

준비 셀은 상품 목록, 서울의 예시 좌표 튜플, 주문 딕셔너리, 상품 집합을 만듭니다. 집합은 항목 순서를 보장하지 않으므로 화면에 표시할 때 sorted()로 정렬합니다. 기본 실행은 목록의 첫 항목 키보드, 튜플의 첫 값 37.5665, 딕셔너리의 amount 값 78000원, 집합의 마우스 포함 여부 True를 출력합니다.

중간 관찰에서는 목록 길이 3과 집합 길이 2를 비교합니다. 목록은 주문에 담긴 개수를 세는 데 필요하고 집합은 서로 다른 상품 종류를 세는 데 필요합니다. 두 숫자는 질문이 다르므로 어느 하나가 더 정확한 결과인 것은 아닙니다. 이어서 딕셔너리에 item_count 키를 추가하면 기존 주문번호와 금액을 유지하면서 상품 수를 같은 주문 정보에 담을 수 있습니다.

값 하나 변경 셀은 items.copy()로 복사한 목록에 헤드셋 하나를 추가합니다. 변경 전 목록은 세 항목을 유지하고 변경 후 목록만 네 항목이 됩니다. 변경한 목록으로 만든 집합에는 마우스, 키보드, 헤드셋 세 종류가 표시됩니다.

자료구조

목록, 튜플, 딕셔너리, 집합에 같은 주문 정보를 서로 다른 목적에 맞춰 저장합니다.

실행 환경 준비

이 노트북은 Python 3.12 표준 기능만 사용합니다. 네 자료구조의 출력 모양과 값을 찾는 방법을 비교합니다. 괄호 모양만 외우지 말고 순서가 필요한지, 값을 바꿀지, 이름으로 찾을지, 중복을 없앨지를 먼저 판단합니다.

In [1]:
# 같은 주문을 목적에 맞는 네 자료구조로 표현합니다.
items = ["키보드", "마우스", "키보드"]
delivery_point = (37.5665, 126.9780)
order = {"id": "A102", "amount": 78000}
unique_items = set(items)
print(items)
print(delivery_point)
print(order)
print(sorted(unique_items))
출력:
['키보드', '마우스', '키보드']
(37.5665, 126.978)
{'id': 'A102', 'amount': 78000}
['마우스', '키보드']

기본 실행

각 자료구조에서 값을 읽는 방법을 확인합니다. items[0]의 대괄호는 목록의 위치 0을 읽고, order['amount']는 딕셔너리에서 amount 키와 짝인 값을 읽습니다. '마우스' in unique_items는 집합에 해당 값이 있는지 검사해 불리언을 반환합니다. 집합은 순서를 보장하지 않으므로 sorted()에 넣어 정렬된 새 목록을 반환받은 뒤 출력합니다.

In [2]:
# 위치, 키, 포함 여부에 맞는 읽기 방법을 사용합니다.
print(f"첫 상품: {items[0]}")
print(f"위도: {delivery_point[0]}")
print(f"주문 금액: {order['amount']}원")
print(f"마우스 포함: {'마우스' in unique_items}")
출력:
첫 상품: 키보드
위도: 37.5665
주문 금액: 78000원
마우스 포함: True

중간 결과 관찰

목록에는 중복 상품이 남고 집합에는 고유한 상품만 남습니다. len()은 묶음을 입력받아 항목 수를 정수로 반환합니다. order['item_count'] = item_count는 딕셔너리에 새 키와 값을 추가합니다. 목록의 길이 3은 담긴 상품 수이고 집합의 길이 2는 서로 다른 상품 종류 수이므로 서로 다른 질문의 답입니다.

In [3]:
# 길이를 비교해 중복 제거 결과를 확인합니다.
item_count = len(items)
unique_count = len(unique_items)
order['item_count'] = item_count
print(f"담긴 상품 수: {item_count}")
print(f"서로 다른 상품 수: {unique_count}")
print(order)
출력:
담긴 상품 수: 3
서로 다른 상품 수: 2
{'id': 'A102', 'amount': 78000, 'item_count': 3}

값 하나를 바꿔 비교

items.copy()가 반환한 새 목록을 changed_items에 저장한 뒤 append('헤드셋')으로 끝에 값을 하나 추가합니다. 원본 items는 유지됩니다. 변경한 목록을 set()에 입력하면 중복을 제거한 새 집합이 반환됩니다.

In [4]:
# 원본을 보존하려고 복사본에 값 하나를 추가합니다.
changed_items = items.copy()
changed_items.append("헤드셋")
changed_unique_items = set(changed_items)
print(f"변경 전: {items}")
print(f"변경 후: {changed_items}")
print(f"고유 상품: {sorted(changed_unique_items)}")
출력:
변경 전: ['키보드', '마우스', '키보드']
변경 후: ['키보드', '마우스', '키보드', '헤드셋']
고유 상품: ['마우스', '키보드', '헤드셋']

확인할 점 — 목록 길이 3과 집합 길이 2는 중복 상품을 세는 방식의 차이입니다. 정렬한 집합 출력은 화면 비교를 위한 것이며 집합 자체에 위치 순서가 생긴 것은 아닙니다.

6일부러 실패해 보기

Before 셀에서 backup = cart를 실행하면 두 변수는 같은 목록 객체를 가리킵니다. cart.append("헤드셋") 뒤에 두 변수를 출력하면 모두 ['키보드', '마우스', '헤드셋']으로 나타납니다. cart is backup도 True입니다. 백업이라는 이름을 붙였지만 실제 사본은 만들어지지 않았으므로 원본을 수정하면 백업이라고 생각한 값도 함께 바뀝니다.

After 셀은 backup = cart.copy()를 사용합니다. 헤드셋을 추가한 뒤 cart에는 세 항목, backup에는 원래 두 항목만 남습니다. 두 객체가 같은지 확인한 출력도 False입니다. 이 예제의 항목은 문자열뿐이므로 얕은 복사로 충분합니다. 목록 안에 또 다른 변경 가능한 목록이 들어 있다면 안쪽 객체까지 분리해야 하는지 별도로 확인해야 합니다.

Before — 실패 코드

실패 재현

객체는 실행 중 만들어진 값의 실체이고 변수 이름은 그 객체를 가리킵니다. 같은 내용을 가진 별개 객체와, 한 객체를 가리키는 여러 이름을 구분합니다.

backup = cart는 cart의 내용을 복사하는 문장이 아닙니다. 두 변수 이름이 같은 목록 객체를 가리키게 합니다. 따라서 cart.append('헤드셋')으로 객체 하나를 수정하면 backup을 통해 읽은 내용에도 헤드셋이 나타납니다. cart is backup은 두 변수가 같은 객체를 가리키는지 검사합니다.

In [5]:
# backup과 cart가 같은 목록 객체를 가리키는 상태를 만듭니다.
cart = ["키보드", "마우스"]
backup = cart
cart.append("헤드셋")
print(f"cart: {cart}")
print(f"backup: {backup}")
print(f"같은 객체: {cart is backup}")
출력:
cart: ['키보드', '마우스', '헤드셋']
backup: ['키보드', '마우스', '헤드셋']
같은 객체: True

After — 수정 코드

수정

copy()는 현재 항목을 담은 새 목록을 반환합니다. backup = cart.copy()로 반환값을 저장하면 두 변수는 서로 다른 목록 객체를 가리킵니다. 이후 원본만 수정하므로 백업은 수정 전 값 두 개를 유지하고, cart is backup은 False를 반환합니다.

In [6]:
# copy로 서로 다른 목록 객체를 만듭니다.
cart = ["키보드", "마우스"]
backup = cart.copy()
cart.append("헤드셋")
print(f"cart: {cart}")
print(f"backup: {backup}")
print(f"같은 객체: {cart is backup}")
assert backup == ["키보드", "마우스"]
출력:
cart: ['키보드', '마우스', '헤드셋']
backup: ['키보드', '마우스']
같은 객체: False

7주의할 점과 실무 메모

  • 목록과 튜플의 위치 번호는 0부터 시작합니다. 항목이 세 개면 마지막 위치는 2입니다.
  • 딕셔너리에서 존재하지 않는 키를 대괄호로 읽으면 오류가 발생합니다. 키가 없을 수 있는 입력은 포함 여부를 먼저 확인하거나 get()의 기본값을 정합니다.
  • 집합은 중복 제거와 포함 검사에 맞지만 입력 순서를 보여 주는 용도로 사용하지 않습니다. 출력 비교가 필요하면 이 노트북처럼 정렬한 새 결과를 표시합니다.
  • copy()는 바깥 목록을 새로 만듭니다. 중첩된 목록까지 모두 복제하는 동작은 아니므로 데이터 구조의 깊이를 확인합니다.

8정리와 다음 절

  • 목록은 순서와 변경, 튜플은 고정된 순서, 딕셔너리는 키와 값, 집합은 중복 제거에 맞습니다.
  • 같은 원본에서도 목록 길이와 집합 길이는 서로 다른 질문에 답합니다.
  • 변경 가능한 목록의 사본이 필요하면 대입만 하지 않고 복사를 수행합니다.

다음 학습과 이어지는 지점 — 다음 절에서는 주문 금액과 할인율을 함수의 입력으로 받고 계산 결과를 반환합니다. 태그 목록을 함수에 전달할 때도 목록의 변경 가능성을 다시 확인합니다.

1. 상품 순서와 중복을 모두 유지하려면 어떤 자료구조를 사용합니까?

정답: 목록을 사용합니다. 예제의 목록은 키보드, 마우스, 키보드 순서와 중복을 유지합니다.

2. 목록 길이는 3인데 집합 길이는 2인 이유는 무엇입니까?

정답: 목록에는 키보드가 두 번 들어 있지만 집합은 같은 값을 한 번만 유지하기 때문입니다.

3. 주문 금액 78000원을 딕셔너리에서 읽는 표현을 쓰십시오.

정답: order["amount"]입니다. "amount"가 금액 값과 연결된 키입니다.

4. backup = cart와 backup = cart.copy()의 차이를 출력에 근거해 설명하십시오.

정답: 대입만 하면 두 변수가 같은 객체를 가리켜 헤드셋 추가가 양쪽에 보이고 is 결과가 True입니다. 복사하면 백업은 두 항목을 유지하고 is 결과가 False입니다.
