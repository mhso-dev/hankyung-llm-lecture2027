2이 내용을 배우는 이유

주문 금액에서 할인액을 빼는 계산을 여러 화면에서 사용한다고 가정합니다. 계산식을 매번 복사하면 한 화면만 다른 반올림 규칙을 사용할 수 있고, 수정할 곳도 늘어납니다. 계산에 이름을 붙여 한 번 정의하면 입력만 바꾸어 같은 규칙을 다시 사용할 수 있습니다. 함수는 프로그램을 역할 단위로 나누고 입력과 결과의 경계를 보여 줍니다. 이 절에서는 결제 금액 계산을 함수로 만들고, 함수 안의 변수와 기본 인자가 어디까지 유지되는지 확인합니다.

4핵심 개념

계산 절차에 이름을 붙입니다

함수(function)는 입력을 받아 정해진 처리를 하고 결과를 제공하는 코드 묶음입니다. def calculate_payment(amount, discount_rate):는 함수를 실행하는 문장이 아니라 정의하는 문장입니다. def 다음은 함수 이름, 소괄호 안은 입력 자리, 콜론 다음의 들여쓴 줄은 처리 순서입니다. calculate_payment(78000, 0.1)처럼 이름 뒤에 소괄호를 붙여야 정의해 둔 함수가 호출됩니다.

함수 정의에 적은 amount와 discount_rate 같은 입력 자리 이름을 매개변수(parameter)라고 합니다. 실제 호출에서 전달하는 78000과 0.1은 인자(argument)입니다. 호출하면 첫 인자가 첫 매개변수에, 두 번째 인자가 두 번째 매개변수에 저장됩니다. 본문은 할인액을 계산하고 round()로 가장 가까운 정수 금액을 만듭니다. 반환(return)은 처리한 결과를 호출한 곳으로 보냅니다. 반환값을 변수에 저장하면 뒤 계산의 입력으로 다시 사용할 수 있습니다.

범위(scope)는 변수 이름을 사용할 수 있는 코드 영역입니다. 함수 안에서 만든 지역 변수는 그 함수 안에서 사용하며, 함수 밖의 같은 이름을 가진 변수와 구분됩니다. 기본 인자(default argument)는 호출할 때 값을 생략하면 사용할 값입니다. tags=[]처럼 변경 가능한 기본값은 함수가 정의될 때 한 번 만들어져 호출 사이에서 공유될 수 있습니다. None은 값이 아직 없음을 나타내는 특별한 값이며, 이를 기본값으로 두고 함수 본문에서 새 목록을 만들면 호출별 결과를 분리할 수 있습니다. 타입 힌트 표기와 검사는 07절에서 배웁니다.

도식 읽기

위쪽 줄을 왼쪽에서 오른쪽으로 읽으면 78000과 0.1이 함수에 전달되고 할인 후 70200이 반환되는 순서가 보입니다. 가운데 상자는 함수 안팎의 label이 서로 다른 범위에 있음을 보여 줍니다. 아래쪽은 기본 목록을 공유한 두 호출의 결과와 None에서 새 목록을 만들어 분리한 결과를 비교합니다. 아래 비교는 위쪽 금액 계산과 별도의 함수 예제입니다.

5실행 예제

calculate_payment(amount, discount_rate)는 주문 금액과 할인율을 입력받습니다. 함수 안에서는 두 값을 곱해 할인액을 처리하고, 원래 금액에서 할인액을 뺀 뒤 round()가 정수 70200을 반환합니다. 기본 실행은 이 반환값을 payment에 저장합니다. payment // 1000의 //는 나눗셈 결과보다 크지 않은 정수로 내린 몫을 반환합니다. 이 예제의 양수 금액에서는 소수 부분을 버린 값과 같으므로 적립 예정 점수는 70점입니다.

지역 변수 관찰 셀은 함수 밖 label에 "주문"을 저장합니다. make_label() 안에서도 같은 이름을 사용하지만 "주문번호 A102"를 반환한 뒤 바깥 변수를 출력하면 여전히 "주문"입니다. 값 하나 변경 셀은 주문 금액을 유지하고 할인율만 0.1에서 0.2로 바꿉니다. 같은 처리에서 70200원과 62400원이 각각 반환됩니다.

함수

입력값을 받아 결제 금액을 계산하고 반환하는 함수를 작성합니다. 함수 정의, 호출, 입력, 처리, 반환을 한 단계씩 확인한 뒤 변수의 범위와 기본값의 주의점을 살펴봅니다.

실행 환경 준비

이 노트북은 Python 3.12 표준 기능만 사용합니다. 타입 힌트는 07절에서 배우므로 여기서는 함수의 기본 구조에 집중해 이름과 괄호만 사용합니다. def로 함수를 정의하고, 함수 이름 뒤에 소괄호를 붙여 호출합니다.

In [1]:
# amount와 discount_rate를 입력받아 결제 금액을 반환합니다.
def calculate_payment(amount, discount_rate):
    discount = amount * discount_rate
    return round(amount - discount)

print(calculate_payment(78000, 0.1))
출력:
70200

기본 실행

첫 줄 def calculate_payment(amount, discount_rate):는 함수를 정의합니다. amount와 discount_rate는 함수가 받을 입력의 자리 이름인 매개변수입니다. 들여쓴 두 줄은 입력으로 할인액을 계산하는 처리입니다. return은 계산 결과를 호출한 곳에 반환합니다. calculate_payment(amount=78000, discount_rate=0.1)에서 등호로 이름을 지정한 실제 입력값은 인자이며, 반환된 정수 70200이 payment에 저장됩니다. // 1000은 나눗셈 결과보다 크지 않은 정수로 내리는 몫 연산입니다. 이 예제의 양수 70200을 1000으로 나눈 70.2에서는 70이 됩니다.

In [2]:
# 반환값을 변수에 저장하면 뒤 계산에서 다시 사용할 수 있습니다.
payment = calculate_payment(amount=78000, discount_rate=0.1)
reward_points = payment // 1000
print(f"결제 금액: {payment}원")
print(f"적립 예정: {reward_points}점")
출력:
결제 금액: 70200원
적립 예정: 70점

중간 결과 관찰

함수 안에서 만든 지역 변수는 함수 밖의 같은 이름을 가진 변수와 별개입니다. 바깥 label에는 "주문"이 저장되어 있습니다. make_label()을 호출하면 안쪽에 별도의 label이 만들어지고, 그 값만 반환합니다. 함수가 끝난 뒤 바깥 변수를 출력하면 여전히 "주문"입니다.

In [3]:
# 함수 안과 밖의 label은 이름만 같고 범위가 다릅니다.
label = "주문"

def make_label(order_id):
    label = f"주문번호 {order_id}"
    return label

print(make_label("A102"))
print(label)
출력:
주문번호 A102
주문

값 하나를 바꿔 비교

주문 금액은 78000원으로 고정하고 두 번째 인자만 0.1에서 0.2로 바꿉니다. 같은 정의를 다시 작성하지 않아도 함수 호출마다 다른 입력을 처리해 각각의 결제 금액을 반환합니다.

In [4]:
# 할인율 하나만 바꿔 반환값을 비교합니다.
payment_10 = calculate_payment(78000, 0.1)
payment_20 = calculate_payment(78000, 0.2)
print(f"10% 할인: {payment_10}원")
print(f"20% 할인: {payment_20}원")
출력:
10% 할인: 70200원
20% 할인: 62400원

확인할 점 — 함수 정의만으로는 계산이 실행되지 않습니다. 실제 인자를 넣어 호출해야 본문이 처리되고 반환값이 생깁니다. 반환된 70200은 출력뿐 아니라 적립 점수 계산의 입력으로 다시 사용됩니다.

6일부러 실패해 보기

Before 함수는 tags=[]처럼 빈 목록을 기본값으로 둡니다. 이 목록은 호출할 때마다 새로 만들어지지 않습니다. 첫 호출 직후 복사한 상태는 ['신규']입니다. 두 번째 호출에서 "배송"을 추가한 뒤 첫 번째 반환값을 다시 확인하면 ['신규', '배송']으로 바뀌어 있습니다. 두 반환값의 객체 동일성을 검사한 결과도 True입니다.

After 함수는 기본값을 None으로 둡니다. 함수 안에서 tags is None일 때 새 빈 목록을 만든 뒤 태그를 추가합니다. 입력은 호출별 태그 문자열이고, 처리는 새 목록 생성과 추가이며, 반환은 해당 호출만의 태그 목록입니다. 첫 호출 결과는 ['신규'], 두 번째 호출 결과는 ['배송']이고 같은 객체인지 확인한 값은 False입니다.

앞의 실행 예제를 실행한 같은 노트북에서 Before 다음 After 순서로 실행합니다. 출력은 실제 실행 결과입니다.

Before — 실패 코드

실패 재현

tags=[]의 등호 오른쪽은 인자를 생략했을 때 사용할 기본값입니다. 함수 정의가 실행될 때 빈 목록이 한 번 만들어지며, 호출할 때마다 자동으로 새 목록이 생기지 않습니다. 첫 호출이 이 목록에 신규를 추가하고 두 번째 호출이 같은 목록에 배송을 추가하므로 두 호출의 결과가 섞입니다. 타입 힌트는 아직 사용하지 않습니다.

In [5]:
# 기본 목록이 호출 사이에 공유되는 결과를 관찰합니다.
def add_tag_before(tag, tags=[]):
    tags.append(tag)
    return tags

first_tags = add_tag_before("신규")
first_snapshot = first_tags.copy()
second_tags = add_tag_before("배송")
print(f"첫 호출 시점: {first_snapshot}")
print(f"두 번째 호출 뒤 첫 변수: {first_tags}")
print(f"두 번째 호출 결과: {second_tags}")
print(f"같은 객체: {first_tags is second_tags}")
출력:
첫 호출 시점: ['신규']
두 번째 호출 뒤 첫 변수: ['신규', '배송']
두 번째 호출 결과: ['신규', '배송']
같은 객체: True

After — 수정 코드

수정

기본값을 None으로 바꿉니다. None은 값이 아직 없음을 나타내는 특별한 값입니다. 인자가 생략되어 tags is None이 참일 때 함수 본문에서 빈 목록을 새로 만들기 때문에 각 호출은 서로 다른 목록을 처리하고 반환합니다.

In [6]:
# 호출마다 새 목록을 만들어 이전 호출의 변경을 분리합니다.
def add_tag(tag, tags=None):
    if tags is None:
        tags = []
    tags.append(tag)
    return tags

first_tags = add_tag("신규")
second_tags = add_tag("배송")
print(f"첫 호출: {first_tags}")
print(f"두 번째 호출: {second_tags}")
print(f"같은 객체: {first_tags is second_tags}")
assert first_tags == ["신규"]
assert second_tags == ["배송"]
출력:
첫 호출: ['신규']
두 번째 호출: ['배송']
같은 객체: False

7주의할 점과 실무 메모

  • 함수 이름은 calc()보다 calculate_payment()처럼 역할이 드러나게 작성합니다. 함수 하나에는 설명할 수 있는 한 역할을 둡니다.
  • 함수 안에서 print()만 실행하고 반환하지 않으면 결과를 뒤 계산에 사용하기 어렵습니다. 호출한 곳에서 필요한 값은 return으로 제공합니다.
  • 위치로 인자를 전달할 때는 매개변수 순서를 지켜야 합니다. amount=78000처럼 이름을 지정하면 어떤 입력인지 코드에서 확인할 수 있습니다.
  • 목록·딕셔너리·집합처럼 변경 가능한 값을 기본 인자로 직접 만들지 않습니다. None을 기본값으로 두고 함수 안에서 새 객체를 만듭니다.

8정리와 다음 절

  • 함수는 매개변수로 입력을 받고 return으로 결과를 반환합니다.
  • 지역 변수는 함수 안의 범위에 속하며 바깥의 같은 이름과 구분됩니다.
  • 변경 가능한 기본 인자는 호출 사이에 공유되므로 None을 사용해 새 값을 만듭니다.

다음 학습과 이어지는 지점 — 다음 절에서는 파일에서 읽은 문자열을 함수에 전달하고, 파일이 없거나 숫자 변환이 실패할 때 발생하는 예외를 처리합니다.

9복습 문제

문제와 해설

1. calculate_payment(78000, 0.1)에서 매개변수와 인자를 구분하십시오.

정답: 함수 정의의 amount와 discount_rate가 매개변수이고, 호출에서 전달한 78000과 0.1이 인자입니다.

2. 78000원에 10%와 20% 할인을 적용한 반환값은 각각 얼마입니까?

정답: 10% 할인은 70200원, 20% 할인은 62400원입니다. 주문 금액은 같고 할인율만 바뀌었습니다.

3. make_label()을 호출한 뒤 바깥 label이 여전히 "주문"인 이유는 무엇입니까?

정답: 함수 안의 label은 지역 변수이며 함수 밖 변수와 범위가 다르기 때문입니다.

4. 빈 목록을 기본 인자로 직접 두었을 때 관찰한 문제와 수정 방법을 쓰십시오.

정답: 같은 목록이 두 호출에 공유되어 두 태그가 함께 남고 객체 동일성도 True였습니다. 기본값을 None으로 두고 함수 안에서 새 목록을 만들면 호출 결과가 분리됩니다.
