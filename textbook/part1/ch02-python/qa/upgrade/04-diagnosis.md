- **학습 질문·데이터·형식 유지**: 「기본 목록이 호출 사이에서 공유되는 이유」를 쉬운 말로 「기본값을 빈 목록으로 둔 함수를 목록 없이 두 번 부르면, 두 호출이 목록을 따로 받을까요?」로 바꿈(뜻 같음). 78000·0.1·70200, 0.2 → 62400, 태그 신규·배송 두 호출, `tags=[]` → `tags=None`, 첫 호출 직후 `copy()` 스냅숏, `is` True → False 유지. `make_label()`·`label` 범위 예제는 이미 정의한 `calculate_payment()`의 지역 변수 `discount`로 바꿈(함수 하나를 더 만들지 않음). `reward_points = payment // 1000`은 가르치지 않은 `//`라 뺌
