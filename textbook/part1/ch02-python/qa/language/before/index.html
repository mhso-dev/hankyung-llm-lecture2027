어느 순서로 학습하나요?

처음 프로그래밍을 배운다면 01~08절을 순서대로 읽습니다. 기초 문법을 배운 경험이 있다면 복습 문제와 실행 결과로 이해한 내용을 점검하고 09~11절의 B트랙 확장 내용을 학습합니다. 12절의 async/await는 두 트랙 모두 필수입니다. A트랙은 08절에서 12절로 이어갈 수 있습니다.

총 40시간의 학습 범위입니다. A트랙은 B트랙 확장 시간에 기초 예제 수정·버그 찾기·테스트 작성을 보충합니다. 실행 결과를 먼저 예측하고, 코드의 값 하나를 바꾸어 비교한 다음, 실패 원인을 수정하고 테스트로 확인합니다. 각 절은 새 노트북 커널에서 처음부터 실행할 수 있습니다.

챕터 2 노트북과 실행 환경 받기를 선택하면 12개 노트북과 환경 준비 안내를 함께 받을 수 있습니다. 이 챕터는 API 키 없이 실행합니다. 각 절의 HTML은 읽기와 복사용이며 코드는 Jupyter에서 실행합니다.

Ch 1의 hello.py에서 시작한 계산과 오류 수정을 함수·모듈·테스트로 확장합니다. 여기에서 배운 파일·함수는 Ch 4의 데이터 처리로, 비동기 대기는 Ch 18의 API 호출과 Ch 30의 FastAPI로 이어집니다.
