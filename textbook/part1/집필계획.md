각 절은 학습 질문 하나를 중심으로 10개 고정 블록, 독립 실행 노트북, 실제 출력, 도식, 해설이 있는 복습 문제를 갖춥니다. 강의 1시간당 본문 약 2,500자를 기준으로 작성하며, 본문 길이를 채우기 위한 반복 설명은 넣지 않습니다. 실제 원인을 수정하는 절은 비교형, 조건에 따른 관찰을 해석하는 절은 실험형으로 작성합니다.

공식 문서 조사 → 템플릿 생성 → 짧은 노트북 셀 실행 → 본문과 도식 → 빌드 → 별도 주제 검토 → 일반 슬롭·맞춤법·산문 윤문 → 최종 의미 대조 순서입니다. 챕터별 작성자가 해당 디렉터리를 소유하고 리더가 목차·배포·진행표·최종 검증을 통합합니다.

Ch 3은 임시 저장소·로컬 bare 원격·명백한 가상 시크릿으로 실습합니다. GitHub PR의 화면 절차와 로컬에서 실제 검증한 Git 작업을 구분합니다. Ch 4는 로컬 HTTP 서비스와 학습 데이터를 사용하고, Ch 19에 넘길 조회 함수 3종을 테스트합니다. Ch 5는 로컬 사전학습 모델을 사용하여 첫 API 호출이 Ch 6이라는 규칙을 유지합니다. Transformer 내부 구현은 학습 범위에 넣지 않습니다.

완료 기준은 신규 18절·노트북의 새 커널 실행, 노트북↔HTML 코드·출력·다운로드 일치, 본문↔관찰↔도식↔복습 대조, 1280px·390px 화면과 복사 검증, Part 1 목차 및 실습 ZIP의 파일·해시·로컬 링크 확인입니다. 기존 Ch 1·2에는 새 실험을 덮어쓰지 않습니다. 확인하지 못한 플랫폼·서비스 단계는 검토 기록과 전달 문구에 남깁니다.

외부 맞춤법 검사 스킬은 상업적 대량 처리를 금지하므로 교재 전체를 외부로 전송하지 않고 로컬 맞춤법 검토와 정밀 윤문을 수행합니다. Excalidraw MCP 미리보기 도구가 없어 같은 생성기로 SVG와 Excalidraw JSON을 만든 뒤 브라우저에서 확인합니다. 이 대체 절차를 완료 기록에 명시합니다.
