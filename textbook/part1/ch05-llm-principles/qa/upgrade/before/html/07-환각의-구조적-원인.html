1학습 목표

  • 언어 모델의 다음 토큰 예측과 사실 확인이 서로 다른 목표임을 설명할 수 있습니다.
  • 근거가 없는 두 질문에 대한 실제 답에서 근거 없는 생성과 불확실성 표현을 구분할 수 있습니다.
  • 답변 제약을 추가한 전후 결과를 비교하고 관찰 범위를 제한할 수 있습니다.
  • 환각을 줄이기 위해 지시, 근거 제공, 검증, 평가 기준을 함께 설계해야 하는 이유를 말할 수 있습니다.

2이 내용을 배우는 이유

언어 모델의 답은 문법이 자연스럽고 설명의 형식도 익숙합니다. 이 때문에 독자는 문장이 자연스러우면 내용도 확인된 사실이라고 받아들이기 쉽습니다. 그러나 이 절의 로컬 모델은 답변을 만들 때 웹이나 사내 데이터베이스를 자동으로 조회하지 않습니다. 입력과 학습 과정에서 얻은 패턴을 바탕으로 다음 토큰을 이어 갑니다. 질문에 필요한 근거가 없는데도 답을 요구받으면 그럴듯한 표현을 선택할 수 있습니다. 제품에 모델을 연결하는 개발자는 자연스러운 문장과 검증된 사실을 분리해야 합니다.

환각을 “모델이 거짓말한다”라고만 설명하면 대응 방법을 잘못 고르게 됩니다. 거짓말은 알고 있는 사실과 다른 내용을 의도적으로 말한다는 뜻을 포함하지만, 언어 모델에는 사람과 같은 의도를 그대로 적용할 수 없습니다. 이 절에서는 환각(hallucination)을 입력이나 확인 가능한 근거가 뒷받침하지 않는 내용을 모델이 답으로 생성한 현상이라고 제한해 사용합니다. 한 출력만 보고 모델 전체의 환각률을 판단하지 않고, 질문에 근거가 있었는지와 답이 어떤 주장을 만들었는지부터 읽습니다.

실습은 실제로 존재하지 않는 기관·제도와 제품을 묻습니다. 첫 질문에 모델은 지원 절차처럼 보이는 내용을 생성했고, 두 번째 질문에는 실제 제품 정보가 없다고 밝혔습니다. 두 답을 모두 같은 실패라고 표시하면 불확실성을 표현한 동작을 놓칩니다. 이후 “근거가 없으면 확인할 수 없다고 답하라”는 지시를 추가해 두 응답이 어떻게 바뀌었는지 관찰합니다. 이 결과는 지시 한 줄이 모든 환각을 막는다는 보증이 아닙니다.

3앞에서 배운 내용

앞 절에서 같은 프롬프트와 모델도 샘플링 설정과 난수 상태에 따라 다른 문자열을 만들 수 있음을 확인했습니다. 출력이 달라지는 현상과 사실이 틀리는 현상은 같은 개념이 아닙니다. 다양한 답이 모두 근거에 맞을 수도 있고, 매번 같은 답이 계속 잘못될 수도 있습니다. 이번 노트북은 temperature를 0으로 설정해 가장 높은 후보를 고르는 방식으로 실행합니다. 샘플링 변화를 줄이고 질문 정보와 지시문 변화에 집중하기 위한 선택입니다.

실행 모델과 함수는 앞 절과 같습니다. Qwen/Qwen2.5-0.5B-Instruct의 같은 고정 revision을 불러오고, 채팅 템플릿과 tokenizer를 거쳐 최대 64개의 새 토큰을 생성합니다. 로컬 모델은 외부 검색 도구, 사내 문서, 실제 상품 데이터에 연결되어 있지 않습니다. 질문 문장에도 정답 근거를 제공하지 않습니다. 따라서 구체적인 지원금 액수나 배터리 용량을 확인해 답할 수 있는 자료가 없습니다.

4핵심 개념

문장을 잘 이어 쓰는 능력과 자료를 확인하는 능력을 구분합니다

이 절은 모델을 새로 학습하거나 내부 구조를 구현하지 않습니다. 입력은 질문 또는 지시문과 질문을 합친 문자열이고, 처리는 다음 토큰 생성이며, 반환은 모델이 만든 답변 문자열입니다.

환각 판정은 답이 마음에 드는지가 아니라 주장과 근거의 관계를 봅니다. 먼저 답에서 외부 확인이 필요한 구체적 주장을 찾고, 다음으로 입력이나 확인 가능한 자료에 그 주장을 뒷받침하는 근거가 있는지 확인합니다. 근거 없이 만들어진 주장이 있으면 이 절의 기준에서 환각으로 분류합니다.

회의록에서 다음 문장을 자연스럽게 이어 쓰는 사람과 회계 시스템에서 실제 금액을 조회하는 사람은 서로 다른 일을 합니다. 문장 작성자는 문맥에 어울리는 표현을 만들 수 있지만, 장부를 보지 않았다면 정확한 금액을 확인할 수 없습니다. 언어 모델의 사전학습(pretraining)은 많은 텍스트에서 다음 토큰을 예측하는 능력을 학습하는 과정입니다. 이 과정은 언어 패턴과 여러 지식을 모델 파라미터에 반영하지만, 각 생성 문장이 현재 시점의 사실인지 자동으로 조회하고 증명하는 절차는 아닙니다.

다음 토큰 예측(next-token prediction)은 앞의 토큰이 주어졌을 때 이어질 토큰의 확률을 높이는 학습 목표입니다. 모델은 “지원금은” 뒤에 금액이나 결정 절차가 이어지는 문장 패턴을 배울 수 있습니다. 그러나 가상 제도의 실제 근거가 없다는 표지가 모든 질문에 명시적으로 붙어 있는 것은 아닙니다. OpenAI의 2025년 연구는 희소하거나 임의적인 사실에서 이러한 학습 목표가 유창한 추측을 만들 수 있고, 정확도만 보상하는 평가가 불확실성 표현보다 추측을 유리하게 만들 수 있다는 한 구조적 설명을 제시합니다. 이것은 환각의 유일한 원인이라는 주장이 아닙니다.

근거(grounding evidence)는 답을 확인하는 데 사용할 수 있는 입력 자료입니다. 정책 원문, 제품 사양표, 데이터베이스 조회 결과, 도구가 반환한 값 등이 될 수 있습니다. 근거가 없을 때 모델이 “확인할 수 없습니다”라고 답하는 행동을 답변 보류(abstention)라고 부릅니다. 보류는 무조건 좋은 답이라는 뜻도 아닙니다. 근거가 충분한데도 계속 답하지 않으면 유용성이 낮아집니다. 시스템은 어떤 질문에서 답하고 어떤 질문에서 보류할지 평가 기준을 정해야 합니다.

지시문(instruction)은 모델이 답을 만드는 방식과 제한을 알려 주는 입력입니다. 실습은 “정답 근거가 없으면 추측하지 말고 정해진 문장으로 답하라”고 명시합니다. 이 지시가 실제 두 질문에서는 답변 보류를 유도했습니다. 하지만 모델이 모든 표현, 언어, 긴 문맥, 공격적인 입력에서도 지시를 따른다는 보증은 아닙니다. 실제 서비스에서는 답에 필요한 근거를 함께 제공하고, 출처를 표시하며, 중요한 수치와 이름을 별도 규칙이나 도구로 검사합니다.

평가 기준(evaluation criterion)은 답을 성공 또는 실패로 판단하는 규칙입니다. 첫 질문은 존재하지 않는 기관의 지원 제도를 실제처럼 설명했으므로 근거 없는 주장을 만들었습니다. 두 번째 질문은 “실제 제품에 대한 정보는 없습니다”라고 밝혔고 구체적인 용량을 만들지 않았습니다. 문장이 끝까지 완성되지 않았지만, 기록된 범위에서 이미 불확실성을 표현했습니다. 두 응답을 모두 환각으로 세면 관찰한 내용과 맞지 않습니다.

도식 읽기

도식은 왼쪽에서 오른쪽으로 근거 없는 질문, 다음 토큰 예측, 추측 또는 불확실성 표현, 근거 확인 필요를 놓습니다. 네 상자는 직선 화살표로 이어집니다. 가운데의 “추측/불확실 표현”은 근거 없는 질문에서 두 종류의 답이 나올 수 있음을 압축해 나타냅니다. 어느 질문에 어떤 답이 기록됐는지와 답변 보류 지시를 추가한 결과는 아래 노트북에서 따로 확인합니다. 마지막 상자는 답을 사실로 받아들이기 전에 근거를 확인해야 한다는 뜻입니다.

5실행 예제

첫 코드 셀은 로컬 생성 모델과 tokenizer를 불러오고 파라미터 수 494,032,768개를 확인합니다. 다음 셀은 temperature 0일 때 샘플링을 끄는 generate() 함수를 정의합니다. 이어지는 셀은 두 질문을 순서대로 모델에 전달합니다. “해바라기 연구소”와 “초록 패스”, “노을 워커 3”은 실습을 위해 만든 이름입니다. 질문에는 제도 지원금이나 제품 배터리 용량의 정답 자료가 없습니다.

첫 답은 지원금 액수를 직접 완성하지 못했지만, 해당 지원금이 2026년에 결정됐고 연구 결과 공개와 연결된다는 절차를 실제 정보처럼 생성했습니다. 질문이나 제공 자료에서 확인할 수 없는 주장입니다. 두 번째 답은 제품이 실제로 존재하지 않는 것으로 보인다고 말하고 구체적인 배터리 용량을 제공하지 않았습니다. 이 응답은 이미 불확실성을 표현했으므로 첫 답과 같은 종류의 근거 없는 사실 생성으로 분류하지 않습니다.

마지막 셀은 질문 앞에 답변 보류 지시를 추가합니다. 같은 두 질문 모두 “제공된 정보로는 확인할 수 없습니다”로 출력됐습니다. 질문 내용과 모델은 유지하고 지시문만 추가했으므로 이 두 사례에서는 지시 변화와 응답 변화의 관계를 볼 수 있습니다. 다만 생성 길이, 다른 표현의 질문, 다른 모델, 대화 이력까지 시험하지 않았습니다.

환각의 구조적 원인

모델이 알지 못하는 고유 사실을 물었을 때, 왜 그럴듯한 문장을 이어 말할 수 있을까요?

Python 3.12와 잠긴 패키지를 사용합니다. 첫 실행에서는 로컬 모델을 다운로드합니다.

로컬 생성 모델 준비

사전학습 모델은 학습이 끝난 파라미터를 저장해 둔 모델입니다. 이 노트북은 모델을 새로 학습하거나 내부 구조를 구현하지 않습니다. 질문 문자열을 입력하고 모델이 반환한 답변 문자열에서 근거가 필요한 주장을 찾습니다.

In [1]:
# 위 설명의 조건을 실행하고 실제 출력을 확인합니다.
import warnings
warnings.filterwarnings("ignore", message="IProgress not found")
import torch
from transformers import AutoModelForCausalLM, AutoTokenizer, logging, set_seed

logging.set_verbosity_error()

MODEL_ID = "Qwen/Qwen2.5-0.5B-Instruct"
REVISION = "7ae557604adf67be50417f59c2c2f167def9a775"
tokenizer = AutoTokenizer.from_pretrained(MODEL_ID, revision=REVISION)
model = AutoModelForCausalLM.from_pretrained(MODEL_ID, revision=REVISION)
model.eval()
print("model:", MODEL_ID)
print("parameters:", f"{model.num_parameters():,}")
출력:
model: Qwen/Qwen2.5-0.5B-Instruct
parameters: 494,032,768
In [2]:
def generate(prompt: str, *, temperature: float = 0.7, seed: int = 0, max_new_tokens: int = 48) -> str:
    # 채팅 템플릿을 적용한 뒤 새로 생성된 토큰만 복원합니다.
    messages = [{"role": "user", "content": prompt}]
    text = tokenizer.apply_chat_template(messages, tokenize=False, add_generation_prompt=True)
    inputs = tokenizer(text, return_tensors="pt")
    set_seed(seed)
    with torch.inference_mode():
        output = model.generate(
            **inputs,
            max_new_tokens=max_new_tokens,
            do_sample=temperature > 0,
            temperature=temperature if temperature > 0 else None,
            top_p=0.9 if temperature > 0 else None,
            pad_token_id=tokenizer.eos_token_id,
        )
    new_tokens = output[0, inputs["input_ids"].shape[1]:]
    return tokenizer.decode(new_tokens, skip_special_tokens=True).strip()

근거가 없는 고유 정보 질문

입력은 실습을 위해 만든 기관·제도와 제품에 관한 두 질문입니다. 정답 자료는 제공하지 않습니다. 각 반환 문자열에서 금액·날짜·절차·제품 사양처럼 외부 확인이 필요한 주장을 먼저 표시하고, 입력에 그 근거가 있었는지 확인합니다. 자연스러운 문장인지 여부는 사실 판정 기준이 아닙니다.

In [3]:
# 위 설명의 조건을 실행하고 실제 출력을 확인합니다.
questions = [
    "2026년 가상 기관 '해바라기 연구소'의 초록 패스 제도 지원금은 얼마인가요?",
    "가상 제품 '노을 워커 3'의 배터리 용량은 몇 mAh인가요?",
]
without_context = []
for question in questions:
    print("Q:", question)
    answer = generate(question, temperature=0, max_new_tokens=64)
    without_context.append(answer)
    print("A:", answer)
출력:
Q: 2026년 가상 기관 '해바라기 연구소'의 초록 패스 제도 지원금은 얼마인가요?
출력:
A: 해바라기 연구소의 초록 패스 제도 지원금은 2026년에 결정되었습니다. 이는 해바라기 연구소가 학술적으로 인정받고 있는 연구를 위한 지원을 제공하는 방식으로, 이는 연구 결과를 공개하고 교

출력:
A: "노을 워커 3"라는 이름으로 인해, 실제 제품에 대한 정보는 없습니다. "노을 워커 3"이라는 제품이 실제로 존재하지 않는 것으로 보입니다. 이 제품의 배터리 용량에 대해 구체적인 정보를 제공하려면,

답변 제약을 추가한 비교

정보가 주어지지 않으면 알 수 없다고 답하도록 제약을 추가합니다. 이 제약이 항상 정확한 답을 보장하지는 않습니다.

6실험 결과 해석

첫 질문의 기록된 답에는 “지원금은 2026년에 결정되었습니다”, “연구 결과를 공개하고”와 같은 주장이 나타납니다. 실습 자료에는 이러한 제도 자체가 없으므로 주장을 뒷받침할 근거도 없습니다. 답에는 질문의 기관·제도 이름과 함께 지원 절차에서 볼 법한 표현이 나타났습니다. 이러한 문장이 어떤 내부 계산이나 학습 자료에서 비롯됐는지는 이 실험으로 알 수 없습니다. 액수는 생성 길이 안에서 나오지 않았지만, 숫자를 만들지 않았다는 이유로 안전한 답이 되는 것은 아닙니다. 확인되지 않은 절차도 사실 주장입니다.

두 번째 질문의 답은 “실제 제품에 대한 정보는 없습니다”, “실제로 존재하지 않는 것으로 보입니다”라고 말합니다. 문장이 최대 생성 길이에서 끝나 완전한 답은 아니지만, 기록된 범위에서는 배터리 용량을 임의로 만들지 않았습니다. 따라서 이 질문까지 환각이라고 세지 않습니다. 같은 모델과 같은 생성 방식에서도 두 질문의 응답 유형은 다르게 나타났습니다. 이 차이가 어떤 학습 자료나 내부 계산에서 비롯됐는지는 이 실험으로 알 수 없습니다.

답변 보류 지시를 추가한 뒤 두 질문은 모두 지정 문장과 정확히 같은 답을 반환했습니다. 이 실행에서는 지시가 원하는 행동을 유도했습니다. 그러나 두 질문과 한 번씩의 실행만 관찰했습니다. 모델이 지시를 무시하도록 유도하는 입력, 근거가 일부만 있는 질문, 오래된 사실, 서로 충돌하는 자료, 여러 차례의 대화는 다루지 않았습니다. 중요한 업무에서 지시 한 줄만으로 사실성을 보장했다고 판단하면 안 됩니다.

환각의 원인은 하나로 고정할 수 없습니다. 다음 토큰 예측이라는 학습 목표, 학습 자료의 오류와 빈틈, 질문에 제공된 정보, 모델 크기와 조정 방식, 생성 설정, 평가가 추측에 주는 보상이 함께 영향을 줄 수 있습니다. 이 절은 그중 “근거 없는 고유 사실 질문에도 유창한 답을 이어 갈 수 있다”는 구조를 관찰했습니다. 원인을 정확히 분리하려면 학습 자료와 모델 내부, 반복 평가 자료가 더 필요합니다.

7주의할 점과 실무 메모

  • 자연스러운 문장과 확인된 사실을 같은 것으로 취급하지 않습니다. 특히 금액, 날짜, 법률, 의학, 인물 정보는 원자료나 도구 결과로 다시 확인합니다.
  • “모르면 모른다고 답하라”는 지시는 유용한 한 층이지만 보안 장치나 사실 검증기의 역할을 대신하지 않습니다.
  • 출처를 요청했다고 해서 출력된 URL이나 문헌이 실제 존재하고 주장을 뒷받침한다고 보장할 수 없습니다. 출처 자체와 연결된 내용을 확인합니다.
  • 보류율만 높이면 환각처럼 보이는 답은 줄 수 있지만 답할 수 있는 질문에도 응답하지 않을 수 있습니다. 정확한 답, 근거 없는 답, 적절한 보류를 함께 측정합니다.
  • 두 번째 답처럼 불확실성을 이미 표현한 사례를 환각으로 세지 않습니다. 평가 전에 어떤 주장이 근거를 요구하는지 판정 규칙을 작성합니다.
  • 실습의 작은 로컬 모델과 두 가상 질문은 현상을 설명하는 사례입니다. 서비스의 실제 환각률이나 다른 모델의 순위를 제공하지 않습니다.

8정리와 다음 절

  • 다음 토큰 예측은 자연스러운 문장 생성을 학습하지만 각 문장의 사실 여부를 자동으로 검증하는 절차는 아닙니다.
  • 근거 없는 첫 질문에서는 확인되지 않은 제도 절차가 생성됐고, 둘째 질문은 이미 정보 부재를 표현했습니다.
  • 답변 보류 지시는 이 두 사례에서 원하는 문장을 만들었지만 사실성을 보장하지 않으므로 근거 제공과 평가를 함께 설계합니다.

다음 학습과 이어지는 지점 — 다음 절에서는 생성·유사도·빈칸 채우기처럼 작업 종류가 다른 모델 후보를 먼저 구분합니다. 라이선스와 실행 가능성으로 후보를 좁힌 뒤 자체 질의셋으로 품질을 측정해야 합니다. Ch 9부터는 외부 문서를 검색해 모델 입력에 근거를 제공하는 RAG 흐름을 만듭니다.

9복습 문제

문제와 해설

1. 첫 번째 질문의 답에서 근거 없이 만들어진 주장은 무엇입니까?

정답: 가상 연구소의 지원금이 2026년에 결정됐고 연구 결과 공개와 연결된다는 제도 절차입니다. 질문과 제공 자료에는 이러한 근거가 없습니다.

2. 두 번째 질문의 제약 전 답을 첫 번째 답과 같은 환각으로 세지 않은 이유는 무엇입니까?

정답: 실제 제품 정보가 없고 존재하지 않는 것으로 보인다고 불확실성을 밝혔으며 구체적인 배터리 용량을 만들지 않았기 때문입니다.

3. 답변 보류 지시를 추가한 뒤 실제로 관찰한 결과와 보장할 수 없는 내용을 구분하십시오.

정답: 두 질문 모두 지정한 확인 불가 문장을 반환한 것은 관찰했습니다. 다른 질문·모델·대화에서도 항상 지시를 따르고 환각이 사라진다고 보장할 수는 없습니다.

4. 환각 대응에서 지시문 외에 필요한 조치를 두 가지 쓰십시오.

정답: 정책 원문이나 검색 결과 같은 근거를 입력에 제공하고, 중요한 주장과 출처를 별도 도구·규칙·질의셋으로 검증해야 합니다. 적절한 보류도 평가 항목에 포함합니다.
