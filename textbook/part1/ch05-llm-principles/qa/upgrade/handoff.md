2. **가져오기 셀**: 따로 셀을 만들지 않고 기존 import 준비 셀 끝에 `# …를 도구 파일에서 가져옵니다` 주석 + `from llm_tools import a, b, c`(이름 알파벳 순). 준비 설명 셀에 고정 세 문장 「앞에서 배운 함수는 `llm_tools.py`에 모아 두었습니다. 파일을 열면 코드를 볼 수 있습니다. 노트북과 같은 폴더(`notebooks/`)에 있는 파일입니다.」 + 「이 노트북은 NN절 `f()`…를 가져옵니다.」 + (처음 가져오는 절만) 인자 모양 한 문장. 「같은 코드로 다시 정의합니다」·「노트북은 서로 독립이라」는 쓰지 않는다. 가져온 함수만 설명하던 소절은 코드 없는 설명으로 합치고 절 번호를 당긴다(09절 선례).
3. **NumPy 이름 설명**: Ch 5 02·03·06절에서 푼 이름(`np.array`·`@`(점곱·표 @ 벡터·비중 @ 표)·`np.linalg.norm`·`np.exp`·`sum()`·`np.round`·`tolist()`·`mean(axis=0)`·`np.argmax`)은 뒤 챕터에서 다시 풀지 않고 「Ch 5 02절처럼」으로 한 번 가리킨다. 새 이름(`np.argsort`·`axis=1`·`keepdims`·`.T`·2차원 표끼리 `@` 등)은 처음 쓰는 자리에서 한 문장. 반복문 판은 계산의 뜻을 처음 가르치는 절만.
4. **출력 인용**: NumPy 배열은 쉼표 없는 모양 그대로 인용·그림 라벨에 쓰고, 들쭉날쭉한 소수 배열은 `np.round(…).tolist()`. `round(np.float32, 4)`는 `0.8987`처럼 그대로 찍힘. 반올림 전 끝자리가 반복문 판과 다를 수 있음(02절 선례) → 반올림한 값만 인용.
5. **절차**: `before-2-7/` 스냅숏 → 생성기 고침 → `run_section.sh`(PYTHONPATH 자동) → 새 커널 두 번 + `/tmp` 사본으로 셀별 대조 → 리팩터 전 노트북과 대조 → 시간 값처럼 매번 바뀌는 값은 마지막 실행 값으로 `mdpatch.py` → `count_code.py`로 수치 → 학생 묶음(Part 1·2: `textbook/part{N}/public-files.json`, Part 3~7: 기존 목록) → 묶음을 풀어 노트북 폴더를 작업 폴더로 한 절 실행.
