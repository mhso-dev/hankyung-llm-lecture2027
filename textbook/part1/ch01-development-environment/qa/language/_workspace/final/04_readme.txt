# Ch 1 실습 시작 안내

Ch 1은 API 키 없이 숫자·파일·개발 도구를 다룹니다. 먼저 [uv 공식 설치 안내](https://docs.astral.sh/uv/getting-started/installation/)와 [VS Code 설치 안내](https://code.visualstudio.com/docs/getstarted/overview)에서 자신의 운영체제에 맞는 프로그램을 설치합니다. 설치 후 새 터미널을 엽니다.

압축을 풀고 안의  폴더를 VS Code의 File → Open Folder로 엽니다. 왼쪽에 , , , 가 보이는지 확인합니다. Terminal → New Terminal로 터미널을 연 뒤 이 폴더에서 다음 명령을 한 줄씩 실행합니다.



환경 준비에는 인터넷 연결이 필요할 수 있습니다. 버전 출력이 로 시작하고 첫 스크립트가 을 출력하는지 확인합니다.

VS Code에서 Microsoft의 Python·Python Debugger·Jupyter 확장을 준비합니다. 명령 팔레트의 에서 이 폴더의 를 선택합니다. 의 파일을 연 뒤 오른쪽 위 Select Kernel → Python Environments에서도 같은 를 선택합니다. 첫 코드 셀부터 로 순서대로 실행합니다. 값이 이전 실행 상태로 남아 있다면 커널을 다시 시작한 뒤 첫 셀부터 실행합니다.

01절은 예상값과 실행 결과, 02절은 파일 경로, 03절은 가상환경, 04절은 스크립트와 디버거, 05절은 Git·Docker 준비를 확인합니다. 처음에는 주석과 설명을 읽고 제공된 코드를 그대로 실행합니다.

05절에서 Git 또는 Docker가 없으면 해당 상태를 기록하고 나머지 점검을 계속합니다. Git은 [공식 설치 안내](https://git-scm.com/book/en/v2/Getting-Started-Installing-Git)를 확인합니다. Docker 클라이언트가 응답해도 서버가 응답하지 않으면 실행 준비가 완료된 것으로 판단하지 않습니다. Docker를 사용하는 후속 실습 전에 운영체제별 Docker Desktop 설치 조건과 실행 상태를 다시 확인합니다.
