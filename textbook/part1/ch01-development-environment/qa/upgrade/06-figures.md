색 규칙: 작업 폴더(우리가 고르는 값)는 파랑, 1~5절에서 배운 확인은 초록(파일·명령을 다루는 도구)입니다. 점검표와 통과한 결과는 노랑입니다. 빨강은 실제로 통과하지 못한 결과에만 씁니다. 06-3의 Docker 「명령을 찾지 못함」은 05절 05-1·05-4처럼 빨강이고, 실행 2의 파일·hello.py·Git(종료 코드 2·128)도 빨강입니다. 06-2는 sequenceDiagram이라 메모가 모두 노랑이며, Docker 메모도 노랑입니다(본문은 「노트북 안에서 바로 확인한 결과」로 설명). 삽화의 색은 비유 대상이라 도식 색 규칙과 연결하지 않습니다.
