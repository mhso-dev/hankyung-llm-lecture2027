## 결론

최종 본문은 초보자용 설명과 실습의 관찰 범위가 서로 맞습니다. Write를 외부 파일/현재 호출 밖의 정보로 구체화했고, `컨텍스트 윈도`라는 용어를 본문·목록·참고 자료에 통일했습니다. 네 실패 모드는 표준 용어가 아닌 교육용 분류임을 밝히며, Context rot 실험은 저하를 관찰하지 못한 경우를 저하 재현으로 부르지 않습니다. Ch 20 전의 agent loop·subagent를 도입하지 않는 경계도 유지합니다.

## 수동 정독과 Phase 6 의미 보존

전문 정독으로 다음을 확인했습니다.

- 사실·수치·조건: 단계적 공개 노트북의 기준 문장은 “회원 1명당 최대 7권, 대출 기간 14일, 예약이 없으면 1회 7일 연장”이며, 압축문·자동 확인·After 검사가 같은 7권과 14일을 확인합니다.
- 핵심 개념과 범위: Write/Select/Compress/Isolate의 설명은 외부 기록, 현재 질문에 필요한 선택, 조건·출처 보존 압축, 입력 분리라는 각 역할을 유지합니다. Isolate를 보안 경계나 agent 구현으로 확대하지 않습니다.
- 관찰과 주장: 실패 입력을 만들었다는 사실과 모델 오류를 관찰했다는 사실을 구분합니다. Context rot의 문자열 확인은 답 전체 정확도를 보장하지 않는다고 밝히고, 작은 실험 결과를 일반화하지 않습니다.
- 용어·주체·부정·한정어: ‘컨텍스트 윈도’, `AIMessage`, `usage_metadata`, `skipped`의 뜻과 적용 범위가 노트북·HTML에서 일치합니다. 사용량 없음/키 없음은 0으로 처리하지 않습니다.
- 문체: 합쇼체가 일관되고, 코드 블록은 감사 대상에서 제외했습니다. 짧은 문장이 많은 것은 노트북의 단계 제목·실행 안내의 성격에서 나왔으며, 설명 단락에서는 주체·행동·확인 기준이 남아 있습니다.

초기 스냅샷은 Ch 8 재실행 변경과 같은 시점에 수집되어, 이후 참고 자료의 ‘창→윈도’ 한 건만 before/after 차이로 남았습니다. 따라서 이 스냅샷만으로 재실행 전의 모든 문장 변화를 기계적으로 증명할 수는 없습니다. 위의 의미 보존 판정은 최종 `_src`·노트북 원문을 직접 대조한 결과입니다.

## 한국어 감사 단계

1. `ai-slop-reviewer` 기준으로 반복 문구, 과장된 단정, 구어 축약, 불필요한 대조를 전문 정독했습니다. 학생이 확인할 데이터·조건을 지운 문장은 발견하지 못했습니다.
2. 외부 맞춤법 검사는 실행하지 않았습니다. `korean-spell-check/SKILL.md`의 “대량 배치, SaaS 백엔드 연동, 상업 서비스 내 무단 재판매·재노출에는 사용하지 않습니다.” 지침과 본 감사의 상업적 일괄 교재 범위에 따라 제외했습니다. 대신 사람이 직접 맞춤법·조사·용어를 읽었습니다.
3. `korean-humanize`의 Phase 2.5 정독과 Phase 6의 수치·명칭·용어·부정·조건·인과·새 주장 여부 점검을 위 방식으로 완료했습니다.

- `metrics.py --genre essay`: before/after 모두 `medium`.
- `verify_gates.py --ignore-markup --json`: 실제 종료 코드 **1**, verdict **WARN**. P0은 문자 변경률 0.0% 미만으로 저윤문 경고이고, P1 목표 달성·P2·P3 불변식은 PASS입니다. P3은 수치·직접 인용 보존과 합쇼체 일관성을 보고했습니다.
