## 한국어 감사 3단

### 1차: AI 슬롭 정독

본문을 절 단위로 읽어 반복되는 결론, 근거 없는 강조, 제목과 내용의 중복, 번역투 대조, 구어 축약형, 금지 어휘를 확인했습니다. `함정`, `선수 지식 회수`, `컨텍스트 창`, `창 밖`, 실행 의미의 `돌리다`, 측정 의미의 `재다`가 학생용 범위에 남지 않았습니다. Ch 7의 CoT·ReAct 절에 나타나는 `ToolNode`와 에이전트 언급은 구현 주장이 아니라 Ch 20까지의 범위를 명시하는 문맥임을 확인했습니다.

### 3차: Phase 2.5·6 수동 판정

규칙 지표가 가리키는 짧은 문장 밀집 구간을 포함해 전문을 다시 읽었습니다. 평균 문장 길이와 단문 비율은 코드 확인 절·표·복습 문항이 섞인 교재라는 구조적 이유로 짧게 측정됩니다. 원인·조건·다음 행동을 잇는 설명이 사라지거나, 명령문 단편이 연속되어 이해를 방해하는 구간은 찾지 못했습니다.

Phase 6에서 다음을 원문·노트북 출력·참고 자료와 대조했습니다.

- Ch 6은 `AIMessage`, `usage_metadata`, 스트리밍 블록, Pydantic 검증, 시간 초과·재시도·fallback을 서로 다른 경계로 설명합니다. 누락된 사용량을 0으로 바꾸지 않으며, 제공자별 실행 가능 여부와 관찰값의 범위를 분리합니다.
- Ch 6의 현재 실행값은 본문과 노트북 출력에서 모두 OpenAI 입력 18, 출력 27, 전체 45토큰, 770.5밀리초, 0.000135달러로 일치합니다. Anthropic·Google은 키 부재로 `skipped`이며 실제 비교 결과로 표현하지 않습니다.
- Ch 7은 역할 메시지의 제공자 특이성, 페르소나와 과업 제약의 비교 혼재, few-shot 예시의 회귀와 데이터 누출, 공개 근거와 비공개 추론의 구분을 보존합니다. CoT 비교의 1.187초·1.393초 지연 방향도 현재 노트북과 대조해 둘째 조건이 더 길다고 바로잡은 최종 문장을 확인했습니다. ReAct 도구 반복이나 에이전트 실행을 앞당기지 않습니다.
- Ch 7은 self-consistency의 합의와 답 내용의 완전성, JSON 문법·필드·자료형·업무 내용 검사를 구분합니다. 프롬프트 버전 비교는 v2→v3에서 관련 예시 하나만 더한 조건과, 저장 JSON의 재현성 한계를 함께 설명합니다.
- Ch 8은 Write·Select·Compress·Isolate를 고정된 함수 흐름으로 설명하며, `컨텍스트 윈도` 용어를 일관되게 사용합니다. 대출 규칙(회원당 7권, 14일, 예약이 없으면 1회 7일 연장)과 Context rot의 관찰·미관찰 조건도 본문과 노트북에서 대응합니다.
- 가격, 모델 이름, 날짜, 수치, 부정·가능성 표현, 공식 문서 링크와 라이선스 표기는 현재 스냅샷을 기준으로 대조했습니다. 수치가 재실행으로 바뀐 Ch 6·7은 새 수치가 본문과 현재 출력에 함께 있는지 확인했습니다.

## 확인 필요 항목

- Anthropic과 Google의 실제 API 호출은 키가 없어 실행 검증하지 못했습니다. 실행 분기와 모델 ID·패키지 호환성은 확인했지만, 실제 사용량·지연·비용 비교는 키가 준비된 동일 조건에서 다시 실행해야 합니다.
- 제공자 가격, 모델 별칭과 접근 권한은 변동할 수 있습니다. 배포 직전에 각 절의 공식 가격·모델 문서와 계정 접근 권한을 다시 확인해야 합니다.
- 이 보고서는 언어·의미 감사입니다. 생성 HTML의 렌더링, 전체 노트북 실행, 도식 시각 검증은 해당 검증 기록을 따릅니다.
