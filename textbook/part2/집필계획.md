# Part 2 집필 및 통합 검증 계획

대상은 커리큘럼 v6의 Ch 6~8입니다. 총 56시간 중 강의 20시간, 실습 36시간에 해당합니다. Ch 6의 6절과 Ch 7의 8절을 새로 작성하고 Ch 8의 기존 6절을 현재 실행 결과로 다시 확인합니다.

| 챕터 | 강의 / 실습 | 개념 절 |
| --- | --- | --- |
| Ch 6 LangChain 시작 | 6h / 10h | 계층 지도와 첫 호출, 메시지와 제공자 전환, Pydantic 구조화 출력, 스트리밍, 타임아웃·재시도·폴백, 토큰·비용·지연 |
| Ch 7 프롬프트 엔지니어링 | 8h / 16h | 역할별 메시지, 페르소나와 제약, Few-shot, 프롬프트 템플릿, CoT·ReAct, Self-Consistency, 출력 설계와 실패 진단, 버전 관리와 A/B 비교 |
| Ch 8 컨텍스트 엔지니어링 | 6h / 10h | 토큰 예산, Write·Select, Compress·Isolate, 네 실패 모드, Context rot, 단계적 공개·세 설계 비교 |

각 절은 하나의 학습 질문을 끝까지 다룹니다. 강의 1시간당 본문 약 2,500자 이상의 자습 설명을 기준으로 하고, 짧은 독립 실행 노트북·실제 출력·개념 도식·해설이 있는 복습 문제를 함께 제공합니다. 각 챕터의 절별 질문과 시수는 챕터 집필 점검표에 기록합니다.

## 작성 순서

공식 문서 조사와 챕터별 집필을 병렬로 진행합니다. 작성자는 노트북 코드를 먼저 실행하고 저장된 응답을 읽은 뒤 본문을 완성합니다. Ch 6·7은 공통 템플릿으로 만들며, Ch 8의 원고나 실행 해시를 복제하지 않습니다. 생성 호출은 LangChain의 `init_chat_model`, `invoke`, `AIMessage.text`를 사용합니다. 사용량은 응답의 `usage_metadata`에서 읽습니다.

고정 입력에서 비교 조건을 하나씩 바꾸며, 실패를 관찰하지 못했으면 미관찰로 설명합니다. Ch 20 이전에는 도구를 선택해 실행하는 에이전트 루프를 구현하지 않습니다. Ch 7의 ReAct는 개념과 후속 학습 범위를 설명합니다. 모델의 비공개 추론 과정을 요구하지 않으며, 답을 점검할 수 있는 짧은 근거와 최종 답을 사용합니다.

## 통합 완료 기준

- 20절 모두 고정 10개 블록, 실행 정본과 일치하는 HTML, 해설이 있는 복습 문제를 포함합니다.
- 노트북은 절마다 새로운 Python 3.12 커널에서 설치 셀부터 실행하고 실제 API 응답과 검증 해시를 저장합니다.
- 각 절의 입력·실제 연산·관찰 결과·본문 해석을 작성자와 구분되는 검토자가 대조합니다.
- 1280px·390px에서 글자 크기·대비·잘림·가로 넘침·도식 경계·복사·다운로드를 검사합니다.
- Part 2 시작 화면, 전체 시작 화면, 노트북 배포 묶음과 진행표를 갱신합니다.
- 한국어 검토는 일반 슬롭 검토 후 정밀 윤문과 최종 의미 대조를 수행합니다. 외부 맞춤법 서비스는 스킬의 상업적 대량 처리 제한에 따라 생략하고, 로컬 정독으로 맞춤법을 함께 확인합니다.

## 알려진 검증 경계

Anthropic·Google 키가 없으면 해당 제공자의 응답·비용·지연은 미실행으로 표시합니다. 키가 없다는 사실을 호출 실패나 성능 차이로 해석하지 않습니다. 모델별 기능과 가격은 확인 날짜를 함께 적습니다. 절당 API 비용은 1달러 미만으로 제한합니다.

현재 세션에는 Excalidraw MCP 미리보기 도구가 노출되지 않습니다. 요소 목록에서 SVG와 Excalidraw JSON을 함께 생성하고 브라우저에서 확정본을 검증합니다. 기존 Ch 8 삽화는 유지하며, 의미가 더 정확한 개념 도식으로 충분한 절은 생성형 삽화를 추가하지 않습니다.
