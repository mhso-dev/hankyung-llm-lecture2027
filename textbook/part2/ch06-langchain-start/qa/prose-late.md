## 05 타임아웃 재시도 폴백

| 확인 항목 | 집필 근거 | 판정 |
| --- | --- | --- |
| 학습 질문 | 타임아웃·재시도·폴백을 어디에 두고 전체 시도 횟수와 비용 위험을 어떻게 계산하는가? | 본문 2·4번에서 답함 |
| 입력과 조건 | 실제 건강 확인 API는 별도 실행. 실패 흐름은 `RunnableLambda`와 `TimeoutError`로 로컬 시뮬레이션 | 실제 장애로 표현하지 않음 |
| 실제 연산 | `with_retry(..., stop_after_attempt=2)`와 `with_fallbacks(..., exceptions_to_handle=(TimeoutError,))` | 본문 4·5·6번에 처리 범위와 전체 횟수를 설명함 |
| 실제 관찰 | 로컬 재시도는 두 번째 시도에서 성공. Before 기본 경로 1회 실패. After 뒤 누적 기본 경로 2회 | 본문 5·6번과 일치 |
| 해석 범위 | 제공자 장애·복구율·내부 재시도 간격을 측정한 결과가 아님 | 본문 5·6·8번에 명시 |
| 도식 | `{{svg:05-resilience}}` | 같은 경로 재시도와 다른 경로 폴백을 구분함 |
| 형식 | paired | 5번 `|example`, 6번 `|failure`를 각각 한 번 사용함 |

## 06 토큰 비용 지연 비교

| 확인 항목 | 집필 근거 | 판정 |
| --- | --- | --- |
| 학습 질문 | 같은 과제를 여러 제공자에 보낼 때 어떤 원자료와 상태를 남겨야 비교 가능한가? | 본문 2·4번에서 답함 |
| 입력과 조건 | 세 제공자에 같은 메시지·반복 1회·출력 상한 적용. 키가 있는 제공자만 호출 | 키 값은 소스와 출력에 포함하지 않음 |
| 실제 연산 | 응답 원문·`usage_metadata`·`perf_counter()` 지연·기준일 단가를 한 레코드로 저장 | 본문 4·5번에서 각 필드의 이유를 설명함 |
| 실제 관찰 | OpenAI 행만 실행: 입력 18, 출력 27, 전체 45토큰, 770.5ms, 예상 0.000135달러. Anthropic·Google은 키가 없어 건너뜀 | 본문 6번에 실행일과 변동 가능성을 함께 기록함 |
| 비용 처리 | GPT-5.4 mini 일반 입력 0.75달러, 캐시 입력 0.075달러, 출력 4.50달러/100만 토큰. 캐시 세부 정보가 있을 때만 할인 단가 적용 | 누락된 사용량·비용을 0으로 바꾸지 않음 |
| 해석 범위 | 실행된 제공자 한 개이므로 제공자 간 수치 비교와 순위 판정 불가 | 본문 6·8번에 명시 |
| 도식 | `{{svg:06-observation}}` | 동일 과제의 제공자 분기와 상태·토큰·지연·비용 기록을 설명함 |
| 형식 | experiment | 5번에는 `|example` 한 번, 6번에는 노트북 마커 없음 |

## 형식 및 문체 검사

- 세 파일 모두 `id="b1"`부터 `id="b10"`까지 10개 고정 블록을 순서대로 사용합니다.
- 세 파일 모두 해설이 포함된 복습 문제 4개를 사용합니다.
- 코드 태그 내용을 제외하고 센 한글 음절 수는 04가 3,228자, 05가 3,168자, 06이 3,376자입니다. 각 절은 최소 2,500자를 넘습니다.
- `당연히`, `간단히`, `쉽게`, `함정`, 실행 의미의 `돌리다`, 구어 축약형 금지어를 자체 검색했고 검출되지 않았습니다.
- API 키의 실제 값, 전체 환경 변수, 인증 헤더를 본문과 이 점검표에 기록하지 않았습니다.
