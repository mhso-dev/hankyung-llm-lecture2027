색 규칙(01~04절 선례 이어받음): 넣은 목록·설정은 초록, 코드 줄은 파랑, 실행한 서비스 모델은 보라, 출력으로 확인한 값·오류는 노랑입니다.
`tiny_model`(gpt-5.4-mini, 0.001초)은 05-1·05-4에서 모두 보라, `with_retry`는 05-1·05-3에서 모두 파랑, 받은 `OpenAITimeoutError`는 05-1·05-2·05-3에서 노랑입니다.
빨강은 05-4 Before 한 곳입니다. 오류를 받아 셀은 끝까지 갔지만 사용자에게 보여 줄 답이 없는 결함 결과라 01절 Before `ValidationError`·03절 Before 선례를 따릅니다. 7·8절에서 받아 출력한 오류와 After 확인의 404는 코드가 받아 기록한 오류라 노랑입니다(02절 404 선례).
`typo_model`(gpt-5.4-mimi)은 서버에 없는 모델이라 실행한 모델(보라)로 칠하지 않고, 우리가 넣은 잘못된 설정으로 초록에 두었습니다.
노드 수: 05-1 7개, 05-3 6개, 05-4 7개. 05-1·05-4는 자동 줄바꿈이 오류 이름을 끊어 `wrappingWidth: 320`을 주고 `<br>`로 직접 줄을 나눴습니다. 05-2는 첫 메시지 라벨이 viewBox 936이라 줄여 793, 05-4는 963 → 796.
