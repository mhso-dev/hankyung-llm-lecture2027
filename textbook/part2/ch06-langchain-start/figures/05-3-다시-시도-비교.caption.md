- 설명 대상 문장: 모델 객체 안의 재시도는 걸린 시간으로만 보였고, with_retry()는 시도를 셀 수 있었으며 목록에 없는 오류는 다시 시도하지 않았습니다.
- 캡션: 적지 않은 max_retries도 기다린 시간을 늘렸고, with_retry는 시간 초과만 3번 시도했으며 모델 없음 오류는 1번으로 멈췄습니다.
