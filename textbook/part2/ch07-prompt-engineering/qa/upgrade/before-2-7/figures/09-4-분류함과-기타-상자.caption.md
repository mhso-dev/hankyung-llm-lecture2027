- 설명 대상 문장: 분류 상자가 셋뿐이면 맞는 상자가 없는 문의도 셋 가운데 하나에 들어가고, 상자를 하나 더 두면 그 문의가 갈 곳이 생깁니다.
- 캡션: 상자가 셋인 왼쪽 책상에서는 붓 메모지가 트럭 상자에 비스듬히 끼어 있고, 회색 상자를 더한 오른쪽 책상에서는 붓 메모지가 회색 상자에 바르게 들어갑니다.
- 대응: 두 책상 = 실행 1(v1)·실행 2(v2), 파란 명찰 = system 페르소나, 주황 클립보드 = developer 과업 명세(오른쪽이 줄이 더 많음 = 출력 형식 글이 조금 늘어남), 트럭·둥근 화살표·동전 상자 = 허용 이름 배송·교환·환불, 회색 빈 상자 = 기타, 금 간 컵 메모지 = 텀블러 문의(두 책상 모두 교환 상자), 붓 메모지 = 글꼴 문의(왼쪽 배송 상자에 억지로, 오른쪽 기타 상자에 바르게).
