# Ch 7 — 프롬프트 엔지니어링 실습

`notebooks/`의 9개 노트북은 각각 빈 Python 3.12 커널에서 독립 실행합니다. 01~08 노트북은 같은 고객 문의(텀블러 뚜껑·A-1042)를 같은 모델에 보내고, 조건마다 프롬프트 한 곳만 바꿔 답 원문·토큰 수·걸린 초를 기록합니다. 07·09는 글꼴 문의도 보냅니다. 확인 단어 표시는 원문에서 읽을 곳을 찾는 도구이고, 답의 품질 점수는 매기지 않습니다.

모델은 LangChain `init_chat_model("openai:gpt-5.4-mini", temperature=0, reasoning_effort="none")`로 만듭니다. 응답은 `AIMessage.text`, 사용량은 `AIMessage.usage_metadata`에서 읽습니다. `.env`에서는 `OPENAI_API_KEY`의 존재만 확인하며 키 값은 출력하거나 노트북에 저장하지 않습니다.

모델 출력은 실행마다 달라질 수 있습니다. 실습은 실패를 만들려고 질문을 바꾸지 않으며, 관찰되지 않은 실패는 관찰했다고 기록하지 않습니다.

챕터 폴더를 VS Code에서 열고 `uv sync --locked`를 실행한 뒤 이 폴더의 `.venv`를 노트북 커널로 선택합니다. 노트북은 새 커널에서 각각 실행할 수 있지만, `08-프롬프트-버전과-AB-비교.ipynb`은 Ch 6의 `runs/provider-comparison-continuity.json`을 읽어 최상위 키·mini 요금과 파일 지문을 확인하고, 출처로 적습니다. 08 노트북은 `notebooks` 폴더를 작업 폴더로 두고 실행합니다(실습 폴더 맨 위에서는 두 경로를 모두 찾지 못해 멈춥니다). 배포본에는 검증한 정본이 함께 들어 있습니다.

`runs/prompt-ab-continuity.json`은 현재 학생 노트북의 정본입니다. `runs/continuity/<실행 시각>/`에는 08 노트북이 실행할 때마다 같은 내용의 사본을 새 폴더로 남깁니다. 지금 있는 `runs/continuity/20260917T070701/`은 08 노트북이 만든 현재 기록 파일의 사본입니다. `runs/prompt-ab-v1.json`은 이전 구현의 증거로 남겨 두었으며 현재 노트북이 덮어쓰지 않습니다.

`09-프롬프트-엔지니어링-실습.ipynb`은 챕터 끝 실습 절입니다. 고객 문의 분류 틀에 JSON 세 층 검사와 버전 기록을 붙여 허용 이름 하나만 바꾼 두 버전을 비교하며, 파일을 만들거나 고치지 않습니다(`runs` 폴더도 그대로 둡니다).
