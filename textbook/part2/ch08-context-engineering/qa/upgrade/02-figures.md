색 규칙(01절·Ch 6·7 선례): 넣은 글·기록·파일은 초록, 노트북 코드의 단계(`json.dumps`·`with open`·`json.loads`·조건 반복문)는 파랑, 실행한 `gpt-5.4-mini`는 보라, 출력으로 확인한 값은 노랑, 출력하지 않은 값·실행하지 않은 단계는 회색입니다. 같은 요소는 절 안 모든 그림에서 같은 색입니다(user 글 02-1·02-2·02-4 초록, 조건 검사 02-1·02-2·02-3 파랑, 고른 기록 02-1·02-2·02-3 노랑).
빨강은 02-4 Before 결과 한 상자뿐입니다(paired Before 결함 결과, 규격 §5-3). 5절 값 바꿔 보기의 4개·101토큰은 코드가 확인한 값이라 노랑입니다.
02-4는 두 답에 모두 있던 「주차 2시간」을 결과 상자에 넣지 않았습니다(규격 §5-3). 두 칸의 입력 목록이 달라 입력 토큰 수도 넣지 않았습니다.
렌더 기록: 02-1 첫 판(TB 세로 7상자, 폭 302·높이 880)은 파일 → 조건 화살표가 Select 칸 제목을 지나감 → 칸끼리 잇는 화살표(`WRITE --> SELECT`)로 바꿔 칸 안이 LR로 배치(폭 810). 02-4 첫 판은 노란 상자 라벨이 「E01 / p.5」로 잘림 → `<br>`로 세 줄, 첫 상자를 파랑(코드)에서 초록(넣은 글)으로 바꿔 02-1·02-2와 색을 맞춤(폭 830). viewBox 폭 02-1 810 · 02-2 557 · 02-3 756 · 02-4 830으로 모두 868 이하.
