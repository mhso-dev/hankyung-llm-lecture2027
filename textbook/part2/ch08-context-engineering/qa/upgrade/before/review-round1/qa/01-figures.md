색 규칙(Ch 6·7 선례 이어받음): 정한 값·넣은 글·목록은 초록, 노트북 코드의 계산·정의한 함수(`input_budget`·`count_tokens`)는 파랑, 실행한 서비스 모델은 보라, 출력으로 확인한 값은 노랑, 노트북에서 실행하지 않은 단계·값(모델 최대 한도, 7절 요청)은 회색입니다. 같은 요소는 절 안 모든 그림에서 같은 색입니다(3절 목록 01-2·01-3 초록, `gpt-5.4-mini` 01-2·01-4 보라).
빨강은 01-4 Before 결과 한 상자뿐입니다(paired Before 결함 결과, 규격 §5-3). 7절 `False`·`넘친 토큰 수: 130`은 값 바꿔 보기에서 코드가 확인한 값이라 노랑입니다.
01-4의 두 칸은 입력 목록이 다르므로(긴 목록 584 / 3절 목록 201) 입력 토큰 수를 비교하지 않고, 결과 상자에 두 조건 공통 값을 한 조건의 효과로 넣지 않았습니다(규격 §5-3). After 답이 6절 답과 같았다는 것은 본문 b6에만 적었습니다.
