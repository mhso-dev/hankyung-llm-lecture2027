색 규칙(01·02절·Ch 6·7 선례): 넣은 글·원문·목록·사람이 정한 지킬 말은 초록, 노트북 코드의 단계(`find_missing_words`·`build_messages`)는 파랑, 실행한 `gpt-5.4-mini`는 보라, 출력으로 확인한 값(검사 결과·추정 입력)은 노랑, 실행하지 않은 요청은 회색입니다. 같은 요소는 절 안 모든 그림에서 같은 색입니다(두 목록 03-1·03-3 초록, `find_missing_words` 03-1·03-2 파랑, 줄인 기록 검사 결과 03-1·03-2 노랑).
03-1의 원문 상자는 넣은 글이라 초록이고, 03-2의 「원문 141토큰 빠진 말 없음」은 원문을 검사한 출력이라 노랑입니다(상자 라벨이 검사 결과를 담음). 02절 기록의 빠진 말 세 개는 검사가 받아 출력한 값이라 노랑입니다(실패가 아님).
빨강은 03-4 Before 결과 한 상자뿐입니다(paired Before 결함 결과, 규격 §5-3). 03-4는 두 답에 모두 있던 「1회 7일 연장」과 둘째 문장 「대출 기준은 7권·14일입니다.」를 결과 상자에 넣지 않았습니다. 두 칸의 입력 토큰 수도 넣지 않았습니다.
렌더 기록: 03-1 첫 판은 두 목록을 노랑(추정 입력 라벨)으로 그렸으나 03-3의 목록 초록과 달라 라벨을 「E01 p.N 기록 + 질문」으로 바꾸고 초록으로 맞춤. 03-2 첫 판(TB, 오른쪽 칸 direction LR 무시로 폭 297·높이 639) → LR로 바꾸자 칸 안도 LR이 되어 폭 1177 → 칸 안 `direction TB` + `R1 ~~~ R2 ~~~ R3`로 폭 774. 03-4 After 라벨 「예약이 없는 경우에 한해」(탐색 답 표현) → 노트북 답 「예약이 없는 경우에만」으로 고침. viewBox 폭 03-1 760 · 03-2 774 · 03-3 774 · 03-4 821로 모두 868 이하.
