# Ch28 실행 검증

- 실행일: 2026-09-11
- Python: 3.12.13
- 패키지: LangChain 1.4.0, langchain-openai 1.6.0, FastMCP 4.0.3, MCP Python SDK 2.2.0
- 모델: gpt-5.4-mini, 05절에서 실제 OpenAI API 호출 3회

## 실제 결과

- 01절: 메모리 전송의 실제 FastMCP 클라이언트가 도구 `lookup_policy`, 리소스 `policy://handbook`, 프롬프트 `explain_policy`를 각각 1개 발견했습니다. 도구 호출은 14일, 리소스 읽기는 세 규정, 프롬프트 가져오기는 대출 주제를 반환했습니다. API 키가 필요하지 않아 오프라인 대표 실행 후보입니다.
- 02절: 등록 전 `tools=[]`와 `ToolError`를 확인했습니다. `@after.tool` 등록 뒤 `tools=['lookup_policy']`와 14일 결과를 확인했습니다.
- 03절: 하위 프로세스에 전달할 이름을 PATH와 PYTHONUNBUFFERED로 제한했고 OPENAI_API_KEY 이름이 없음을 확인했습니다. 이 값을 MCP 서버 설정의 `env`에 적용한 뒤 `MCPAdapter`가 실제 stdio 서버를 시작해 운영 규정을 호출했습니다. 컨텍스트 종료 뒤 `course_server.py` 프로세스가 남지 않았습니다.
- 04절: LangChain 1.4.0의 beta `MCPAdapter`가 도구 이름 `lookup_policy`, 필수 인자 `topic`을 가진 BaseTool을 만들고 stdio 호출 결과에 평일 20:00를 반환했습니다. 알려진 `LangChainBetaWarning`만 메시지 패턴과 경고 클래스로 좁게 필터했으며 beta 상태는 본문과 연구 기록에 남겼습니다.
- 05절: 정의 직렬화 문자는 direct 1개 289자, MCP 1개 216자, MCP 5개 1,288자였습니다. 첫 모델 호출 입력/출력 토큰은 direct 1개 158/18, MCP 1개 158/18, MCP 5개 316/31이었습니다. 세 호출 추정 비용 합계는 0.0007755달러입니다. MCP 전송 바이트는 이 모델 토큰에 포함되지 않습니다.

## 해석 제한

직접 도구와 MCP 도구 한 개는 이름과 변환 스키마 표현이 완전히 같지 않습니다. MCP 한 개와 다섯 개 비교도 도구 수와 각 정의 내용이 함께 바뀝니다. 따라서 측정은 이 고정 질문과 구현에서 도구 정의 규모가 커진 결과를 보여 주며, MCP 자체의 고정 토큰 비용이나 모든 모델의 증가율을 뜻하지 않습니다. 01절 메모리 전송도 MCP 클라이언트·서버의 실제 프로토콜 메서드를 사용하지만 하위 프로세스 수명은 03·04절 stdio 실행으로 별도 확인했습니다. 공개 HTTP 서버는 배포하지 않았습니다.
