# 03절 그림 설계표 (stdio와 원격 전송·권한 경계 · paired)

- 색(규격 §5-3·과정 요약 §8·챕터 공통 「색」): 서버 쪽 프로세스·서버가 받는 값·넣은 가짜 이름 **초록(tool)** · 우리가 쓴 설정·클라이언트 코드 **파랑(flow)** · 노트북 출력으로 확인한 값과 받아 출력한 거절(`MCPError`·401·`Unknown tool`) **노랑(measure)** · 두 설정 공통 값·설치판 서버가 하는 일(출력은 6·7절에서 따로 봄) **회색(클래스 없음)** · **보라 0장**(모델 없음) · **빨강은 03-3 Before 결과 상자 하나뿐**(Before 결함 결과 — 가짜 이름 도착 `True`·빠진 이름 0·가짜 값 읽힘).
- 라벨 규칙: 모델을 부르지 않아 라벨 값은 모두 서버·클라이언트가 주고받은 구조 값이고, 새 커널 두 번 셀별 출력 글 25/25 같음(A 20:49:51Z · B 20:50:12Z, 출력 글 연결 해시 `2990776bc39697e8` 둘 다). 흔들림 확인(`03-probe.md`)은 모델 판단이 없어 두지 않았습니다. 포트 번호·준비 시도 횟수는 라벨에 넣지 않음. 라벨 숫자 1·0·10·401·127.0.0.1은 출력 또는 본문에 있음. 대괄호·따옴표·중괄호는 라벨에서 뺌.
- 차례: 새 커널 A(`run_section.sh`, 그림 첨부 단계에서 멈춤 — 03-1 PNG가 아직 없어서) → 사본 B → **이 설계표** → `.mmd` 넷·캡션 → `author_03.py --src-only` → `run_section.sh … --no-exec`(렌더·첨부·빌드) → 삽화.
