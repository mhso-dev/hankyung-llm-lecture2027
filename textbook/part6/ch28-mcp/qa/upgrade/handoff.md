### 비동기 허용 범위 (01 판)

- **쓰는 것**: 셀 맨 위 `async with Client(...) as client:`와 블록 안 `x = await client.메서드(...)` · 블록 안에서 속성을 읽어 변수에 담기(블록 밖에서는 `protocol_version` `None`·`is_connected()` `False` — 01 3절 출력).
- **첫 자리 풀이(01이 함 — 뒤 절은 「01절에서 본 것처럼」)**: `async with` = Ch 2 05 `with open(...)`처럼 블록을 벗어날 때 연결을 닫는 줄, 여는 일·닫는 일도 기다려야 해서 `async` · 셀 맨 위 await = 노트북 도구(IPython)의 기능(Ch 18 03 선례) · 파이썬 파일에서는 Ch 2 12처럼 `async def` 안에서 `asyncio.run()` · 노트북 셀에서는 `asyncio.run()`을 쓰지 않음(`RuntimeError` — 01은 실행하지 않고 노트북 밖 작은 노트북으로 확인).
- **아직 안 쓴 것(처음 쓰는 절이 한 문장)**: `ainvoke`(「`invoke`의 비동기 판」 — MCP 도구는 `coroutine`만 있어 `.invoke()`가 `NotImplementedError`, 준비 노트 §2 04) · `async def`(함수 안에서 await가 필요할 때만, 셀당 하나·본문 8줄 이하·힌트 없음 — Ch 18 03 「함수 안에서 await를 쓰므로 정의 줄을 `async def`로」) · `asyncio.gather`(Ch 2 12 — 필요 없으면 쓰지 않음).
- 쓰지 않음: `asyncio.run`(노트북) · `asyncio.create_task`로 HTTP 서버 띄우기(소켓이 남음 — 아래) · `nest_asyncio`.

### 하위 프로세스·포트 정리 규칙 (02~06 — 01 노트북 밖 확인 `/tmp/ch28-01/exp/x3_stdio_env.py`)

- **stdio**: MCP 설정 한 벌에 **`"keep_alive": False`**(기본 `True`면 블록을 벗어나도 서버가 남고, 노트북은 커널 루프가 살아 있어 셀을 다시 돌릴 때마다 쌓임 — 준비 노트 e9) + **`"env": {"FASTMCP_SHOW_SERVER_BANNER": "false", "FASTMCP_CHECK_FOR_UPDATES": "off", "FASTMCP_LOG_LEVEL": "WARNING"}`**. 확인 결과: 블록 안 자식 프로세스 1 → 블록 뒤 0, 표준 오류 **0줄**, 네트워크 없음. `env`가 없으면 배너 + PyPI 새 판 확인(`Update available: 4.0.10`, 결과를 `fastmcp.settings.home/version_cache.json`에 씀) + `INFO Starting MCP server …`(시각) = 27줄. 세 이름은 설치판 `fastmcp/settings.py`(`env_prefix="FASTMCP_"`, `show_server_banner` 312~324행·`check_for_updates` 326~339행·`log_level` 77행). **주의**: 설정의 `env`는 SDK 기본 여섯 이름(`HOME·LC_CTYPE·LOGNAME·PATH·SHELL·USER` — **틀린 목록, 아래 「§03 → §04」 9번에서 바로잡음: 설치판 목록은 `HOME·LOGNAME·PATH·SHELL·TERM·USER`, Windows는 다른 열둘, `LC_CTYPE`은 서버 쪽 Python이 만든 이름**)에 **더해짐**(준비 노트 §6-4) → 03의 환경 이름 장면은 이 셋이 더해진 이름 수로 셈(개수는 기기마다 다를 수 있어 참·거짓과 이름만). 대안(서버 파일 끝 `mcp.run(transport="stdio", show_banner=False)`)은 배너·새 판 확인은 막지만 `INFO` 기록은 남고 서버 파일 해시가 바뀜.
