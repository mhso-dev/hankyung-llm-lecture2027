# 04-5-같은-빨래를-하는-옛-세탁기와-새-세탁기 (Higgsfield 삽화)

설명 대상 문장(본문 b4 비유 단락): 이번에는 옛 세탁기와 새 세탁기를 나란히 둡니다. 두 기계는 같은 수건을 빨지만, 옛 기계에는 빨래가 끝난 뒤 한 번 더 거치는 작은 칸이 옆에 붙어 있습니다. … 옆에 붙은 칸은 양식을 넘겼을 때 옛 그래프에만 더해지는 노드 `generate_structured_response`입니다. 같은 수건은 두 함수에 똑같이 넘긴 모델·도구·시스템 메시지 글입니다.

구성 요소와 배치: 왼쪽 **연녹색 위 뚜껑형 옛 세탁기 한 대**(= 옛 함수 그래프) · 그 오른쪽 옆에 **짧은 관 하나로 이어진 작은 회색 상자 하나**(= 옛 그래프에만 더해지는 양식 노드) · 오른쪽 **흰 앞문형 세탁기 한 대**(01-5~03-5와 같은 세탁기 — 윗면 오른쪽 둥근 버튼 하나·앞면 둥근 유리문 하나, 옆에 붙은 것 없음, = 새 함수 그래프) · 두 기계 앞 바닥에 **똑같이 개어진 연노랑 수건 한 장씩**(= 같은 재료). 사람·손·화살표·화면·다이얼·바구니·선반·서랍·판·카드·꼬리표 없음. 인계 소품(대야·빨래판·헹굼 통 01, 나무 판·몸체 틈 02, 주황 카드·셔츠 이름표 03)과 앞 챕터 소품(쟁반·서랍·바구니·저울·울타리·발자국·공구판·승강 상자·식당 전표·집게) 되풀이 금지.

시선 순서: 두 세탁기 → 옛 기계 옆에만 붙은 회색 상자 → 두 기계 앞의 같은 수건.

검수 기준: 그림만 보고 「두 기계가 같은 수건을 빤다」, 「왼쪽 기계에만 관으로 이어진 상자가 옆에 붙어 있다」, 「세탁기 둘·상자 하나·수건 둘」이 읽히는가. 글자·숫자·사람이 없는가.

비유 계열: 챕터 리드 결정 11 **「세탁기(코스 버튼과 동그란 창)」**(01절이 엶) — 04는 옛 세탁기와 새 세탁기를 나란히(인계 「04 후보」 — 같은 일, 다른 자리), 옛 기계에만 있는 칸 하나.
