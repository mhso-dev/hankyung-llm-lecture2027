# 01절 흔들림 확인 (노트북 밖, 2026-09-25)

규격 §2-7 10번 끝 · 챕터 리드 결정 8 · 준비 노트 §2 01·§9-5. 노트북을 쓰기 **전에** 핵심 관찰(질문에 따라 도구를 부르는지 · 메시지 종류와 수 · 도구 메시지 수 · 호출 ID 짝)을 노트북 밖에서 **5번** 봅니다. 키는 루트 `.env`에서만 읽고 출력하지 않습니다.

## 0. 실행 전에 적은 입력과 판단 규칙 (2026-09-25, 첫 요청 전)

공통(노트북과 같은 코드):

- 모델 `init_chat_model("openai:gpt-5.4-mini", temperature=0, reasoning_effort="none")`(과정 표준 — `nbkit.key_and_model_cells`). 모델 **객체**를 `create_agent`에 넘김(챕터 리드 결정 1, Ch 22 모양).
- 자료 `POLICIES` 셋과 도구 `@tool lookup_policy(topic: str)` — **Ch 20 01 노트북 셀과 글자까지 같음**(대출 「일반 도서는 1인 5권까지 14일 동안 대출할 수 있습니다.」 · 운영 「평일은 09:00~20:00, 토요일은 10:00~17:00에 운영합니다.」 · 연체 「연체한 일수만큼 새 대출이 제한됩니다.」, 없는 주제면 `raise ValueError("지원하지 않는 주제: " + topic)`).
- 시스템 메시지 글(설계로 정함, 결과를 보고 바꾸지 않음): 「교육센터 자료실 안내 도우미입니다. 자료실 규정을 묻는 질문에는 lookup_policy 도구로 찾은 규정 글에 근거해 답하세요.」
- 에이전트 `create_agent(model, tools=[lookup_policy], system_prompt=system_text)` — 여럿 담기(`parallel_tool_calls`)를 끄는 인자는 주지 않음(설치판 `factory.py`에 그 인자가 없음 — 미들웨어 없이 `bind_tools(도구, tool_choice=None)`만 부름, 1431~1436행 · `model_node`가 `tool_choice=None`을 넣음 1474행). 실행 한도 인자 없음.
- 입력 상태 `{"messages": [HumanMessage(content=질문)]}`.

입력 셋(모두 Ch 20 01 노트북과 같은 글):

- **L(도구가 필요한 질문, 주 입력)** 「자료실에서 일반 도서를 며칠 빌릴 수 있나요?」
- **G(도구가 필요 없는 질문, 주 입력)** 「안녕하세요. 한 문장으로 인사해 주세요.」
- **T(값 바꿔 보기 후보)** 「자료실 운영 시간과 연체 규정을 함께 알려 주세요.」 — Ch 20 01은 여럿 담기를 꺼 응답마다 요청 하나씩(모델 요청 3·도구 메시지 2)이었음. 여기서는 끄지 않았으므로 한 응답에 요청 둘이 올 수 있다고 예상.

셀 표지(한 회차마다 기록): 결과 딕셔너리 키 · 메시지 종류 차례 · 응답마다 도구 호출 요청 이름과 인자 · 도구 메시지 결과 상태와 내용 · 요청 `id` 목록 == 도구 메시지 호출 ID 목록 · 마지막 응답의 도구 호출 요청 수 · 메시지 목록에 시스템 메시지가 있는지 · 응답마다 사용량(입력·출력·캐시 입력) · 답 글(기록만, 결론에 안 씀).

판단 규칙(결론에 쓸 수 있는 관찰):

- L: 종류 `HumanMessage, AIMessage, ToolMessage, AIMessage` · 첫 응답 요청 1건 `lookup_policy` `{'topic': '대출'}` · 결과 상태 `success` · 호출 ID 짝 `True` · 결과 키 `['messages']` — **5번 모두 같으면** 노트북 주 입력으로 쓰고 결론·그림에 씀.
- G: 종류 `HumanMessage, AIMessage` · 도구 호출 요청 0건 — 5번 모두 같으면 주 입력.
- T: 응답 수(= 모델 요청 수)·한 응답의 요청 수·인자 차례를 기록. 5번 모두 같은 모양이면 그 모양을 결론·그림에 씀. 다르면 입력을 그대로 두고, 결론은 코드로 세는 값(도구 메시지 수·호출 ID 짝·「모델 요청 수 = 응답 수」)에만 두고 응답 모양은 둘째 단락·「확인할 점」·b7에만.
- 5번 가운데 하나라도 다르면: L·G는 **입력을 그대로 두고** 학생 본문 b7에 「같은 요청도 실행한 때에 따라 달라질 수 있다」와 다른 회차 수를 적고, 노트북 결과가 다르면 사실대로 둔 채 원래 관찰일 때의 값을 셈 한 문장으로 덧붙임.
- 입력 후보는 위 셋뿐입니다. 결과를 보고 질문·시스템 메시지 글을 바꾸지 않습니다.
