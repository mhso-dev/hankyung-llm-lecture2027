### 01이 푼 문장 (뒤 절은 되풀이하지 말고 「01절에서 본 것처럼」으로)

- `create_agent`는 모델 객체·도구 목록·시스템 메시지 글을 받아 **컴파일한 그래프(`CompiledStateGraph`)**를 내놓음 = 에이전트 그래프. 만드는 줄에서는 모델 요청이 나가지 않음.
- 구조 문자열 상자 넷(`__start__`·`model`·`tools`·`__end__`)은 Ch 20 01과 같고, 갈래 셋은 모두 **점선**(`tools -.-> model`도 점선 — Ch 20은 실선).
- `agent.builder`(설계 객체): `등록된 노드: ['model', 'tools']` · `고정 엣지로 적힌 수: 1` · `조건부 엣지를 적은 노드 수: 2` · `상태 칸: ['messages', 'jump_to', 'structured_response']` · `노드 tools의 종류: ToolNode` · 조건 함수 `tools | 조건 함수: tools_to_model | 갈 수 있는 곳: ['model']` · `model | 조건 함수: model_to_tools | 갈 수 있는 곳: ['tools', '__end__']`. **`tools_condition`은 쓰지 않음**(출력 + `factory.py` 28행).
- 소스로만: `model_to_tools`는 요청이 없으면 끝, 있으면 **요청마다 `Send("tools", [요청])`**(1923~1975행) · `tools_to_model`이 끝으로 가는 경우는 둘뿐 — 부르자마자 끝내는 설정(`return_direct`)의 도구, **구조화 출력용 도구가 실행됐을 때**(2004~2037행, 이번에 실행 안 함 — **02가 출력으로 보일 수 있는 자리**) · `jump_to`는 결과에서 빠지는 비공개 칸.
- 결과 딕셔너리 키 `['messages']`(흔적 칸 없음 → **모델 요청 수는 응답(`AIMessage`) 수로 셈**, `sum_usage`의 `requests`).
- **여럿 담기**: `create_agent`에는 `parallel_tool_calls` 인자가 없고 값을 보내지 않음(1431~1436·1474행, langchain-openai `base.py` 2427~2428행) → 운영·연체 질문 첫 응답에 요청 둘, 모델 요청 **2**(Ch 20 01은 3). 「모델 요청 수 = 도구 메시지 수 + 1」은 요청을 하나씩 받을 때만. 요청 둘을 한 단계에서 함께 실행하는지·단계 수는 **세지 않음**.
- 없는 주제어(`ValueError`)는 에이전트 그래프에서 **실행하지 않음** — `ToolNode`의 오류 처리 인자는 기본값(1089행), Ch 20 02 기본값 노드처럼 올라와 멈출 것으로 보임(b7).
