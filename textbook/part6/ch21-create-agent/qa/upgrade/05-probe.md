### 0-2. 흔들림 확인 입력(노트북과 같은 코드)

- 모델 `init_chat_model("openai:gpt-5.4-mini", temperature=0, reasoning_effort="none")` 객체(01~04와 같음).
- 검색 도구(설계로 정함):
  ```python
  @tool
  def search_documents(query: str):
      """교육센터 자료실 안내 문서 열두 건에서 검색어와 가까운 문서 세 건을 찾습니다. query에는 찾을 내용을 짧은 검색어로 넣습니다."""
      hit_list = search_hits(embedding_model, query, doc_vectors, doc_ids, top_count)
      found_text = ""
      for hit in hit_list:
          doc_id = hit["doc_id"]
          found_text = found_text + "[" + doc_id + "] " + text_by_doc[doc_id] + "\n"
      return found_text
  ```
  (도구 메시지 = Ch 14 `build_answer_prompt` 자료 줄과 같은 「[문서 ID] 글」 세 줄. 거리는 넣지 않음 — 소수 둘째 자리 흔들림이 도구 메시지 글에 들어가지 않게.)
- 시스템 메시지 글(첫 문장은 01 글과 같음): 「교육센터 자료실 안내 도우미입니다. 자료실 이용을 묻는 질문에는 search_documents 도구로 찾은 문서 글에 근거해 답하세요. 찾은 문서에 답이 없으면 검색어를 바꿔 한 번만 더 검색하고, 그래도 없으면 문서에서 찾지 못했다고 답하세요.」 — 「한 번만 더」는 **모델에게 적은 글이고 코드 제한이 아님**(그래프에 검색 수를 세거나 막는 줄이 없음).
- 에이전트: `create_agent(model, tools=[search_documents], system_prompt=system_text)`(01 모양, 도구 하나).
- 설정 둘(바꾼 값은 질문 하나):
  - **S5** Ch 14 질문 파일의 `C05` 「토요일 자료실 폐관 시각은?」(정답 문서 ID `FAC-003`, Ch 14 기준선 첫 자리 `FAC-003`) — 노트북 7절.
  - **SP** 「자료실 주차 요금은 얼마인가요?」 — 문서 열두 건에 주차 이야기가 없는 질문(값 바꿔 보기). 노트북 8절.
- 프로세스마다 한 번: 문서 임베딩(요청 1) + 질문 글을 그대로 검색(요청 1, 검색어가 아닌 질문 글의 거리 순위 기록).

회차마다 기록: 메시지 종류 차례 · 응답마다 도구 호출 요청 이름과 인자(검색어) · 도구 메시지마다 결과 상태와 문서 ID 차례(줄 머리 `[…]`) · 요청 id 목록 == 호출 ID 목록 · 응답 수 · 도구 메시지 수 · **같은 검색어 다시 부르기**(도구 호출 요청을 `search_documents.invoke(요청)`으로 다시 보내 도구 메시지 글과 같은지 — Ch 19 05절 모양, 요청마다 임베딩 1번) · 응답마다 사용량(입력·출력·캐시 입력) · 모델 이름 · 마지막 응답 글 · 오류.
