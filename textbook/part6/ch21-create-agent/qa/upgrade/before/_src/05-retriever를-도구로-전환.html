1학습 목표

  • 검색 함수를 @tool로 제공하는 방법을 적용할 수 있습니다.
  • 실제 tool_calls와 검색 로그로 모델의 검색 선택을 확인할 수 있습니다.
  • 검색 결과가 없을 때 재검색 횟수와 답변 범위를 제한할 수 있습니다.

2이 내용을 배우는 이유

항상 한 번 검색하던 RAG에서 모델이 검색과 재검색 여부를 선택하게 하려면 무엇이 필요한가?

고정 RAG는 모든 질문에 같은 검색 단계를 실행합니다. retriever를 도구로 노출하면 모델이 검색 필요 여부와 검색어를 정할 수 있고, 결과가 없을 때 한 번 더 찾아볼 수 있습니다.

3앞에서 배운 내용

Part4의 검색 파이프라인과 Ch19의 @tool를 사용합니다. 필요한 자료와 객체는 노트북에서 다시 선언하므로 앞 노트북의 메모리 상태는 필요하지 않습니다.

4핵심 개념

정의와 구체 예

Agentic RAG는 검색 증강 생성의 검색 단계를 에이전트 도구로 제공합니다. search_rules는 읽기 전용 규정 자료를 조회하고 검색어를 SEARCH_LOG에 남깁니다. system_prompt는 규정 질문에서 검색하고 결과가 없으면 다른 검색어로 한 번 재검색하며 근거를 만들지 말라고 제한합니다.

코드를 읽는 순서

리트리버(retriever)는 질문을 받아 관련 문서를 반환하는 검색 인터페이스입니다. 이것을 도구로 등록하면 검색 시점과 검색어를 모델이 선택합니다. search_rules(query: str) -> str에서 query는 모델이 만든 검색 문자열이고, 함수는 DOCS를 읽어 관련 문장을 줄바꿈 문자열로 반환합니다. SEARCH_LOG.append(query)는 검색 품질을 높이는 기능이 아니라 이번 실행에서 모델이 어떤 검색어를 선택했는지 관찰하는 기록입니다.

고정 RAG는 애플리케이션 코드가 매 질문마다 정해진 검색을 먼저 실행합니다. Agentic RAG는 모델이 검색할지, 어떤 말로 검색할지, 결과가 없을 때 다시 검색할지를 정합니다. create_agent(..., [search_rules])는 이 선택권을 제공하지만 검색 결과의 정확성까지 보장하지 않습니다. 도구의 설명과 반환 형식이 모호하면 모델이 적절한 검색어를 만들어도 근거를 잘못 읽을 수 있습니다.

5실행 예제

준비 셀에서 Python 3.12와 고정 패키지를 확인한 뒤, 데이터·함수·객체 생성·invoke·관찰을 짧은 셀로 나누어 실행합니다. 각 코드 셀의 첫 주석은 그 셀에서 확인할 행동을 설명합니다.

확인할 점 — 예약 도서 질문은 검색 도구를 호출했고 최종 답에 보관 기간 3일이 포함됐습니다. 주차 요금 질문은 주차 규정이 없음을 설명했으며 SEARCH_LOG에는 첫 검색과 다른 표현의 재검색이 남았습니다. 이 경로는 키워드 if문이 아니라 실제 모델의 tool_calls로 결정됐습니다.

다른 상황과 적용 경계

상품 지원 시스템에서는 주문 번호가 있는 질문만 주문 도구를 호출하고 일반 안내는 검색 없이 답하게 할 수 있습니다. 반면 모든 질문이 같은 사내 문서 한 묶음에서 답을 찾아야 한다면 고정 검색이 실행 횟수와 재현성을 관리하기 쉽습니다. 모델 선택이 필요한 경우와 애플리케이션 규칙으로 충분한 경우를 구분합니다.

검색 로그가 두 줄이면 재검색했다는 사실은 알 수 있지만 두 번째 검색어가 더 좋았다는 결론은 문서와 답을 함께 읽어야 합니다. 결과 없음 답변도 성공한 거부인지 검색어 실패인지 구분해야 하므로, 이 셀은 검색어와 최종 답을 함께 출력합니다.

6실험 결과 해석

예약 도서 질문은 검색 도구를 호출했고 최종 답에 보관 기간 3일이 포함됐습니다. 주차 요금 질문은 주차 규정이 없음을 설명했으며 SEARCH_LOG에는 첫 검색과 다른 표현의 재검색이 남았습니다. 이 경로는 키워드 if문이 아니라 실제 모델의 tool_calls로 결정됐습니다.

재검색을 허용하면 recall이 좋아질 가능성이 있지만 호출 수와 지연도 늘 수 있습니다. 반복 상한과 근거 없음 응답을 함께 두어야 합니다.

7주의할 점과 실무 메모

  • 재검색을 허용하면 recall이 좋아질 가능성이 있지만 호출 수와 지연도 늘 수 있습니다. 반복 상한과 근거 없음 응답을 함께 두어야 합니다.
  • 실제 모델 호출 비용은 절당 1달러 미만으로 예상하며, API 키 값은 출력하지 않습니다.
  • 재실행하면 모델 문장과 지연이 달라질 수 있으므로 저장된 원문 출력과 조건을 함께 읽습니다.
