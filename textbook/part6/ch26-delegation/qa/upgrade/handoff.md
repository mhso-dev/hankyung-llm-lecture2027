### 01이 푼 문장 (뒤 절은 되풀이하지 말고 「01절에서 본 것처럼」으로)

- 서브에이전트 = 중앙 에이전트가 도구로 감싸 불러 쓰며 일 하나를 맡기는 전문 에이전트(공식 문서 subagent 뜻) · 도구 함수 안 `invoke`는 **넘긴 글 한 줄로 시작한 새 목록**으로 일함(안쪽 목록 두 줄 — 도구 없는 전문 에이전트) · 바깥 목록에는 전문 에이전트의 응답 객체가 없고 **마지막 답 글만 도구 메시지 내용**으로 들어감(`True`) · 에이전트는 시스템 메시지 글을 메시지 칸에 담지 않음(두 목록 시스템 메시지 0 — Ch 21 01에서 본 것) · 바깥 목록에 붙인 앞 차례 기록은 안쪽 목록에 넘어가지 않음(`False`) · Ch 8 03 나누기(Isolate) = 이 모양, Ch 22 08 컨텍스트 분리 = 같은 생각(01 b3 한 문장).
- 요청 수: Ch 19 `sum_usage`는 **목록 안의 `AIMessage`를 모두 요청 하나로 셈** → ① 바깥 목록만 세면 전문 에이전트 요청이 빠짐 ② 손으로 적은 `AIMessage`(사용량 `None`)도 요청으로 세다가 멈춤(노트북 밖 확인) → **이번 실행이 더한 바깥 메시지(`결과 목록[넣은 메시지 수:]`) + 안쪽 목록**을 셈(01 `usage_with_specialists`). 셈: **중앙 = 도구를 요청한 응답 수 + 1 · 전문 = 부른 횟수 × 전문 안 요청 수(도구 없으면 1)** → 한 번 맡기면 **중앙 2 + 전문 1 = 3**(한 응답에서 두 번 맡기면 2 + 2, 응답 둘에서 한 번씩이면 3 + 2).
- `create_agent` 그래프의 기본 실행 한도 **9999**(출력 `supervisor.config["recursion_limit"]` · 설치판 `agents/factory.py` 1829~1831행) → `invoke(입력, {"recursion_limit": 10})`이 덮어씀(설치판 `_internal/_config.py` `ensure_config`는 뒤 설정이 이김 — 소스 확인). 도구 없는 에이전트 노드 `['__start__', 'model', '__end__']`, 도구가 있으면 `tools`가 더해짐.
- 한 응답의 도구 요청 여럿은 도구 실행 노드가 함께 실행(설치판 `prebuilt/tool_node.py` 821~824행) · 공식 문서도 한 차례에 서브에이전트 여럿 — **01은 실행하지 않음**.
