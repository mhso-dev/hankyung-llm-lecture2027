# Ch27 DeepAgents Harness 실습

이 폴더에는 Ch27의 8개 절을 각각 독립적으로 실행하는 Jupyter Notebook이 있습니다. 모든 노트북은 Python 3.12와 `deepagents==0.7.0`, `langchain==1.4.0`을 기준으로 작성했습니다. 앞 절에서 만든 변수나 파일이 없어도 첫 셀부터 실행할 수 있습니다.

## 실행 환경 준비

프로젝트 루트에서 다음 명령으로 고정된 의존성을 설치합니다.

```bash
uv sync --locked --project labs/part6/ch27-deepagents --python 3.12
```

Jupyter에서 `labs/part6/ch27-deepagents/.venv/bin/python`을 사용하는 새 Python 3.12 커널을 선택합니다. 각 노트북의 설치 셀에는 같은 기준 버전의 `%pip install` 명령이 있으므로, 새 커널에서 맨 위 셀부터 순서대로 실행합니다.

모델을 호출하는 절에는 `OPENAI_API_KEY`가 필요합니다. 노트북은 `find_dotenv(usecwd=True)`로 현재 작업 폴더부터 상위 폴더까지 `.env`를 찾습니다. 키의 존재 여부만 검사하며 키 값은 출력하거나 노트북에 저장하지 않습니다. 프로젝트 루트의 `.env`에 다음 이름으로 설정합니다.

```dotenv
OPENAI_API_KEY=발급받은_키
```

04·05·07·08절은 실행 중 다음 새 폴더를 자동으로 만듭니다. 각 폴더는 프로젝트 루트를 기준으로 한 상대 경로이므로 다른 컴퓨터에서도 같은 구조로 생성됩니다.

- `labs/part6/ch27-deepagents/workspace/`
- `labs/part6/ch27-deepagents/workspace-05/`
- `labs/part6/ch27-deepagents/workspace-08/`

## 절별 기능과 실행 범위

| 절 | 확인하는 기능 | 실행 범위 |
|---|---|---|
| 01 하네스와 일곱 기능 | 파일시스템, 서브에이전트, 컨텍스트 요약, 스킬, 장기 메모리, 파일 권한과 사람 승인, 비동기 서브에이전트의 조립 경로 | 설치된 0.7.0 소스를 읽는 로컬 검사입니다. 모델 API를 호출하지 않습니다. |
| 02 `create_deep_agent`와 도구 | 실제 에이전트가 `course_lookup` 도구를 선택하고 결과를 읽는 메시지 흐름 | 고정 자료 도구는 모의 데이터이며, 도구 선택과 최종 응답은 OpenAI 모델 API의 실제 실행입니다. |
| 03 플래닝과 시스템 프롬프트 | `TodoListMiddleware`를 명시적으로 추가한 뒤 `write_todos` 상태가 완료되는 과정 | 계획 도구 호출은 실제 모델 API 실행입니다. 65% 값은 릴리스 PR에 제시된 두 수치를 다시 계산한 결과이며 이 노트북의 토큰 절감률이 아닙니다. |
| 04 파일시스템과 중간 결과 | `FilesystemBackend`의 가상 경로 쓰기·읽기·목록 조회 | 로컬 파일시스템의 실제 입출력입니다. 모델 API를 호출하지 않습니다. |
| 05 컨텍스트 관리와 오프로딩 | 큰 도구 결과가 `large_tool_results` 파일로 이동하고 미리보기만 메시지에 남는 과정 | `large_result` 내용은 의도적으로 만든 모의 자료이며, 도구 선택·오프로딩·최종 응답은 실제 에이전트 실행입니다. |
| 06 서브에이전트 위임 | 부모가 `task` 도구로 `source-reviewer`를 호출하고 최종 보고를 받는 과정 | `source_lookup`은 검증 범위를 고정한 모의 자료입니다. 부모와 자식 에이전트의 모델 호출은 실제 API 실행입니다. |
| 07 출처 검증형 deep research | 제공된 두 자료를 자식 에이전트가 확인하고 근거·한계·출처 ID를 파일로 저장하는 과정 | 실제 부모·자식 모델 호출을 사용하지만 공개 웹을 탐색하지 않습니다. 교재가 미리 검증해 제공한 자료 범위만 조사합니다. |
| 08 통합 실행과 운영 한계 | 허용 경로 보고서 작성, 차단 경로 쓰기 거부, 종료 상태 확인 | 파일 권한 규칙과 에이전트 호출을 실제로 실행합니다. 외부 시스템의 권한 정책까지 검증한 결과는 아닙니다. |

## 생성되는 파일과 데이터

노트북은 다음 실행 결과를 남깁니다.

- `workspace/research/source-a.md`: 04절이 직접 작성한 중간 자료입니다.
- `workspace/research/final.md`: 07절 조사 에이전트가 작성한 근거·한계·출처 ID 보고서입니다.
- `workspace-05/large_tool_results/<tool-call-id>`: 05절에서 메시지 한도를 넘은 큰 도구 결과의 원문입니다. 파일명은 호출할 때마다 달라질 수 있습니다.
- `workspace-08/run/report.md`: 08절에서 허용된 쓰기 결과입니다.
- `workspace-08/blocked.txt`: 권한 규칙이 쓰기를 거부하므로 생성되지 않아야 합니다.

07절의 조사 자료는 노트북 코드에 포함된 짧은 고정 자료입니다. 별도 데이터 파일을 내려받지 않습니다. `workspace*` 폴더는 실행 중 생기는 결과이므로 공개 파일 목록에는 포함하지 않습니다.

## 모델 사용량을 읽는 범위

최종 `AIMessage.usage_metadata`는 그 메시지를 생성한 모델 호출의 입력·출력 토큰을 나타냅니다. 부모 에이전트의 마지막 메시지에 표시된 값은 자식 에이전트가 내부에서 사용한 토큰을 자동으로 합산하지 않습니다. 특히 06·07절의 총사용량을 구하려면 부모와 각 자식의 모델 실행 구간을 추적하고 모든 사용량을 합해야 합니다.

07절의 최근 새 커널 실행에서 마지막 부모 메시지는 입력 2,379토큰, 출력 34토큰, 합계 2,413토큰을 기록했습니다. 이는 해당 실행의 부모 마지막 호출 범위이며 전체 조사 실행 비용을 뜻하지 않습니다. 모델 가격은 바뀔 수 있으므로 운영 비용은 실행 시점의 공식 가격과 전체 추적 기록으로 다시 계산합니다. 이 장의 예제는 절당 1달러 미만을 목표로 입력 크기와 반복 횟수를 제한했습니다.
