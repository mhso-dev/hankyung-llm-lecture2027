## 진단 요약

- 장르: 산문. 최소 심각도 S1로 전문을 정독했습니다.
- 1차 AI 슬롭 검토에서 확인한 일반화된 학습 목표·확인 문구·복습 문제를 해당 실습의 사건 수, 상태 비교, 측정 경계에 맞게 바꿨습니다.
- 2차 맞춤법 단계는 상업적 대량 검토 제한 때문에 `nara-speller.co.kr` 외부 전송을 하지 않았습니다. 로컬 맞춤법·용어 검토로 대체했습니다.
- 3차 `korean-humanize` Phase 6 대조에서 수치·API 용어·인용·문서 경로·코드 참조가 보존되었고, 과도한 격식화나 구어 종결 전환이 없음을 확인했습니다.

## 수정 텍스트 범위

- 01은 로컬 그래프이고 API 호출이 없다는 점, 체크포인터와 복수 모드 출력의 의미를 분명히 했습니다.
- 02는 messages 사건 88개와 내용 조각 84개, 이어 붙인 답변과 최종 상태의 일치를 설명했습니다.
- 03은 client 관찰 TTFT 근삿값과 first_event·total의 차이, 세 별도 호출의 usage·가격 합계를 분명히 했습니다.
- 세 절의 복습 문제는 실제 코드의 assert, 상태, 출력, 비용 계산을 묻도록 바꿨습니다. Ch25-02의 모델 응답 생성 도식은 보라색으로 바로잡았습니다.
