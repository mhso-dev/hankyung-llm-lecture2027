1학습 목표

  • 조사 역할을 서브에이전트로 분리할 때 전달되는 입력과 반환 결과를 확인합니다.
  • 실행 출력에서 서브에이전트 위임의 구성과 결과를 구분할 수 있습니다.
  • 이 실험이 확인한 범위를 설명할 수 있습니다.

2이 내용을 배우는 이유

부모가 원문 조회와 세부 검증을 모두 수행하면 도구 출력이 부모 문맥에 쌓입니다. source-reviewer에 한 자료의 확인을 맡기면 부모는 task의 최종 보고를 받아 요약에 집중할 수 있습니다. 위임 여부는 task ToolMessage로 확인합니다.

3앞에서 배운 내용

Ch 26에서 서브에이전트의 완료 조건을 적었습니다. 이번 완료 조건은 release ID를 source_lookup으로 조회하고 지원되는 주장 하나를 반환하는 것입니다. 웹 검색 전체가 아니라 제공 자료 한 건에 대한 검증입니다.

노트북은 앞 절 변수에 의존하지 않으며 Python 3.12, deepagents==0.7.0, langchain==1.4.0을 설치하고 상위 폴더의 .env를 찾습니다.

4핵심 개념

정의와 구체적인 상황

서브에이전트는 별도 메시지 문맥에서 조사하고 최종 보고만 부모에게 반환합니다. 상세한 도구 출력이 부모 문맥을 채우는 일을 줄일 수 있지만, 호출 비용과 조정 시간이 추가됩니다. 부모와 선언형 서브에이전트가 같은 백엔드를 사용하면 파일 경로를 중간 결과의 인계 지점으로 쓸 수 있습니다. 완료 조건은 ‘조사하기’가 아니라 ‘URL·핵심 주장·한계를 파일에 기록하기’처럼 확인 가능하게 적습니다.

6실험 결과 해석

부모 호출 목록에는 task가 있었고 위임 반환에는 release 자료와 planning opt-in 주장이 포함됐습니다. 부모 메시지에서 source_lookup 호출 자체가 보이지 않는 것은 문맥 격리의 결과입니다. 한 번의 반환만으로 누락률이나 잘못된 위임률은 알 수 없습니다.

7주의할 점과 실무 메모

  • deepagents의 최신 문서는 이후 버전의 기능을 포함할 수 있으므로 이 장은 설치된 0.7.0 소스와 릴리스 노트를 함께 확인합니다.
  • 파일 도구의 루트와 권한을 지정하지 않은 채 사용자 입력을 경로로 사용하지 않습니다. 특히 0.7의 delete와 기존 파일을 교체하는 write_file을 구분합니다.
  • API 호출 절의 예산은 입력 10만 토큰·출력 1만 토큰 이하를 가정하면 2026-09-11 공개 단가 기준 약 0.12달러로, 절당 1달러 미만입니다. 실제 비용은 전체 서브에이전트 사용량과 최신 가격표로 다시 계산합니다.

재현 기록에는 실행 날짜, 패키지 잠금, 모델 이름, 입력, 생성 파일 경로를 함께 적습니다. 모델이 같은 도구를 선택하지 않을 수 있으므로 저장된 출력은 한 번의 관찰입니다. 배포 전에는 정상 입력뿐 아니라 도구가 선택되지 않은 경우, 권한이 거부된 경우, 결과 파일이 빠진 경우도 반복해서 확인합니다.

  • 부모 호출 목록에는 task가 있었고 위임 반환에는 release 자료와 planning opt-in 주장이 포함됐습니다.
  • 버전과 측정 범위를 실행 기록에 함께 남깁니다.
