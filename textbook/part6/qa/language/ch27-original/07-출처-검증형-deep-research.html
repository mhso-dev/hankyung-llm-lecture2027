1학습 목표

  • 제공한 공식 자료만 조회하는 도구를 가진 조사 에이전트를 실행하고 근거 파일을 남깁니다.
  • 실행 출력에서 출처 검증형 deep research의 구성과 결과를 구분할 수 있습니다.
  • 이 실험이 확인한 범위를 설명할 수 있습니다.

2이 내용을 배우는 이유

deep research라는 이름만 붙여도 출처가 자동으로 검증되지는 않습니다. 조사 도구가 어떤 자료를 반환하는지, 서브에이전트가 어떤 범위에서 결론을 내리는지, 최종 파일에 식별자가 남는지를 설계해야 합니다.

3앞에서 배운 내용

앞 절은 release 한 건을 위임했습니다. 이번에는 overview와 release 두 제공 자료를 조회하고 부모가 /research/final.md를 작성합니다. FilesystemBackend는 부모와 서브에이전트가 같은 경로를 인계 지점으로 쓰게 합니다.

노트북은 앞 절 변수에 의존하지 않으며 Python 3.12, deepagents==0.7.0, langchain==1.4.0을 설치하고 상위 폴더의 .env를 찾습니다.

4핵심 개념

정의와 구체적인 상황

이 실습의 deep research는 웹 전체를 자율 탐색하지 않습니다. 교재가 미리 검증해 제공한 Deep Agents 공식 문서와 0.7.0 릴리스 자료를 source_lookup 도구로 조회합니다. 따라서 실행 결과는 제공 자료에 대한 출처 검증형 조사입니다. 검색 누락, 상충 자료 탐색, 웹페이지 변경 감지는 포함하지 않으며 실제 서비스에서는 검색 도구와 URL 허용 정책을 별도로 설계해야 합니다.

6실험 결과 해석

실제 실행은 final.md에 하네스 정의, 0.7 opt-in과 빈 프롬프트, 65% 측정 범위를 기록했습니다. Scope limits에는 짧은 제공 자료만 확인했고 다른 웹 자료는 찾지 않았다고 명시했습니다. 저장된 실행의 부모 마지막 응답은 입력 2,367·출력 6토큰이었지만 서브에이전트 전체 사용량 합계는 아닙니다.

7주의할 점과 실무 메모

  • deepagents의 최신 문서는 이후 버전의 기능을 포함할 수 있으므로 이 장은 설치된 0.7.0 소스와 릴리스 노트를 함께 확인합니다.
  • 파일 도구의 루트와 권한을 지정하지 않은 채 사용자 입력을 경로로 사용하지 않습니다. 특히 0.7의 delete와 기존 파일을 교체하는 write_file을 구분합니다.
  • API 호출 절의 예산은 입력 10만 토큰·출력 1만 토큰 이하를 가정하면 2026-09-11 공개 단가 기준 약 0.12달러로, 절당 1달러 미만입니다. 실제 비용은 전체 서브에이전트 사용량과 최신 가격표로 다시 계산합니다.

재현 기록에는 실행 날짜, 패키지 잠금, 모델 이름, 입력, 생성 파일 경로를 함께 적습니다. 모델이 같은 도구를 선택하지 않을 수 있으므로 저장된 출력은 한 번의 관찰입니다. 배포 전에는 정상 입력뿐 아니라 도구가 선택되지 않은 경우, 권한이 거부된 경우, 결과 파일이 빠진 경우도 반복해서 확인합니다.

8정리와 다음 절

  • 제공한 공식 자료만 조회하는 도구를 가진 조사 에이전트를 실행하고 근거 파일을 남깁니다.
  • 실제 실행은 final.
  • 버전과 측정 범위를 실행 기록에 함께 남깁니다.

다음 학습과 이어지는 지점 — 마지막 절에서는 새 작업 폴더에서 허용 쓰기와 거부 쓰기를 함께 실행해 운영 경계와 종료 결과를 확인합니다.

9복습 문제

문제 1

이 실습을 웹 전체 deep research라고 부를 수 없는 이유는 무엇인가요?

해설 source_lookup이 미리 제공한 overview와 release 두 자료만 반환하기 때문입니다.

문제 2

final.md의 Scope limits가 필요한 이유는 무엇인가요?

해설 확인하지 않은 자료와 결론의 적용 범위를 독자가 구분할 수 있게 합니다.

문제 3

부모 마지막 응답의 토큰을 전체 실행 비용에 바로 쓸 수 있나요?

해설 아닙니다. 서브에이전트 호출 전체 합계가 포함됐는지 별도로 측정해야 합니다.
