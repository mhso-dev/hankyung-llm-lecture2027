# Part 6 통합 기술 검토

## 초안에서 발견한 내용과 보완 요청

2026-09-11. 작성 담당자와 구분되는 통합 담당자가 실행된 노트북의 실제 코드와 출력을 읽고 아래 항목을 지적했습니다. 이 기록의 지적은 해결 여부를 확인하기 전까지 통과로 간주하지 않습니다.

| 대상 | 초안의 문제 | 요청한 보완 |
| --- | --- | --- |
| 전체 챕터 | 한국어 코드 주석이 없고 여러 학습 행동을 3–5개 셀에 묶음. 일부 설치 셀·타입 힌트·단언문 누락 | 모든 코드 셀에 목적과 처리 의미를 설명하고 한 행동씩 나눔. 고정 버전 설치와 독립 새 커널 재실행 |
| Ch21 06 | 앞 RAG 자료와 연결되지 않은 세 규정만 사용. 최종 문자열 포함 여부만 남기고 답변·토큰·호출 기록 누락 | 앞 챕터 자료와 동일 질문·기준을 연결하고 양쪽 원문 답변·전체 사용량·호출 수·지연 수집 |
| Ch26 04 | 고정된 일곱 호출에 세 구조의 이름을 붙임. 분류 응답이 분기에 쓰이지 않으며 종료 조건은 문자열로만 출력 | 실제 Subagent·Handoff·Router를 동일 과제로 실행하고 분기·상태·종료와 측정 기록 연결 |
| Ch26 비용 | 다른 챕터와 다른 모델 단가 사용 | 공식 가격·확인 날짜·캐시 적용 범위 확인 후 동일 기준으로 기록 |
| Ch27 02·03·05·06 | signature·소스 문자열·설정 딕셔너리 조회가 기능 실습을 대신함 | 도구 에이전트 호출, 플래닝 opt-in, 큰 결과 처리, 서브에이전트 위임을 실제 실행 |
| Ch27 08 | 이전 절 파일에 의존하고 파일이 없어도 정상 마무리 | 새 커널·새 폴더에서 통합 작업을 실행하고 실제 종료·권한 조건 확인 |
| Ch27 환경 | `.env` 상위 탐색 없음, 개인 절대 경로 출력, 설치·주석·검증 누락 | 공통 작성 규격을 적용하고 새 커널에서 다시 검증 |
| Ch28 05 | 경고 출력에 임시 개인 환경 경로 포함, 직접/MCP 도구 정의의 차이 설명 필요 | 확인된 특정 beta 경고만 처리하고 beta 범위를 본문에 설명. 도구 수 외에 바뀐 조건과 해석 한계 명시 |

검증 도구가 통과해도 기능을 실제로 확인했다는 뜻은 아닙니다. 최종 검토는 학습 질문·입력·실제 연산·출력·해석의 연결을 확인하며, 해결 근거는 후속 검토와 챕터별 점검표에 기록합니다.
