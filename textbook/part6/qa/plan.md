튜터 리서치 → 독립 노트북 실행 → 개념 단위 집필 → 도식 → 빌드 → 기술·한국어 독립 검토 → 화면·복사·다운로드·묶음 검증 순서로 진행합니다. 정본은 `_src/`와 실행된 노트북이며 신규 챕터는 `_template/scaffold.py`로 생성합니다. 패키지와 공식 문서를 확인하여 커리큘럼의 미확인·과도한 표현은 실제 확인 범위로 설명합니다.

각 집필 담당자는 지정 챕터만 수정합니다. 통합 담당자는 공통 도구의 Part6 등록, 시작 화면, 실습 안내, 배포 묶음과 진행표를 관리합니다. API 키 값은 출력하지 않으며 기본 실행은 절당 예상 비용 1달러 미만으로 제한합니다. 제공된 자료의 분석과 실시간 외부 검색은 구분합니다.

완료 기준은 모든 발행 절의 새 커널 실행, HTML·노트북 코드 및 출력 일치, 10개 본문 블록과 복습 해설, SVG·Excalidraw 도식 일치, PC 1280px·모바일 390px 시각 검사, 로컬 링크와 ZIP 원본 해시 검증입니다. 학습 질문·실제 연산·해석이 같은 내용을 다루는지 별도로 정독합니다.

현재 Excalidraw MCP 도구가 없어 같은 요소에서 SVG와 편집용 JSON을 생성하고 브라우저로 검증합니다. 실행 흐름은 도식이 더 정확하므로 장식용 생성 삽화는 만들지 않습니다. 외부 맞춤법 서비스는 설치 스킬의 상업적 대량 처리 제한에 따라 사용하지 않고 독립 검토자가 로컬 맞춤법과 정밀 윤문·최종 의미 보존을 확인합니다. 미확인 사항은 최종 검증 기록에 남깁니다.
