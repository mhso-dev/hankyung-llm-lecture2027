## 확인 필요 항목과 관찰 범위

- MCP는 확인 가능한 공식 2025-11-25 사양을 기준으로 했습니다. 커리큘럼의 MCP 2026-07과 차이가 있어 해당 문서가 공개되면 개강 전에 재확인해야 합니다. 로컬 stdio를 실제 실행했으며 공개 원격 서버 배포나 조직 인증 운영까지 검증한 결과는 아닙니다.
- Ch21의 세 질문과 Ch29의 작은 기록 집합은 절차를 배우는 표본입니다. 재실행에서 LLM judge 판정이 달라졌고 현재 비교는 양쪽 3/3입니다. 이 값으로 구조의 일반적 품질 우열을 정하지 않습니다. Ch18과 Ch21의 품질 척도도 서로 다릅니다.
- Ch25의 세 모드는 같은 입력으로 각각 한 번씩 순서대로 호출했습니다. 첫 사건과 첫 답변 조각의 도착 시간을 구분하며, 결과를 모드 자체의 속도 차이로 해석하지 않습니다.
- Ch27의 65%는 공식 PR의 수치를 다시 계산한 값입니다. 이 실습에서 측정한 절감률이 아닙니다. 제공된 두 자료를 조사하며 공개 웹 전체를 탐색하지 않습니다. 부모 마지막 메시지의 사용량은 자식 호출을 포함한 전체 비용이 아닙니다.
- Ch23은 실제 로컬 PostgreSQL 17과 프로세스 종료·재개를 확인했습니다. async 저장의 복구 범위는 종료 시점에 따라 달라집니다. 작업용 PostgreSQL 컨테이너는 검증 후 정리했습니다.
