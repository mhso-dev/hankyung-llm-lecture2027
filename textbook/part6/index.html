실험 결과를 읽는 방법

질문·자료·모델·평가 기준을 고정한 뒤 바꾼 조건과 관찰한 결과를 비교합니다. 호출 수나 입력 토큰이 늘었다는 사실만으로 답변의 품질이 좋아졌다고 판단하지 않습니다. 복구 실험의 결과도 저장 방식과 중단 시점이 같은 범위에서 해석합니다.

모델의 문장·도구 선택·지연 시간은 다시 실행할 때 달라질 수 있습니다. 실제 API 호출 결과, 제공된 실행 기록, 원리를 확인하는 고정 예시를 구분합니다. 기본 실습에서 확인한 범위를 읽은 뒤 자신의 자료로 실험을 확대합니다.
