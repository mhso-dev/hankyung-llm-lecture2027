# Ch17 독립 기술·출처 검토

검토자: Part5 통합 담당(GPT-6, 작성 담당과 다른 모델). 노트북과 본문, 공개 원본 실행 기록을 대조했습니다.

01절은 도구 수가 아니라 다음 단계 결정 주체로 구조를 분류합니다. 02절의 적합 점수는 교육용 체크리스트이며 표준 진단 지표가 아닙니다. 합성 추가 호출 2회·시간 3.5초·비용 단위 3은 직접 모델을 측정한 값과 구분합니다. 03절은 기록된 사건에 정지 규칙을 적용하며 도구 에이전트를 실행했다고 설명하지 않습니다. 04절의 3/5단계·1170/2990ms·비용 단위 2/4는 고정 예시 계산과 일치하고 최종 품질이 없는 비교의 한계를 설명합니다.

05절의 SWE-agent와 mini-SWE-agent 원본을 커밋 고정 URL에서 다시 읽고 SHA-256과 MIT 라이선스를 확인했습니다. SWE-agent의 14개 행동과 10→11단계의 편집 오류 수정, 재현값 344→345가 원본과 맞습니다. mini-SWE-agent에는 명령 10개와 ZeroDivisionError 관찰이 있으며 마지막 기록만으로 완료를 확인하지 못합니다. 추출 자료는 이를 unconfirmed로 표시합니다. 자세한 근거는 ch17-source-evidence.json입니다. 공개 데모·테스트 자료 분석이며 현재 버전 제품을 새로 실행한 비교가 아닙니다.

독립 검토 중 코드 주석·타입 표시·결과 단언 누락과 도구 색상 오류를 지적했습니다. 작성자가 모든 코드 셀에 한국어 설명, 네 함수의 타입 표시, 각 노트북에 결과 단언을 추가하고 새 커널로 다시 실행했습니다. 총 25셀, 최대 17줄이며 03절 도구 실행·결과는 초록으로 맞췄습니다. 계산과 비교 조건을 바꾸지 않았습니다.

판정: 기술·출처 범위 **accept**. 별도 한국어 감사 이후 원본 해시·HTML·배포 파일 일치를 통합 검증합니다.


## 통합 마지막 수정

02절은 임계값을 바꾸는 반복문 안에서 출력하도록 수정해 3·4·5 결과를 모두 확인했습니다. 01절의 읽기 전용 인자는 `Mapping`, 03·04절의 사건 필드는 `TypedDict`로 표현해 숫자 합산과 입력 타입을 명시했습니다. 사례 목록의 타입과 파생 목록도 함께 맞추고 setup import를 정리했습니다. 의미 검토에서 분류 기준·정지 우선순위·계산값이 유지되는 것을 확인했습니다. 최종 실행·정적 진단 결과와 감사 후 해시는 별도 검토 기록 및 `final-manifest.json`에 연결합니다.

독립 code-reviewer의 최종 재검토 판정은 **APPROVE**, 남은 CRITICAL/HIGH/MEDIUM/LOW 모두 0건입니다. 노트북 5개 fresh-kernel PASS, 25셀·최대 17줄, 노트북 및 초안 생성기 Ruff PASS, 코드 셀 추출본·초안 생성기·빌드·도식 생성기 Pyright 오류/경고 0건을 확인했습니다. 고정 공개 원본의 SHA-256을 다시 대조했고 공식 궤적 문서에 기재된 SWE-agent v0.7.0 데모라는 설명도 확인했습니다. 최종 코드·출력 해시는 각 노트북 `metadata.verification`과 배포 파일에 포함됩니다.
