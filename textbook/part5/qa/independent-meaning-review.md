# Part 5 최종 의미·연결 검토

검토일: 2026-09-10. 검토자: 통합 담당 GPT-6. 장별 집필자와 별도로 본문을 읽고 코드·출력·도식과 대조했습니다. 장별 한국어 감사는 `language/`에 기록합니다. 이 기록은 학생 본문을 수정하는 후처리 단계가 아니라 최종본의 의미를 확인한 근거입니다.

## 진단 요약

Ch 18–20의 본문을 전문 정독하고 Ch 17의 앞선 본문과 최종 원문 대조를 확인했습니다. 목표·선수 지식·개념·실행·결과 해석·복습의 연결과 숫자·조건·가능성을 검토했습니다. 실측, 고정 예시 계산, 공개 기록 분석의 범위가 구분되며 관찰하지 못한 개선을 성공으로 표시하지 않습니다.

## 수정 텍스트

별도 전재본을 만들지 않습니다. 전달되는 확정본은 각 챕터 `_src/`와 실행 노트북을 빌드한 HTML입니다. 장별 감사의 승인 해시와 `final-manifest.json`이 검토 대상 파일을 식별합니다. 코드 셀·출력은 언어 감사에서 보호하며 기술 수정은 다시 실행하고 HTML에 반영합니다.

## 주요 변경사항

Ch 17은 고정 사건 목록에 정지 규칙을 적용하는 예제와 실제 에이전트 실행을 구별했습니다. 공개 궤적은 커밋과 원본 해시를 확인했고, 오류 수정 단계와 마지막 완료 확인 여부를 대조했습니다. 설명의 ‘제품 트레이스’는 현재 제품을 새로 실행했다는 의미로 확대하지 않았습니다. 임계값 3·4·5가 모두 출력되도록 반복문의 출력 위치를 수정하고 재실행했습니다. 마지막 타입 수정의 Case·TraceEvent·CostEvent와 Mapping은 이미 사용한 필드와 읽기 전용 인자를 명시하며 분류·정지 조건·합산값을 유지합니다. 최종 _src는 이 타입 수정 전후 동일하고 노트북 5개 재실행·정적 진단·HTML 대조를 통과했습니다.

Ch 18은 라우팅 절에도 모델 판단이 있다는 사실을 반영해 동적 워커 절의 ‘처음’ 표현을 수정했습니다. A·A·B 투표를 동률로 설명하지 않으며, strict 응답 검증 실패와 빈 답변을 혼동하지 않습니다. 다섯 패턴 비교의 지연 문제는 근거 없는 4배 비교를 제거했습니다. 채점의 단계 검사는 날짜 숫자를 단계 수로 세지 않습니다. 평가자 96점으로 첫 반복에서 종료한 실행과 미관찰 종료 분기를 구분했습니다.

Ch 19는 도구 설명 외 조건을 고정한 실험에서 두 설명 모두 9/9였음을 유지했습니다. 질문 3개를 3회씩 실행한 9개 응답으로 단위를 명확히 했습니다. 마지막 모델 호출의 입력 290·출력 36토큰과 전체 호출의 추정 비용을 구분했습니다. 두 도구 요청을 반환하는 모델 동작과 Python에서 순서대로 실행하는 구현을 구분합니다. 쓰기 통제는 모델 인자가 아닌 애플리케이션의 확인 상태와 주문 ID를 검사하며 실제 주문을 변경하지 않습니다.

Ch 20의 선수 지식은 Ch 18의 패턴 구현과 Ch 19의 도구 호출을 구분하도록 고쳤습니다. 동일 그래프에서 선택 노드만 바꾸는 비교인지 코드·도식을 함께 확인했습니다. 전체 그래프 지연과 실제 사용량을 출력과 대조했습니다. 도식은 조건부 종료·도구 결과·모델 재호출을 표시하며 반복 제한 예외를 정상 종료 뒤의 단계로 그리지 않습니다.

최종 판정: **accept**. 뜻을 바꾸는 잔여 지적은 없습니다. 외부 맞춤법 서비스 전송은 스킬의 상업적 대량 처리 제한으로 생략했으며 로컬 맞춤법·문맥·의미 검토로 보완했습니다. 기술 수정 후의 최종 파일과 확인 범위는 `verification.md`를 따릅니다.
