정본은 템플릿에서 생성한 `_src/`와 절별 노트북이다. 담당자는 챕터 폴더만 수정하고 통합 담당자는 공통 도구와 Part5 안내·배포·진행표를 관리한다. 원고와 실제 셀·출력을 대조하는 기술 검토, 작성자와 구분된 한국어 검토, 화면·복사·다운로드 대조 뒤에 발행한다.

완료 기준은 절별 새 커널 실행과 코드·출력·HTML 일치, 10개 본문 블록과 복습 해설, 도식 원본 쌍, 1280/390px 화면 검사, 내부 링크와 배포 파일 해시 검증이다. 실제 외부 서비스·제품 실행 기록과 교육용 재구성 기록은 구분한다. 공개 문서로 확인할 수 없는 제품 내부 판단을 추정하여 실측이라고 쓰지 않는다.

Ch18은 동적 작업 분해를 다루므로 Ch20을 모든 모델 판단의 최초라고 서술하지 않는다. Ch20에서는 모델이 요청한 도구 실행 결과를 모델에 다시 전달하는 ToolNode 그래프 루프를 처음 조립한다.

공통 도구 변경은 Ch18 경로에만 SDK 허용 예외를 추가한다. 정상 허용·프레임워크 거부·다른 경로 거부 회귀 검사에서 변경 전 실패와 변경 후 통과를 확인했다. 통합 전 공통 도구 원본은 `before-integration/`에 보존한다.

Excalidraw MCP 도구는 현재 목록에 없어 로컬 SVG와 편집 가능한 JSON을 같은 요소에서 생성한다. 처리 흐름은 도식이 더 정확하므로 생성형 삽화를 추가하지 않는다. 외부 맞춤법 전송은 해당 스킬의 상업적 대량 처리 금지에 따라 생략하고 별도 검토자가 로컬 맞춤법과 전문 윤문·의미 보존을 확인한다.
