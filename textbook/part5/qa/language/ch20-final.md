### 손대지 않은 자리

- 고정 `if` 분기와 모델 선택의 내용상 대조, Before/After 비교 구조는 학습 목표에 필요하므로 유지했습니다.
- 모델명, 패키지 버전, 토큰·비용·지연, 반복 횟수와 실제 출력 수치는 바꾸지 않았습니다.
- 언어 감사에서는 코드 셀과 출력을 수정하지 않았습니다. 이후 저자 보완에서 타입 주석과 필요한 import만 추가하고 API 사용 노트북 세 개를 다시 실행했으며, 아래 실측값은 그 최종 출력과 대조했습니다.
- 도식 캡션은 색상과 읽는 순서를 정확하게 설명하고 있어 문장을 고치지 않았습니다.
