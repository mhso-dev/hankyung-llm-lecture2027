실행 결과를 읽는 방법

호출 수가 늘면 추가로 얻은 결과가 그 비용과 지연에 비해 필요한지 확인합니다. 같은 과제와 평가 기준에서 실행한 결과를 비교하고, 한두 질문의 결과를 다른 업무 전체에 적용하지 않습니다. 설명문별 도구 선택률이 같거나 품질 차이가 나타나지 않았다면 관찰한 그대로 기록합니다.

공개 제품의 실행 기록, 원리를 설명하기 위해 만든 고정 예시, 직접 API를 호출해 얻은 출력은 출처가 다릅니다. 각 절에 적힌 자료 종류와 실행 범위를 확인합니다. 모델 출력과 처리 시간은 다시 실행할 때 달라질 수 있으며 API 호출에는 비용이 발생합니다.

각 노트북은 새 커널에서 실행합니다. 필요한 데이터와 앞 챕터의 자료는 제공 폴더 구조를 유지합니다. 파일과 개념의 연결은 묶음의 labs/part5/continuity-guide.md에서 확인합니다.
