- `02-1`: 맨 위 회색 테두리 칸 「양식 클래스 OrderQuery」 안에 파란 상자 둘이 나란히(왼쪽 상태 칸 status · 오른쪽 최대 개수 칸 limit). 두 상자에서 화살표가 가운데 회색 상자 `@tool / args_schema=OrderQuery / 도구 search_orders`로 모이고, 아래 노란 셋(왼쪽부터 입력 형식 `같은가 True` · 명세의 status 칸 `enum 세 글` · 명세의 limit 칸 `minimum 1 · maximum 10`)으로 나뉩니다. 첫 렌더에서 `direction LR`을 준 칸 안의 두 상자가 위아래로 쌓여(칸 밖으로 이어지면 방향이 무시됨) 칸의 방향 줄을 빼고 두 상자에서 따로 화살표를 그어 나란히 놓았고, 회색 상자 첫 줄이 저절로 꺾여 `<br>`로 세 줄에 나눴습니다.

## 라벨에 넣은 숫자 · 표기

- 라벨의 두 자리 넘는 숫자는 `10`(3·4절 출력 `'maximum': 10`)·`O101`·`O103`(4절 출력)·`01절`(본문)뿐이고, 한 자리 `0`·`1`·`2`는 모두 출력에 있는 값입니다(`받은 주문 수: 0`·`limit 1`·`최대 개수: 2`). 개수는 한글(「두 줄」·「세 글」·「칸 셋」).
