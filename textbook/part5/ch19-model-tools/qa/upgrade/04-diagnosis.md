## 3. 설계 — experiment (결정과 까닭)

- **실험 변수 = 도구 설명 하나.** 공개 이름을 두 판 모두 **`tool_a`(목록, 인자 `status`) · `tool_b`(한 건, `order_id`) · `tool_c`(합계, `status`)**로 가림(인계 5항 권고). 공개 이름은 **인자 있는 `@tool("tool_a")` 모양**으로 주고(02절 `@tool(args_schema=…)`와 같은 「괄호 안에 따로 준다」로 이어 한 문장), 설명은 03절처럼 독스트링에 적음. 짧은 판 = 03 짧은 판 독스트링 셋(03 생성기 `SHORT_*` 셀에 든 글과 문자열 대조 `assert`), 자세한 판 = `author_03.GOOD_*_DOC` 문자열 그대로(import). 함수 이름은 `short_list`·`detailed_list`처럼 판마다 다르게 지어 03의 「같은 이름 다시 정의」를 쓰지 않음. 노트북 4절 `이름 같음: True`·`입력 형식 같음: True`(세 도구), 5절 첫 명세에 함수 이름이 없음을 출력으로.
- **`@tool("이름", description=…)` 모양은 쓰지 않음** — 노트북 밖에서 `description=` 모양과 독스트링 모양의 `convert_to_openai_tool` 결과가 같음 `True`를 확인(`/tmp/ch19-04/check_forms.py`, 요청 없음)하고 b7에 한 문장.
- **질문 셋과 기대 도구(실행 전에 정함, 흔들림 확인 전에 적음)**: 「결제된(paid) 주문 목록을 보여 줘.」 → `tool_a` · 「O103 주문의 금액은 얼마야?」 → `tool_b` · 「결제된(paid) 주문은 모두 몇 건이야?」 → `tool_c`(03 자세한 판 합계 도구의 사용 조건 「주문 목록 대신 개수나 합계를 물을 때 씁니다」). 목록 도구를 골라도 프로그램이 줄 수를 세면 답할 수 있다는 것을 b4 「비교와 경계」·b7에 밝힘(「틀린 도구」라 쓰지 않고 「이 절이 정한 역할 나눔」).
- **흔들림 먼저 확인(`04-probe.md`)**: 실행 전에 적은 첫 입력 P(위 질문 셋 · 03 짧은 판 대 자세한 판)에서 조건마다 5번 — 건수 질문 **짧은 판 `tool_a` 5/5 · 자세한 판 `tool_c` 5/5**, 목록·한 건 질문은 두 판 5/5 같음. 값 바꿔 보기 후보 M(합계 도구 설명만 자세한 판)도 5번 — 건수 질문 `tool_c` 5/5. **대비가 서서 미리 적어 둔 후보 C1·C2는 보내지 않았습니다.**
- **반복 3번**은 노트북 안에서 미리 정한 값(`repeats = 3`, 값 고르기 아님). 채점 `count_expected` = 기록의 고른 도구 목록이 `[기대 도구]`와 같은가(이름만, 인자 안 봄, 도구 0개·2개 이상이면 맞지 않음으로 셈). 모델 답에 `assert` 0건.
- **`bind_tools` 첫 사용**: 「모델에게 도구를 알려 주는 메서드 → 도구마다 명세를 만들어 요청마다 함께 싣는 모델 객체를 새로 내놓음」 한 문장 + 비유(손님 자리에 메뉴판). 속성 `kwargs`(요청마다 덧붙일 값 딕셔너리)로 실을 명세를 보이고 `convert_to_openai_tool(short_list)`와 같음 `True` — 01 인계 「`bind_tools`도 도구마다 이 함수로 명세를 만든다 — 04가 확인할 몫」을 노트북 출력으로 참이 되게 함. `parallel_tool_calls=False` = 「한 응답에 도구 호출 요청을 하나까지만」(여럿은 05절).
- **도구 호출 목록(`tool_calls`)**: Ch 7 05 말 「도구 호출 목록」을 이어 쓰고, 목록의 딕셔너리 한 건을 새 말 **「도구 호출 요청」**(칸 `name`·`args`·`id`·`type`)으로. 「Ch 7 05절에서 도구를 알려 주지 않은 요청은 목록이 비어 있었다 → 이번에는 찬다」로 이음. 칸 `id`는 요청마다 달라 인용하지 않고 「05절에서 씁니다」. **도구는 실행하지 않음**(05 몫, 인계 확인) — 본문·노트북·그림(점선 회색 상자)에 밝힘.

- **처음 쓴 문법·API(각각 한 문장)**: `@tool("이름")` · `model.bind_tools(도구 목록, parallel_tool_calls=False)` · 속성 `.kwargs` · 응답 `.tool_calls`(Ch 7 05 이음)·`.content`의 길이 · 이중 `for`(질문 × 반복, Part 2 모양) · `[기대 도구]` 한 원소 목록과 목록 비교. 이어 쓴 것: `init_chat_model`·`usage_metadata`(Ch 6) · `estimate_cost`(Ch 6 06) · `convert_to_openai_tool`(01) · `range(len(목록))`(03).
