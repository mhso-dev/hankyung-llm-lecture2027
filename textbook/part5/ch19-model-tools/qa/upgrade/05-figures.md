## 라벨에 넣은 숫자 · 표기

- 숫자는 `1`·`2`·`3`·`0`(요청 차례·요청 수 — 출력 `도구 호출 요청 수: 2`·`'requests': 3` 등), `32000`·`27000`(도구 메시지·금액 줄), `515`·`84`·`771`·`71`(7절 출력), `O101`·`O103`(인자), 모델 이름 `5.4`뿐입니다. 개수는 한글(「둘」·「넷」)이고, 「2건」·「0건」은 출력 `도구 호출 요청 수:` 값입니다.
- 라벨 안 따옴표·대괄호는 쓰지 않았습니다. 인자 딕셔너리 `{'order_id': 'O101'}`는 `order_id O101`로, 사용량 딕셔너리는 `입력 토큰 515`처럼 적었습니다.
- 흔들린 값(3절 도구 호출 요청의 `id`)과 모델이 적은 답 글은 라벨에 넣지 않았습니다. 답 글은 코드로 센 표지(두 금액이 있는가)만 넣었습니다.
