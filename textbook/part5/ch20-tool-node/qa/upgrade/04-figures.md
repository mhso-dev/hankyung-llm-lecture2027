# 04절 그림 설계표 (규격 §5-2)

색 규칙(챕터 리드 결정·인계 「§03 → §04」 10번): 질문(첫 상태) 초록(tool) · 우리 코드가 요청을 만드는 요청 노드 파랑(flow) · **모델에 요청을 보내는 노드(답 노드·모델 노드) 보라(model)** — 이 절은 두 그래프 모두 실제로 모델을 부르므로 모델 요청이 나가는 자리를 보라로 표시(01-2의 연보라 띠와 같은 뜻) · 출력으로 확인한 값(흔적·요청 수·입력 토큰·도구 메시지) 노랑(measure) · LangGraph가 준 것(`ToolNode`·가상 시작점/끝점) 회색 · **experiment라 빨강 0**. 조건 함수 둘(`pick_by_rule`·`tools_condition`)은 상자로 그리지 않고 점선 갈래 라벨로만(규격 §5-3 Ch 13 03-1). 갈래는 점선, 되돌아가는 엣지는 실선, 나란한 결과 상자는 `~~~`, 라벨에 대괄호·따옴표 없음, 개수는 한글(출력 글자 그대로인 값만 숫자), 노드 id `call`·`end` 안 씀. 라벨의 값은 새 커널 두 번(A·B)에서 같았던 값만(달라진 출력 토큰·예상 비용 합·답 글은 넣지 않음). 초안은 흔들림 확인 값으로 먼저 렌더해 폭만 보았고, A·B 대조 뒤 라벨 숫자를 출력과 다시 대조했습니다.
