# Part 5 실습 시작하기

이 묶음은 Ch 17–20의 노트북과 실행에 필요한 공개 자료를 포함합니다. 교재 HTML은 코드를 읽고 복사하는 화면이며, 코드는 Jupyter 커널에서 실행합니다.

## 환경 준비

압축을 풀어 만든 `part5-practice` 폴더의 구조를 유지합니다. Ch 19 노트북은 `labs/part5/ch19-model-tools/data/orders.csv`를 읽습니다. Ch 4 원본과 비교할 수 있도록 `labs/part1/ch04-data-tools`도 함께 제공합니다. 필요한 파일을 찾는 방법은 각 노트북의 준비 셀에 있습니다.

Ch 1에서 준비한 uv와 Python 3.12를 사용합니다. 지금 학습할 챕터 폴더에서 `uv sync --locked`를 실행한 뒤, VS Code의 Python·Jupyter 확장에서 해당 챕터의 `.venv`를 커널로 선택합니다. 예를 들어 Ch 18의 폴더는 `labs/part5/ch18-workflow-patterns`입니다. `uv run python --version`으로 Python 3.12인지 확인합니다. JupyterLab을 쓰면 같은 폴더에서 `uv run --with jupyterlab==4.4.9 jupyter lab`으로 실행할 수 있습니다.

API 실습은 묶음 최상위의 `env.example`을 `.env`로 복사하고 `OPENAI_API_KEY=`의 등호 오른쪽에 자신의 키를 넣습니다. 노트북은 현재 작업 폴더부터 상위 폴더에서 `.env`를 찾습니다. 키 값은 코드·출력·질문에 붙여 넣지 않습니다. 제공 파일에는 실제 키가 들어 있지 않습니다.

## 학습 순서

Ch 17에서 모델에 맡길 판단을 정리합니다. Ch 18에서는 OpenAI SDK로 다섯 가지 패턴을 구현하고 같은 과제를 비교합니다. Ch 19에서는 조회 함수를 도구로 만들고 설명문과 선택 결과를 관찰합니다. Ch 20에서는 모델과 도구를 반복 연결하며 오류와 정지 조건을 확인합니다.

노트북마다 새 커널을 시작하고 준비 셀부터 순서대로 실행합니다. 설치 셀도 실행하고 완료될 때까지 기다립니다. 각 셀의 결과를 확인한 뒤 다음 셀로 이동합니다. 앞 절에서 만든 변수가 자동으로 이어진다고 가정하지 않습니다.

## 결과 비교와 문제 해결

같은 실험을 다시 실행해도 모델 문장·도구 선택·처리 시간은 달라질 수 있습니다. 실행 조건과 원문 출력을 함께 읽습니다. 고정 예시나 공개 자료를 분석한 결과는 직접 API를 호출해 측정한 결과와 구분합니다. 교재의 작은 표본이 자신의 프로젝트에서도 같은 결과를 보인다는 뜻은 아닙니다.

`NameError`는 준비 셀을 빠뜨렸는지 확인합니다. `ModuleNotFoundError`는 현재 챕터의 환경과 선택한 커널을 확인합니다. `FileNotFoundError`는 폴더 구조와 제공 파일을 확인합니다. 키 관련 오류가 나면 `.env`의 위치와 변수 이름을 확인하되 키 값은 출력하지 않습니다. 변수 상태를 확인하기 어렵다면 커널을 다시 시작하고 첫 셀부터 실행합니다.

API 셀을 다시 실행하면 비용이 발생합니다. 호출 횟수와 출력 길이를 제한한 기본 설정부터 실행하고, 반복 실험을 늘리기 전에 각 절의 비용 안내를 읽습니다. 학습용 조회 자료는 합성 자료이며 실제 고객 정보가 아닙니다.
