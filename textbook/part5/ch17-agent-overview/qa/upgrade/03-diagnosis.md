## 4. 설계 — experiment

**학습 질문**: 모델이 다음 행동을 고르는 반복은 무엇으로 이루어지고, 그 반복은 어떤 조건에서 누가 멈추게 할까요? 정지 조건 하나를 바꾸면 무엇이 달라질까요?

- **옛 학습 질문 유지**: 모델·도구·루프의 역할, 완료·최대 단계(→ 바퀴 한도)·사람 확인을 서로 다른 정지 이유로 기록. 「예산」은 Ch 16 호출 한도와의 관계로 b4에서만 다루고 정지 조건으로 구현하지 않았습니다(이 절은 바퀴마다 요청 한 번이라 바퀴 한도가 요청 수 상한을 겸함 — 한 바퀴에 요청이 여러 번이면 따로 두어야 한다고 적음).
- **도구 흉내 셋**(`run_tool`, `if` 셋 + 기본 글): 주문 조회 → 「주문 A-1024 · 무선 이어폰 · 배송 완료 · 받은 지 5일」 · 환불 규정 확인 → 「받은 지 7일 안의 상품은 환불할 수 있음」 · 환불 요청 등록 → 「환불 요청을 등록함」 · 그 밖 → 「목록에 없는 도구」. 이름은 02절 환불 기록과 같게. 환불 요청 등록은 부작용 도구로 `confirm_tools`에.
- **요청 글**: 머리글 네 줄(할 일 · `", ".join`으로 도구 이름 · 끝 고르기 · JSON 답 모양) + 문의 + 「지금까지 부른 도구와 결과」(도구 줄만, 없으면 「없음」). 함수 `build_request`·`ask_next`(요청 1번, 칸 「다음」만 내놓음).
- **정지 조건 넷**: `stop_reason(name, steps, confirm_tools)` — 끝 → 「모델이 끝을 고름」 · `confirm_tools`에 있음 → 「사람 확인」 · `count_steps(steps, "단계", name) > 0` → 「같은 도구를 다시 고름」(도구에 인자가 없어 같은 결과만 받으므로 이 절에서 정한 규칙) · 없으면 `""`. 넷째 **바퀴 한도**는 `run_loop`의 `for turn in range(turn_limit)`가 다 돌면 멈춤 줄 「바퀴 한도」. 멈춤 줄 `stop_line`의 칸 「고른 쪽」은 누가 멈추기로 정했는지(끝만 모델). `turn_lines`는 멈출 까닭이 없을 때만 도구를 부름 → 사람 확인에서 멈추면 등록 도구는 불리지 않음.
- **실행 넷**(바퀴 한도 4는 이 절에서 정한 값): 5절 한 번 고르기(받은 글 그대로 + `json.loads`) · 7절 도착 문의 · 8절 환불 문의 · 9절 값 바꿔 보기 1 바퀴 한도 2 · 10절 값 바꿔 보기 2 `confirm_tools = []`. 요약 함수 `print_summary`(모델 요청 수 = 한 쪽 모델 줄 수 · 도구 차례 `tool_names` · 멈춘 까닭 `steps[-1]` · 구조 `classify`).
- **`assert`**: 손으로 적은 기록 한 줄로 `stop_reason` 네 경우만(모델 글 0).
- **새 말 다섯**(meta 「새 용어 5」): 루프(loop) · 바퀴 · 정지 조건(stopping condition) · 바퀴 한도 · 사람 확인. 도구 흉내(「이 절에서 만든 도구 흉내」)는 이름표로만.
- **처음 쓴 모양(한 문장씩 풂)**: `!=`(Ch 16 07) · 목록에 `in`(Ch 15 02) · 반복문 안 `return`(Ch 16 05) · `join`(Ch 16 01) · `steps[-1]` · 모델 글 `json.loads`(Ch 15 02). 쓰지 않은 것: f-string·내포식·제너레이터·`lambda`·조건 표현식·`elif`·`any`·`sum`·`zip`·`enumerate`·`isinstance`·`+=`·기본값 매개변수·타입힌트·튜플 풀기·클래스·`while`.
- **노트북 차례**: 제목 → 오늘 볼 그림(`03-1`) → 1 준비(`%pip` 셋 · `json`·`init_chat_model`·도구 파일 셋) → 2 키와 모델 → 3 도구 흉내 셋 → 4 머리글·`build_request`·첫 요청 글 → 5 한 번 고르기(받은 글·`json.loads`·`ask_next`) → 6 정지 조건(`stop_reason`·손 확인·`stop_line`·`turn_lines`·`print_results`·모델 없는 두 바퀴) → 7 `run_loop`·도착 문의 → 8 환불 문의·`print_summary`·두 문의 표 → 9 값 바꿔 보기 바퀴 한도 2 → 10 값 바꿔 보기 사람 확인 빼기·02절 차례와 견줌 → 정리.
