## 칸 순서 확인 (PNG를 직접 열어 본 결과)

- `01-1`은 위 초록 기록 한 줄 → 파랑 세기 상자이고, 파랑 상자 오른쪽에 회색 상자(칸 「한 쪽」)가 나란히 놓였습니다. 파랑 상자에서 점선 둘이 나와 왼쪽 「없으면」 → 노랑 워크플로우, 오른쪽 「하나라도 있으면」 → 노랑 에이전트 후보입니다.
- `01-2`는 위에서 아래로 초록 사례 넷 → 파랑 `count_steps` → 파랑 `classify`, 거기서 점선 둘이 왼쪽 「없으면」 노랑 워크플로우 둘, 오른쪽 「있으면」 노랑 에이전트 후보 둘로 갑니다.
- `01-3`은 왼쪽 칸(도구 단계 둘을 더한 환불 절차: 초록 → 노랑), 오른쪽 칸(형식 검사 한 줄만 바꾼 요약 절차: 초록 → 노랑), 아래 가운데 회색 상자입니다.
- `01-4`는 위 초록 종류 이름 → 파랑 `pick_next_step`, 거기서 점선 셋이 왼쪽 노랑 환불 안내 찾기 · 가운데 회색 배송 조회 · 오른쪽 노랑 상담원 연결로 가고, 맨 아래 가운데 노랑 사례 5 결과 상자가 있습니다. 첫 렌더에서 결과 상자의 「모델이 고른 단계 없음 · 워크플로우」가 저절로 두 줄로 꺾여 「·」가 줄 끝에 남아, `<br>`로 「모델이 고른 단계 없음」 / 「구조 워크플로우」를 나눠 다시 렌더했습니다.
