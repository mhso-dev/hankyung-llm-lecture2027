## 3. 설계 — experiment

**학습 질문**: 쓰는 모델과 평가 모델에게 요청을 번갈아 보낼 때, 멈출지는 누가 무엇을 보고 정할까요? 평가 점수가 기준값을 넘은 초안도 셀 수 있는 조건을 어기면 어떻게 다음 바퀴로 보낼까요? (옛 학습 목표 「생성자와 평가자 분리」·「정지 조건을 코드로」·「어떤 조건으로 끝났는지 기록」을 이음)

- **평가를 둘로(챕터 리드 설계 방향)**: 평가 모델(0~100 정수 점수 + 고칠 점 한 문장) + 코드 검사 `check_length`·`check_draft`(글자 수 `len()`이 최소~최대 안인지 · 꼭 담을 말 넷이 글자 그대로 있는지). 옛 117자·100점 문제를 교재 내용으로 살림.
- **정지 판정 `decide_stop(rounds, threshold, turn_limit)`**: 마지막 바퀴 줄의 점수 ≥ 기준값 85 **이고** 코드 검사 문제 0 → 「기준 통과」 / 아니면 바퀴 줄 수 ≥ 바퀴 한도(3) → 「바퀴 한도」 / 아니면 「계속」. 세 갈래는 손으로 적은 바퀴 줄 넷으로 `assert`(`['기준 통과', '계속', '계속', '바퀴 한도']` — 둘째는 점수 95라도 문제 있음, 셋째는 문제 없어도 점수 70). 셋째 정지 조건(점수가 더 오르지 않음, 옛 「개선 폭」)은 **넣지 않음**(b4 「비교와 경계」 한 문장) — 코드 검사와 섞이면 「무엇이 나아지지 않았나」가 두 값이 되어 함수가 8줄을 넘고, 모델 답으로 실행되지 않을 갈래를 하나 더 두게 됨.
- **바퀴 줄(이 절 말)**: 한 바퀴 결과 딕셔너리 `{"초안", "글자 수", "점수", "고칠 점", "문제"}`, 목록 `rounds`. 기록 줄(01 모양 `{"단계", "입력 토큰", "출력 토큰"}`)과 따로 둠 — 기록 칸은 01 그대로(단계 이름 `쓰기`·`평가`), 새 칸 없음.
- **고칠 점 넘기기 `build_notes(rounds)`**: 다음 쓰기 요청 글 = 첫 쓰기 요청 글 + 「앞 초안 · 앞 초안 글자 수 · 평가 모델의 고칠 점 · 코드 검사의 문제(문제마다)」. 평가 요청은 과제·공통 사실·이번 초안만 받음(앞 바퀴 기록 없음 — 독립 평가).
- **흐름 함수**: `write_and_judge`(한 바퀴 = 쓰기 1 + 평가 1 + 코드 검사) · `finish_loop`(「기준 통과」면 상태 「완료」, 「바퀴 한도」면 「멈춤」, 마지막 초안은 칸 「안내문」) · `run_write_judge_loop`(`for turn in range(바퀴 한도)` + `break` — Ch 17 05 자리 찾기 셀의 `for`·`break`). 변수 `turn`은 쓰지 않는다고 결과 읽기에 한 문장.
- **누가 멈춤을 고르는가(Ch 17 01·03과 맞춤)**: 다음 바퀴/멈춤을 코드(`decide_stop`)가 고르고 두 모델은 초안·점수·고칠 점만 씀 → 칸 「고른 쪽」 모두 코드 → 워크플로우(b4·노트북 9절·복습 3). Ch 17 03 루프는 모델이 다음 도구를 고르고 끝을 고를 수도 있었다(그런 기록은 에이전트 후보)는 점이 다르다고 한 단락. Anthropic 글 「Workflow: Evaluator-optimizer」(WebFetch 확인).
- **Ch 16·15와 잇기**: b3에 Ch 16 04 「호출 한도」(예산의 요청 수 상한) ≠ 「바퀴 한도」 한 문장, Ch 15 02 평가 모델(judge) — 점수는 정답률이 아니라 모델이 매긴 값, 03절 투표의 평가자와 같은 뜻(지시 글만 다른 같은 모델).
- **공통 사실·과제**: 01~04와 같은 공통 사실(131자, `help@company.test`). 옛 「등록 절차 1)·2)·3)」은 빼고 「등록 방법」(공통 사실의 보안 메뉴). 과제 글 「전 직원에게 보낼 2단계 인증 안내문을 150~170자로 쓰세요. 적용 날짜, 대상, 등록 방법, 문의처 주소를 담습니다.」(§4 흔들림 확인으로 고름). 요청 글마다 「JSON」: 쓰기 머리글 「아래 과제에 맞는 안내문을 JSON으로 쓰세요.」 · 평가 머리글 「아래 과제와 공통 사실로 초안을 평가해 JSON으로 답하세요.」.
- **값 바꿔 보기(11절)**: 설정 `copy()` 뒤 칸 「바퀴 한도」만 3 → 1(예상 먼저: 첫 바퀴가 코드 검사에 걸리면 「바퀴 한도」·「멈춤」·요청 2). 딕셔너리 `copy()`는 한 문장으로 풂.
- **처음 쓴 모양**(한 문장씩 풂): 함수 안 다른 함수가 내놓은 목록에 이어 `append`(`check_draft`가 `check_length` 목록을 받음) · `for turn in range(n)` + `break`로 한도 안에서 도는 반복 · `rounds[-1]`(01 `records[-1]`과 같음) · 딕셔너리 `copy()` · `str(수)`로 문제 글 만들기. `raise`·`try`·`while`·`elif`는 쓰지 않음.
