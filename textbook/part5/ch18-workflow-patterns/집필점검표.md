## 품질 개선 (규격 `textbook/QUALITY-UPGRADE.md`, 2026-09-23~)

위 표는 개선 전(2026-09-10) 기록입니다. 01절은 이제 「재시도 0회」·`AsyncOpenAI`·「필드 누락을 실제 실패로」가 맞지 않습니다(아래 01 행). 02절도 「재시도 0회」가 맞지 않고, 「허용 목록 밖 분류를 실제 실패로」는 이제 실제 `KeyError`와 신뢰도 낮은 분류 두 결함으로 봅니다(아래 02 행). 03절은 이제 `AsyncOpenAI`를 쓰지 않고(동기 `ask_json` + `asyncio.to_thread` + `gather`), 「A/A/B 원표」는 손으로 쓴 후보 글에 대한 새 표입니다(아래 03 행). 04절의 「동적 작업 3개와 5회 호출」도 개선 전 판입니다 — 지금은 계획 모델이 작업 넷을 써 흐름 한 번에 요청 6번, 값 바꿔 보기 흐름은 작업 셋·요청 5번이고, 옛 「고정 목록 사용: False」(손으로 적은 값)는 계산한 비교로 바꿨습니다(아래 04 행). 05절의 「96점에서 품질 임계값 종료」도 개선 전 판입니다 — 지금은 평가 모델 점수와 코드 검사(글자 수·꼭 담을 말)를 함께 보고, 첫 바퀴는 점수가 기준값을 넘어도 코드 검사에 걸려 다음 바퀴로 갑니다(아래 05 행). 06절의 「다섯 패턴의 호출·토큰·지연·품질 표」도 개선 전 판입니다 — 지금은 01~05 흐름 함수를 도구 파일에서 가져와 같은 과제로 실행하고, 품질은 05 코드 검사(글자 수·꼭 담을 말 다섯 항목)로 셉니다(아래 06 행). 품질 개선은 절 단위로 진행하며 절별 기록은 `qa/upgrade/NN-diagnosis.md`, 절 사이 인계는 `qa/upgrade/handoff.md`, 검증 표는 `qa/verification.md`, 준비 조사는 `qa/upgrade/chapter-lead-notes.md`입니다.
